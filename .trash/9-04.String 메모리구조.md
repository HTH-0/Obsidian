# 📝 `String` 클래스의 메모리 구조와 비교 연산

## 📌 내용 요약

- `String` 객체의 **리터럴 방식 vs `new` 연산자 방식** 차이 확인
- `System.identityHashCode()`를 사용하여 메모리 주소 비교
- `==` 연산자와 `.equals()` 비교의 차이

---

## 💻 코드 정리

```java
package Ch09;

public class C04StringClass {
    public static void main(String[] args) {
        String str1 = "java";
        String str2 = "java";
        String str3 = new String("java");
        String str4 = new String("java");

        // 메모리 주소 출력
        System.out.printf("%X\n", System.identityHashCode(str1));  // [[identityHashCode (Java)]]
        System.out.printf("%X\n", System.identityHashCode(str2));
        System.out.printf("%X\n", System.identityHashCode(str3));
        System.out.printf("%X\n", System.identityHashCode(str4));

        System.out.println("-----------------------------");
        
        // == 연산자로 객체 비교
        System.out.println("str1 == str2 ? : " + (str1 == str2));
        System.out.println("str3 == str4 ? : " + (str3 == str4));
        System.out.println("str1 == str3 ? : " + (str1 == str3));
        System.out.println("str2 == str4 ? : " + (str2 == str4));
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **문자열 저장 방식**

```java
String str1 = "java";
String str2 = "java";
```

- **리터럴 방식** → 문자열 풀(String Pool)에 저장
- 동일한 값이면 **재사용** (즉, 같은 메모리 주소를 가짐)

```java
String str3 = new String("java");
String str4 = new String("java");
```

- `new` 연산자 사용 시, **Heap 영역**에 **새로운 객체 생성**
- 따라서 `str3`과 `str4`는 각각 다른 객체

### 2️⃣ **메모리 주소 비교 (`System.identityHashCode()`)**

```java
System.out.printf("%X\n", System.identityHashCode(str1));
System.out.printf("%X\n", System.identityHashCode(str2));
System.out.printf("%X\n", System.identityHashCode(str3));
System.out.printf("%X\n", System.identityHashCode(str4));
```

- `str1`과 `str2`는 같은 메모리 주소 (String Pool에서 재사용)
- `str3`과 `str4`는 서로 다른 메모리 주소 (Heap에 각각 새로 생성)

### 3️⃣ **객체 비교 (`==` 연산자)**

```java
System.out.println("str1 == str2 ? : " + (str1 == str2));  // true
System.out.println("str3 == str4 ? : " + (str3 == str4));  // false
System.out.println("str1 == str3 ? : " + (str1 == str3));  // false
System.out.println("str2 == str4 ? : " + (str2 == str4));  // false
```

- `str1 == str2` → **true** (리터럴 풀에서 같은 객체 공유)
- `str3 == str4` → **false** (`new`로 생성된 서로 다른 객체)
- `str1 == str3`, `str2 == str4` → **false** (리터럴 풀과 Heap의 객체는 다름)

---

## 🔎 추가 정보

- **`.equals()`를 사용해야 문자열 값 비교 가능**

```java
System.out.println("str3.equals(str4) ? : " + str3.equals(str4));  // true
```

- `==` → 객체의 **주소값** 비교
- `.equals()` → 객체의 **내용 값** 비교
