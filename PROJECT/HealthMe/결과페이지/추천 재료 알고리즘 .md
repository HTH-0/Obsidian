## 사용자 맞춤형 음식 추천 시스템 - 알고리즘 설계 및 구현 요약

### 목표

사용자의 설문 데이터를 기반으로 부족한 영양소를 보충할 수 있는 음식을 우선적으로 추천하는 시스템 구현.

### 기본 구조

Content-Based Filtering 기반 추천.  
사용자의 영양소 결핍 정도와 각 음식의 영양소 함량을 내적 계산하여 점수화.  
해당 점수를 기준으로 정렬하여 Top-N 추천.

### 추천 점수 산출 방식

사용자의 각 영양소별 결핍도를 0~1 범위로 정규화 (결핍도 = 1 - 설문 응답값).  
음식의 영양소 함량과 결핍도를 곱해 기여도를 산출.  
모든 영양소에 대해 합산하여 Matching Score 계산.

```
Matching Score = Σ (결핍도_i × 음식 영양소 함량_i)
```

예시:

|영양소|결핍도|음식의 함량|기여도|
|---|---|---|---|
|비타민|0.7|30mg|21.0|
|철분|0.3|10mg|3.0|
|단백질|0.6|2g|1.2|

총 Matching Score = 25.2

### 카테고리 필터링

음식 데이터는 상위 및 하위 카테고리로 분류됨.  
사용자가 선호하거나 시스템이 판단한 유효 카테고리를 기준으로 필터링 수행 후 추천 점수 계산.  
예: 사용자가 '곡류'에 관심이 있거나 철분 결핍도가 높을 경우, 관련 음식군 먼저 필터링.

### 추천 절차 흐름

1. 사용자 설문 결과로부터 영양소 결핍도 벡터 생성
    
2. 음식 리스트를 불러와 각 영양소 함량 벡터와 내적 수행
    
3. Matching Score 계산
    
4. 카테고리 필터링 수행
    
5. 점수 기준 정렬 후 상위 N개 반환
    

### 다양성 확보 전략 (Top-N Diversity)

정렬만 수행할 경우 동일한 유형의 음식이 반복되는 문제 발생.  
이를 방지하기 위해 다음 방식 고려:

- 카테고리별로 그룹화 후 각 그룹에서 Top-K만 추출
    
- 유사한 추천 항목에 패널티를 적용하여 다양성 확보
    

예: 전체 추천 6개 중 곡류, 과일, 축산물, 채소 등 다양한 카테고리가 분산되도록 조정

### 고도화 방향

- DB 내 희귀 영양소에 대한 가중치 강화 (TF-IDF 방식과 유사)
    
- 사용자 클릭/구매 로그 수집 후 협업 필터링 병합
    
- 사용자 목적 기반 추천 모드 (단백질 집중, 식이섬유 중심 등) 제공
    

### 정리

- 추천 알고리즘은 Content-Based Filtering 기반
    
- 사용자 결핍 상태와 음식 영양소 간의 내적 연산으로 추천 점수 계산
    
- 단순 점수 정렬이 아닌 카테고리 필터링 및 다양성 제어 로직 포함
    
- 설문 기반 맞춤형 추천에 적합한 구조이며, 보완 가능성도 확보됨
