설문 점수 → 영양소 분석 결과 제공 구조 설계

---

### 목표

- 질문 → 응답 점수 → 영양소별 점수 집계
    
- 영양소별 점수 → 퍼센트 환산
    
- 점수 범위에 따라 설명(desc) 제공
    

---

### 핵심 아이디어

- 영양소별로 점수 구간별 desc를 DB에 저장
    
- 점수 하드코딩 없이 테이블에서 동적으로 가져옴
    
- 설문 응답값은 프론트에서 `Map<String, Integer>` 형태로 전달받음
    

---

### DB 설계

`nutrient_result_desc` 테이블

|필드|설명|
|---|---|
|id|PK, auto increment|
|nutrient|영양소 이름 (예: 단백질, 지방 등)|
|desc_percent|퍼센트 기준 구간 (예: 0, 20, 40...)|
|desc|설명 텍스트|

---

### 처리 흐름 (Spring 기준)

1. 클라이언트에서 Map<String, Integer> 형식으로 응답 전달  
    → 예: `{"단백질": 45, "지방": 75}`
    
2. 서비스에서 영양소별로 퍼센트 계산  
    → `percent = (score / maxScoreForNutrient) * 100`
    
3. 구간 구해서 desc 조회
    
    ```java
    int range = (percent / 20) * 20;
    descRepository.findByNutrientAndDescPercent(nutrient, range);
    ```
    

---

### Repository 예시

```java
@Query("SELECT d FROM NutrientResultDesc d WHERE d.nutrientName = :nutrient AND d.descPercent = :percent")
Optional<NutrientResultDesc> findByNutrientAndDescPercent(@Param("nutrient") String nutrient, @Param("percent") int percent);
```

---

### 기타

- 퍼센트는 프론트 표시용 → 실제 구간은 20 단위로 끊음
    
- 설명은 DB에서 관리해서 향후 수정이나 다국어 적용 용이
    
- 관리자 페이지로 desc 등록/수정 기능 만들면 확장성 높아짐
