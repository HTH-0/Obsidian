# 🧩 서블릿 기반 회원가입 → 로그인 전체 흐름 정리

## 📂 전체 경로 구조

```
/join.do     → GET: join.jsp 출력
             → POST: 사용자 정보 세션에 저장 → /login.do 리다이렉트

/login.do    → GET: login.jsp 출력 (세션 정보 사용)

/main.do     → GET: main.jsp 출력

/WEB-INF/    ├─ join.jsp
             ├─ login.jsp
             ├─ main.jsp
```

---

## 🔧 1. 회원가입 서블릿: `C04Servlet_Test.java`

### 🔹 GET 요청

```java
req.getRequestDispatcher("/WEB-INF/join.jsp").forward(req, resp);
```

- `join.jsp`로 이동 (보안 경로 `/WEB-INF`)
    
- 사용자가 직접 접근 불가 → 서블릿 통해서만 접근 가능
    

### 🔹 POST 요청

```java
String username = req.getParameter("username");
String password = req.getParameter("password");

HttpSession session = req.getSession();
session.setAttribute("username", username);
session.setAttribute("password", password);

resp.sendRedirect(req.getContextPath() +"/login.do");
```

- 폼으로부터 받은 아이디/비밀번호를 세션에 저장
    
- 로그인 화면으로 리다이렉트
    

---

## 📄 join.jsp

### 주요 내용 요약

- `form` 태그로 사용자 입력 받음
    
- action: `/join.do`, method: POST
    

```jsp
<form action="./join.do" method="post">
  아이디: <input type="text" name="username" />
  비밀번호: <input type="password" name="password" />
  <button type="submit">회원가입</button>
</form>
```

## 🔧 2. 로그인 서블릿: `C05Servlet_Test.java` _(추정 흐름)_

```java
@WebServlet("/login.do")
public class C05Servlet_Test extends HttpServlet {
	@Override
	protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
		req.getRequestDispatcher("/WEB-INF/login.jsp").forward(req, resp);
	}
}
```

- 세션에 저장된 아이디/비밀번호를 확인 가능
    
- 예: 로그인 확인 없이 단순 출력만 할 수도 있음
    

---

## 📄 login.jsp

### 주요 내용 요약

- 세션에 저장된 사용자 정보 출력
    

```jsp
<%
	String id = (String) session.getAttribute("username");
	String pw = (String) session.getAttribute("password");
%>
아이디: <%= id %><br>
비밀번호: <%= pw %><br>
<a href="./main.do">메인으로 이동</a>
```

- 실제 인증 처리는 없음 → 단순 확인 용도

## 🔧 3. 메인 서블릿: `C03Servlet_Test.java`

```java
@WebServlet("/main.do")
public class C03Servlet_Test extends HttpServlet {
	@Override
	protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
		req.getRequestDispatcher("/WEB-INF/main.jsp").forward(req, resp);
	}

```

- 로그인 완료 후 이동할 **메인 화면**


## 🔁 전체 흐름 요약 다이어그램

```
클라이언트
   ↓ GET
[ /join.do ]
   ↓
[ join.jsp 출력 ]
   ↓ POST
입력정보 전송 (username/password)
   ↓
[ C04Servlet_Test ]
   → 세션 저장
   → redirect /login.do
   ↓ GET
[ /login.do ]
   ↓
[ login.jsp 출력 → 세션 정보 표시 ]
   ↓ 클릭
[ /main.do ]
   ↓
[ main.jsp 출력 ]
```

## ✅ 핵심 포인트 정리

|구분|내용|
|---|---|
|서블릿 방식|어노테이션 기반 (`@WebServlet`)|
|데이터 전달|`request.getParameter()` → `session.setAttribute()`|
|이동 방식|내부 이동: `forward()`, 외부 이동: `sendRedirect()`|
|뷰 위치|`/WEB-INF/` 하위에 JSP 파일 위치 (보안상 직접 접근 불가)|
|학습 목적|세션 활용, 파라미터 처리, 서블릿-뷰 연결 흐름 익히기|
