# 서블릿을 통한 페이지 이동 처리 (C03Servlet_Test)

## 📌 클래스 개요

- `HttpServlet`을 상속받아 GET 요청을 처리하는 서블릿
    
- 클라이언트가 `/main.do`로 요청할 경우, 내부적으로 `main.jsp`로 포워딩
    
- **컨트롤러 역할**을 수행하는 기본 서블릿 예제
    

---

## 🧩 URL 매핑

```java
@WebServlet("/main.do")
```

- `/main.do` 경로로 들어오는 요청에 대해 이 서블릿이 작동함
    
- 별도 설정 없이 어노테이션 기반으로 매핑
    

---

## 🔧 doGet() 오버라이딩

```java
@Override
protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
	System.out.println("GET /main.do...");
	req.getRequestDispatcher("/WEB-INF/main.jsp").forward(req, resp);
}
```

|코드|설명|
|---|---|
|`doGet()`|GET 요청이 들어왔을 때 실행되는 메서드|
|`req.getRequestDispatcher(...).forward(...)`|클라이언트에게 직접 응답하지 않고 **내부적으로 JSP로 전달**|

---

## 📂 포워딩 대상 JSP

- 이동 경로: `/WEB-INF/main.jsp`
    
- `WEB-INF`는 클라이언트가 직접 접근할 수 없음
    
- 오직 **서블릿을 통해서만 접근 가능한 보안 디렉토리**
    

---

## ✅ 핵심 정리

- GET 방식 요청을 받아 내부적으로 JSP 페이지로 **포워딩 처리**
    
- 클라이언트에게 URL 노출 없이 내부적으로 JSP로 이동 (`forward`)
    
- 실무에서 컨트롤러 역할을 하는 서블릿의 가장 기본적인 구조
    
- URL 매핑은 `.do`, `.action`, `.go` 등으로 다양하게 확장 가능
