# 🧩 UTF8_EncodingFilter.java 정리

## 📌 클래스 개요

- `Filter` 인터페이스를 구현한 **인코딩 전용 필터**
    
- 모든 요청/응답에 대해 UTF-8 인코딩을 적용함
    
- 한글 깨짐 방지 및 글로벌 문자 처리의 기본 구성 요소
    

---

## 🔧 주요 코드 설명

```java
request.setCharacterEncoding("UTF-8");
```

- 클라이언트가 서버로 전송한 데이터의 인코딩 방식 지정
    
- 폼 전송 시 한글이 깨지지 않도록 설정
    

```java
response.setContentType("text/html; charset=UTF-8");
```

- 서버가 클라이언트로 응답을 보낼 때의 문자셋 지정
    
- JSP나 Servlet에서 출력되는 텍스트가 한글로 제대로 표시됨
    

```java
chain.doFilter(request, response);
```

- 필터 체인을 통해 다음 필터 또는 서블릿으로 요청을 전달
    

---

## ⚙️ 작동 순서

```plaintext
클라이언트 요청
   ↓
[UTF8_EncodingFilter]
   ↳ request.setCharacterEncoding("UTF-8")
   ↓
다음 필터 or 서블릿 실행
   ↓
[UTF8_EncodingFilter]
   ↳ response.setContentType("text/html; charset=UTF-8")
   ↓
클라이언트 응답
```

---

## 🧪 적용 대상 예시

- 회원가입 폼 전송 시: 이름, 주소, 메시지 등에 한글 포함 가능
    
- 로그인 시 ID/비밀번호가 한글일 경우
    

---

## ✅ 핵심 정리

|항목|내용|
|---|---|
|목적|모든 요청/응답에 UTF-8 인코딩 적용|
|필터 위치|보통 **가장 먼저 실행되는 필터**로 설정|
|효과|한글 데이터 깨짐 방지, 다국어 지원 기본 세팅|
|권장 방식|`@WebFilter("/*")` 또는 `web.xml`에 전역 필터 등록|
