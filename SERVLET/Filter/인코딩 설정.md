# 🌐 web.xml + 필터 구성 완전 정리 (06FILTER 프로젝트 기준)

업로드한 `web.xml`을 기반으로, 현재 설정된 **서블릿/필터 구조 전체**를 최대한 자세하게 정리해줄게.  
서블릿 3종 + 필터 1종이 등록되어 있고, 주석 처리된 필터도 존재함.

---

## 📁 프로젝트 이름

```xml
<display-name>06FILTER</display-name>
```

- 해당 웹 프로젝트의 이름 → 톰캣 콘솔이나 관리자 페이지에서 표시
    

---

## 🚪 웰컴 파일 설정

```xml
<welcome-file-list>
  <welcome-file>index.html</welcome-file>
  ...
  <welcome-file>/WEB-INF/index.jsp</welcome-file>
</welcome-file-list>
```

- `/`로 진입 시 가장 먼저 보여줄 파일 목록
    
- `/WEB-INF/index.jsp`는 직접 접근 불가 → `forward()` 필수
    

---

## 🚀 서블릿 설정

|서블릿명|클래스|매핑 주소|
|---|---|---|
|`Home`|`Servlet.Home`|`/index.do`, `/main.do`|
|`Login`|`Servlet.Login`|`/login.do`|
|`Join`|`Servlet.Join`|`/join.do`|

```xml
<servlet>
  <servlet-name>Home</servlet-name>
  <servlet-class>Servlet.Home</servlet-class>
</servlet>
<servlet-mapping>
  <servlet-name>Home</servlet-name>
  <url-pattern>/index.do</url-pattern>
  <url-pattern>/main.do</url-pattern>
</servlet-mapping>
```

- 서블릿 각각은 `.do` 확장자를 기반으로 URL 매핑됨
    
- 모두 `@WebServlet`을 쓰지 않고 XML 기반 설정으로 관리

## 🧼 필터 설정

### ✅ 1. UTF-8 인코딩 필터 (적용 중)

```xml
<filter>
  <filter-name>UTF8_EncodingFilter</filter-name>
  <filter-class>Filter.UTF8_EncodingFilter</filter-class>
</filter>
<filter-mapping>
  <filter-name>UTF8_EncodingFilter</filter-name>
  <url-pattern>*.do</url-pattern>
</filter-mapping>
```

|항목|설명|
|---|---|
|적용 대상|`.do`로 끝나는 모든 요청|
|기능|요청 시 `request.setCharacterEncoding("UTF-8")`, 응답 시 `response.setContentType("text/html; charset=UTF-8")`|

### 🚫 2. Index / Main 필터 (주석 처리됨)

```xml
<!--
<filter>
  <filter-name>Index</filter-name>
  <filter-class>Filter.C01Filter_Test</filter-class>
</filter>
<filter-mapping>
  <filter-name>Index</filter-name>
  <url-pattern>/index.do</url-pattern>
  <url-pattern>*.do</url-pattern>
</filter-mapping>
-->
```

- 현재 `C01Filter_Test`, `C02Filter_Test`는 등록만 되어 있고 비활성화 상태
    
- 추후 세션 체크, 로그 필터 등으로 확장 가능

## 🧠 전체 실행 흐름 예시

```plaintext
사용자 → /join.do
 → [UTF8_EncodingFilter]
 → [Join 서블릿]
 → DB 처리
 → redirect /login.do

사용자 → /login.do
 → [UTF8_EncodingFilter]
 → [Login 서블릿]
 → 세션 저장
 → redirect /main.do

사용자 → /main.do
 → [UTF8_EncodingFilter]
 → [Home 서블릿]
 → main.jsp 출력
```

## ✅ 핵심 정리 요약표

|항목|설정 방식|내용|
|---|---|---|
|서블릿 매핑|`web.xml`|3개 등록 (`Home`, `Login`, `Join`)|
|필터 등록|`web.xml`|UTF-8 필터만 활성화 중|
|필터 범위|`*.do`|모든 `.do` 요청에 인코딩 적용|
|확장 가능|`C01`, `C02` 필터 주석 해제하여 조건부 필터 가능||
|보안설계|JSP는 `/WEB-INF/`에 배치 → 직접 접근 차단||
