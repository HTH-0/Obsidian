# 회원가입 처리 서블릿 (C04Servlet_Test)

## 📌 클래스 개요

- `/join.do` 경로로 들어오는 요청을 처리하는 **회원가입용 서블릿**
    
- GET 요청 → 가입 폼 페이지로 이동
    
- POST 요청 → 사용자 입력값을 **세션에 저장** 후 `/login.do`로 리다이렉트
    

---

## 🧩 URL 매핑

```java
@WebServlet("/join.do")
```

- `/join.do` 경로와 연결된 서블릿
    
- `GET`과 `POST` 요청을 모두 처리
    

---

## 🔁 doGet(): 가입 폼 보여주기

```java
req.getRequestDispatcher("/WEB-INF/join.jsp").forward(req, resp);
```

|목적|설명|
|---|---|
|포워딩 대상|`/WEB-INF/join.jsp` (직접 접근 불가능한 보안 디렉토리)|
|포워딩 방식|내부 forward (URL 변경 없음)|
|상황|처음 회원가입 화면을 보여줄 때 사용|

---

## ✍ doPost(): 회원가입 처리

```java
String username = req.getParameter("username");
String password = req.getParameter("password");
```

- 클라이언트가 입력한 `username`과 `password`를 파라미터로 받음
    

```java
HttpSession session = req.getSession();
session.setAttribute("username", username);
session.setAttribute("password", password);
```

- 로그인 정보(아이디/비밀번호)를 **세션에 저장**
    

```java
resp.sendRedirect(req.getContextPath() + "/login.do");
```

- 가입 완료 후 **로그인 화면으로 리다이렉트**
    
- `resp.sendRedirect()`는 URL 재요청 (forward와 다름)
    

---

## 🔐 로그인 연결 흐름

|단계|동작|
|---|---|
|1. GET `/join.do`|회원가입 폼 표시|
|2. POST `/join.do`|사용자 입력값을 세션에 저장|
|3. Redirect `/login.do`|로그인 화면으로 이동|
|4. login.do 서블릿에서 `join.jsp` 정보 활용 가능||

---

## ✅ 핵심 정리

- `GET`: 가입 페이지 출력
    
- `POST`: 입력값 받아 **세션 저장** → 리다이렉트 처리
    
- `session.setAttribute()`를 사용해 로그인 전 사용자 정보 유지
    
- 후속 서블릿 (`login.do`)에서 세션 정보 꺼내 사용 가능
