# 🧩 MySQL 기반 로그인 시스템 전체 흐름 정리 (Join → Login → Main)

## 📂 전체 구조 흐름

```plaintext
/join.do   → GET: 회원가입 폼
           → POST: 사용자 등록 → 성공 시 /login.do 이동

/login.do  → GET: 로그인 폼
           → POST: 인증 확인 → 성공 시 /main.do 이동

/index.do or /main.do
           → GET: 메인페이지 출력
```

---

## 🔹 1. Home.java

### 📌 역할

- 진입점 컨트롤러 (멀티 매핑)
    
- `/index.do`, `/main.do` 요청을 받아 각각 JSP 페이지로 연결
    

### 🔧 주요 코드

```java
@WebServlet(urlPatterns = {"/index.do","/main.do"})
```

```java
if(uri.contains("/index.do")) {
  req.getRequestDispatcher("/WEB-INF/index.jsp").forward(req, resp);
} else {
  req.getRequestDispatcher("/WEB-INF/main.jsp").forward(req, resp);
}
```

### 💡 특징

- 하나의 서블릿으로 **다수 URL 처리**
    
- URI를 기준으로 JSP 경로를 다르게 설정
    
- **컨트롤러로서의 역할에 충실**

## 🔹 2. Join.java

### 📌 역할

- 회원가입 폼 출력 + 사용자 등록 처리
    
- MySQL DB에 사용자 정보 저장 (`tbl_user`)
    

### 🔧 흐름

#### GET 요청

```java
/join.do → /WEB-INF/user/join.jsp
```

#### POST 요청

1. 폼 데이터 수신
    
2. `MysqlDbUtils.insert()` 호출
    
3. 등록 성공 → `/login.do` 리다이렉트  
    등록 실패 → `/join.jsp`로 다시 포워드
    

```java
int result = dbutils.insert(new UserDto(username,password,"ROLE_USER"));
```

### 💡 특징

- `UserDto`에 사용자 정보 저장
    
- 역할(role)은 기본값 `"ROLE_USER"`로 고정
    
- DB 연결은 `init()`에서 싱글톤 인스턴스 가져옴
    

---

## 🔹 3. Login.java

### 📌 역할

- 로그인 폼 출력 + 인증 처리
    
- DB에서 사용자 정보 조회 → 세션 저장
    

### 🔧 흐름

#### GET 요청

```java
/login.do → /WEB-INF/user/login.jsp
```

#### POST 요청

1. 사용자 정보 받아서 DB에서 조회
    
2. 비밀번호 일치 여부 확인
    
3. 성공 시 세션에 `username`, `role` 저장 → `/main.do` 리다이렉트
    
4. 실패 시 다시 `/login.jsp` 포워딩
    

```java
UserDto dbUser = dbutils.selectOne(username);
if(dbUser != null && dbUser.getPassword().equals(password)) {
    HttpSession session = req.getSession();
    session.setAttribute("username", username);
    session.setAttribute("role", dbUser.getRole());
}
```

## 📑 테이블: `tbl_user`

|필드명|타입|설명|
|---|---|---|
|username|VARCHAR|사용자 ID (PK)|
|password|VARCHAR|비밀번호|
|role|VARCHAR|사용자 권한 (예: ROLE_USER)|

## 🧠 전체 흐름 다이어그램

```plaintext
[ 클라이언트 ]
     ↓
GET /join.do
 → join.jsp 출력

     ↓
POST /join.do
 → DB 저장 성공
 → redirect /login.do

     ↓
GET /login.do
 → login.jsp 출력

     ↓
POST /login.do
 → DB 조회 및 인증 성공
 → 세션 저장
 → redirect /main.do

     ↓
GET /main.do
 → main.jsp 출력
```

## ✅ 핵심 정리

|기능|설명|
|---|---|
|회원가입|DB에 사용자 저장 (`UserDto`)|
|로그인|DB에서 사용자 정보 비교 후 세션 저장|
|메인 이동|세션 확인 없이 JSP 출력 (확장 가능)|
|DB 연결|`MysqlDbUtils.getInstance()` → 싱글톤|
|데이터 보관|사용자 세션 (`username`, `role`)|
