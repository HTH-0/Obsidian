# 🌐 MySQL 기반 로그인 시스템 완성 정리 (서블릿 + JSP + 설정 포함)

---

## 1️⃣ 전체 흐름 요약

```
/join.do   → [join.jsp]  ← 회원가입 입력
           → DB 저장 성공 → redirect → /login.do

/login.do  → [login.jsp] ← 로그인 입력
           → 로그인 성공 → redirect → /main.do
                         → 실패 → 다시 login.jsp

/main.do   → [main.jsp]  ← 로그인 후 메인화면 출력
```

---

## 2️⃣ JSP 파일 역할 정리

### 📄 `/WEB-INF/user/join.jsp`

**회원가입 화면**

```jsp
<form action="./join.do" method="post">
  아이디: <input type="text" name="username" />
  비밀번호: <input type="password" name="password" />
  <button type="submit">회원가입</button>
</form>
```

- 폼 전송 대상: `/join.do` (POST)
    

---

### 📄 `/WEB-INF/user/login.jsp`

**로그인 화면**

```jsp
<form action="./login.do" method="post">
  아이디: <input type="text" name="username" />
  비밀번호: <input type="password" name="password" />
  <button type="submit">로그인</button>
</form>
```

- 폼 전송 대상: `/login.do` (POST)
    

---

### 📄 `/WEB-INF/main.jsp`

**로그인 이후 메인 화면**

```jsp
<h2>메인페이지입니다.</h2>
<p>
  <%
    String username = (String) session.getAttribute("username");
    out.print(username + "님 환영합니다!");
  %>
</p>
```

- 세션에 저장된 사용자 이름 출력
    

---

### 📄 `/WEB-INF/index.jsp`

**첫 진입용 초기 페이지**

```jsp
<h1>시작 페이지입니다</h1>
<a href="./join.do">회원가입</a> |
<a href="./login.do">로그인</a>
```

- 사용자 최초 진입 시 진입점 역할
    

---

## 3️⃣ web.xml 설정

```xml
<web-app ...>
  <display-name>05EX</display-name>
  <welcome-file-list>
    <welcome-file>index.html</welcome-file>
    ...
    <welcome-file>index.jsp</welcome-file>
    <welcome-file>/WEB-INF/index.jsp</welcome-file>
  </welcome-file-list>
</web-app>
```

### 💡 주의사항

- `/WEB-INF/index.jsp`는 클라이언트가 직접 접근할 수 없기 때문에 `welcome-file`로 지정하더라도 실제 진입되진 않음
    
- 첫 화면 진입을 위하여 `/index.do` 요청을 `Home.java`에서 받아서 포워딩 처리하는 구조를 활용
    

---

## 4️⃣ 전체 서블릿 ↔ JSP 구조 요약 표

|URL|서블릿|메서드|연결 JSP|역할|
|---|---|---|---|---|
|`/join.do`|`Join.java`|GET|`/WEB-INF/user/join.jsp`|회원가입 폼|
|`/join.do`|`Join.java`|POST|redirect `/login.do` or join|회원가입 처리|
|`/login.do`|`Login.java`|GET|`/WEB-INF/user/login.jsp`|로그인 폼|
|`/login.do`|`Login.java`|POST|redirect `/main.do` or login|로그인 처리|
|`/index.do`|`Home.java`|GET|`/WEB-INF/index.jsp`|시작페이지|
|`/main.do`|`Home.java`|GET|`/WEB-INF/main.jsp`|로그인 후 메인|

---

## ✅ 학습 포인트 정리

|주제|설명|
|---|---|
|Servlet + JSP 연결|모든 JSP는 `/WEB-INF/`에 위치, 서블릿 통해서만 접근|
|세션|로그인 성공 시 `username`, `role` 저장|
|DB 연동|MySQL 기반, `MysqlDbUtils` 사용|
|리다이렉트 vs 포워드|성공 시 `sendRedirect`, 실패 시 `forward`|
|인증 처리|사용자 정보 비교 후 인증 성공 여부 판단|
