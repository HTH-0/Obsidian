# 🧩 사용자 로그인/권한 처리용 클래스 정리 (MySQL 기반)

## 📦 사용된 파일 목록

- `UserDto.java`: 사용자 정보를 담는 DTO 클래스
    
- `MysqlDbUtils.java`: MySQL용 DB 유틸리티 클래스 (사용자 등록 및 조회)
    
- `OracleDBUtils.java`: 오라클용 DB 유틸 클래스 (현재 기능 없음)
    

---

## 🔹 UserDto.java

### 📌 역할

- 사용자 계정 정보를 담는 단순 데이터 객체
    

### 🧾 필드 구성

|필드명|설명|
|---|---|
|`username`|사용자 ID|
|`password`|비밀번호|
|`role`|사용자 역할 (`admin`, `user` 등)|

### 💡 특징

- 생성자 오버로딩 (기본 + 전체 매개변수)
    
- getter/setter 제공
    
- `toString()` 오버라이딩으로 출력 디버깅 가능
    

---

## 🔹 MysqlDbUtils.java

### 📌 역할

- `tbl_user` 테이블을 대상으로 사용자 정보 **저장 및 조회** 처리
    
- JDBC 기반 MySQL 연결, 싱글톤 패턴 적용
    

---

### 📂 필드 구성

|필드명|설명|
|---|---|
|`url`|MySQL 접속 URL (`testDB`)|
|`id`, `pw`|MySQL 계정 (`root` / `1234`)|
|`conn`, `pstmt`, `rs`|JDBC 객체|

---

### 🔧 주요 메서드

#### 1. `insert(UserDto userDto)`

```java
pstmt = conn.prepareStatement("insert into tbl_user values(?,?,?)");
pstmt.setString(1, userDto.getUsername());
pstmt.setString(2, userDto.getPassword());
pstmt.setString(3, userDto.getRole());
```

- `tbl_user` 테이블에 데이터 삽입
    
- username, password, role 순으로 바인딩
    
- 실행 결과는 삽입된 행 수 (`int result`)
    

---

#### 2. `selectOne(String username)`

```java
pstmt = conn.prepareStatement("select * from tbl_user where username=?");
pstmt.setString(1, username);
...
userDto = new UserDto(rs.getString(1), rs.getString(2), rs.getString(3));
```

- 특정 사용자 ID에 해당하는 정보를 조회
    
- 결과를 `UserDto` 객체로 생성해 반환
    

---

### 💡 특징 요약

- DB 연결은 `com.mysql.cj.jdbc.Driver` 사용
    
- `getInstance()`로 싱글톤 객체 반환
    
- 자원 정리 부분이 약간 미흡 → `finally` 처리 또는 `try-with-resources`가 필요
    

---

## 🔹 OracleDBUtils.java

### 📌 역할

- 오라클 DB 접속 유틸 클래스
    
- 구조는 `MysqlDbUtils`와 동일하나 **현재 쿼리 관련 기능 없음**
    

### 📌 향후 확장 가능성

- 메서드만 추가하면 오라클 DB에서도 동일한 기능 수행 가능
    

---

## ✅ 전체 흐름 요약

|구성요소|설명|
|---|---|
|`UserDto`|사용자 객체 정의 (`username`, `password`, `role`)|
|`MysqlDbUtils.insert()`|사용자 정보 DB 저장|
|`MysqlDbUtils.selectOne()`|특정 사용자 정보 조회|
|`OracleDBUtils`|동일한 구조의 오라클 전용 클래스 (비어 있음)|

---

## 🧠 추가 팁

- **보안 주의**: 실제 서비스에서는 비밀번호를 `평문`으로 저장하지 말고, 반드시 `SHA-256`, `BCrypt` 등의 해시처리 필요
    
- **역할 기반 권한 처리(role)**도 가능 (관리자/일반회원 구분)
