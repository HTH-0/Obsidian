# 📌 `static` 메서드를 활용한 배열 조작 (`concat()`, `print()`)

## 📝 내용 요약

- `static` 메서드를 활용하여 **배열 연결(`concat`)과 출력(`print`)** 구현
- `concat()`: 두 개의 배열을 합쳐 새로운 배열 반환
- `print()`: 배열의 모든 요소를 출력

---

## 💻 코드 정리

```java
package Ch11;

class ArrayUtils {
    // 배열 a와 b를 연결하여 새로운 배열 반환
    public static int[] concat(int[] a, int[] b) {
        int len = a.length + b.length;  // 새로운 배열의 길이
        int[] newArr = new int[len];    // 새로운 배열 생성

        int i = 0;
        for (; i < len; i++) {
            if (i < a.length)
                newArr[i] = a[i];       // 첫 번째 배열 요소 복사
            else
                newArr[i] = b[i - a.length];  // 두 번째 배열 요소 복사
        }
        return newArr;
    }

    // 배열 요소 출력
    public static void print(int[] a) {
        for (int el : a)
            System.out.print(el + " ");
        System.out.println();
    }
}

public class C04Ex {
    public static void main(String[] args) {
        int[] array1 = { 1, 5, 7, 9 };
        int[] array2 = { 3, 6, -1, 100, 77 };
        int[] array3 = ArrayUtils.concat(array1, array2);
        ArrayUtils.print(array3);
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **배열 연결 (`concat()`)**

```java
public static int[] concat(int[] a, int[] b)
```

- 두 개의 배열을 입력받아 **합친 새로운 배열 반환**
- `a.length + b.length` → 새 배열의 크기 계산
- `for` 문을 사용하여 **첫 번째 배열(`a`) 복사 후 두 번째 배열(`b`) 복사**

### 2️⃣ **배열 출력 (`print()`)**

```java
public static void print(int[] a)
```

- `for-each` 문을 사용하여 배열 요소 출력
- 마지막에 `System.out.println();`을 추가하여 줄 바꿈 처리

### 3️⃣ **테스트 코드 (`main()`)**

```java
int[] array1 = { 1, 5, 7, 9 };
int[] array2 = { 3, 6, -1, 100, 77 };
int[] array3 = ArrayUtils.concat(array1, array2);
ArrayUtils.print(array3);
```

- `array1`, `array2`를 `concat()`을 통해 결합하여 `array3` 생성
- `print()`를 사용하여 `array3` 출력

## 🔎 추가 정보

### ✅ `concat()` 메서드 개선 (배열 `System.arraycopy()` 활용)

- `System.arraycopy()`를 사용하면 더 간결하고 성능이 향상됨

```java
public static int[] concat(int[] a, int[] b) {
    int[] newArr = new int[a.length + b.length];
    System.arraycopy(a, 0, newArr, 0, a.length);
    System.arraycopy(b, 0, newArr, a.length, b.length);
    return newArr;
}
```

- 첫 번째 `System.arraycopy()` → `a`의 요소를 `newArr`에 복사
- 두 번째 `System.arraycopy()` → `b`의 요소를 `newArr`의 남은 공간에 복사
