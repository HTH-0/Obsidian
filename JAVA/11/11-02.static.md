# 📌 Java `static` 메서드와 변수 접근 규칙

## 📝 내용 요약

- `static` 메서드와 인스턴스 변수의 관계 학습
- `static` 메서드는 **클래스 변수(static 변수)만 접근 가능**
- 인스턴스 변수는 **객체 생성 후 접근 가능**하며 `static` 메서드에서 직접 접근 불가능

---

## 💻 코드 정리

```java
package Ch11;

class C02Simple {
    static int n1;  // static 변수 (클래스 변수)
    int n2;         // 인스턴스 변수

    // 일반 메서드 (인스턴스 메서드)
    void func1() {
        n1 = 100;  // static 변수 접근 가능
        n2 = 200;  // 인스턴스 변수 접근 가능
    }

    // static 메서드
    static void func2() {
        n1 = 100;  // static 변수 접근 가능
        // n2 = 200;  // 컴파일 오류 발생 (static 메서드에서 인스턴스 변수 접근 불가능)
    }
}

public class C02StaticMain {
    public static void main(String[] args) {
        // 프로그램 실행 부분
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **`static` 변수와 인스턴스 변수 선언**

```java
static int n1;  // 클래스 변수 (모든 객체가 공유)
int n2;         // 인스턴스 변수 (각 객체마다 독립적)
```

- `n1` → `static` 변수: 모든 객체가 공유
- `n2` → 인스턴스 변수: 개별 객체마다 독립적

### 2️⃣ **인스턴스 메서드에서 `static` 변수, 인스턴스 변수 접근 가능**

```java
void func1() {
    n1 = 100;  // static 변수 접근 가능
    n2 = 200;  // 인스턴스 변수 접근 가능
}
```

- 인스턴스 메서드는 **객체 생성 후 호출**되므로, `static` 변수와 인스턴스 변수 모두 접근 가능

### 3️⃣ **`static` 메서드에서 인스턴스 변수 접근 불가능**

```java
static void func2() {
    n1 = 100;  // static 변수 접근 가능
    // n2 = 200;  // 컴파일 오류 발생
}
```

- `static` 메서드는 **클래스 로딩 시 메모리에 올라감**
- `n2` (인스턴스 변수)는 객체가 생성되어야 메모리에 할당되므로, `static` 메서드에서 직접 접근 불가능

---

## 🔎 추가 정보

### ✅ `static` 메서드에서 인스턴스 변수 사용하려면?

- **객체를 생성해서 접근**

```java
static void func2() {
    C02Simple obj = new C02Simple();  // 객체 생성
    obj.n2 = 200;  // 인스턴스 변수 접근 가능
}
```

- `static` 메서드에서는 인스턴스 변수를 직접 사용할 수 없지만, **객체를 생성하면 가능**

### ✅ `static` 키워드의 특징

1. **클래스 로딩 시 메모리에 할당**
2. **객체 없이 클래스명으로 접근 가능**
3. **static 메서드는 static 변수와 지역 변수만 사용 가능**
4. **객체 생성 없이 호출 가능하므로 인스턴스 변수 사용 불가**
