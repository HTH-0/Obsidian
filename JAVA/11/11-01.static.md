# 📌 Java Static 변수와 인스턴스 변수

## 📝 내용 요약

- `static` 변수와 인스턴스 변수의 차이 학습
- `static` 변수는 클래스 단위로 관리되며 모든 객체가 공유
- 인스턴스 변수는 객체마다 개별적으로 할당됨

---

## 💻 코드 정리

```java
package Ch11;

class C01Simple {
    static int num1;  // static 변수 (클래스 변수)
    int num2;         // 인스턴스 변수

    public C01Simple() {
        num1 = 0;
        num2 = 0;
    }

    public C01Simple(int num1, int num2) {
        this.num1 = num1;  // static 변수이므로 모든 객체가 공유
        this.num2 = num2;  // 인스턴스 변수이므로 객체별로 독립적
    }

    @Override
    public String toString() {
        return "C01Simple [num1=" + num1 + ", num2=" + num2 + "]";
    }
}

public class C01StaticMain {
    public static void main(String[] args) {
        C01Simple ob1 = new C01Simple();
        C01Simple ob2 = new C01Simple();

        C01Simple.num1 = 100;  // static 변수는 클래스명으로 접근 가능
        System.out.println(C01Simple.num1);

        System.out.println(ob1);
        System.out.println(ob2);
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **`static` 변수 선언 및 공유**

```java
static int num1;
```

- `static` 키워드가 붙은 변수는 **클래스 변수**
- 모든 객체가 공유하며, **클래스명으로 직접 접근 가능**
- 하나의 객체에서 값을 변경하면, 다른 모든 객체에서도 변경된 값이 적용됨

### 2️⃣ **인스턴스 변수 선언**

```java
int num2;
```

- `static`이 없는 변수는 **인스턴스 변수**
- 각 객체가 독립적으로 값을 가짐

### 3️⃣ **생성자에서 초기화**

```java
public C01Simple() {
    num1 = 0;
    num2 = 0;
}
```

- `num1` (static 변수)은 모든 객체가 공유
- `num2` (인스턴스 변수)는 개별 객체마다 초기화됨

### 4️⃣ **객체 생성 및 `static` 변수 변경**

```java
C01Simple ob1 = new C01Simple();
C01Simple ob2 = new C01Simple();

C01Simple.num1 = 100;
```

- `C01Simple.num1 = 100;` → `static` 변수이므로 모든 객체가 공유하는 값이 변경됨
- `ob1`, `ob2` 두 객체가 존재하지만, `num1`은 공유됨

### 5️⃣ **객체 출력**

```java
System.out.println(ob1);
System.out.println(ob2);
```

- `toString()` 메서드에서 `num1`을 출력할 때 **모든 객체가 같은 값**을 가짐
- `num2`는 객체마다 개별 값 유지

## 🔎 실행 결과

```plaintext
100
C01Simple [num1=100, num2=0]
C01Simple [num1=100, num2=0]
```

- `num1`이 static 변수이므로 두 객체 모두 **100**으로 출력됨
- `num2`는 각 객체마다 별도로 관리됨

---

## 🔎 추가 정보

- `static` 변수는 **클래스 로딩 시 단 한 번만 메모리에 할당됨**
- `static` 변수는 **객체 생성 없이도 사용 가능**
- `static` 변수는 **여러 객체가 값을 공유**하지만, 인스턴스 변수는 개별적으로 관리됨
