# 📝 Java 함수형 인터페이스 실습 - `@FunctionalInterface`

## 📌 내용

- 함수형 인터페이스 선언 및 사용
- `람다식`으로 인터페이스 구현 → 코드 간결화
- 가변 인자, `reduce`, `boxed`, `sorted` 등 활용

---

## 💻 코드 정리

```java
@FunctionalInterface
interface Func1 {
    void say(String message);  // [[say() (Java)]]
}

@FunctionalInterface
interface Func2 {
    int sum(int ...args);  // [[sum() (Java)]]
}

@FunctionalInterface
interface Func3 {
    List<Integer> createdListDesc(int ... args);  // [[createdListDesc() (Java)]]
}

public class C01FuntionalInterfaceMain {
    public static void main(String[] args) {

        Func1 f1 = message -> System.out.println(message);
        f1.say("HELLO WORLD");

        Func1 f2 = System.out::println;
        f2.say("HELLO WORLD2");

        Func2 func2 = (arg) -> {
            int sum = 0;
            for (int el : arg) sum += el;
            return sum;
        };
        System.out.println(func2.sum(10, 20, 30, 40, 556, 6, 7, 8, 9));

        Func2 func2_2 = (arg) -> Arrays.stream(arg)
                                       .reduce(0, (sum, el) -> sum + el);
        System.out.println(func2_2.sum(10, 20, 30, 40, 556, 6, 7, 8, 9));

        Func3 func3 = (items) -> Arrays.stream(items)
                                       .boxed()
                                       .sorted((a, b) -> b - a)
                                       .collect(Collectors.toList());

        List<Integer> li = func3.createdListDesc(10, 100, 24, 1612, 42, 123, 15, 4, 1);
        System.out.println(li);
    }
}
```

---

## 🔎 코드 분석

### ✅ `@FunctionalInterface`

- 컴파일러에게 함수형 인터페이스임을 명시
- **단 하나의 추상 메서드만 가질 수 있음**

---

### 1️⃣ `Func1` - 문자열 출력

```java
Func1 f1 = message -> System.out.println(message);
Func1 f2 = System.out::println;
```

- 람다식을 통해 `say()` 구현
- `System.out::println`으로 메서드 참조 가능

---

### 2️⃣ `Func2` - 가변 인자 합산

```java
Func2 func2 = (arg) -> {
    int sum = 0;
    for (int el : arg) sum += el;
    return sum;
};
```

- 가변 인자를 반복문으로 누적

```java
Func2 func2_2 = (arg) -> Arrays.stream(arg)
                               .reduce(0, (sum, el) -> sum + el);
```

- `reduce()`를 사용해 누적 합 구함

---

### 3️⃣ `Func3` - 정수 배열을 내림차순 정렬 후 리스트로 변환

```java
Func3 func3 = (items) -> Arrays.stream(items)
                               .boxed()                         // int → Integer
                               .sorted((a, b) -> b - a)         // 내림차순 정렬
                               .collect(Collectors.toList());   // List로 수집
```
