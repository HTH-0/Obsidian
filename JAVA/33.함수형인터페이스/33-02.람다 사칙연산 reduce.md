# 📝 Java 람다식 계산기 - `@FunctionalInterface` + `reduce()` 활용

## 📌 내용

- 람다식을 활용한 사칙연산 계산기 구현
- 가변 인자 처리(`int... args`)
- `@FunctionalInterface`로 동작 방식 정의
- `reduce()`, `boxed()`, `sorted()` 등 고급 스트림 메서드 적용

---

## 💻 코드 정리

```java
@FunctionalInterface
interface Functional {
    Integer execute(int ...args);  // [[execute() (Java)]]
}

class Calc {
    Functional sum;
    Functional sub;
    Functional mul;
    Functional div;

    Calc() {
        sum = (arg) -> {
            int hap = 0;
            for (int el : arg) hap += el;
            return hap;
        };

        sub = (arg) -> {
            return Arrays.stream(arg)
                         .boxed()
                         .sorted((a, b) -> b - a)
                         .reduce(0, (sub, el) -> sub < el ? el - sub : sub - el);
        };

        mul = (arg) -> {
            int gop = 1;
            for (int el : arg) gop *= el;
            return gop;
        };

        div = (arg) -> {
            return Arrays.stream(arg)
                         .boxed()
                         .sorted((a, b) -> b - a)
                         .reduce((a, b) -> a / b)
                         .orElse(0);
        };
    }
}

public class C02Ex {
    public static void main(String[] args) {
        Calc calc = new Calc();
        System.out.println("합 : " + calc.sum.execute(10,20,30,40,50,60));
        System.out.println("차 : " + calc.sub.execute(1, 4, 2, 16));  // 큰 수부터 감산
        System.out.println("곱 : " + calc.mul.execute(10,20,30,40,50,60));
        System.out.println("나눗셈 : " + calc.div.execute(1, 4, 2, 16));  // 큰 수부터 나눗셈
    }
}
```

## 🔎 코드 분석

### 1️⃣ `@FunctionalInterface` 선언

```java
interface Functional {
    Integer execute(int ...args);
}
```

- 단일 추상 메서드를 가진 함수형 인터페이스
- 다양한 연산을 람다로 구현할 수 있게 기반 제공

---

### 2️⃣ 덧셈 구현

```java
sum = (arg) -> {
    int hap = 0;
    for (int el : arg) hap += el;
    return hap;
};
```

- 모든 요소를 반복문으로 누적하여 합계 계산

---

### 3️⃣ 뺄셈 구현 (내림차순 정렬 후 누적 감산)

```java
sub = (arg) -> {
    return Arrays.stream(arg)
                 .boxed()
                 .sorted((a, b) -> b - a)
                 .reduce(0, (sub, el) -> sub < el ? el - sub : sub - el);
};
```

- 큰 수부터 작은 수 순서로 정렬한 후
- 첫 번째 값을 기준으로 순차적으로 감산 수행

---

### 4️⃣ 곱셈 구현

```java
mul = (arg) -> {
    int gop = 1;
    for (int el : arg) gop *= el;
    return gop;
};
```

- 반복문으로 곱셈 누적

---

### 5️⃣ 나눗셈 구현 (내림차순 정렬 후 `reduce`)

```java
div = (arg) -> {
    return Arrays.stream(arg)
                 .boxed()
                 .sorted((a, b) -> b - a)
                 .reduce((a, b) -> a / b)
                 .orElse(0);
};
```

- 큰 수부터 작은 수로 정렬 후 나눗셈 수행  
    예: `16 / 4 / 2 / 1`
