# 📝 Java 제공 함수형 인터페이스 실습 - `Function`, `andThen`, 커링(Currying)

## 📌 내용

- Java 기본 제공 함수형 인터페이스 중 `Function<T, R>`에 집중
- `apply()`, `andThen()`, **스트림+람다+instanceof** 활용
- 고차 함수 및 **커링(Currying)** 구조 실습

---

## 💻 코드 정리

```java
public class C03FunctionalInterfaceMain {

    public static Function<Integer, Integer> func1 = x -> x * x;  // 제곱
    public static Function<Integer, Integer> func2 = x -> x + x;  // 두 배
    public static Function<List<Integer>, Integer> func3 = x -> 
        x.stream().reduce(0, Integer::sum);  // 리스트 합계

    public static Function<List<Object>, Integer> func4 = (li) -> 
        li.stream()
          .filter(obj -> obj instanceof Integer)
          .map(obj -> (Integer)obj)
          .reduce(0, Integer::sum);  // Object 리스트 → Integer만 합계

    public static Function<List<Object>, List<Integer>> func5 = (li) -> 
        li.stream()
          .filter(obj -> obj instanceof Integer)
          .map(obj -> (Integer)obj)
          .collect(Collectors.toList());  // Integer만 필터링해서 리스트 변환

    public static Function<Integer, Integer> func6 = func1.andThen(func2);  // 제곱 후 두 배
    public static Function<Integer, Integer> func7 = func2.andThen(func1);  // 두 배 후 제곱

    public static Function<List<Integer>, Integer> subFunc = x -> 
        x.stream().reduce(0, (sum, x1) -> sum + x1);

    public static Function<List<Object>, Integer> func8 = func5.andThen(subFunc);  
    // Integer만 필터링한 후 → 합계 계산

    // 고차 함수 형태 (함수를 리턴하는 함수)
    public static Function<Integer, Function<Integer, Integer>> func9 = x -> x1 -> x1 + x1;
    public static Function<Integer, Function<Integer, Integer>> func10 = x -> y -> x + y;
    public static Function<Integer, Function<Integer, Function<Integer, Integer>>> func11 = 
        x -> y -> z -> x + y + z;
}
```

---

## 🔎 코드 분석

### ✅ `Function<T, R>`

- 입력 `T`, 출력 `R`의 타입을 가지는 함수형 인터페이스
- `apply(T t)` 메서드 제공

---

### 1️⃣ 기본 함수식

```java
func1 = x -> x * x;               // 입력값의 제곱
func2 = x -> x + x;               // 입력값의 두 배
```

---

### 2️⃣ 리스트 합계 (`reduce`)

```java
func3 = x -> x.stream().reduce(0, Integer::sum);
```

---

### 3️⃣ `Object` 리스트에서 `Integer`만 합산

```java
func4 = li -> li.stream()
                .filter(obj -> obj instanceof Integer)
                .map(obj -> (Integer)obj)
                .reduce(0, Integer::sum);
```

---

### 4️⃣ `Object` → `List<Integer>` 추출

```java
func5 = li -> li.stream()
                .filter(obj -> obj instanceof Integer)
                .map(obj -> (Integer)obj)
                .collect(Collectors.toList());
```

---

### 5️⃣ `andThen()` 체이닝

```java
func6 = func1.andThen(func2);  // 제곱 후 두 배
func7 = func2.andThen(func1);  // 두 배 후 제곱
```

---

### 6️⃣ 조합형: `func5` + `subFunc`

```java
func8 = func5.andThen(subFunc);  // Integer 리스트 추출 → 합계 계산
```

---

### 7️⃣ 커링 (Currying)

```java
func9 = x -> x1 -> x1 + x1;              // 내부 함수로 람다 리턴
func10 = x -> y -> x + y;                // x 고정 → y 입력 받아 합
func11 = x -> y -> z -> x + y + z;       // 3중 커링
```

## ✅ 실행 예시 결과 요약

|함수|결과|
|---|---|
|`func1.apply(10)`|100|
|`func2.apply(10)`|20|
|`func3.apply([10,20,30,40])`|100|
|`func4.apply(["ㄱ",10,20,"ㄴㄴ",30,40])`|100|
|`func5.apply(["ㄱ",10,20,"ㄴㄴ",30,40])`|`[10, 20, 30, 40]`|
|`func6.apply(5)`|50 → `(5*5)=25 → 25*2=50`|
|`func7.apply(5)`|100 → `(5+5)=10 → 10*10=100`|
|`func8.apply(["ㄱ",10,20,...])`|170|
|`func9.apply(5).apply(10)`|20|
|`func10.apply(5).apply(10)`|15|
|`func11.apply(5).apply(10).apply(15)`|30|
