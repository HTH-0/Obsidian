# 📌 Java 소켓 프로그래밍 - 클라이언트 수신 스레드 분석

## 💡 주요 개념

- **Runnable 인터페이스 구현**: `run()` 메서드를 오버라이딩하여 스레드 실행
- **`DataInputStream` 사용**: 서버로부터 데이터를 수신
- **무한 루프 + 종료 조건**: `q` 입력 시 종료
- **예외 처리 및 리소스 정리**: `try-catch-finally` 구조 활용

---

## 💻 주요 코드

```java
package Ch24;

import java.io.DataInputStream;

public class ClientRecvThread implements Runnable {

    DataInputStream din;

    // 생성자: 서버로부터 데이터를 받을 입력 스트림을 초기화
    ClientRecvThread(DataInputStream din) {
        this.din = din;
    }

    public void run() {
        String recv;

        try {
            while (true) {
                // 서버로부터 데이터 수신
                recv = din.readUTF();
                
                // 종료 조건 (서버가 "q"를 보내면 종료)
                if (recv.equals("q")) 
                    break;
                
                // 수신한 메시지 출력
                System.out.println("[CLIENT] : " + recv);
            }
        } catch (Exception e) {
            System.out.println("[CLIENT] 연결 오류 발생: " + e.getMessage());
        } finally {
            try {
                din.close(); // 입력 스트림 닫기
            } catch (Exception e) {
                System.out.println("[CLIENT] 리소스 해제 중 오류 발생: " + e.getMessage());
            }
        }
    }
}
```

## 🔎 코드 분석

### 1️⃣ **클래스 선언 및 생성자**

```java
public class ClientRecvThread implements Runnable {
```

- `Runnable` 인터페이스를 구현하여 스레드 기능 추가

```java
ClientRecvThread(DataInputStream din) {
    this.din = din;
}
```

- 생성자에서 `DataInputStream`을 받아 초기화
- `DataInputStream`은 서버에서 오는 데이터를 읽는 역할

---

### 2️⃣ **서버에서 데이터 수신**

```java
recv = din.readUTF();
```

- `readUTF()`를 사용하여 UTF-8 형식의 문자열을 수신
- 서버가 데이터를 전송할 때까지 대기

---

### 3️⃣ **종료 조건 설정**

```java
if (recv.equals("q")) 
    break;
```

- 수신된 메시지가 `"q"`이면 반복문 종료 → 클라이언트 수신 종료

---

### 4️⃣ **예외 처리 및 리소스 해제**

```java
} catch (Exception e) {
    System.out.println("[CLIENT] 연결 오류 발생: " + e.getMessage());
} finally {
    try {
        din.close();
    } catch (Exception e) {
        System.out.println("[CLIENT] 리소스 해제 중 오류 발생: " + e.getMessage());
    }
}
```

- **예외 발생 시 오류 메시지 출력**
- **`finally` 블록에서 `din.close()`로 리소스 해제**  
    (입력 스트림을 닫지 않으면 메모리 누수 가능)

## 🎯 핵심 정리

1. `Runnable` 구현하여 스레드에서 실행 가능하도록 구성
2. `DataInputStream`을 사용해 서버에서 데이터 수신
3. `"q"` 수신 시 종료하는 조건문 추가
4. `try-catch-finally`로 예외 처리 및 리소스 해제

✔ **이제 클라이언트가 서버의 메시지를 수신할 수 있도록 구현 완료!**
