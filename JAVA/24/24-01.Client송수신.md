# 📌 Java 소켓 프로그래밍 - 클라이언트 코드 분석

## 💡 주요 개념

- **소켓 프로그래밍**: 네트워크 통신을 위해 `Socket` 클래스 사용
- **데이터 입출력**: `DataInputStream`, `DataOutputStream`으로 데이터 송수신
- **멀티스레딩**: `Thread`를 사용하여 송신(`ClientSendThread`), 수신(`ClientRecvThread`)을 분리

---

## 💻 주요 코드

```java
package Ch24;

import java.io.DataInputStream;
import java.io.DataOutputStream;
import java.io.IOException;
import java.io.InputStream;
import java.io.OutputStream;
import java.net.Socket;
import java.net.UnknownHostException;

public class Client {
    public static void main(String[] args) throws UnknownHostException, IOException, InterruptedException {
        
        // 서버 소켓 연결 (IP: 192.168.16.70, 포트: 7001)
        Socket client = new Socket("192.168.16.70", 7001);    
        System.out.println("[CLIENT] 연결 시작합니다");

        // 클라이언트의 IP 정보 출력
        System.out.println("CLIENT IP : " + client.getInetAddress());

        // 데이터 송수신을 위한 스트림 생성
        OutputStream out = client.getOutputStream();
        DataOutputStream dout = new DataOutputStream(out);
        InputStream in = client.getInputStream();
        DataInputStream din = new DataInputStream(in);

        // 수신 및 송신 스레드 실행
        ClientRecvThread recv = new ClientRecvThread(din);
        ClientSendThread send = new ClientSendThread(dout);

        Thread th1 = new Thread(send);
        Thread th2 = new Thread(recv);

        th1.start();
        th2.start();

        // 스레드 종료 대기
        th1.join();
        th2.join();

        // 리소스 해제
        in.close();
        out.close();
        client.close();
        System.out.println("[CLIENT] 연결 종료합니다");
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **서버 소켓 연결**

```java
Socket client = new Socket("192.168.16.70", 7001);
```

- 서버의 IP(`192.168.16.70`)와 포트(`7001`)로 연결
- 서버가 실행 중이어야 정상적으로 연결 가능

### 2️⃣ **클라이언트 정보 출력**

```java
System.out.println("CLIENT IP : " + client.getInetAddress());
```

- `getInetAddress()`로 클라이언트의 IP 주소 확인 가능

### 3️⃣ **입출력 스트림 생성**

```java
OutputStream out = client.getOutputStream();
DataOutputStream dout = new DataOutputStream(out);
InputStream in = client.getInputStream();
DataInputStream din = new DataInputStream(in);
```

- **출력 스트림 (`dout`)**: 데이터를 서버로 전송
- **입력 스트림 (`din`)**: 서버에서 데이터를 수신

### 4️⃣ **송신 및 수신 스레드 실행**

```java
ClientRecvThread recv = new ClientRecvThread(din);
ClientSendThread send = new ClientSendThread(dout);

Thread th1 = new Thread(send);
Thread th2 = new Thread(recv);

th1.start();
th2.start();
```

- 송신(`send`)과 수신(`recv`)을 별도 스레드에서 처리하여 동시 실행

### 5️⃣ **스레드 종료 대기**

```java
th1.join();
th2.join();
```

- `join()`을 사용하여 두 스레드가 종료될 때까지 대기

### 6️⃣ **자원 해제 및 종료**

```java
in.close();
out.close();
client.close();
System.out.println("[CLIENT] 연결 종료합니다");
```

- **스트림 및 소켓 닫기**: 사용이 끝난 네트워크 리소스를 정리

---

## 🎯 핵심 정리

1. `Socket` 클래스를 사용해 서버에 연결
2. `DataInputStream`, `DataOutputStream`을 사용해 데이터를 송수신
3. 송신(`ClientSendThread`), 수신(`ClientRecvThread`)을 별도 스레드로 처리
4. `join()`을 사용해 스레드 종료까지 대기
5. 사용이 끝난 스트림과 소켓을 닫아 리소스를 정리
