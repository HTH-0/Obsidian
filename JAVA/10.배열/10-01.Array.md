## 📌 학습 내용 요약

- **배열 생성 및 입력 받기**
- **배열 출력 방법**: `for`문, `for-each`, 람다 스트림
- **최대값/최소값 구하는 방법**
    - **`for`문 사용** (직접 비교)
    - **이중 `for`문을 이용한 정렬 후 선택**
    - **`Arrays.sort()` 활용**
    - **`Stream API` 활용 (`max()`, `min()`)**

---

## 💻 코드 정리

```java
package Ch10;

import java.util.Arrays;
import java.util.Scanner;

public class C01ArrayMain {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int[] arr1 = new int[5];

        System.out.println("배열길이 : " + arr1.length);
        System.out.println("5개의 값을 입력하세요");

        // 배열 입력 받기
        for (int i = 0; i < arr1.length; i++) {
            arr1[i] = sc.nextInt();
        }

        // 1️⃣ for문을 이용한 배열 출력
        for (int i = 0; i < arr1.length; i++) {
            System.out.println(i + "번째 배열 " + arr1[i]);
        }
        System.out.println("----------------");

        // 2️⃣ for-each문을 이용한 배열 출력
        for (int el : arr1) {
            System.out.println(el);
        }
        System.out.println("----------------");

        // 3️⃣ Stream API를 이용한 배열 출력
        Arrays.stream(arr1).forEach(System.out::println);
        System.out.println("----------------");

        // 4️⃣ 최대값과 최소값 찾기 (case 1: 직접 비교)
        int max = arr1[0];
        int min = arr1[0];

        for (int i = 0; i < arr1.length; i++) {
            if (arr1[i] > max) {
                max = arr1[i];
            }
            if (arr1[i] < min) {
                min = arr1[i];
            }
        }

        System.out.println("최대값 : " + max);
        System.out.println("최소값 : " + min);
        System.out.println("----------------");

        // 5️⃣ 최대값과 최소값 찾기 (case 2: 이중 for문을 이용한 정렬 후 선택)
        for (int i = 0; i < arr1.length - 1; i++) {
            for (int j = i + 1; j < arr1.length; j++) {
                if (arr1[i] > arr1[j]) {
                    int temp = arr1[i];
                    arr1[i] = arr1[j];
                    arr1[j] = temp;
                }
            }
        }

        System.out.println("이중 for문 정렬 후");
        System.out.println("최대 : " + arr1[arr1.length - 1]);
        System.out.println("최소 : " + arr1[0]);
        System.out.println("----------------");

        // 6️⃣ 최대값과 최소값 찾기 (case 3: Arrays.sort() 활용)
        Arrays.sort(arr1);  // 오름차순 정렬
        System.out.println("Arrays.sort() 정렬 후");
        System.out.println("최대 : " + arr1[arr1.length - 1]);
        System.out.println("최소 : " + arr1[0]);
        System.out.println("----------------");

        // 7️⃣ 최대값과 최소값 찾기 (case 4: Stream API)
        System.out.println("Stream API 활용");
        System.out.println("최대 : " + Arrays.stream(arr1).max().getAsInt());
        System.out.println("최소 : " + Arrays.stream(arr1).min().getAsInt());

        sc.close();
    }
}
```

## 🔎 코드 분석

### 1️⃣ **배열 입력 받기 (`for`문)**

```java
for (int i = 0; i < arr1.length; i++) {
    arr1[i] = sc.nextInt();
}
```

- 사용자 입력을 받아 배열에 저장

### 2️⃣ **배열 출력 방법**

```java
for (int i = 0; i < arr1.length; i++) {
    System.out.println(i + "번째 배열 " + arr1[i]);
}
```

- 일반 `for`문을 사용하여 인덱스와 함께 출력

```java
for (int el : arr1) {
    System.out.println(el);
}
```

- `for-each` 문을 사용하여 요소만 출력

```java
Arrays.stream(arr1).forEach(System.out::println);
```

- `Stream API`를 사용하여 간결한 출력

### 3️⃣ **최대값/최소값 찾기 (직접 비교)**

```java
int max = arr1[0];
int min = arr1[0];

for (int i = 0; i < arr1.length; i++) {
    if (arr1[i] > max) {
        max = arr1[i];
    }
    if (arr1[i] < min) {
        min = arr1[i];
    }
}
```

- `for`문을 사용하여 배열을 탐색하면서 `max`, `min` 값 갱신

### 4️⃣ **이중 `for`문을 이용한 정렬 후 최대/최소값 선택**

```java
for (int i = 0; i < arr1.length - 1; i++) {
    for (int j = i + 1; j < arr1.length; j++) {
        if (arr1[i] > arr1[j]) {
            int temp = arr1[i];
            arr1[i] = arr1[j];
            arr1[j] = temp;
        }
    }
}
```

- **버블 정렬 방식**으로 **오름차순 정렬**
- **첫 번째 요소가 최소값**, **마지막 요소가 최대값**

### 5️⃣ **`Arrays.sort()` 활용**

```java
Arrays.sort(arr1);
System.out.println("최대 : " + arr1[arr1.length - 1]);
System.out.println("최소 : " + arr1[0]);
```

- `Arrays.sort()`를 사용하여 오름차순 정렬 후, **첫 번째 요소(최소값)**, **마지막 요소(최대값)** 선택

### 6️⃣ **Stream API 활용**

```java
System.out.println("최대 : " + Arrays.stream(arr1).max().getAsInt());
System.out.println("최소 : " + Arrays.stream(arr1).min().getAsInt());
```

- `Arrays.stream(arr1).max().getAsInt()` → 최대값 반환
- `Arrays.stream(arr1).min().getAsInt()` → 최소값 반환

## 🔎 추가 정보

### ✅ **이중 `for`문 vs `Arrays.sort()` 성능 비교**

- **이중 `for`문** → `O(n^2)`: **배열 크기가 클 경우 비효율적**
- **`Arrays.sort()` (Dual-Pivot QuickSort)** → `O(n log n)`: **훨씬 빠름**
- **Stream API** → 내부적으로 `IntSummaryStatistics`를 활용해 최댓값/최솟값을 효율적으로 찾음

> **결론**: **큰 데이터셋에서는 `Arrays.sort()` 또는 `Stream API`를 사용**하는 것이 더 효율적
