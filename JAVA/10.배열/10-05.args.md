# 📌 `main()` 메서드의 매개변수 (`String[] args`) 활용

## 📝 내용 요약

- `main(String[] args)`에서 **명령행 인자(Command Line Arguments)**를 받아 처리하는 방법 학습
- **`args.length`를 사용하여 인자의 개수 확인**
- **`for-each` 문을 사용하여 `args` 배열의 값 출력**

---

## 💻 코드 정리

```java
package Ch10;

public class C05MainParam {
    public static void main(String[] args) {
        System.out.println("length : " + args.length);
        
        for (String param : args) {
            System.out.println(param);
        }
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **`args.length`를 활용한 인자 개수 확인**

```java
System.out.println("length : " + args.length);
```

- `args.length`를 사용하여 **입력된 명령행 인자의 개수 출력**

### 2️⃣ **`for-each` 문을 사용하여 명령행 인자 출력**

```java
for (String param : args) {
    System.out.println(param);
}
```

- `args` 배열의 각 요소(명령행 인자)를 순차적으로 출력

---

## 🔎 실행 예제

### ✅ 실행 방법 (명령 프롬프트 또는 터미널 사용)

```sh
java C05MainParam Hello World 123
```

### ✅ 실행 결과

```plaintext
length : 3
Hello
World
123
```

- `args.length = 3` → `Hello`, `World`, `123` 총 **3개의 인자**가 전달됨
- 각 인자가 개별적으로 출력됨

---

## 🔎 추가 정보

### ✅ `args` 배열 활용 예제 (합산 계산기)

- 명령행에서 숫자를 입력하면 **합산하여 출력**

```java
public class SumArgs {
    public static void main(String[] args) {
        int sum = 0;
        for (String arg : args) {
            sum += Integer.parseInt(arg);
        }
        System.out.println("합계: " + sum);
    }
}
```

#### 실행 예제

```sh
java SumArgs 10 20 30
```

#### 실행 결과

```plaintext
합계: 60
```
