# 📝 Java - 객체 배열 활용

## 📌 내용

- **객체 배열**을 활용하여 여러 객체를 관리
- `toString()`을 **재정의**하여 객체 정보를 출력
- `for-each` 문을 사용한 배열 순회

---

## 💻 코드 정리

```java
package Ch10;

class C04Person {
    String name;
    int age;

    // 디폴트 생성자
    public C04Person() {}

    // 모든 인자 생성자
    public C04Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // toString() 재정의
    @Override
    public String toString() {
        return "C04Person [name=" + name + ", age=" + age + "]";
    }
}

public class C04ClassArrayMain {
    public static void main(String[] args) {
        // 객체 배열 생성
        C04Person list[] = new C04Person[3];

        // 객체 초기화
        list[0] = new C04Person();
        list[0].name = "홍길동";
        list[0].age = 55;

        list[1] = new C04Person();
        list[1].name = "김영희";
        list[1].age = 35;

        list[2] = new C04Person();
        list[2].name = "김범수";
        list[2].age = 40;

        // 배열 요소 출력 (toString() 활용)
        for (C04Person person : list) {
            System.out.println(person);
        }
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **객체 배열 생성**

```java
C04Person list[] = new C04Person[3];
```

- `C04Person` 타입의 배열 `list` 선언
- 크기 `3`인 배열 공간 할당 (하지만 객체는 아직 `null` 상태)

### 2️⃣ **객체 개별 생성 및 초기화**

```java
list[0] = new C04Person();
list[0].name = "홍길동";
list[0].age = 55;
```

- 배열 각 요소에 `new C04Person()`을 할당하여 객체 생성
- `name`, `age` 필드를 직접 할당하여 초기화

### 3️⃣ **객체 정보 출력**

```java
for (C04Person person : list) {
    System.out.println(person);
}
```

- `for-each` 문을 사용하여 배열을 순회
- `System.out.println(person)` 실행 시 `toString()`이 자동 호출됨

### 4️⃣ **toString() 메서드 재정의**

```java
@Override
public String toString() {
    return "C04Person [name=" + name + ", age=" + age + "]";
}
```

- 객체를 출력할 때, 메모리 주소가 아닌 `name`과 `age` 값을 반환하도록 설정

---

## 🔎 추가 정보

- **객체 배열을 초기화하지 않으면 `NullPointerException` 발생 가능**
- `new C04Person("홍길동", 55);` 처럼 **생성자를 활용하면 코드가 간결해짐**
- `Arrays.toString()`을 활용하여 한 줄 출력 가능:
    
    ```java
    System.out.println(Arrays.toString(list));
    ```
