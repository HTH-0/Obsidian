### 📌 **Java `Set` 활용 예제**

- `HashSet`을 사용하여 중복 없는 데이터 저장, 삭제, 조회 기능 구현

---

### 💻 **코드 정리**

```java
package Ch17;

import java.util.HashSet;
import java.util.Iterator;
import java.util.Set;

public class C03SetMain {
    public static void main(String[] args) {

        Set<String> set = new HashSet<>();

        // 데이터 추가 (중복 불가)
        set.add("HTML/CSS/JS");
        set.add("JQUERY");
        set.add("NODEJS");
        set.add("SCSS");
        set.add("REACT");
        set.add("JAVA");
        set.add("JSP/SERVLET");
        set.add("STS");
        set.add("SPRING BOOT"); // 중복된 값 추가 (덮어쓰기 효과)

        // 개수 확인
        System.out.println("개수 확인 : " + set.size()); 

        // 데이터 삭제
        set.remove("NODEJS");

        // Set 요소 조회 (인덱스 접근 불가능)
        System.out.println("Set 요소 출력:");
        for (String el : set) {
            System.out.println(el);
        }

        // 전체 삭제
        set.clear();
    }
}
```

---

### 🔎 **코드 분석**

#### 1️⃣ **`Set` 생성 및 데이터 추가**

```java
Set<String> set = new HashSet<>();
```

- `Set`은 중복을 허용하지 않는 자료구조
- `HashSet`을 사용하여 내부적으로 **해시 테이블**을 이용한 빠른 검색 제공

```java
set.add("SPRING BOOT"); 
set.add("SPRING BOOT"); // 기존 값 덮어쓰기 (중복 허용 X)
```

- 같은 값이 여러 번 추가되더라도 한 번만 저장됨

#### 2️⃣ **저장된 개수 확인**

```java
System.out.println("개수 확인 : " + set.size());
```

- `size()`를 사용하여 저장된 요소 개수 확인

#### 3️⃣ **데이터 삭제 (`remove()`)**

```java
set.remove("NODEJS");
```

- 특정 값을 제거

#### 4️⃣ **Set 요소 출력**

```java
for (String el : set) {
    System.out.println(el);
}
```

- `Set`은 **인덱스를 지원하지 않음**
- `for-each` 문을 사용하여 모든 요소 출력

#### 5️⃣ **전체 삭제 (`clear()`)**

```java
set.clear();
```

- `clear()`를 사용하여 모든 요소 제거

---

### 📌 **추가 정보**

- `Set`의 종류
    
    - `HashSet` : 순서 보장 X, 빠른 검색
    - `LinkedHashSet` : 입력 순서 유지
    - `TreeSet` : 정렬된 상태 유지 (오름차순)
- `Set`은 **중복 제거**가 필요한 경우 유용
    
- 리스트에서 중복 요소를 제거할 때 `Set` 활용 가능
