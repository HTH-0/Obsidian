# 📌 `HashMap` 활용 예제 - Key-Value 저장

## 📌 내용

- `HashMap`을 활용하여 데이터를 Key-Value 형태로 저장
- `put()`을 이용한 데이터 추가
- `remove()`를 이용한 데이터 삭제
- `get()`, `keySet()`을 이용한 데이터 조회

---

## 💻 코드 정리

```java
package Ch17;

import java.util.HashMap;
import java.util.Map;

public class C06MapMain {
    public static void main(String[] args) {
        
        Map<String, Integer> map = new HashMap<>();  // [[HashMap (Java)]]

        // 데이터 추가
        map.put("aaa", 11);
        map.put("bbb", 22);
        map.put("ccc", 33);
        map.put("ddd", 44);
        map.put("ddd", 34); // 중복 Key → 기존 값 덮어쓰기
        map.put("eee", 55);

        // 데이터 삭제
        map.remove("aaa");  // [[remove() (Java)]]
        
        // 데이터 조회
        System.out.println("Size : " + map.size());  // [[size() (Java)]]
        System.out.println("단건 : " + map.get("bbb"));  // [[get() (Java)]]
        System.out.println("복수건 : " + map);
        
        // 모든 요소 조회 (for-each)
        for(String key : map.keySet()) {  // [[keySet() (Java)]]
            System.out.println(key + " : " + map.get(key));
        }
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **`HashMap` 객체 생성**

```java
Map<String, Integer> map = new HashMap<>();
```

- `Map` 인터페이스를 구현한 `HashMap` 객체 생성
- `String`을 Key, `Integer`를 Value로 저장

### 2️⃣ **데이터 추가 (`put()`)**

```java
map.put("aaa", 11);
map.put("bbb", 22);
map.put("ccc", 33);
map.put("ddd", 44);
map.put("ddd", 34); // 중복 Key
```

- `put(key, value)`를 사용하여 데이터 삽입
- `"ddd"` Key가 중복되므로 기존 값 `44`가 `34`로 덮어쓰기됨

### 3️⃣ **데이터 삭제 (`remove()`)**

```java
map.remove("aaa");
```

- `"aaa"` Key에 해당하는 데이터를 삭제

### 4️⃣ **데이터 조회 (`get()`, `size()`)**

```java
System.out.println("Size : " + map.size());  
System.out.println("단건 : " + map.get("bbb"));
System.out.println("복수건 : " + map);
```

- `size()` → 현재 `Map`에 저장된 요소 개수 반환
- `get("bbb")` → Key `"bbb"`에 해당하는 값 `22` 반환

### 5️⃣ **전체 요소 조회 (`keySet()`, `get()`)**

```java
for(String key : map.keySet()) {
    System.out.println(key + " : " + map.get(key));
}
```

- `keySet()`을 이용해 모든 Key를 가져온 후, 각 Key의 Value를 출력

---

## 🔎 추가 정보

- `HashMap`은 **Key 중복을 허용하지 않음**, 동일한 Key가 입력되면 **기존 값이 덮어쓰기됨**
- `remove()`는 삭제할 Key가 존재하지 않으면 아무 동작도 하지 않음
- `keySet()`은 `Set<String>`을 반환하므로, **데이터 순서는 보장되지 않음**
- **Key 순서를 유지하려면 `LinkedHashMap`을 사용**
- **자동 정렬이 필요하면 `TreeMap`을 사용**
