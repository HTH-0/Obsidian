### 📌 **Java의 `List` 사용 예제**

- `ArrayList`를 활용한 데이터 추가, 조회, 삭제, 전체 삭제 기능 구현

---

### 💻 **코드 정리**

```java
package Ch17;

import java.util.ArrayList;
import java.util.List;

public class C01ListMain {
    public static void main(String[] args) {
        
        List<String> list = new ArrayList<>();
        
        // 데이터 추가
        list.add("HTML/CSS/JS");
        list.add("JQUERY");
        list.add("NODEJS");
        list.add("SCSS");
        list.add("REACT");
        list.add("JAVA");
        list.add("JSP/SERVLET");
        list.add("STS");
        list.add("SPRING BOOT");
        list.add("SPRING BOOT");  // 중복 추가 가능

        // 조회
        System.out.println("개수 확인 : " + list.size());   // 리스트 크기 출력
        System.out.println("idx로 조회 : " + list.get(2));  // 인덱스 2번 요소 가져오기
        System.out.println("Value로 idx 확인 : " + list.indexOf("JAVA")); // "JAVA"의 인덱스 찾기
        
        // 리스트 전체 출력
        list.forEach(System.out::println);
        
        // 삭제
        list.remove(0);      // 인덱스 0번 요소 삭제
        list.remove("JQUERY");  // "JQUERY" 값 삭제

        // 삭제 후 리스트 출력
        for(String el : list) {
            System.out.println(el);
        }
        
        // 전체 삭제
        list.clear();
    }
}
```

---

### 🔎 **코드 분석**

#### 1️⃣ **리스트 생성**

```java
List<String> list = new ArrayList<>();
```

- `List` 인터페이스를 구현한 `ArrayList` 객체 생성
- `<>` 안에 `String`을 명시하여 문자열만 저장할 수 있도록 설정

#### 2️⃣ **데이터 추가 (`add()`)**

```java
list.add("HTML/CSS/JS");
list.add("JQUERY");
list.add("SPRING BOOT");
```

- `add()` 메서드를 사용하여 리스트에 요소 추가
- 중복 데이터도 추가 가능 (ex: `"SPRING BOOT"` 2번 추가)

#### 3️⃣ **데이터 조회**

```java
System.out.println("개수 확인 : " + list.size());
System.out.println("idx로 조회 : " + list.get(2));
System.out.println("Value로 idx 확인 : " + list.indexOf("JAVA"));
```

- `size()` : 리스트에 저장된 요소 개수 반환
- `get(인덱스)` : 해당 인덱스에 있는 요소 반환
- `indexOf(값)` : 특정 값의 인덱스 반환 (없으면 `-1` 반환)

#### 4️⃣ **리스트 출력 (`forEach()`)**

```java
list.forEach(System.out::println);
```

- 람다식 활용하여 리스트 요소를 한 줄씩 출력

#### 5️⃣ **요소 삭제 (`remove()`)**

```java
list.remove(0); // 인덱스로 삭제
list.remove("JQUERY"); // 값으로 삭제
```

- `remove(인덱스)` : 해당 인덱스의 요소 삭제
- `remove(값)` : 해당 값을 가진 요소 삭제 (첫 번째로 발견된 값만 삭제됨)

#### 6️⃣ **전체 삭제 (`clear()`)**

```java
list.clear();
```

- 리스트의 모든 요소 제거

---

### 📌 **추가 정보**

- `ArrayList`는 내부적으로 **배열**을 사용 → 요소 추가/삭제 시 **새로운 배열 생성 필요**
- 중간에 요소 삭제 시, 뒤에 있는 요소들이 **왼쪽으로 이동** → 성능 저하 가능
- 데이터 추가/삭제가 빈번한 경우 `LinkedList` 사용 고려
