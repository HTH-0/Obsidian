### 📌 **Java `List` 활용 예제**

- 리스트에서 특정 조건을 만족하는 데이터 필터링 및 숫자 처리 기능 구현

---

### 💻 **코드 정리**

```java
package Ch17;

import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class C02Ex {
    Scanner sc = new Scanner(System.in);

    // 짝수만 필터링하여 저장하는 메서드
    public static List<Integer> func1(List<String> list) {
        List<Integer> evenList = new ArrayList<>();
        for (String el : list) {
            try {
                int num = Integer.parseInt(el); // 문자열을 숫자로 변환
                if (num % 2 == 0) { // 짝수인지 확인
                    evenList.add(num); // 짝수만 리스트에 추가
                }
            } catch (NumberFormatException e) {
                // 숫자가 아닌 경우 예외 처리
            }
        }
        return evenList;
    }

    // 문자열 길이가 5보다 큰 요소만 필터링하는 메서드
    public static List<String> func2(List<String> list) {
        List<String> lengthFilterList = new ArrayList<>();
        for (String el : list) {
            if (el.length() > 5) {
                lengthFilterList.add(el);
            }
        }
        return lengthFilterList;
    }

    // 숫자만 추출하여 합산하는 메서드
    public static int func3(List<String> list) {
        int numCheck = 0;
        for (String el : list) {
            try {
                numCheck += Integer.parseInt(el);
            } catch (NumberFormatException e) {
                // 숫자가 아닌 경우 예외 처리
            }
        }
        return numCheck;
    }

    public static void main(String[] args) {
        List<String> li = new ArrayList<>();

        // 리스트에 테스트 데이터 추가
        li.add("10");
        li.add("hello");
        li.add("123");
        li.add("world");
        li.add("Java");
        li.add("6");
        li.add("SpringBoot");

        // 짝수 필터링
        List<Integer> evenNumbers = func1(li);
        System.out.println("짝수 리스트: " + evenNumbers);

        // 문자열 길이 5 이상 필터링
        List<String> lengthFilterList = func2(li);
        System.out.println("길이 5 초과 문자열: " + lengthFilterList);

        // 숫자 합계 계산
        int sum = func3(li);
        System.out.println("숫자의 합: " + sum);
    }
}
```

### 🔎 **코드 분석**

#### 1️⃣ **짝수 값만 필터링 (`func1()`)**

```java
public static List<Integer> func1(List<String> list) {
    List<Integer> evenList = new ArrayList<>();
    for (String el : list) {
        try {
            int num = Integer.parseInt(el); // 문자열을 숫자로 변환
            if (num % 2 == 0) { // 짝수인지 확인
                evenList.add(num); // 짝수만 리스트에 추가
            }
        } catch (NumberFormatException e) {
            // 숫자가 아닌 경우 예외 처리
        }
    }
    return evenList;
}
```

- `parseInt()`를 이용해 숫자로 변환
- 변환된 값이 짝수면 리스트에 추가
- 숫자가 아닌 경우 예외 처리 (`NumberFormatException`)

#### 2️⃣ **문자열 길이가 5보다 큰 요소만 필터링 (`func2()`)**

```java
public static List<String> func2(List<String> list) {
    List<String> lengthFilterList = new ArrayList<>();
    for (String el : list) {
        if (el.length() > 5) {
            lengthFilterList.add(el);
        }
    }
    return lengthFilterList;
}
```

- 문자열 길이를 체크 (`length()`)
- 길이가 5보다 크면 리스트에 추가

#### 3️⃣ **숫자만 추출해 합 구하기 (`func3()`)**

```java
public static int func3(List<String> list) {
    int numCheck = 0;
    for (String el : list) {
        try {
            numCheck += Integer.parseInt(el);
        } catch (NumberFormatException e) {
            // 숫자가 아닌 경우 예외 처리
        }
    }
    return numCheck;
}
```

- `parseInt()`를 이용해 숫자로 변환 후 합산
- 숫자가 아닌 경우 예외 처리

#### 4️⃣ **`main()`에서 테스트**

```java
public static void main(String[] args) {
    List<String> li = new ArrayList<>();

    // 리스트에 테스트 데이터 추가
    li.add("10");
    li.add("hello");
    li.add("123");
    li.add("world");
    li.add("Java");
    li.add("6");
    li.add("SpringBoot");

    // 짝수 필터링
    List<Integer> evenNumbers = func1(li);
    System.out.println("짝수 리스트: " + evenNumbers);

    // 문자열 길이 5 초과 필터링
    List<String> lengthFilterList = func2(li);
    System.out.println("길이 5 초과 문자열: " + lengthFilterList);

    // 숫자 합계 계산

```

- 문자열 리스트 생성 및 데이터 추가
- 각 기능 실행 후 결과 출력

### 📌 **추가 정보**

- `parseInt()`는 숫자가 아닌 문자열을 변환할 경우 예외 발생 (`NumberFormatException`)
- 짝수 필터링과 숫자 합산을 처리하는 로직이 비슷하므로 `func1()`과 `func3()`를 통합할 수도 있음
- `stream API`를 활용하면 더 간결한 코드 작성 가능 (`filter()`, `mapToInt()` 등)
