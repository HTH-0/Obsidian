# 📌 `Properties` 클래스 활용하여 설정 파일 읽기

## 📌 주요 개념

- `Properties` 클래스를 사용하여 **외부 설정 파일**(`application.properties`)을 읽음
- `System.getProperty()`를 이용하여 시스템 속성 정보 가져오기
- `FileInputStream`을 통해 파일을 **스트림으로 읽고** `Properties.load()`로 로드
- `properties.getProperty("key")`를 사용하여 설정값을 가져옴

---

## 💻 코드 정리

```java
package Ch17;

import java.io.File;
import java.io.FileInputStream;
import java.io.IOException;
import java.util.Properties;

public class C08PropertiesMain {
    public static void main(String[] args) throws IOException {
        
        // 시스템 속성 가져오기
        String classPath = System.getProperty("java.class.path");
        System.out.println("classPath : " + classPath);
        
        String dirPath = System.getProperty("user.dir");
        System.out.println("dirPath : " + dirPath);
        
        String packagePath = C08PropertiesMain.class.getPackageName();
        System.out.println("packagePath : " + packagePath);
        
        // application.properties 파일 경로 설정
        String filePath = dirPath + File.separator + "src" + File.separator + packagePath + File.separator + "application.properties";
        FileInputStream fin = new FileInputStream(filePath);
        
        // Properties 객체 생성 및 로드
        Properties properties = new Properties();
        properties.load(fin);
        
        // 설정값 가져오기
        String url = properties.getProperty("url");
        String username = properties.getProperty("username");
        String password = properties.getProperty("password");
        
        System.out.printf("%s %s %s\n", url, username, password);
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **시스템 속성 가져오기 (`System.getProperty()`)**

```java
String classPath = System.getProperty("java.class.path");
String dirPath = System.getProperty("user.dir");
String packagePath = C08PropertiesMain.class.getPackageName();
```

- `java.class.path`: 클래스 경로 확인
- `user.dir`: 현재 실행 중인 디렉토리 확인
- `getPackageName()`: 패키지 이름 가져오기

### 2️⃣ **설정 파일 경로 생성**

```java
String filePath = dirPath + File.separator + "src" + File.separator + packagePath + File.separator + "application.properties";
```

- `File.separator` → OS에 따라 적절한 경로 구분자 사용 (`/` 또는 `\`)
- `application.properties` 경로를 동적으로 생성

### 3️⃣ **설정 파일 로드 (`Properties.load()`)**

```java
FileInputStream fin = new FileInputStream(filePath);
Properties properties = new Properties();
properties.load(fin);
```

- `FileInputStream`을 이용하여 파일을 **바이트 스트림**으로 읽음
- `Properties.load()`를 이용해 키-값 쌍으로 로드

### 4️⃣ **설정값 가져오기 (`getProperty()`)**

```java
String url = properties.getProperty("url");
String username = properties.getProperty("username");
String password = properties.getProperty("password");
System.out.printf("%s %s %s\n", url, username, password);
```

- `getProperty("key")`를 사용하여 설정값을 문자열로 가져옴

## 🔎 추가 정보

### ✅ `application.properties` 예시

```properties
url=jdbc:mysql://localhost:3306/mydb
username=root
password=1234
```

- `key=value` 형식으로 설정값 저장
- `Properties.getProperty("key")`로 값 불러오기

### ✅ `Properties` 클래스 특징

|메서드|설명|
|---|---|
|`load(InputStream inStream)`|프로퍼티 파일을 로드|
|`getProperty(String key)`|특정 키의 값 가져오기|
|`setProperty(String key, String value)`|키-값 설정|
|`store(OutputStream out, String comments)`|파일로 저장|
