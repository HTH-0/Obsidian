### 📌 Java 랜덤 로또 번호 생성 및 정렬

## ✅ 개요

1. `Random` 클래스를 이용해 1~45 사이의 숫자 6개를 랜덤으로 추출하고 `Set<Integer>`에 저장
2. 저장된 `Set`을 오름차순으로 정렬하는 두 가지 방법을 사용:
    - **Stream API 사용**
    - **Collections.sort() 사용**

---

## 💻 코드 정리

```java
package Ch17;

import java.util.*;

public class C04Ex {
    public static void main(String[] args) {
        // 로또 번호 저장을 위한 HashSet 생성
        Set<Integer> Lotto = new HashSet<>();
        Random random = new Random();

        // 1~45 사이의 랜덤 숫자 6개 생성하여 Set에 저장
        while (Lotto.size() < 6) {
            int RandomLottoNum = random.nextInt(45) + 1;
            Lotto.add(RandomLottoNum);
        }

        // 생성된 로또 번호 출력
        System.out.println("랜덤 로또 번호: " + Lotto);

        // 1️⃣ Stream API를 이용한 정렬
        List<Integer> LottoAsc = Lotto.stream().sorted().toList();
        System.out.println("Stream을 이용한 오름차순 정렬: " + LottoAsc);

        // 2️⃣ Collections.sort()를 이용한 정렬
        List<Integer> Lottolist = new ArrayList<>(Lotto);
        Collections.sort(Lottolist);
        System.out.println("Collections.sort()를 이용한 오름차순 정렬: " + Lottolist);
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **랜덤 로또 번호 생성**

```java
Set<Integer> Lotto = new HashSet<>();
Random random = new Random();

while (Lotto.size() < 6) {
    int RandomLottoNum = random.nextInt(45) + 1;
    Lotto.add(RandomLottoNum);
}
```

- `HashSet<Integer>`를 사용하여 중복을 자동으로 제거
- `random.nextInt(45) + 1` → 1~45 범위의 랜덤 정수 생성
- `Set`은 순서를 보장하지 않음

---

### 2️⃣ **Stream API를 이용한 오름차순 정렬**

```java
List<Integer> LottoAsc = Lotto.stream().sorted().toList();
System.out.println("Stream을 이용한 오름차순 정렬: " + LottoAsc);
```

- `Lotto.stream()`을 사용해 `Set`을 스트림으로 변환
- `sorted()`를 호출해 오름차순 정렬
- `toList()`를 사용하여 정렬된 리스트 생성

---

### 3️⃣ **Collections.sort()를 이용한 오름차순 정렬**

```java
List<Integer> Lottolist = new ArrayList<>(Lotto);
Collections.sort(Lottolist);
System.out.println("Collections.sort()를 이용한 오름차순 정렬: " + Lottolist);
```

- `ArrayList`로 변환 후 `Collections.sort()` 사용
- `Collections.sort()`는 내부적으로 **퀵 정렬**(Dual-Pivot QuickSort)을 사용하여 정렬 성능이 우수

---

## 📌 핵심 정리

|방법|설명|
|---|---|
|`Stream API`|`sorted()` 사용하여 정렬, `toList()`로 리스트 변환|
|`Collections.sort()`|리스트로 변환 후 정렬|

- `Set`은 순서를 보장하지 않으므로 정렬이 필요할 경우 `List`로 변환하여 처리
- `Stream`을 사용하면 가독성이 좋고, `Collections.sort()`는 직관적인 방법
