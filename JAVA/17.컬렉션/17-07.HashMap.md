# 📌 `HashMap`을 활용한 데이터 저장 및 조회

## 📌 내용

- `HashMap`을 활용하여 데이터를 동적으로 저장하고 관리
- `Map<String, Object>`을 사용하여 다양한 타입의 데이터를 저장
- `setMap()`을 이용한 데이터 추가
- `getMap()`을 이용한 데이터 조회

---

## 💻 코드 정리

```java
package Ch17;

import java.util.ArrayList;
import java.util.Arrays;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class C07Ex {

    static Map<String, Object> map = new HashMap<>();  // [[HashMap (Java)]]

    // 01. 함수의 파라미터로 Map을 전달받아 데이터 추가
    public static void setMap(Map<String, Object> params) {
        map.putAll(params);  // 기존 map에 params 추가
        System.out.println(map);
    }

    // 02. 저장된 데이터를 리턴하는 함수
    public static Map<String, Object> getMap() {
        return map;
    }

    public static void main(String[] args) {

        // 01. 파라미터 생성
        Map<String, Object> params = new HashMap<>();

        // 02. 데이터 추가 (자격증 목록)
        String[] value = { "정보처리기사", "빅데이터분석기사", "네트워크관리사", "..." };
        params.put("자격증", Arrays.asList(value));  // 배열을 List로 변환하여 저장
        setMap(params);
        params.clear();  // 기존 데이터 제거

        // 02. 데이터 추가 (취미 목록)
        List<String> hobby = new ArrayList<>();
        hobby.add("등산");
        hobby.add("독서");
        hobby.add("게임");

        params.put("취미", hobby);  // List 형태로 저장
        setMap(params);

        // 03. 저장된 데이터 조회 및 출력
        System.out.println(getMap());
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **전역 `HashMap` 선언**

```java
static Map<String, Object> map = new HashMap<>();
```

- `static` 필드로 전역 `HashMap` 생성
- `Object` 타입을 Value로 지정하여 **다양한 타입의 데이터를 저장 가능**

### 2️⃣ **`setMap()` - `Map`을 파라미터로 받아 데이터 저장**

```java
public static void setMap(Map<String, Object> params) {
    map.putAll(params);  
    System.out.println(map);
}
```

- `putAll()`을 사용하여 기존 `map`에 새로운 데이터를 추가
- `System.out.println(map);`을 통해 저장된 데이터 출력

### 3️⃣ **`getMap()` - 저장된 데이터를 반환**

```java
public static Map<String, Object> getMap() {
    return map;
}
```

- 현재 `map`에 저장된 모든 데이터를 반환

### 4️⃣ **자격증 목록 추가 (`String[] → List`)**

```java
String[] value = { "정보처리기사", "빅데이터분석기사", "네트워크관리사", "..." };
params.put("자격증", Arrays.asList(value));  
setMap(params);
params.clear();
```

- `String[]` 배열을 `Arrays.asList(value)`를 사용하여 `List`로 변환 후 저장
- `params.clear();`를 사용하여 기존 데이터 제거 후 재사용

### 5️⃣ **취미 목록 추가 (`List<String>`)**

```java
List<String> hobby = new ArrayList<>();
hobby.add("등산");
hobby.add("독서");
hobby.add("게임");

params.put("취미", hobby);
setMap(params);
```

- `ArrayList`를 활용하여 취미 데이터를 추가 후 `setMap()`으로 저장

### 6️⃣ **최종 저장된 데이터 조회 (`getMap()`)**

```java
System.out.println(getMap());
```

- `getMap()`을 호출하여 현재 저장된 모든 데이터를 출력

---

## 🔎 추가 정보

- `HashMap<String, Object>`을 사용하면 다양한 타입을 저장 가능
- `putAll()`을 사용하면 여러 데이터를 한 번에 추가할 수 있음
- `clear()`는 `params` 자체를 초기화하지만, 기존 `map`에 영향을 주지는 않음
- **저장 순서를 유지하려면 `LinkedHashMap`을 사용**
- **자동 정렬이 필요하면 `TreeMap`을 사용**
