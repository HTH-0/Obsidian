# 📌 `HashSet` 활용 예제 - 사용자 정의 객체 (`Person`) 저장

## 📌 내용

- `HashSet`을 활용하여 중복 없는 데이터 저장
- `equals()`와 `hashCode()`를 재정의하여 `Set`의 중복 판별 방식 변경
- `toString()`을 재정의하여 객체 출력 방식 변경

---

## 💻 코드 정리

```java
package Ch17;

import java.util.HashSet;
import java.util.Objects;
import java.util.Set;

class Person {
    String name;
    int age;

    // 생성자
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // toString() 재정의
    @Override
    public String toString() {
        return "Person의 이름 : " + name + " 나이 : " + age;
    }

    // equals() 재정의 (객체 비교)
    @Override
    public boolean equals(Object obj) {
        if (obj instanceof Person) {
            Person down = (Person) obj;
            return this.name.equals(down.name) && this.age == down.age;
        }
        return false;
    }

    // hashCode() 재정의 (중복 방지)
    @Override
    public int hashCode() {
        return Objects.hash(this.age, this.name);
    }
}

public class C05SetMain {
    public static void main(String[] args) {
        
        Set<Person> set = new HashSet<>();  // [[HashSet (Java)]]

        Person ob1 = new Person("홍길동", 55);
        Person ob2 = new Person("남길동", 35);
        Person ob3 = new Person("홍길동", 55);  // ob1과 동일 데이터

        // equals() 비교
        System.out.println(ob1.equals(ob2)); // false
        System.out.println(ob1.equals(ob3)); // true

        // Set에 추가
        set.add(ob1);
        set.add(ob2);
        set.add(ob3);  // 중복이면 저장되지 않음

        System.out.println("SIZE : " + set.size());  // 중복 제거 후 크기 확인
    }
}
```

## 🔎 코드 분석

### 1️⃣ **사용자 정의 클래스 (`Person`) 생성**

```java
class Person {
    String name;
    int age;
}
```

- `name`, `age` 필드 보유
- `HashSet`에 저장될 사용자 정의 객체

### 2️⃣ **`toString()` 재정의**

```java
@Override
public String toString() {
    return "Person의 이름 : " + name + " 나이 : " + age;
}
```

- 객체 정보를 문자열로 변환하여 출력할 때 사용됨

### 3️⃣ **`equals()` 재정의 (객체 비교 기준 변경)**

```java
@Override
public boolean equals(Object obj) {
    if (obj instanceof Person) {
        Person down = (Person) obj;
        return this.name.equals(down.name) && this.age == down.age;
    }
    return false;
}
```

- `name`과 `age`가 동일한 경우 같은 객체로 간주
- `HashSet` 내부에서 중복 판별 시 사용

### 4️⃣ **`hashCode()` 재정의 (중복 방지)**

```java
@Override
public int hashCode() {
    return Objects.hash(this.age, this.name);
}
```

- 동일한 `name`과 `age`를 가진 객체가 동일한 `hashCode`를 가짐
- `HashSet`은 `hashCode()`를 기반으로 중복을 판별하므로, 반드시 `equals()`와 함께 재정의 필요

### 5️⃣ **객체 추가 및 중복 확인**

```java
Set<Person> set = new HashSet<>();
Person ob1 = new Person("홍길동", 55);
Person ob2 = new Person("남길동", 35);
Person ob3 = new Person("홍길동", 55);

set.add(ob1);
set.add(ob2);
set.add(ob3);
```

- `ob1`과 `ob3`는 동일한 데이터를 가지므로 `Set`에서 중복으로 처리됨

### 6️⃣ **출력 결과 확인**

```java
System.out.println("SIZE : " + set.size());
```

- 중복 객체 제거 후 `Set`의 크기를 확인

## 🔎 추가 정보

- `HashSet`은 내부적으로 `HashMap`을 사용하여 데이터를 저장
- **`equals()`와 `hashCode()`를 재정의하지 않으면 객체 비교 시 `Object`의 기본 메서드를 사용하여 중복 검사가 되지 않음**
- `TreeSet`을 사용하면 **자동 정렬** 기능 추가 가능 (`Comparable` 인터페이스 구현 필요)
