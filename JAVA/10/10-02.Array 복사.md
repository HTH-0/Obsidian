## 📌 학습 내용 요약

- **배열 복사의 개념**
    - **얕은 복사 (Shallow Copy)**: 주소값을 공유 (참조 복사)
    - **깊은 복사 (Deep Copy)**: 새로운 배열을 만들어 값만 복사
- **배열 복사 방법**
    - **기본 `for`문을 이용한 복사**
    - **`Arrays.copyOf()`를 활용한 복사**

---

## 💻 코드 정리

```java
package Ch10;

import java.util.Arrays;

public class C02ArrayMain {
    public static void main(String[] args) {
        
        // 1️⃣ 얕은 복사 (Shallow Copy)
        int arr1[] = {10, 20, 30};
        int arr2[];
        arr2 = arr1; // 주소값 복사
        arr1[0] = 100; // arr1의 값을 변경하면 arr2에도 반영됨

        System.out.println("arr1 배열:");
        Arrays.stream(arr1).forEach(System.out::println);
        System.out.println("---------------");
        System.out.println("arr2 배열:");
        Arrays.stream(arr2).forEach(System.out::println);
        System.out.println("---------------");

        // 2️⃣ 깊은 복사 (Deep Copy)
        int arr3[] = new int[3];
        for (int i = 0; i < arr1.length; i++) {
            arr3[i] = arr1[i]; // 개별 요소를 복사 (새로운 배열 할당)
        }

        // 3️⃣ Arrays API를 활용한 깊은 복사
        int arr4[] = Arrays.copyOf(arr1, arr1.length);

        // 4️⃣ 배열의 해시코드 비교 (참조 값 확인)
        System.out.println("arr1의 주소값: " + arr1);
        System.out.println("arr2의 주소값 (얕은 복사): " + arr2);
        System.out.println("arr3의 주소값 (깊은 복사): " + arr3);
        System.out.println("arr4의 주소값 (깊은 복사 - Arrays.copyOf): " + arr4);
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **얕은 복사 (Shallow Copy)**

```java
int arr1[] = {10, 20, 30};
int arr2[];
arr2 = arr1;
```

- `arr2 = arr1;` → **배열의 주소값을 복사**
- **`arr1`과 `arr2`는 같은 배열을 가리킴**
- `arr1[0] = 100;`을 하면 `arr2[0]`도 100으로 변경됨

#### ✅ **출력 결과**

```
arr1 배열:
100
20
30
---------------
arr2 배열:
100
20
30
```

- `arr2`도 `arr1`과 동일한 값이 출력됨 (같은 배열을 공유)

---

### 2️⃣ **깊은 복사 (Deep Copy - `for`문 이용)**

```java
int arr3[] = new int[3];
for (int i = 0; i < arr1.length; i++) {
    arr3[i] = arr1[i];
}
```

- **새로운 배열을 생성**하고 값을 하나씩 복사
- **기존 배열과 독립적으로 동작** (서로 영향을 주지 않음)

---

### 3️⃣ **깊은 복사 (Deep Copy - `Arrays.copyOf()`)**

```java
int arr4[] = Arrays.copyOf(arr1, arr1.length);
```

- **새로운 배열을 생성하면서 복사**
- `Arrays.copyOf()`는 내부적으로 `System.arraycopy()`를 사용하여 성능이 좋음

---

### 4️⃣ **배열의 주소값 확인**

```java
System.out.println(arr1);
System.out.println(arr2);
System.out.println(arr3);
System.out.println(arr4);
```

- **`arr1`과 `arr2`의 주소값이 동일** (얕은 복사)
- **`arr3`과 `arr4`는 새로운 주소값을 가짐** (깊은 복사)

#### ✅ **출력 결과 예시**

```
[I@6d06d69c
[I@6d06d69c  // arr1과 arr2는 같은 주소 (얕은 복사)
[I@7852e922  // arr3은 다른 주소 (깊은 복사)
[I@4e25154f  // arr4도 다른 주소 (깊은 복사 - Arrays.copyOf)
```

- `[I@` → 배열의 주소값을 나타냄
- **얕은 복사된 `arr2`는 `arr1`과 같은 주소를 공유**
- **깊은 복사된 `arr3`, `arr4`는 서로 다른 주소를 가짐**

## 🔎 추가 정보

### ✅ **배열 복사 방법 비교**

|방법|설명|특징|
|---|---|---|
|`=` 연산자|주소값만 복사|**얕은 복사**, 원본과 같은 배열을 공유|
|`for`문 사용|개별 요소 복사|**깊은 복사**, 새로운 배열 생성|
|`Arrays.copyOf()`|내부적으로 `System.arraycopy()` 사용|**빠르고 효율적인 깊은 복사**|
|`System.arraycopy()`|**고속 복사** (네이티브 메서드)|특정 범위 복사가 가능|
