## 📌 학습 내용 요약

- **가변 길이 2차원 배열**
- **행과 열의 길이 확인**

---

## 💻 코드 정리

```java
package Ch10;

public class C03ArrayMain {
    public static void main(String[] args) {
        // 2차원 배열 (가변 길이)
        int arr[][] = {
                {10, 20, 30},         // 3열
                {40, 50, 60, 65, 67}, // 5열
                {70, 80, 90, 96, 11, 56}, // 6열
                {100, 110, 120, 15, 22, 33, 44} // 7열
        };

        // 배열의 행 길이 확인
        System.out.println("전체 행 개수: " + arr.length);
        for (int i = 0; i < arr.length; i++) {
            System.out.println((i + 1) + "행의 길이: " + arr[i].length);
        }
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **가변 길이 2차원 배열 생성**

```java
int arr[][] = {
    {10, 20, 30},         // 3열
    {40, 50, 60, 65, 67}, // 5열
    {70, 80, 90, 96, 11, 56}, // 6열
    {100, 110, 120, 15, 22, 33, 44} // 7열
};
```

- **행마다 열의 개수가 다름** → **가변 배열 (Jagged Array)**

---

### 2️⃣ **배열 길이 출력**

```java
System.out.println("전체 행 개수: " + arr.length);
for (int i = 0; i < arr.length; i++) {
    System.out.println((i + 1) + "행의 길이: " + arr[i].length);
}
```

- **`arr.length`** → 행의 개수 출력
- **`arr[i].length`** → 각 행의 열 개수 출력

#### ✅ **출력 결과**

```
전체 행 개수: 4
1행의 길이: 3
2행의 길이: 5
3행의 길이: 6
4행의 길이: 7
```

- **행마다 길이가 다름** → **정사각형 배열이 아닌 가변 배열**

---

## 🔎 추가 정보

### ✅ **가변 배열 vs 정사각형 배열**

|배열 타입|특징|예제|
|---|---|---|
|정사각형 배열|모든 행의 열 개수가 같음|`int[][] arr = new int[3][4];`|
|가변 배열|행마다 열 개수가 다름|`int[][] arr = new int[3][];`|

```java
// 가변 배열 예제
int[][] jaggedArr = new int[3][];
jaggedArr[0] = new int[2]; // 첫 번째 행 (2열)
jaggedArr[1] = new int[4]; // 두 번째 행 (4열)
jaggedArr[2] = new int[3]; // 세 번째 행 (3열)
```
