# 📌 2차원 배열을 활용한 학생 성적 계산

## 📝 내용 요약

- **학생별 국어, 영어, 수학 점수 입력** (5명의 학생, 3개 과목)
- **각 학생의 총점 및 평균 계산**
- **각 과목(국어, 영어, 수학)의 총점 및 평균 계산**
- **2차원 배열을 활용하여 점수를 저장하고, 반복문을 사용하여 계산 수행**

---

## 💻 코드 정리

```java
package Ch10;

import java.util.Scanner;

public class C06Ex {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int score[][] = new int[5][3]; // 5명의 학생, 3과목(국어, 영어, 수학)
        
        // 학생별 점수 입력
        for (int i = 0; i < score.length; i++) {
            System.out.printf("%d 번째 학생 국영수 입력 : ", i + 1);
            for (int j = 0; j < score[i].length; j++) {
                score[i][j] = sc.nextInt(); // 국어, 영어, 수학 점수 입력
            }
        }
        
        // 학생별 총점 및 평균 계산
        for (int i = 0; i < score.length; i++) {
            int sum = 0;
            for (int j = 0; j < score[i].length; j++) {
                sum += score[i][j];
            }
            double avg = (double) sum / score[i].length;
            System.out.printf("%d 번째 학생 총점 : %d 평균 : %.2f\n", i + 1, sum, avg);
        }

        // 과목별 총점 및 평균 계산
        int subject_sum[] = new int[3];
        for (int i = 0; i < score[0].length; i++) { // 국어, 영어, 수학
            for (int j = 0; j < score.length; j++) {
                subject_sum[i] += score[j][i];
            }
        }

        System.out.printf("국어 총점 : %d 국어 평균 : %.2f\n", subject_sum[0], (double) subject_sum[0] / score.length);
        System.out.printf("영어 총점 : %d 영어 평균 : %.2f\n", subject_sum[1], (double) subject_sum[1] / score.length);
        System.out.printf("수학 총점 : %d 수학 평균 : %.2f\n", subject_sum[2], (double) subject_sum[2] / score.length);
        
        sc.close();
    }
}
```

## 🔎 코드 분석

### 1️⃣ **학생별 점수 입력 (`2차원 배열 활용`)**

```java
for (int i = 0; i < score.length; i++) {
    System.out.printf("%d 번째 학생 국영수 입력 : ", i + 1);
    for (int j = 0; j < score[i].length; j++) {
        score[i][j] = sc.nextInt();
    }
}
```

- `score[i][j]`를 통해 **각 학생(i)의 과목(j) 점수 입력**
- `score[i][0]`: 국어, `score[i][1]`: 영어, `score[i][2]`: 수학

### 2️⃣ **학생별 총점 및 평균 계산**

```java
for (int i = 0; i < score.length; i++) {
    int sum = 0;
    for (int j = 0; j < score[i].length; j++) {
        sum += score[i][j];
    }
    double avg = (double) sum / score[i].length;
    System.out.printf("%d 번째 학생 총점 : %d 평균 : %.2f\n", i + 1, sum, avg);
}
```

- 학생별로 총점(`sum`)을 구한 후, 평균(`avg`) 계산
- `%.2f`를 사용하여 소수점 2자리까지 출력

### 3️⃣ **과목별 총점 및 평균 계산**

```java
int subject_sum[] = new int[3];
for (int i = 0; i < score[0].length; i++) { // 과목 반복
    for (int j = 0; j < score.length; j++) { // 학생 반복
        subject_sum[i] += score[j][i];
    }
}
```

- `subject_sum[0]`: 국어 총점, `subject_sum[1]`: 영어 총점, `subject_sum[2]`: 수학 총점

### 4️⃣ **과목별 총점 및 평균 출력**

```java
System.out.printf("국어 총점 : %d 국어 평균 : %.2f\n", subject_sum[0], (double) subject_sum[0] / score.length);
System.out.printf("영어 총점 : %d 영어 평균 : %.2f\n", subject_sum[1], (double) subject_sum[1] / score.length);
System.out.printf("수학 총점 : %d 수학 평균 : %.2f\n", subject_sum[2], (double) subject_sum[2] / score.length);
```

- `subject_sum[i] / score.length`를 이용해 과목별 평균 계산

## 🔎 추가 정보

### ✅ **2차원 배열에서 행과 열의 개념**

|학생 번호|국어|영어|수학|
|---|---|---|---|
|학생 1|80|90|85|
|학생 2|70|85|80|
|학생 3|90|75|95|
|학생 4|60|80|70|
|학생 5|85|95|90|

- `score[i][j]`
    - `i`: **학생 번호** (0~4)
    - `j`: **과목 번호** (0: 국어, 1: 영어, 2: 수학)

### ✅ **1차원 배열 vs 2차원 배열 차이**

- **1차원 배열**: 같은 유형의 데이터를 나열할 때 사용
    
    ```java
    int[] scores = {80, 90, 85}; // 한 학생의 성적
    ```
    
- **2차원 배열**: 여러 개의 데이터 그룹을 다룰 때 사용
    
    ```java
    int[][] scores = {
        {80, 90, 85},  // 학생 1
        {70, 85, 80},  // 학생 2
        {90, 75, 95}   // 학생 3
    };
    ```
