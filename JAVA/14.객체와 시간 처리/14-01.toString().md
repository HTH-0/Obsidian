# 📝 Java 객체의 `toString()` 메서드 사용법

## 📌 핵심 개념 정리

- **`toString()` 메서드**는 객체를 문자열로 표현할 때 사용됨
- 기본적으로 클래스명과 해시코드를 반환하며, 재정의(오버라이드)하여 객체 정보를 보기 쉽게 표현 가능

---

## 💻 코드 정리

```java
class A {
    int x;
    int y;
    
    @Override
    public String toString() {
        return "A [x=" + x + ", y=" + y + "]";
    }
}

public class C01ObjectMain {
    public static void main(String[] args) {
        A ob1 = new A();
        System.out.println(ob1);              // 자동으로 ob1.toString() 호출
        System.out.println(ob1.toString());   // 명시적으로 toString() 호출
        
        Object ob2 = new Object();
        System.out.println(ob2);              // 기본 Object 클래스의 toString()
        System.out.println(ob2.toString());   // 기본 Object 클래스의 toString()
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ 클래스 A 정의 및 `toString()` 오버라이딩

```java
@Override
public String toString() {
    return "A [x=" + x + ", y=" + y + "]";
}
```

- 객체 정보(x, y)를 명확히 출력하도록 재정의(오버라이딩)

### 2️⃣ `main()` 메서드에서 객체 생성 및 출력

```java
A ob1 = new A();
System.out.println(ob1);            // 자동으로 toString() 호출됨
System.out.println(ob1.toString()); // 명시적 호출
```

- 객체를 `println()`으로 출력 시 내부적으로 `toString()` 호출

### 3️⃣ 기본 Object 클래스의 `toString()`

```java
Object ob2 = new Object();
System.out.println(ob2);
```

- 기본 Object 클래스는 클래스명과 객체 해시코드를 문자열로 반환 (`java.lang.Object@15db9742` 형태)

---

## 🔎 추가 정보

- `toString()` 오버라이딩 목적: 객체 상태(속성 값)를 보기 쉽게 출력
- IDE 자동 완성 기능을 사용해 편리하게 오버라이딩 가능 (Eclipse, IntelliJ 등)
