# 📝 Java 날짜 형식화 (SimpleDateFormat 사용법)

## 📌 핵심 개념 정리

- **`SimpleDateFormat`**: 날짜와 시간을 원하는 형식으로 출력하거나 문자열에서 파싱할 때 사용
- 주로 문자열 ↔ 날짜 변환 시 이용 (`parse`, `format` 메서드 활용)

---

## 💻 코드 정리

```java
import java.text.SimpleDateFormat;
import java.util.Date;
import java.util.Scanner;

public class C06SimpleDateFormatMain {
    public static void main(String[] args) throws Exception {
        Scanner sc = new Scanner(System.in);
        String ymd = sc.next();

        // 입력받은 문자열을 Date 객체로 변환
        SimpleDateFormat fmtIn = new SimpleDateFormat("yyyy/MM/dd");
        Date date = fmtIn.parse(ymd);

        System.out.println("기본 Date 출력: " + date);

        // Date 객체를 원하는 형식으로 출력
        SimpleDateFormat fmtOut = new SimpleDateFormat("yyyy년 MM월 dd일");
        System.out.println("형식화된 출력: " + fmtIn.format(date));
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ 문자열 → Date 변환 (`parse`)

```java
SimpleDateFormat fmtIn = new SimpleDateFormat("yyyy/MM/dd");
Date date = fmtIn.parse(ymd);
```

- 입력된 문자열(`ymd`)을 지정된 형식(`"yyyy/MM/dd"`)에 맞춰 `Date` 객체로 변환

### 2️⃣ Date 객체 → 문자열 형식화 (`format`)

```java
System.out.println("기본 Date 출력: " + date);
```

- 출력 시 기본 형식(Date 클래스의 기본 형식)을 사용
- 기본 출력 형식: `Wed Mar 05 00:00:00 KST 2025` 형태로 나타남

### 📍 사용자 정의 출력 형식 예시

```java
SimpleDateFormat fmtOut = new SimpleDateFormat("yyyy년 MM월 dd일");
System.out.println(fmtOut.format(date));  // "2025년 03월 10일"
```

|dd|일(01~31)||

|mm|분(0~59)||
