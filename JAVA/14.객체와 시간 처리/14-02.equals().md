# 📝 Java에서 `equals()` 메서드 오버라이딩

## 📌 핵심 개념 정리

- **`equals()` 메서드**는 객체의 논리적 동등성(logical equality)을 판단하는 데 사용
- 기본적으로는 두 객체의 **참조 주소를 비교**하며, 값(속성)을 기준으로 비교하려면 **재정의(오버라이딩)** 필수

---

## 💻 코드 정리

```java
class C02Simple {
    int n;
    
    C02Simple(int n){
        this.n = n;
    }

    @Override
    public boolean equals(Object obj) {
        if (obj instanceof C02Simple) {
            C02Simple down = (C02Simple) obj;
            return this.n == down.n;
        }
        return false;
    }
}

public class C02ObjectMain {
    public static void main(String[] args) {
        C02Simple ob1 = new C02Simple(10);
        C02Simple ob2 = new C02Simple(10);
        C02Simple ob3 = new C02Simple(20);
        
        System.out.println(ob1.equals(ob2));  // true
        System.out.println(ob1.equals(ob3));  // false
        
        String str1 = new String("JAVA");
        String str2 = new String("JAVA");
        System.out.println(str1.equals(str2));  // true
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **클래스 정의 및 생성자**

```java
C02Simple(int n){
    this.n = n;
}
```

- 생성자를 통해 객체 생성 시 정수 값(n)을 받아 필드 초기화

### 2️⃣ **`equals()` 메서드 오버라이딩**

```java
@Override
public boolean equals(Object obj) {
    if (obj instanceof C02Simple) {
        C02Simple down = (C02Simple) obj;
        return this.n == down.n;
    }
    return false;
}
```

- `instanceof`로 객체 타입 확인 후 형변환하여 내부 값을 비교
- 객체가 같음을 판단하는 기준을 필드 `n`의 값으로 설정

### 3️⃣ **객체 동등성 테스트**

```java
C02Simple ob1 = new C02Simple(10);
C02Simple ob2 = new C02Simple(10);
C02Simple ob3 = new C02Simple(20);

System.out.println(ob1.equals(ob2));  // true (값 동일)
System.out.println(ob1.equals(ob3));  // false (값 다름)
```

- 값이 같으면 `true`, 다르면 `false` 반환

### 4️⃣ **문자열 비교 (`String` 클래스의 equals)**

```java
String str1 = new String("JAVA");
String str2 = new String("JAVA");
System.out.println(str1.equals(str2));  // true
```

- `String` 클래스는 기본적으로 내용을 기준으로 `equals()`를 재정의함

---

## 🔎 추가 정보

- `equals()`와 `==` 연산자 차이
    
    - `==`: 두 객체의 참조값(메모리 주소)을 비교
    - `equals()`: 객체가 가진 값(내용)의 동등성을 판단할 때 사용
- 객체를 비교할 때는 `equals()`를 오버라이딩하여 논리적 비교가 필수적
