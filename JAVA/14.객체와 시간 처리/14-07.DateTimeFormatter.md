# 📝 Java 날짜와 시간 형식화 (`LocalDateTime`, `DateTimeFormatter` 활용)

## 📌 핵심 개념 정리

- **`LocalDateTime`** 클래스는 날짜와 시간을 동시에 관리하는 **불변 객체**
- **`DateTimeFormatter`** 클래스는 날짜·시간을 문자열로 변환하거나, 문자열을 날짜·시간 객체로 변환하는 데 사용

---

## 💻 코드 정리

```java
import java.time.LocalDate;
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.util.Scanner;

public class C05DateTimeFormatterMain {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // 날짜 입력 및 포맷 변환 (LocalDate 사용)
        System.out.print("YYYY/MM/DD 입력 : ");
        String ymd = sc.next();
        DateTimeFormatter inputFormatter = DateTimeFormatter.ofPattern("yyyy/MM/dd");
        LocalDate date = LocalDate.parse(ymd, inputFormatter);
        System.out.println("입력된 날짜: " + date);

        DateTimeFormatter outputFormatter = DateTimeFormatter.ofPattern("yyyy~MM~dd");
        System.out.println("변환된 날짜: " + date.format(outputFormatter));

        // 날짜 및 시간 입력
        sc.nextLine(); // 버퍼 클리어
        System.out.print("YYYY/MM/DD HH:MM:SS 입력 : ");
        String ymdhms = sc.nextLine();
        DateTimeFormatter dateTimeInFmt = DateTimeFormatter.ofPattern("yyyy/MM/dd HH:mm:ss");
        LocalDateTime dateTime = LocalDateTime.parse(ymdhms, dateTimeInFmt);
        System.out.println("입력된 날짜시간: " + dateTime);

        DateTimeFormatter dateTimeOutFmt = DateTimeFormatter.ofPattern("yyyy~MM~dd HH-mm-ss");
        System.out.println("변환된 날짜시간: " + dateTime.format(dateTimeOutFmt));

        sc.close();
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ 날짜 문자열 → LocalDate 변환 (`parse`)

```java
LocalDate date = LocalDate.parse(ymd, inputFormatter);
```

- 입력된 문자열을 지정한 패턴으로 파싱하여 `LocalDate` 객체 생성

### 2️⃣ LocalDate 객체를 다른 형식으로 출력 (`format`)

```java
System.out.println(date.format(outputFormatter));
```

- 날짜 정보를 원하는 형식으로 변환하여 출력

### 3️⃣ 날짜 및 시간 문자열 → LocalDateTime 변환

```java
LocalDateTime dateTime = LocalDateTime.parse(ymdhms, dateTimeInFmt);
```

- 날짜와 시간이 포함된 문자열을 파싱하여 `LocalDateTime` 객체 생성

### 3️⃣ 날짜·시간 객체 출력 형식 변환

```java
System.out.println(dateTime.format(outputFormatter));
```

- `format` 메서드를 통해 지정된 형식으로 출력

---

## 🔎 추가 정보

- 입력 형식과 출력 형식이 다를 때 자주 사용
- 포맷 변환 시 `DateTimeFormatter` 패턴 문자를 숙지 필요
    - 예: `"yyyy-MM-dd HH:mm:ss"`, `"yyyy년 MM월 dd일"` 등
