# 📝 Java Wrapper 클래스 (Boxing과 Unboxing)

## 📌 핵심 개념 정리

- **Wrapper 클래스**: 기본 자료형(int, char 등)을 객체로 다루기 위한 클래스
- **Boxing**: 기본형 → Wrapper 클래스 객체
- **Unboxing**: Wrapper 클래스 객체 → 기본형
- **Auto Boxing/Unboxing**: 자동 변환 (JDK 1.5 이상)

---

## 💻 코드 정리

```java
public class C04WrapperMain {

    public static void main(String[] args) {
        // Boxing (기본 자료형 → Wrapper 객체)
        Integer ob1 = new Integer(100);          // int → Integer
        Integer ob2 = new Integer("100");        // String → Integer
        Integer ob3 = Integer.valueOf("300");    // valueOf 메서드 이용
        
        System.out.println(ob1 + ob2 + ob3);     // Wrapper 객체끼리 연산 (자동 Unboxing)

        // Unboxing (Wrapper 객체 → 기본 자료형)
        int n1 = ob1.intValue();
        int n2 = ob2.intValue();
        int n3 = ob3.intValue();
        
        System.out.println(n1 + n2 + n3);

        // Auto Boxing
        Integer ob4 = 100;                       // 자동 Boxing (int → Integer)

        // Auto Unboxing
        int n4 = ob1 + ob2 + ob3;                // 자동 Unboxing 후 연산 수행
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **Boxing (기본형 → 객체형)**

```java
Integer ob1 = new Integer(100);
Integer ob2 = new Integer("100");
Integer ob3 = Integer.valueOf("300");
```

- Wrapper 클래스의 객체를 생성하여 기본 자료형의 값을 저장
- 문자열 형태도 Integer 객체로 변환 가능

### 2️⃣ **Unboxing (객체형 → 기본형)**

```java
int n1 = ob1.intValue();
int n2 = ob2.intValue();
int n3 = ob3.intValue();
```

- Wrapper 객체 내부 값을 기본 자료형으로 반환

### 3️⃣ **Auto Boxing과 Auto Unboxing**

```java
Integer ob4 = 100;             // Auto Boxing (int → Integer)
int n4 = ob1 + ob2 + ob3;      // Auto Unboxing (Integer → int)
```

- 기본 자료형과 객체 간 변환이 자동으로 이루어짐 (JDK 1.5 이상)
- 연산 시 Wrapper 객체는 자동으로 Unboxing되어 계산 수행

---

## 🔎 추가 정보

- Wrapper 클래스는 Collection(List, Set 등) 사용 시 필요
- 자바 9 이후부터 `new Integer()` 생성자는 deprecated → `Integer.valueOf()` 권장

예시:

```java
Integer num = Integer.valueOf(10);  // 권장되는 방법 (성능 효율성)
```
