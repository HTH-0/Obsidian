# 📝 Java 날짜와 시간 처리 (`LocalDateTime` 활용)

## 📌 핵심 개념 정리

- Java에서 날짜와 시간을 다루는 대표 클래스는 `Date`, `Calendar`, `LocalDateTime` 등 존재
- **`LocalDateTime`** 클래스는 Java 8 이후 권장되는 **불변 객체(Immutable)**로서 날짜와 시간 표현에 최적화
- 기존 클래스(`Date`, `Calendar`)의 복잡한 단점과 문제점을 해결하기 위해 새롭게 설계됨

---

## 💻 코드 정리

```java
import java.time.DayOfWeek;
import java.time.LocalDateTime;

public class C05DateMain {
    public static void main(String[] args) {
        LocalDateTime now = LocalDateTime.now();

        int year = now.getYear();
        int month = now.getMonthValue();
        int day = now.getDayOfMonth();
        int hour = now.getHour();
        int minute = now.getMinute();
        int second = now.getSecond();
        DayOfWeek dayOfWeek = now.getDayOfWeek();

        System.out.println("연: " + year);
        System.out.println("월: " + month);
        System.out.println("일: " + day);
        System.out.println("시: " + hour);
        System.out.println("분: " + minute);
        System.out.println("초: " + second);
        System.out.println("요일: " + dayOfWeek);
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **현재 시간 가져오기 (`LocalDateTime.now()`)**

```java
LocalDateTime now = LocalDateTime.now();
```

- 현재 시스템의 날짜와 시간을 가져와 `LocalDateTime` 객체로 저장

### 2️⃣ **날짜/시간의 필드값 추출하기**

```java
int year = now.getYear();
int month = now.getMonthValue();
int day = now.getDayOfMonth();
int hour = now.getHour();
int minute = now.getMinute();
int second = now.getSecond();
DayOfWeek dayOfWeek = now.getDayOfWeek();
```

- 메서드를 통해 각각의 시간 구성 요소를 얻을 수 있음
- `DayOfWeek` enum 타입으로 요일 표현 (MONDAY, TUESDAY, ...)

---

## 🔎 추가 정보

- `Date`, `Calendar` 클래스는 Deprecated(비권장), 가능하면 `LocalDateTime`, `LocalDate`, `LocalTime`을 사용할 것
- 날짜/시간을 특정 형식으로 출력할 땐 **`DateTimeFormatter`** 사용 추천
    
    ```java
    DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
    System.out.println(now.format(formatter));
    ```
