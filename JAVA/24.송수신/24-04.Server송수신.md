# 📌 Java 소켓 프로그래밍 - 서버 코드 분석

## 💡 주요 개념

- **서버 소켓 생성 (`ServerSocket`)**: 클라이언트의 연결을 기다림
- **클라이언트와 연결 (`accept()`)**: 연결 요청이 들어오면 수락
- **데이터 입출력 (`DataInputStream`, `DataOutputStream`)**: 클라이언트와 메시지를 주고받음
- **멀티스레딩 (`Thread`)**: 송신(`ServerSendThread`), 수신(`ServerRecvThread`)을 별도로 실행
- **자원 해제 (`close()`)**: 통신 종료 후 소켓 및 스트림 닫기

---

## 💻 주요 코드

```java
package Ch24;

import java.io.DataInputStream;
import java.io.DataOutputStream;
import java.io.IOException;
import java.io.InputStream;
import java.io.OutputStream;
import java.net.ServerSocket;
import java.net.Socket;

public class Server {
    public static void main(String[] args) throws IOException, InterruptedException {
        // 서버 소켓 생성 (포트 7000에서 대기)
        ServerSocket server = new ServerSocket(7000);
        System.out.println("[INFO] SERVER SOCKET LISTENING");

        // 클라이언트 연결 대기 및 수락
        Socket client = server.accept();
        System.out.println("[SERVER] 연결 시작합니다");

        // 클라이언트 정보 출력
        System.out.println("CLIENT IP : " + client.getInetAddress());

        // 데이터 송수신을 위한 스트림 생성
        OutputStream out = client.getOutputStream();
        DataOutputStream dout = new DataOutputStream(out);
        InputStream in = client.getInputStream();
        DataInputStream din = new DataInputStream(in);

        // 송신 및 수신 스레드 실행
        ServerSendThread send = new ServerSendThread(dout);
        ServerRecvThread recv = new ServerRecvThread(din);

        Thread th1 = new Thread(send);
        Thread th2 = new Thread(recv);

        th1.start();
        th2.start();

        // 스레드 종료 대기
        th1.join();
        th2.join();

        // 리소스 해제
        in.close();
        out.close();
        client.close();
        server.close();
        System.out.println("[SERVER] 연결 종료합니다");
    }
}
```

## 🔎 코드 분석

### 1️⃣ **서버 소켓 생성 및 클라이언트 대기**

```java
ServerSocket server = new ServerSocket(7000);
System.out.println("[INFO] SERVER SOCKET LISTENING");
```

- 서버 소켓을 생성하고 **포트 7000**에서 연결 대기

```java
Socket client = server.accept();
System.out.println("[SERVER] 연결 시작합니다");
```

- 클라이언트 연결 요청(`accept()`)을 받아들여 소켓 생성

---

### 2️⃣ **클라이언트 정보 출력**

```java
System.out.println("CLIENT IP : " + client.getInetAddress());
```

- `getInetAddress()`를 사용하여 연결된 클라이언트의 IP 주소 출력

---

### 3️⃣ **데이터 입출력 스트림 생성**

```java
OutputStream out = client.getOutputStream();
DataOutputStream dout = new DataOutputStream(out);
InputStream in = client.getInputStream();
DataInputStream din = new DataInputStream(in);
```

- `DataOutputStream`: 클라이언트에게 데이터 전송
- `DataInputStream`: 클라이언트로부터 데이터 수신

---

### 4️⃣ **송신 및 수신 스레드 실행**

```java
ServerSendThread send = new ServerSendThread(dout);
ServerRecvThread recv = new ServerRecvThread(din);

Thread th1 = new Thread(send);
Thread th2 = new Thread(recv);

th1.start();
th2.start();
```

- 송신(`send`)과 수신(`recv`)을 각각 **별도의 스레드**로 실행
- `Thread`를 생성하여 비동기 방식으로 실행

---

### 5️⃣ **스레드 종료 대기**

```java
th1.join();
th2.join();
```

- `join()`을 사용하여 송신 및 수신 스레드가 종료될 때까지 대기

---

### 6️⃣ **자원 해제 및 종료**

```java
in.close();
out.close();
client.close();
server.close();
System.out.println("[SERVER] 연결 종료합니다");
```

- **스트림과 소켓을 닫아 리소스 정리**
- **`server.close()`를 호출하여 서버 종료**

---

## 🎯 핵심 정리

1. `ServerSocket`을 사용해 서버 생성 및 클라이언트 연결 대기
2. `accept()`로 클라이언트 연결을 받아 `Socket` 생성
3. `DataInputStream`, `DataOutputStream`을 사용해 데이터 송수신
4. `Thread`를 이용해 송신(`ServerSendThread`), 수신(`ServerRecvThread`)을 별도 실행
5. `join()`을 사용해 스레드 종료까지 대기
6. `close()`로 스트림 및 소켓을 닫아 리소스 해제
