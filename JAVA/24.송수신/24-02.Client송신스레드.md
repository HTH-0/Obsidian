# 📌 Java 소켓 프로그래밍 - 클라이언트 송신 스레드 분석

## 💡 주요 개념

- **Runnable 인터페이스 구현**: `run()` 메서드를 오버라이딩하여 스레드 실행
- **`DataOutputStream` 사용**: 서버로 데이터를 송신
- **사용자 입력 처리**: `Scanner`를 사용해 콘솔에서 입력받음
- **무한 루프 + 종료 조건**: `q` 입력 시 종료
- **예외 처리 및 리소스 정리**: `try-catch-finally` 구조 활용

---

## 💻 주요 코드

```java
package Ch24;

import java.io.DataOutputStream;
import java.util.Scanner;

public class ClientSendThread implements Runnable {

    DataOutputStream dout;
    Scanner sc = new Scanner(System.in);

    // 생성자: 서버로 데이터를 보낼 출력 스트림을 초기화
    ClientSendThread(DataOutputStream dout) {
        this.dout = dout;
    }

    public void run() {
        String send;

        try {
            while (true) {
                // 사용자 입력 대기
                System.out.print("[CLIENT(q:종료)] :");
                send = sc.nextLine();

                // 종료 조건 (사용자가 "q" 입력 시 종료)
                if (send.equals("q")) {
                    break;
                }

                // 서버로 데이터 전송
                dout.writeUTF(send);
                dout.flush();
            }
        } catch (Exception e) {
            System.out.println("[CLIENT] 연결 오류 발생: " + e.getMessage());
        } finally {
            try {
                if (dout != null)
                    dout.close();
                if (sc != null)
                    sc.close();
            } catch (Exception e) {
                System.out.println("[CLIENT] 리소스 해제 중 오류 발생: " + e.getMessage());
            }
        }
    }
}
```

## 🔎 코드 분석

### 1️⃣ **클래스 선언 및 생성자**

```java
public class ClientSendThread implements Runnable {
```

- `Runnable` 인터페이스를 구현하여 스레드로 실행 가능하도록 설계

```java
ClientSendThread(DataOutputStream dout) {
    this.dout = dout;
}
```

- 생성자에서 `DataOutputStream`을 받아 초기화
- `DataOutputStream`은 데이터를 서버로 보내는 역할

---

### 2️⃣ **사용자 입력 처리 및 서버 전송**

```java
System.out.print("[CLIENT(q:종료)] :");
send = sc.nextLine();
```

- `Scanner`를 사용하여 사용자 입력을 대기

```java
if (send.equals("q")) {
    break;
}
```

- 입력값이 `"q"`이면 반복문 종료 → 클라이언트 송신 종료

```java
dout.writeUTF(send);
dout.flush();
```

- 입력받은 문자열을 `writeUTF()`를 사용하여 서버로 전송
- `flush()` 호출하여 버퍼를 비우고 즉시 전송
