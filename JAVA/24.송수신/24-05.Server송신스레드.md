# 📌 Java 소켓 프로그래밍 - 서버 송신 스레드 분석

## 💡 주요 개념

- **Runnable 인터페이스 구현**: `run()` 메서드를 오버라이딩하여 스레드 실행
- **`DataOutputStream` 사용**: 클라이언트에게 데이터를 송신
- **사용자 입력 처리**: `Scanner`를 사용해 콘솔에서 입력받음
- **무한 루프 + 종료 조건**: `q` 입력 시 종료
- **예외 처리 및 리소스 정리**: `try-catch-finally` 구조 활용

---

## 💻 주요 코드

```java
package Ch24;

import java.io.DataOutputStream;
import java.util.Scanner;

public class ServerSendThread implements Runnable {

    // 데이터 출력 스트림
    DataOutputStream dout;
    Scanner sc = new Scanner(System.in);

    // 생성자: 클라이언트로 데이터를 보낼 출력 스트림 초기화
    ServerSendThread(DataOutputStream dout) {
        this.dout = dout;
    }

    @Override
    public void run() {
        String send;

        try {
            while (true) {
                // 사용자 입력 대기
                System.out.println("[SERVER (q:종료)] :");
                send = sc.nextLine();

                // 종료 조건 (사용자가 "q" 입력 시 종료)
                if (send.equals("q")) {
                    break;
                }

                // 클라이언트로 데이터 전송
                dout.writeUTF(send);
                dout.flush();
            }
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            try {
                dout.close();
            } catch (Exception e) {
                System.out.println("[SERVER] 리소스 해제 중 오류 발생: " + e.getMessage());
            }
        }
    }
}
```

## 🔎 코드 분석

### 1️⃣ **클래스 선언 및 생성자**

```java
public class ServerSendThread implements Runnable {
```

- `Runnable` 인터페이스를 구현하여 스레드 실행 가능

```java
ServerSendThread(DataOutputStream dout) {
    this.dout = dout;
}
```

- 생성자에서 `DataOutputStream`을 받아 초기화
- `DataOutputStream`은 데이터를 클라이언트에게 전송하는 역할

---

### 2️⃣ **사용자 입력 처리 및 클라이언트 전송**

```java
System.out.println("[SERVER (q:종료)] :");
send = sc.nextLine();
```

- `Scanner`를 사용하여 콘솔에서 사용자 입력을 받음

```java
if (send.equals("q")) {
    break;
}
```

- 입력값이 `"q"`이면 반복문 종료 → 서버 송신 종료

```java
dout.writeUTF(send);
dout.flush();
```

- `writeUTF()`를 사용하여 클라이언트에게 UTF-8 형식으로 메시지 전송
- `flush()` 호출하여 버퍼를 비우고 즉시 전송

---

### 3️⃣ **예외 처리 및 리소스 해제**

```java
} catch (Exception e) {
    e.printStackTrace();
} finally {
    try {
        dout.close();
    } catch (Exception e) {
        System.out.println("[SERVER] 리소스 해제 중 오류 발생: " + e.getMessage());
    }
}
```

- **예외 발생 시 `e.printStackTrace()`로 오류 출력**
- **`finally` 블록에서 `dout.close()`로 리소스 해제**  
    (출력 스트림을 닫지 않으면 메모리 누수 가능)

## 🎯 핵심 정리

1. `Runnable`을 구현하여 서버 송신 스레드 생성
2. `Scanner`를 사용해 사용자 입력을 받음
3. `DataOutputStream`을 이용해 클라이언트로 데이터 송신
4. `"q"` 입력 시 종료하는 조건문 추가
5. `try-catch-finally`로 예외 처리 및 리소스 해제
