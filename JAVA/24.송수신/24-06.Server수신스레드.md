# 📌 Java 소켓 프로그래밍 - 서버 수신 스레드 분석

## 💡 주요 개념

- **Runnable 인터페이스 구현**: `run()` 메서드를 오버라이딩하여 스레드 실행
- **`DataInputStream` 사용**: 클라이언트에서 메시지를 수신
- **무한 루프 + 종료 조건**: `"q"` 입력 시 종료
- **예외 처리 및 리소스 정리**: `try-catch-finally` 구조 활용

---

## 💻 주요 코드

```java
package Ch24;

import java.io.DataInputStream;

public class ServerRecvThread implements Runnable {
    DataInputStream din;

    // 생성자: 클라이언트로부터 데이터를 받을 입력 스트림 초기화
    public ServerRecvThread(DataInputStream din) {
        this.din = din;
    }

    @Override
    public void run() {
        String recv;

        try {
            while (true) {
                // 클라이언트로부터 메시지 수신
                recv = din.readUTF();

                // 종료 조건: "q" 입력 시 반복문 종료
                if (recv.equals("q"))
                    break;

                // 수신한 메시지 출력
                System.out.println("[SERVER] : " + recv);
            }
        } catch (Exception e) {
            System.out.println("[SERVER] 연결 오류 발생: " + e.getMessage());
        } finally {
            try {
                if (din != null) {
                    din.close();
                }
            } catch (Exception e) {
                System.out.println("[SERVER] 리소스 해제 중 오류 발생: " + e.getMessage());
            }
        }
    }
}
```

## 🔎 코드 분석

### 1️⃣ **클래스 선언 및 생성자**

```java
public class ServerRecvThread implements Runnable {
```

- `Runnable` 인터페이스를 구현하여 스레드로 실행 가능

```java
public ServerRecvThread(DataInputStream din) {
    this.din = din;
}
```

- 생성자에서 `DataInputStream`을 받아 초기화
- `DataInputStream`은 클라이언트에서 오는 데이터를 읽는 역할

---

### 2️⃣ **클라이언트에서 데이터 수신**

```java
recv = din.readUTF();
```

- `readUTF()`를 사용하여 UTF-8 형식의 문자열을 수신
- 클라이언트가 데이터를 전송할 때까지 대기

---

### 3️⃣ **종료 조건 설정**

```java
if (recv.equals("q"))
    break;
```

- 클라이언트가 `"q"`를 보내면 반복문을 종료하여 스레드 종료

---

### 4️⃣ **예외 처리 및 리소스 해제**

```java
} catch (Exception e) {
    System.out.println("[SERVER] 연결 오류 발생: " + e.getMessage());
} finally {
    try {
        if (din != null) {
            din.close();
        }
    } catch (Exception e) {
        System.out.println("[SERVER] 리소스 해제 중 오류 발생: " + e.getMessage());
    }
}
```

- **예외 발생 시 오류 메시지 출력**
- **`finally` 블록에서 `din.close()`로 리소스 해제**  
    (입력 스트림을 닫지 않으면 메모리 누수 가능)

## 🎯 핵심 정리

1. `Runnable`을 구현하여 서버 수신 스레드 생성
2. `DataInputStream`을 사용해 클라이언트에서 데이터 수신
3. `"q"` 수신 시 종료하는 조건문 추가
4. `try-catch-finally`로 예외 처리 및 리소스 해제
