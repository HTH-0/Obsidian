## 📌 **내용 정리**

- 추상 클래스 `Converter`를 정의하고, 이를 상속받아 `Won2Dollar` 클래스를 구현
- `convert()`, `getSrcString()`, `getDestString()`의 추상 메서드를 오버라이딩하여 원화를 달러로 변환하는 기능 구현
- `run()` 메서드에서 사용자 입력을 받아 변환 과정 수행

---

## 💻 **코드 정리**

```java
package Ch13;

import java.util.Scanner;

abstract class Converter {
    abstract protected double convert(double src);  // 변환 메서드 (추상 메서드)
    abstract protected String getSrcString();  // 입력 단위 반환 (추상 메서드)
    abstract protected String getDestString(); // 출력 단위 반환 (추상 메서드)
    
    protected double ratio; // 변환 비율

    public void run() {
        Scanner scanner = new Scanner(System.in);

        System.out.println(getSrcString() + "을 " + getDestString() + "로 바꿉니다.");
        System.out.print(getSrcString() + "을 입력하세요>> ");
        
        double val = scanner.nextDouble();
        double res = convert(val);
        
        System.out.println("변환 결과: " + res + getDestString() + "입니다");
        
        scanner.close();
    }
}

class Won2Dollar extends Converter {
    Won2Dollar(double ratio) {
        this.ratio = ratio;
    }

    @Override
    protected double convert(double src) {
        return src / ratio;
    }

    @Override
    protected String getSrcString() {
        return "원";
    }

    @Override
    protected String getDestString() {
        return "달러";
    }
}

public class C02Ex {
    public static void main(String[] args) {
        Won2Dollar toDollar = new Won2Dollar(1200); // 1달러 = 1200원
        toDollar.run();
    }
}
```

## 🔎 **코드 분석**

### 1️⃣ **추상 클래스 `Converter` 정의**

```java

    abstract protected String getDestString();

```

- 변환 기능을 가진 `Converter` 클래스 선언 (추상 클래스)
- 변환을 위한 `convert(double src)`, 단위 정보를 반환하는 `getSrcString()`, `getDestString()` 추상 메서드 포함
- `ratio` 필드를 통해 변환 비율을 저장
- `run()` 메서드에서 사용자 입력을 받아 변환 과정을 실행

## 🔎 **추가 정보**

- `Scanner` 사용 후 `scanner.close();`로 리소스 해제 필수
- `convert(double src)`는 구체적인 변환 로직을 하위 클래스에서 구현
- `abstract` 메서드는 `Converter` 클래스 내에서 직접 구현 불가, 하위 클래스에서 필수적으로 구현해야 함
