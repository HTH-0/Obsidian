## 📌 **내용 정리**

- 일반 클래스와 **추상 클래스의 상속 관계** 비교
- **일반 클래스**는 메서드를 오버라이딩하여 재정의 가능
- **추상 클래스**는 반드시 하위 클래스에서 추상 메서드를 구현해야 함
- **업캐스팅(Upcasting)**을 통해 부모 타입 변수로 자식 클래스의 재정의된 메서드 호출 가능

## 🔎 **코드 분석**

### 1️⃣ **일반 클래스 상속**

```java
class Super1 {
    void func() {}
}

class Sub1 extends Super1 {
    @Override
    void func() {
        System.out.println("[Override] Sub1.func() is called.");
    }
}
```

- `Super1` 클래스는 일반 메서드 `func()`를 가짐
- `Sub1`에서 `func()`를 **오버라이딩**하여 기능을 재정의
- 업캐스팅(`Super1 s3 = new Sub1();`) 후에도 `Sub1`의 `func()` 호출 가능

---

### 2️⃣ **추상 클래스 상속**

```java
abstract class Super2 { 
    abstract void func(); // 미완성된 메서드
}

class Sub2 extends Super2 { 
    @Override
    void func() {
        System.out.println("[Override] Sub2.func() is called.");
    }
}
```

- `Super2`는 **추상 클래스** → `func()`는 **추상 메서드**
- `Sub2`에서 `func()`를 **반드시 구현(오버라이딩)해야 함**
- `Super2` 자체로는 객체 생성 불가 (`new Super2();` X)
- `Sub2`에서 구현 후 객체 생성 가능 (`new Sub2();` O)

---

### 3️⃣ **업캐스팅 (Upcasting)**

```java
Super2 s3 = new Sub2();
s3.func(); // [Override] Sub2.func() is called.
```

- `Super2` 타입으로 `Sub2` 객체를 참조 (업캐스팅)
- `s3.func();` 실행 시 `Sub2`에서 재정의된 `func()`가 호출됨

---

## 🔎 **추가 정보**

### ✅ **추상 클래스(abstract class) 특징**

1. **추상 메서드 포함 가능** (`abstract` 키워드 사용)
2. **객체 직접 생성 불가** (자식 클래스에서 상속 후 구현 필요)
3. **상속을 강제**하여 특정 메서드 구현을 요구

### ✅ **업캐스팅(Upcasting)**

- **부모 클래스 타입으로 자식 객체를 참조하는 것**
- **자식 클래스에서 오버라이딩한 메서드는 호출 가능**
- **부모 클래스에 없는 메서드는 호출 불가능**
    
    ```java
    Super1 s = new Sub1();
    s.func();  // 가능 (재정의된 func() 호출)
    ```
