## 📌 내용

- 업캐스팅(Upcasting)과 다운캐스팅(Downcasting) 개념 확인
- 다형성을 활용하여 `A-G` 클래스의 속성을 다루는 `UpDownCastTestFunc` 구현
- `toString()`을 오버라이딩하여 객체 상태 출력

## 💻 코드 정리

```java
package Ch12;

class A {
    int a;

    A(int a) {
        this.a = a;
    }

    @Override
    public String toString() {
        return "A [a=" + a + "]";
    }
}

class B extends A {
    int b;

    B(int a, int b) {
        super(a);
        this.b = b;
    }

    @Override
    public String toString() {
        return "B [b=" + b + ", a=" + a + "]";
    }
}

class C extends A {
    int c;

    C(int a, int c) {
        super(a);
        this.c = c;
    }

    @Override
    public String toString() {
        return "C [c=" + c + ", a=" + a + "]";
    }
}

class D extends B {
    int d;

    D(int a, int b, int d) {
        super(a, b);
        this.d = d;
    }

    @Override
    public String toString() {
        return "D [d=" + d + ", b=" + b + ", a=" + a + "]";
    }
}

class E extends B {
    int e;

    E(int a, int b, int e) {
        super(a, b);
        this.e = e;
    }

    @Override
    public String toString() {
        return "E [e=" + e + ", b=" + b + ", a=" + a + "]";
    }
}

class F extends C {
    int f;

    F(int a, int c, int f) {
        super(a, c);
        this.f = f;
    }

    @Override
    public String toString() {
        return "F [f=" + f + ", c=" + c + ", a=" + a + "]";
    }
}

class G extends C {
    int g;

    G(int a, int c, int g) {
        super(a, c);
        this.g = g;
    }

    @Override
    public String toString() {
        return "G [g=" + g + ", c=" + c + ", a=" + a + "]";
    }
}

public class C07UpDownCastingMain {
    
    public static void UpDownCastTestFunc(A obj, int... arg) {
        obj.a = arg[0];

        if (obj instanceof D) {
            D down = (D) obj;
            down.b = arg[1];
            down.d = arg[2];
        } else if (obj instanceof E) {
            E down = (E) obj;
            down.b = arg[1];
            down.e = arg[2];
        } else if (obj instanceof F) {
            F down = (F) obj;
            down.c = arg[1];
            down.f = arg[2];
        } else if (obj instanceof G) {
            G down = (G) obj;
            down.c = arg[1];
            down.g = arg[2];
        } else if (obj instanceof B) {
            B down = (B) obj;
            down.b = arg[1];
        } else if (obj instanceof C) {
            C down = (C) obj;
            down.c = arg[1];
        }

        System.out.println(obj);
    }

    public static void main(String[] args) {
        A ob1 = new A(0);
        B ob2 = new B(0, 0);
        C ob3 = new C(0, 0);
        D ob4 = new D(0, 0, 0);
        E ob5 = new E(0, 0, 0);
        F ob6 = new F(0, 0, 0);
        G ob7 = new G(0, 0, 0);

        UpDownCastTestFunc(ob1, 10);               
        UpDownCastTestFunc(ob2, 10, 20);           
        UpDownCastTestFunc(ob3, 30, 40);           
        UpDownCastTestFunc(ob4, 50, 60, 70);       
        UpDownCastTestFunc(ob5, 80, 90, 100);      
        UpDownCastTestFunc(ob6, 110, 120, 130);    
        UpDownCastTestFunc(ob7, 140, 150, 160);    
    }
}
```

## 🔎 코드 분석

### 1️⃣ **업캐스팅 & 다운캐스팅 활용**

```java
public static void UpDownCastTestFunc(A obj, int... arg) {
    obj.a = arg[0];

    if (obj instanceof D) {
        D down = (D) obj;
        down.b = arg[1];
        down.d = arg[2];
    }
    ...
    System.out.println(obj);
}
```

- `obj`를 `A` 타입으로 받아 다형성을 활용
- `instanceof` 연산자로 다운캐스팅을 수행하여 `B, C, D, E, F, G` 각각의 필드 값을 설정

### 2️⃣ **객체 생성 및 테스트 함수 호출**

```java
UpDownCastTestFunc(ob1, 10);
UpDownCastTestFunc(ob2, 10, 20);
UpDownCastTestFunc(ob3, 30, 40);
UpDownCastTestFunc(ob4, 50, 60, 70);
```

- `A` 타입의 객체를 `UpDownCastTestFunc`에 전달 → 업캐스팅 발생
- `instanceof`를 통해 적절한 클래스로 다운캐스팅 후 필드 값을 설정

### 3️⃣ **toString() 오버라이딩**

```java
@Override
public String toString() {
    return "B [b=" + b + ", a=" + a + "]";
}
```

- 객체 상태를 출력할 수 있도록 `toString()`을 각 클래스에서 오버라이딩

## 🔎 추가 정보

- **업캐스팅(Upcasting)**: 서브 클래스 객체를 슈퍼 클래스 타입으로 변환
- **다운캐스팅(Downcasting)**: 슈퍼 클래스 타입의 객체를 다시 서브 클래스 타입으로 변환
- **instanceof**: 객체가 특정 클래스의 인스턴스인지 확인하는 연산자
