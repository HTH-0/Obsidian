# 📝 Upcasting과 Downcasting

## 📌 내용

- **Upcasting**: 하위 클래스 객체를 상위 클래스 타입으로 변환
- **Downcasting**: 상위 클래스 객체를 하위 클래스 타입으로 변환 (강제 형변환 필요)
- **Upcasting된 객체는 하위 클래스의 멤버 변수나 메서드에 직접 접근 불가**
- **Downcasting은 Upcasting된 객체에 대해서만 안전하게 수행 가능**

---

## 💻 코드 정리

```java
package Ch12;

class Super {
    int n1;
}

class Sub extends Super {
    int n2;
}

public class C06UpDownCasting {
    public static void main(String[] args) {
        
        // 기본 객체 생성
        Super ob1 = new Super();
        ob1.n1 = 10;
        
        Sub ob2 = new Sub();
        ob2.n1 = 10;
        ob2.n2 = 20;

        // Upcasting (하위 클래스 -> 상위 클래스)
        Super ob3 = new Sub();
        ob3.n1 = 100;
//        ob3.n2 = 200;  // 접근 불가 (n2는 Sub 클래스에 존재)

        Super ob4 = ob2;
        ob4.n1 = 100;
//        ob4.n2 = 200;  // 접근 불가

        // Downcasting (상위 클래스 -> 하위 클래스) - 강제 형변환 필요
//        Sub ob5 = (Sub)ob1;  // 잘못된 다운캐스팅 (런타임 오류)
        Sub ob6 = (Sub)ob3;    // Upcasting된 객체를 다시 Downcasting (정상 동작)
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **Upcasting (자동 형변환)**

```java
Super ob3 = new Sub();
```

- `ob3`는 `Super` 타입이지만 `Sub` 객체를 참조
- `n1`에는 접근 가능하지만, `n2`는 접근 불가능

```java
Super ob4 = ob2;
```

- 기존 `Sub` 객체 `ob2`를 `Super` 타입으로 변환
- `ob4.n1` 접근 가능, `ob4.n2` 접근 불가

---

### 2️⃣ **Downcasting (강제 형변환)**

```java
Sub ob6 = (Sub)ob3;
```

- `ob3`는 원래 `Sub` 객체 → 안전한 다운캐스팅
- `ob6.n1`, `ob6.n2` 모두 접근 가능

```java
Sub ob5 = (Sub)ob1;
```

- `ob1`은 원래 `Super` 객체 → `Sub`로 변환 불가 (런타임 오류 발생)

---

## 🔎 추가 정보

- **Upcasting은 안전하며 자동으로 수행**
- **Downcasting은 Upcasting된 객체에 대해서만 가능하며 강제 형변환 필요**
- 잘못된 Downcasting 시 **`ClassCastException` 발생**
