# 📌 메서드 오버라이딩 (`Method Overriding`)

## 📝 내용 요약

- **오버라이딩(Overriding)**: 부모 클래스의 메서드를 **자식 클래스에서 재정의**하여 다른 동작을 수행하도록 변경
- **다형성(Polymorphism)**: 부모 클래스 타입의 변수로 **자식 클래스 객체를 참조할 때, 자식 클래스의 오버라이딩된 메서드가 실행됨**
- **오버로딩(Overloading)과 차이점**
    - **오버로딩**: 같은 이름의 메서드를 **파라미터만 변경하여 여러 개 정의** (상속 필요 없음)
    - **오버라이딩**: 부모 클래스의 메서드를 **그대로 유지하면서 내부 로직만 변경** (상속 필수)

---

## 💻 코드 정리

```java
package Ch12;

// 부모 클래스
class Animal {
    void sound() {
        System.out.println("소리낸다");
    }
}

// 자식 클래스 (Dog)
class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("멍멍");
    }
}

// 자식 클래스 (Cat)
class Cat extends Animal {
    @Override
    void sound() {
        System.out.println("야옹");
    }
}

public class C03MethodOverriding {
    public static void main(String[] args) {
        // 부모 클래스 타입으로 직접 호출
        Animal ani = new Animal();
        ani.sound();  // 부모 클래스 메서드 실행

        // 자식 클래스의 오버라이딩된 메서드 실행
        Dog dog1 = new Dog();
        dog1.sound();  // "멍멍"
        Cat cat1 = new Cat();
        cat1.sound();  // "야옹"

        System.out.println("--------------");

        // 부모 클래스 타입의 변수로 자식 객체 참조 (다형성 활용)
        ani = dog1;
        ani.sound();  // Dog 클래스의 오버라이딩된 "멍멍" 실행

        ani = cat1;
        ani.sound();  // Cat 클래스의 오버라이딩된 "야옹" 실행
    }
}
```

## 🔎 코드 분석

### 1️⃣ **부모 클래스 `Animal`**

```java
class Animal {
    void sound() {
        System.out.println("소리낸다");
    }
}
```

- `sound()` 메서드는 기본적으로 `"소리낸다"`를 출력
- `오버라이딩`을 통해 자식 클래스에서 `sound()` 메서드를 변경할 수 있음

### 2️⃣ **자식 클래스 `Dog`와 `Cat`**

```java
class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("멍멍");
    }
}

class Cat extends Animal {
    @Override
    void sound() {
        System.out.println("야옹");
    }
}
```

- `@Override`를 사용하여 **부모 클래스의 `sound()` 메서드를 재정의**
- `Dog` → `"멍멍"`, `Cat` → `"야옹"`을 출력하도록 변경

### 3️⃣ **객체 생성 및 실행 흐름**

```java
ani = dog1;
ani.sound();  // Dog의 sound() 실행 -> "멍멍"

ani = cat1;
ani.sound();  // Cat의 sound() 실행 -> "야옹"
```

- 부모 클래스 타입(`Animal`)으로 **자식 객체(`Dog`, `Cat`)를 참조**할 수 있음 (다형성)
- `ani.sound()`를 호출하면 **현재 참조된 자식 객체의 `sound()` 메서드가 실행됨**

## 🔎 추가 정보

### ✅ `@Override`의 역할

- **컴파일러가 메서드 오버라이딩을 정확히 수행했는지 체크**
- 부모 클래스의 메서드와 **동일한 시그니처(반환형, 메서드명, 매개변수)를 유지**해야 함

### ✅ `super` 키워드를 활용한 부모 메서드 호출

```java
class Dog extends Animal {
    @Override
    void sound() {
        super.sound();  // 부모 클래스의 sound() 호출
        System.out.println("멍멍");
    }
}
```

- `super.sound();`를 통해 **부모 클래스의 `sound()`도 실행 가능**
