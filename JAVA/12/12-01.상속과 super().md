# 📌 Java 상속과 `super()` 생성자 호출

## 📝 내용 요약

- **상속(Inheritance)**: `Point3D` 클래스가 `Point2D` 클래스를 상속받아 **x, y** 좌표를 재사용
- **`super()`를 활용하여 부모 클래스의 생성자 호출**
- `toString()` 메서드를 오버라이딩하여 객체 정보를 문자열로 반환

---

## 💻 코드 정리

```java
package Ch12;

// 부모 클래스 (2D 좌표)
class Point2D {
    int x;
    int y;

    // 부모 클래스 기본 생성자
    Point2D() {
        System.out.println("Point2D 디폴트 생성자 호출!");
    }
}

// 자식 클래스 (3D 좌표)
class Point3D extends Point2D {
    int z;

    // 자식 클래스 기본 생성자
    Point3D() {
        super();  // 부모 클래스(Point2D)의 생성자 호출
        System.out.println("Point3D 디폴트 생성자 호출!");
    }

    @Override
    public String toString() {
        return "Point3D [z=" + z + ", x=" + x + ", y=" + y + "]";
    }
}

public class C01InheritanceMain {
    public static void main(String[] args) {
        Point3D ob1 = new Point3D();  // 객체 생성 시 부모 생성자 먼저 호출
        ob1.x = 10;
        ob1.y = 20;
        ob1.z = 30;
        System.out.println(ob1);
    }
}
```

## 🔎 코드 분석

### 1️⃣ **부모 클래스 `Point2D`**

```java
class Point2D {
    int x;
    int y;

    Point2D() {
        System.out.println("Point2D 디폴트 생성자 호출!");
    }
}
```

- `Point2D`는 2차원 좌표를 저장하는 클래스
- 기본 생성자를 정의하여 **객체 생성 시 호출 로그 출력**

### 2️⃣ **자식 클래스 `Point3D`**

```java
class Point3D extends Point2D {
    int z;

    Point3D() {
        super();  // 부모 클래스 생성자 호출
        System.out.println("Point3D 디폴트 생성자 호출!");
    }
}
```

- `extends`를 통해 `Point2D`의 속성(`x, y`)을 상속
- `super();` → 부모 클래스의 생성자를 호출하여 **`Point2D` 객체가 먼저 생성됨**
- `z` 추가로 3차원 좌표를 표현 가능

### 3️⃣ **객체 생성 및 값 할당**

```java
Point3D ob1 = new Point3D();
ob1.x = 10;
ob1.y = 20;
ob1.z = 30;
System.out.println(ob1);
```

- `Point3D` 객체 생성 시 **`Point2D` 생성자 → `Point3D` 생성자 순으로 호출**
- `toString()`을 오버라이딩하여 객체 정보를 문자열로 변환 후 출력

## 🔎 추가 정보

### ✅ `super()`의 역할

- **부모 클래스의 생성자를 명시적으로 호출**
- 자식 클래스가 객체를 생성할 때, **부모 클래스의 생성자가 먼저 실행됨**
- 부모 클래스의 생성자가 **매개변수를 받는 경우** 반드시 `super(값)`을 통해 호출해야 함

### ✅ `super()` 활용한 부모 생성자 호출 (매개변수 포함)

```java
class Point2D {
    int x, y;
    Point2D(int x, int y) {
        this.x = x;
        this.y = y;
        System.out.println("Point2D 생성자 호출!");
    }
}

class Point3D extends Point2D {
    int z;
    Point3D(int x, int y, int z) {
        super(x, y);  // 부모 클래스의 생성자 호출 (x, y 값 전달)
        this.z = z;
        System.out.println("Point3D 생성자 호출!");
    }
}
```

- `super(x, y)`를 통해 부모 클래스의 매개변수 생성자 호출 가능
