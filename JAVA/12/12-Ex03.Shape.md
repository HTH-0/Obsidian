# 📝 Java 다중 레벨 상속 (Multi-Level Inheritance)

## 📌 내용

- **다중 레벨 상속(Multi-Level Inheritance)** 학습
- 업캐스팅 후 **오버라이딩된 메서드 동작 확인**
- 다운캐스팅을 통해 **하위 클래스 고유 메서드 접근 가능 여부 확인**
- 클래스 계층 구조에서 **어떤 메서드를 호출할 수 있는지** 확인

---

## 💻 코드 정리

```java
package Ch12.ex;

// 다중 레벨 상속 예제
class Shape {
    void draw() {
        System.out.println("도형을 그립니다");
    }
}

class Circle extends Shape {
    void draw() {
        System.out.println("원을 그립니다");
    }
    
    void calculateArea() {
        System.out.println("원의 넓이를 계산합니다");
    }
}

class ColoredCircle extends Circle {
    void draw() {
        System.out.println("색칠된 원을 그립니다");
    }
    
    void applyColor() {
        System.out.println("원에 색을 칠합니다");
    }
}

public class Ex03MultiLevel {
    public static void main(String[] args) {
        System.out.println("=== 연습문제 3: 다중 레벨 ===");

        Shape s1 = new ColoredCircle();  // Shape 타입으로 업캐스팅
        s1.draw();  // 동적 바인딩: ColoredCircle의 draw() 호출

        Circle c1 = (Circle) s1;  // Shape -> Circle 다운캐스팅
        c1.calculateArea();  // Circle 클래스의 메서드 호출 가능

        ColoredCircle cc1 = (ColoredCircle) c1;  // Circle -> ColoredCircle 다운캐스팅
        cc1.applyColor();  // ColoredCircle의 applyColor() 호출 가능
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **업캐스팅(Upcasting)**

```java
Shape s1 = new ColoredCircle();
```

- `ColoredCircle` 인스턴스를 `Shape` 타입으로 업캐스팅
- `Shape`에 정의된 메서드만 접근 가능

### 2️⃣ **업캐스팅된 참조로 오버라이딩된 메서드 호출**

```java
s1.draw();
```

- `Shape` 타입이지만, 실제 객체가 `ColoredCircle`이므로 **동적 바인딩**으로 `ColoredCircle.draw()` 실행

### 3️⃣ **다운캐스팅(Shape → Circle)**

```java
Circle c1 = (Circle) s1;
c1.calculateArea();
```

- `Shape`을 `Circle`로 변환하여 `calculateArea()` 호출 가능
- `ColoredCircle`은 `Circle`을 상속했기 때문에 정상적인 캐스팅

### 4️⃣ **다운캐스팅(Circle → ColoredCircle)**

```java
ColoredCircle cc1 = (ColoredCircle) c1;
cc1.applyColor();
```

- `c1`이 원래 `ColoredCircle` 타입이므로 **정상적인 다운캐스팅 가능**
- `applyColor()`는 `ColoredCircle`에서만 정의되었으므로, 원래 객체 타입을 복원하여 호출

---

## 🔎 추가 정보

### ✅ **업캐스팅과 동적 바인딩**

- 업캐스팅된 객체는 **오버라이딩된 메서드만 실행 가능**
- 실제 객체의 타입을 따라가기 때문에 `s1.draw()` 실행 시 `ColoredCircle`의 `draw()`가 호출됨

### ✅ **다운캐스팅 시 `instanceof` 검사를 추천**

```java
if (s1 instanceof ColoredCircle) {
    ColoredCircle cc1 = (ColoredCircle) s1;
    cc1.applyColor();
}
```

- 잘못된 캐스팅 시 **`ClassCastException` 발생 방지**
- 안전하게 원래 객체의 타입을 확인 후 변환
