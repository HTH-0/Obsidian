# 📌 Java 상속 (`Inheritance`)

## 📝 내용 요약

- **상속(Inheritance)**: 기존 클래스(부모 클래스)의 속성과 기능을 새로운 클래스(자식 클래스)에서 **재사용**할 수 있도록 허용하는 문법
- **`extends` 키워드**를 사용하여 부모 클래스를 확장
- **하위 클래스에서 추가 기능 구현 가능**
- **오버라이딩(Overriding) 가능** → 상속받은 메서드를 재정의하여 변경 가능

---

## 💡 **상속의 특징**

1. **코드 재사용 (중복 최소화)**
    - 동일한 기능을 여러 클래스에서 반복적으로 작성할 필요 없음
2. **유지보수성 향상**
    - 부모 클래스만 수정하면 하위 클래스에도 적용 가능
3. **확장성 (Extensibility)**
    - 기존 클래스를 확장하여 새로운 기능을 추가 가능
4. **가독성 증가**
    - 관련된 클래스 간의 관계를 쉽게 이해할 수 있음

---

## 💻 코드 예제: 상속 구현 (`extends` 키워드)

```java
package Ch12;

// 부모 클래스 (Super Class)
class Animal {
    String name;

    void eat() {
        System.out.println(name + " is eating.");
    }
}

// 자식 클래스 (Sub Class) - Animal 클래스를 상속받음
class Dog extends Animal {
    void bark() {
        System.out.println(name + " is barking.");
    }
}

public class C01Inheritance {
    public static void main(String[] args) {
        Dog myDog = new Dog();
        myDog.name = "Buddy";
        
        myDog.eat();  // 부모 클래스의 메서드 사용
        myDog.bark(); // 자식 클래스의 메서드 사용
    }
}
```

### ✅ **실행 결과**

```plaintext
Buddy is eating.
Buddy is barking.
```

- `Dog` 클래스는 `Animal` 클래스를 **상속받아 `eat()` 메서드를 사용**할 수 있음
- `bark()`는 `Dog` 클래스에서 **추가한 기능**

---

## 💡 **오버라이딩(Overriding)**

- 부모 클래스에서 상속받은 메서드를 **자식 클래스에서 재정의하여 동작 변경 가능**
- `@Override` 애너테이션을 사용하여 **컴파일러가 오버라이딩을 정확히 적용했는지 검사**

### 📌 **오버라이딩 예제**

```java
package Ch12;

class Animal {
    void makeSound() {
        System.out.println("Some sound...");
    }
}

class Dog extends Animal {
    @Override
    void makeSound() {
        System.out.println("Bark! Bark!");
    }
}

public class C02Overriding {
    public static void main(String[] args) {
        Dog myDog = new Dog();
        myDog.makeSound();  // 오버라이딩된 메서드 실행
    }
}
```

### ✅ **실행 결과**

```plaintext
Bark! Bark!
```

- `Dog` 클래스에서 `makeSound()`를 **오버라이딩**하여 `Bark! Bark!` 출력
