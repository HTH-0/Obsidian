# 📌 Java 상속과 `super()`를 활용한 다양한 생성자 호출

## 📝 내용 요약

- **부모 클래스 `Point2D`와 자식 클래스 `Point3D` 간의 상속 구현**
- **생성자 오버로딩**을 사용하여 다양한 형태의 객체 생성 가능
- `super()`를 활용하여 **부모 클래스의 생성자를 명시적으로 호출**

---

## 💻 코드 정리

```java
package Ch12;

// 부모 클래스 (2D 좌표)
class Point2D {
    int x;
    int y;

    // 기본 생성자
    Point2D() {
        System.out.println("Point2D 디폴트 생성자 호출!");
    }

    // x만 초기화하는 생성자
    Point2D(int x) {
        this.x = x;
        System.out.println("Point2D(int x) 생성자 호출!");
    }

    // x, y를 초기화하는 생성자
    Point2D(int x, int y) {
        this.x = x;
        this.y = y;
        System.out.println("Point2D(int x, int y) 생성자 호출!");
    }
}

// 자식 클래스 (3D 좌표)
class Point3D extends Point2D {
    int z;

    // 기본 생성자
    Point3D() {
        super();  // 부모 클래스의 기본 생성자 호출
        System.out.println("Point3D 디폴트 생성자 호출!");
    }

    // x만 받는 생성자
    Point3D(int x) {
        super(x);  // 부모 클래스의 Point2D(int x) 생성자 호출
        System.out.println("Point3D(int x) 생성자 호출!");
    }

    // x, y를 받는 생성자
    Point3D(int x, int y) {
        super(x, y);  // 부모 클래스의 Point2D(int x, int y) 생성자 호출
        System.out.println("Point3D(int x, int y) 생성자 호출!");
    }

    // x, y, z를 받는 생성자
    Point3D(int x, int y, int z) {
        super(x, y);  // 부모 클래스의 Point2D(int x, int y) 생성자 호출
        this.z = z;   // 현재 클래스의 멤버 변수 초기화
        System.out.println("Point3D(int x, int y, int z) 생성자 호출!");
    }

    @Override
    public String toString() {
        return "Point3D [z=" + z + ", x=" + x + ", y=" + y + "]";
    }
}

public class C02InheritanceMain {
    public static void main(String[] args) {
        // Point3D 객체 생성 (x=10, y=20, z=30)
        Point3D ob1 = new Point3D(10, 20, 30);
        System.out.println(ob1);
    }
}
```

## 🔎 코드 분석

### 1️⃣ **부모 클래스 `Point2D`**

```java
class Point2D {
    int x, y;

    Point2D() {
        System.out.println("Point2D 디폴트 생성자 호출!");
    }

    Point2D(int x) {
        this.x = x;
        System.out.println("Point2D(int x) 생성자 호출!");
    }

    Point2D(int x, int y) {
        this.x = x;
        this.y = y;
        System.out.println("Point2D(int x, int y) 생성자 호출!");
    }
}
```

- `Point2D` 클래스는 **기본 생성자 + 오버로딩된 생성자(1개 또는 2개의 매개변수)**
- `super()`를 사용하면 부모 클래스의 생성자를 명시적으로 호출할 수 있음

### 2️⃣ **자식 클래스 `Point3D`**

```java
class Point3D extends Point2D {
    int z;

    Point3D(int x, int y, int z) {
        super(x, y);  // 부모 클래스의 생성자 호출
        this.z = z;
        System.out.println("Point3D(int x, int y, int z) 생성자 호출!");
    }
}
```

- `super(x, y)`를 사용하여 부모 클래스의 `(int x, int y)` 생성자를 호출
- `this.z = z;`를 통해 자식 클래스의 `z` 값을 초기화

### 3️⃣ **객체 생성 및 실행 흐름**

```java
Point3D ob1 = new Point3D(10, 20, 30);
System.out.println(ob1);
```

- `Point3D(10, 20, 30)` 생성자를 호출하면 `super(x, y)`를 통해 `Point2D(int x, int y)` 실행
- 실행 순서:
    1. `Point2D(int x, int y) 생성자 호출!`
    2. `Point3D(int x, int y, int z) 생성자 호출!`
    3. `toString()`을 사용하여 객체 정보 출력

## 🔎 추가 정보

### ✅ `super()`의 역할

- **부모 클래스의 생성자를 명시적으로 호출**
- 자식 클래스가 생성될 때, 부모 클래스의 **생성자가 먼저 실행됨**
- 부모 클래스가 매개변수를 받는 생성자만 가지고 있다면, 자식 클래스에서 반드시 `super(값)`을 통해 호출해야 함

### ✅ `super()` 없이 부모 생성자 호출되는 경우

```java
class Parent {
    Parent() {
        System.out.println("부모 클래스 생성자 호출!");
    }
}

class Child extends Parent {
    Child() {
        System.out.println("자식 클래스 생성자 호출!");
    }
}
```

- `super()`를 명시적으로 적지 않아도 기본적으로 **부모 클래스의 기본 생성자가 자동 호출됨**
- 실행 결과:

```plaintext
부모 클래스 생성자 호출!
자식 클래스 생성자 호출!
```
