# 📝 Java 멀티스레드 프로그래밍

## 📌 내용

- 단일 스레드와 멀티스레드 비교
- `Thread.sleep()`을 이용한 실행 흐름 제어
- `Runnable` 인터페이스를 활용한 스레드 분할
- 익명 클래스를 이용한 스레드 생성

---

## 💻 공부 코드

### 1️⃣ **단일 스레드 실행 (`C01ThreadMain`)**

```java
package Ch23;

public class C01ThreadMain {
    public static void main(String[] args) throws InterruptedException {
        for(int i = 0; i < 5; i++) {
            System.out.println("TASK01 ...");
            Thread.sleep(500);
        }
        for(int i = 0; i < 5; i++) {
            System.out.println("TASK02 ...");
            Thread.sleep(500);
        }
    }
}
```

### 2️⃣ **멀티스레드 실행 (`C02ThreadMain`)**

```java
package Ch23;

public class C02ThreadMain {
    public static void main(String[] args) {
        // Runnable 인터페이스를 이용한 스레드 분할
        C02Worker1 w1 = new C02Worker1();
        C02Worker2 w2 = new C02Worker2();

        Thread th1 = new Thread(w1);
        Thread th2 = new Thread(w2);

        th1.start();
        th2.start();

        // 익명 클래스를 사용한 스레드 생성
        new Thread() {
            @Override
            public void run() {
                for(int i = 0; i < 5; i++) {
                    System.out.println("TASK03 ...");
                    try {
                        Thread.sleep(500);
                    } catch (InterruptedException e) {
                        e.printStackTrace();
                    }
                }
            }
        }.start();

        for(int i = 0; i < 5; i++) {
            System.out.println("MAIN`");
            try {
                Thread.sleep(500);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}
```

### 3️⃣ **Runnable 인터페이스 구현 (`C02Worker1`, `C02Worker2`)**

```java
package Ch23;

public class C02Worker1 implements Runnable {
    @Override
    public void run() {
        for(int i = 0; i < 5; i++) {
            System.out.println("TASK01 ...");
            try {
                Thread.sleep(500);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}
```

```java
package Ch23;

public class C02Worker2 implements Runnable {
    @Override
    public void run() {
        for(int i = 0; i < 5; i++) {
            System.out.println("TASK02 ...");
            try {
                Thread.sleep(500);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}
```

## 🔎 주요 개념

### 1️⃣ **단일 스레드 실행 흐름**

- `C01ThreadMain`에서는 `TASK01`을 5번 실행한 후 `TASK02`를 5번 실행
- `Thread.sleep(500)`을 사용해 0.5초 간격으로 실행

### 2️⃣ **멀티스레드 실행 흐름**

- `C02Worker1`, `C02Worker2`는 `Runnable` 인터페이스를 구현
- `C02ThreadMain`에서 `Thread` 객체를 생성하고 `start()` 호출하여 독립적으로 실행
- 익명 클래스를 이용해 추가적인 스레드 생성 가능

### 3️⃣ **익명 클래스를 이용한 스레드 생성**

- `new Thread() { ... }.start();` 형태로 사용
- `run()` 메서드 재정의하여 실행할 작업을 지정

## 🔥 핵심 정리

- **단일 스레드**: 작업이 순차적으로 실행됨
- **멀티스레드**: 여러 작업이 병렬로 실행되어 성능 향상 가능
- `Runnable` 인터페이스를 활용하면 다중 작업을 효율적으로 처리할 수 있음
- `Thread.sleep()`을 사용하면 실행 간격 조정 가능
- 익명 클래스를 사용하면 간단하게 스레드를 생성할 수 있음
