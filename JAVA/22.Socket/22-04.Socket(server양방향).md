### 📌 Java 소켓 프로그래밍 (서버 - 양방향 통신)

## 📌 주요 개념

- **소켓 서버 (`ServerSocket`)**: 클라이언트의 요청을 받아들이고 응답하는 역할
- **TCP 양방향 통신**: `DataInputStream`, `DataOutputStream`을 사용하여 클라이언트와 **실시간 채팅**
- **반복적인 데이터 송수신 (`while` 루프)**: 계속해서 데이터를 주고받을 수 있도록 설정
- **종료 조건**: `"q"` 입력 시 연결 종료

---

## 💻 공부 코드

```java
package Ch22;

import java.io.DataInputStream;
import java.io.DataOutputStream;
import java.io.IOException;
import java.io.InputStream;
import java.io.OutputStream;
import java.net.ServerSocket;
import java.net.Socket;
import java.util.Scanner;

public class C02Server {
    public static void main(String[] args) throws IOException {
        
        // 1. 서버 소켓 생성 (포트 7000에서 클라이언트 요청 대기)
        ServerSocket server = new ServerSocket(7000);
        System.out.println("[INFO] SERVER SOCKET LISTENING");

        // 2. 클라이언트 연결 대기
        Socket client = server.accept();
        System.out.println("SERVER 시작합니다.");
        System.out.println("CLIENT IP : " + client.getInetAddress());

        // 3. 입출력 스트림 생성
        OutputStream out = client.getOutputStream();
        DataOutputStream dout = new DataOutputStream(out);
        InputStream in = client.getInputStream();
        DataInputStream din = new DataInputStream(in);

        // 4. 채팅을 위한 Scanner 객체 생성
        Scanner sc = new Scanner(System.in);
        String recv = null; // 클라이언트가 보낸 메시지
        String send = null; // 서버에서 보낼 메시지

        // 5. 채팅 시작 (q 입력 시 종료)
        while (true) {
            // 5-1. 서버 메시지 입력 및 전송
            System.out.print("[SERVER (q:종료)] : ");
            send = sc.nextLine();
            if (send.equals("q")) {
                break;
            }
            dout.writeUTF(send);
            dout.flush();

            // 5-2. 클라이언트 메시지 수신
            recv = din.readUTF();
            if (recv.equals("q")) {
                break;
            }
            System.out.println("[CLIENT] : " + recv);
        }

        // 6. 자원 해제 및 종료
        din.close();
        dout.close();
        in.close();
        out.close();
        client.close();
        server.close();
        sc.close();
        System.out.println("[SERVER] 연결 종료합니다.");
    }
}
```

## 🔎 주요 코드 분석

### 1️⃣ **서버 소켓 생성**

```java
ServerSocket server = new ServerSocket(7000);
System.out.println("[INFO] SERVER SOCKET LISTENING");
```

- **포트 `7000`에서 클라이언트 요청을 대기**
- `ServerSocket` 객체를 생성하면 **연결 요청을 받을 준비 상태**

---

### 2️⃣ **클라이언트 연결 대기**

```java
Socket client = server.accept();
System.out.println("CLIENT IP : " + client.getInetAddress());
```

- `accept()` 메서드는 **클라이언트의 연결 요청을 수락**
- 클라이언트가 연결될 때까지 **서버는 대기 상태**

---

### 3️⃣ **입출력 스트림 생성**

```java
OutputStream out = client.getOutputStream();
DataOutputStream dout = new DataOutputStream(out);
InputStream in = client.getInputStream();
DataInputStream din = new DataInputStream(in);
```

- **서버 → 클라이언트 데이터 전송**: `OutputStream`
- **클라이언트 → 서버 데이터 수신**: `InputStream`
- **`DataInputStream` / `DataOutputStream`을 사용하여 UTF-8 형식 데이터 송수신**

---

### 4️⃣ **채팅 루프 (`while` 반복문)**

```java
while (true) {
    // 4-1. 서버 메시지 입력 및 전송
    System.out.print("[SERVER (q:종료)] : ");
    send = sc.nextLine();
    if (send.equals("q")) {
        break;
    }
    dout.writeUTF(send);
    dout.flush();

    // 4-2. 클라이언트 메시지 수신
    recv = din.readUTF();
    if (recv.equals("q")) {
        break;
    }
    System.out.println("[CLIENT] : " + recv);
}
```

- **서버가 메시지를 입력 → 클라이언트에게 전송**
- **클라이언트 메시지 수신 → 서버에서 출력**
- **"q" 입력 시 종료**

---

### 5️⃣ **자원 해제 (서버 종료)**

```java
din.close();
dout.close();
in.close();
out.close();
client.close();
server.close();
sc.close();
System.out.println("[SERVER] 연결 종료합니다.");
```

- **모든 스트림과 소켓 닫기**
- **`close()`를 호출하여 메모리 누수 방지**

### 🔹 서버 실행 시

1. **서버 소켓을 생성 (`ServerSocket`)**
2. **클라이언트 연결 요청 수락 (`accept()`)**
3. **서버에서 메시지를 입력 후 전송**
4. **클라이언트 메시지를 수신하여 출력**
5. **"q" 입력 시 서버 종료**

## ✅ 핵심 정리

1️⃣ **소켓 서버 생성**

- `ServerSocket(PORT)`: 특정 포트에서 클라이언트 요청을 대기

2️⃣ **클라이언트 연결 대기**

- `accept()`: 클라이언트의 연결 요청을 받아들임

3️⃣ **양방향 데이터 송수신**

- `writeUTF()`: 클라이언트에게 UTF-8 형식 메시지 전송
- `readUTF()`: 클라이언트의 메시지 수신

4️⃣ **반복적인 채팅 기능**

- `while` 루프를 사용하여 계속 채팅 가능
- `"q"` 입력 시 서버 종료
