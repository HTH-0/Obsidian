### 📌 Java 소켓 프로그래밍 (클라이언트 - 양방향 통신)

## 📌 주요 개념

- **TCP 소켓 통신**: 클라이언트와 서버 간 **양방향 데이터 송수신**
- **입출력 스트림**:
    - `DataOutputStream` → 서버로 데이터 전송
    - `DataInputStream` → 서버에서 데이터 수신
- **반복 메시지 교환**: `while` 루프를 사용하여 **계속 채팅 가능**
- **종료 조건**: 사용자가 `"q"` 입력 시 연결 종료

---

## 💻 공부 코드

```java
package Ch22;

import java.io.DataInputStream;
import java.io.DataOutputStream;
import java.io.IOException;
import java.io.InputStream;
import java.io.OutputStream;
import java.net.Socket;
import java.net.UnknownHostException;
import java.util.Scanner;

public class C02Client {
    public static void main(String[] args) throws UnknownHostException, IOException {
        
        // 1. 서버에 연결 (IP: 192.168.16.70, 포트: 7000)
        Socket client = new Socket("192.168.16.70", 7000);
        System.out.println("CLIENT 시작합니다");
        System.out.println("CLIENT IP : " + client.getInetAddress());

        // 2. 입출력 스트림 생성
        OutputStream out = client.getOutputStream();
        DataOutputStream dout = new DataOutputStream(out);
        InputStream in = client.getInputStream();
        DataInputStream din = new DataInputStream(in);

        // 3. 채팅을 위한 Scanner 객체 생성
        Scanner sc = new Scanner(System.in);
        String recv = null; // 서버에서 받은 메시지
        String send = null; // 서버로 보낼 메시지

        // 4. 채팅 시작 (q 입력 시 종료)
        while (true) {
            // 4-1. 서버 메시지 수신
            recv = din.readUTF();
            if (recv.equals("q")) {
                break;
            }
            System.out.println("[SERVER (q:종료)] :" + recv);

            // 4-2. 클라이언트 메시지 입력 및 전송
            System.out.print("[CLIENT] : ");
            send = sc.nextLine();
            if (send.equals("q")) {
                break;
            }
            dout.writeUTF(send);
            dout.flush();
        }

        // 5. 자원 해제 및 종료
        din.close();
        dout.close();
        in.close();
        out.close();
        client.close();
        sc.close();
        System.out.println("[CLIENT] 연결 종료합니다.");
    }
}
```

## 🔎 주요 코드 분석

### 1️⃣ **클라이언트 소켓 생성**

```java
Socket client = new Socket("192.168.16.70", 7000);
```

- **서버 IP** (`192.168.16.70`)와 **포트** (`7000`)에 연결
- `Socket` 객체 생성 후 **자동으로 서버와 연결 요청**
- **서버가 실행 중이어야 정상적으로 연결 가능**

---

### 2️⃣ **입출력 스트림 생성**

```java
OutputStream out = client.getOutputStream();
DataOutputStream dout = new DataOutputStream(out);
InputStream in = client.getInputStream();
DataInputStream din = new DataInputStream(in);
```

- **데이터 송수신을 위한 스트림 생성**
- `DataInputStream` → **서버에서 데이터 읽기**
- `DataOutputStream` → **서버로 데이터 보내기**

---

### 3️⃣ **채팅 루프 (`while` 반복문)**

```java
while (true) {
    // 서버에서 메시지 수신
    recv = din.readUTF();
    if (recv.equals("q")) {
        break;
    }
    System.out.println("[SERVER (q:종료)] :" + recv);

    // 클라이언트 메시지 입력 및 전송
    System.out.print("[CLIENT] : ");
    send = sc.nextLine();
    if (send.equals("q")) {
        break;
    }
    dout.writeUTF(send);
    dout.flush();
}
```

- **서버 메시지 수신** (`readUTF()`)
- **클라이언트가 입력한 메시지 전송** (`writeUTF()`)
- **"q" 입력 시 종료** (`break`)

---

### 4️⃣ **자원 해제 및 종료**

```java
din.close();
dout.close();
in.close();
out.close();
client.close();
sc.close();
System.out.println("[CLIENT] 연결 종료합니다.");
```

- **모든 스트림과 소켓 닫기**
- **`close()`를 호출하여 메모리 누수 방지**
