### 📌 Java 소켓 프로그래밍 (클라이언트)

## 📌 주요 개념

- **소켓(Socket) 통신**: 네트워크에서 데이터를 송수신하는 기술
- **TCP 연결**: `Socket` 클래스를 사용하여 서버에 접속
- **데이터 스트림**: `DataInputStream`을 이용하여 서버로부터 문자열 수신

---

## 💻 공부 코드

```java
package Ch22;

import java.io.DataInputStream;
import java.io.IOException;
import java.io.InputStream;
import java.net.Socket;
import java.net.UnknownHostException;

public class C01Client {
    public static void main(String[] args) throws UnknownHostException, IOException {
        
        // 1. 서버에 연결 (IP: 192.168.16.203, 포트: 7000)
        Socket client = new Socket("192.168.16.203", 7000);
        
        // 2. 입력 스트림 생성
        InputStream in = client.getInputStream();
        DataInputStream din = new DataInputStream(in);
        
        // 3. 서버로부터 메시지 수신
        String recv = din.readUTF();
        System.out.println("서버로부터 받은 메시지: " + recv);
        
        // 4. 리소스 정리 (스트림 & 소켓 닫기)
        din.close();
        in.close();
        client.close();
    }
}
```

---

## 🔎 주요 코드 분석

### 1️⃣ **클라이언트 소켓 생성**

```java
Socket client = new Socket("192.168.16.203", 7000);
```

- **서버의 IP (`192.168.16.203`)와 포트 (`7000`)에 연결**
- `Socket` 객체를 생성하면 자동으로 서버와 연결을 시도함
- **서버가 실행 중이어야 정상 연결 가능**

---

### 2️⃣ **입력 스트림 생성**

```java
InputStream in = client.getInputStream();
DataInputStream din = new DataInputStream(in);
```

- **서버에서 데이터를 받을 수 있도록 `InputStream` 생성**
- **`DataInputStream`**을 사용하여 UTF-8 형식으로 데이터를 읽음

---

### 3️⃣ **데이터 수신**

```java
String recv = din.readUTF();
System.out.println("서버로부터 받은 메시지: " + recv);
```

- **서버에서 전송한 데이터를 `UTF-8` 형식으로 읽어와 출력**

---

### 4️⃣ **리소스 해제**

```java
din.close();
in.close();
client.close();
```

- **스트림과 소켓을 닫아 자원 해제**
- **안전한 네트워크 종료를 위해 반드시 수행해야 함**

---

## ✅ 실행 흐름

### 🔹 클라이언트 실행 시

1. **서버에 연결** (`Socket client = new Socket(...)`)
2. **서버에서 메시지 수신** (`readUTF()`)
3. **수신한 메시지 출력**
4. **연결 종료**

---

## ✅ 핵심 정리

1️⃣ **소켓 연결**

- `Socket(IP, PORT)` → 서버와 연결을 생성

2️⃣ **데이터 수신**

- `getInputStream()` → 서버에서 데이터를 읽어옴
- `readUTF()` → UTF-8 형식으로 수신

3️⃣ **자원 해제**

- `close()`를 사용하여 스트림과 소켓을 닫음
