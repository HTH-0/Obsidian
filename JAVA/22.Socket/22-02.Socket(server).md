### 📌 Java 소켓 프로그래밍 (서버)

## 📌 주요 개념

- **소켓 서버 (ServerSocket)**: 클라이언트의 요청을 받아들이는 역할
- **TCP 통신**: `accept()`를 통해 클라이언트 연결 수락
- **출력 스트림**: `DataOutputStream`을 이용하여 클라이언트에게 메시지 전송

---

## 💻 공부 코드

```java
package Ch22;

import java.io.DataOutputStream;
import java.io.IOException;
import java.io.OutputStream;
import java.net.ServerSocket;
import java.net.Socket;

public class C01Server {
    public static void main(String[] args) throws IOException {
        
        // 1. 서버 소켓 생성 (포트 7000)
        ServerSocket server = new ServerSocket(7000);
        System.out.println("[INFO] SERVER SOCKET LISTENING");
        
        // 2. 클라이언트 연결 대기
        Socket client = server.accept();
        System.out.println("[INFO] CLIENT CONNECTED");

        // 3. 출력 스트림 생성
        OutputStream out = client.getOutputStream();
        DataOutputStream dout = new DataOutputStream(out);

        // 4. 클라이언트에게 메시지 전송
        dout.writeUTF("[INFO] WELCOME SERVER");

        // 5. 자원 해제
        dout.flush();
        dout.close();
        out.close();
        client.close();
        server.close();

        System.out.println("서버 종료");
    }
}
```

---

## 🔎 주요 코드 분석

### 1️⃣ **서버 소켓 생성**

```java
ServerSocket server = new ServerSocket(7000);
System.out.println("[INFO] SERVER SOCKET LISTENING");
```

- **포트 `7000`에서 클라이언트 요청을 대기**
- `ServerSocket` 객체를 생성하면 **연결 요청을 받을 준비 상태**

---

### 2️⃣ **클라이언트 연결 대기**

```java
Socket client = server.accept();
System.out.println("[INFO] CLIENT CONNECTED");
```

- `accept()` 메서드는 **클라이언트의 연결 요청을 수락**
- 클라이언트가 연결될 때까지 **대기 상태** (Blocking)

---

### 3️⃣ **출력 스트림 생성**

```java
OutputStream out = client.getOutputStream();
DataOutputStream dout = new DataOutputStream(out);
```

- **클라이언트에게 데이터를 전송할 `OutputStream` 생성**
- `DataOutputStream`을 사용하여 문자열을 UTF-8 형식으로 전송

---

### 4️⃣ **클라이언트에게 메시지 전송**

```java
dout.writeUTF("[INFO] WELCOME SERVER");
```

- 클라이언트에게 **"[INFO] WELCOME SERVER"** 메시지 전송
- 클라이언트는 `readUTF()`를 사용하여 수신 가능

---

### 5️⃣ **자원 해제 (서버 종료)**

```java
dout.flush();
dout.close();
out.close();
client.close();
server.close();
System.out.println("서버 종료");
```

- **`flush()`**: 출력 버퍼 비우기
- **`close()`**: 스트림과 소켓 해제 (서버 정상 종료)

---

## ✅ 실행 흐름

### 🔹 서버 실행 시

1. `ServerSocket`이 포트 `7000`에서 클라이언트 요청 대기
2. 클라이언트가 접속하면 `accept()`로 연결
3. 클라이언트에게 `WELCOME SERVER` 메시지 전송
4. 연결 종료

---

## ✅ 핵심 정리

1️⃣ **서버 소켓 생성**

- `ServerSocket(PORT)`: 특정 포트에서 클라이언트 요청을 대기

2️⃣ **클라이언트 연결 대기**

- `accept()`: 클라이언트의 연결 요청을 받아들임

3️⃣ **데이터 송신**

- `writeUTF()`: 클라이언트에게 UTF-8 형식 메시지 전송

4️⃣ **자원 해제**

- `close()`: 소켓과 스트림을 닫아 서버 종료
