# 📝 Java 메서드 오버로딩 (Method Overloading)

## 📌 내용

- **메서드 오버로딩** 개념 학습
- **동일한 메서드명**을 사용하지만 **매개변수 타입, 개수**가 다름
- **자동 형변환**으로 인해 의도치 않은 동작 가능성 존재

---

## 💻 코드 정리

```java
package Ch08;

class C06Simple {
    
    int sum(int x, int y) {
        System.out.println("int sum(int x, int y)");
        return x + y;
    }

    int sum(int x, int y, int z) {
        System.out.println("int sum(int x, int y, int z)");
        return x + y + z;
    }

    int sum(double x, double y, double z) {
        System.out.println("int sum(double x, double y, double z)");
        return (int) (x + y + z);
    }
}

public class C06MethodOverloadingMain {
    public static void main(String[] args) {
        
        C06Simple s1 = new C06Simple();
        
        s1.sum(10, 20);
        s1.sum(10, 20, 30);
        s1.sum(10.5, 20.5, 30.5);
        
        C06Simple s2 = new C06Simple(); 
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **메서드 오버로딩의 정의**

- **오버로딩 (Overloading)**:  
    동일한 이름의 메서드를 **매개변수의 타입, 개수**를 다르게 하여 여러 개 정의하는 기법
- 반환형은 오버로딩과 **무관**함 (반환형만 다르면 오버로딩 불가능)

### 2️⃣ **오버로딩된 `sum()` 메서드**

#### 📌 `sum(int, int)`

```java
int sum(int x, int y) {
    System.out.println("int sum(int x, int y)");
    return x + y;
}
```

- **정수 2개를 입력받아 합산 후 반환**
- 호출 예: `s1.sum(10, 20)`

#### 📌 `sum(int, int, int)`

```java
int sum(int x, int y, int z) {
    System.out.println("int sum(int x, int y, int z)");
    return x + y + z;
}
```

- **정수 3개를 입력받아 합산 후 반환**
- 호출 예: `s1.sum(10, 20, 30)`

#### 📌 `sum(double, double, double)`

```java
int sum(double x, double y, double z) {
    System.out.println("int sum(double x, double y, double z)");
    return (int)(x + y + z);
}
```

- **실수 3개를 입력받아 합산 후 정수로 변환하여 반환**
- `return (int) (x + y + z);` → 소수점 이하 버림 (정수 캐스팅)
- 호출 예: `s1.sum(10.5, 20.5, 30.5)`

## 🔎 실행 결과 (출력)

```
int sum(int x, int y)
int sum(int x, int y, int z)
int sum(double x, double y, double z)
```

---

## ⚠️ 주의할 점

1️⃣ **반환형만 다르면 오버로딩이 아님**

```java
int sum(int x, int y) {...}
double sum(int x, int y) {...} // ❌ 오버로딩 불가
```

2️⃣ **자동 형변환으로 인해 예기치 않은 동작 가능**

- `s1.sum(10.5, 20.5, 30.5);`  
    → `sum(double, double, double)` 호출 후 정수 변환 발생
