## 📌 주요 개념 정리

### 1️⃣ **객체(Object)란?**

- 현실 세계에서 존재하는 사물
- **객체의 구성 요소**
    - **속성(Attributes):** 객체가 가지고 있는 데이터
    - **기능(Methods):** 객체가 수행할 수 있는 동작

---

### 2️⃣ **객체 지향 프로그래밍(OOP) 개념**

- 현실 세계의 객체 정보를 **추출(추상화, Abstraction)** 하여  
    필요한 속성과 기능을 코드로 구현
- OOP의 **핵심 개념**
    - **캡슐화(Encapsulation)**
    - **상속(Inheritance)**
    - **다형성(Polymorphism)**
    - **추상화(Abstraction)**

---

### 3️⃣ **클래스(Class)란?**

- 동일한 종류의 객체를 생성하기 위한 **템플릿(설계도)**
- **특징:**
    - 메모리를 직접 차지하지 않음
    - 객체를 생성해야만 메모리에 할당됨

```java
// 클래스 예시
class Car {
    String model;
    int speed;

    void drive() {
        System.out.println(model + " is driving.");
    }
}
```

---

### 4️⃣ **자바의 메모리 영역**

|메모리 영역|설명|
|---|---|
|**스택(Stack)**|`{}` 블록 내에서 생성되고 소멸되는 지역 변수 저장 (`int, double`)|
|**힙(Heap)**|`new` 키워드로 생성된 **객체(인스턴스) 저장 영역**|
|**메서드(Method) 영역**|공유 메모리 (`static 변수, static 메서드, 생성자, 일반 메서드`)|

---

### 5️⃣ **객체 생성 과정**

```java
Scanner sc = new Scanner(System.in);
```

- `new` → **힙(Heap) 영역에 Scanner 객체 생성**
- `Scanner()` → **생성자 호출 (초기화 진행)**
- `sc` → **Stack에 참조 변수 생성 (Heap의 객체 주소 저장)**

📌 **결과:**

- `sc`는 실제 객체가 아니라, **Heap에 있는 객체의 시작 주소를 저장**

---

## 📌 코드 예제 - 객체 생성 및 메모리 구조 확인

```java
class Car {
    String model;
    int speed;

    // 생성자 (초기화 메서드)
    Car(String model, int speed) {
        this.model = model;
        this.speed = speed;
    }

    void drive() {
        System.out.println(model + " is driving at " + speed + " km/h.");
    }
}

public class Main {
    public static void main(String[] args) {
        // 객체 생성
        Car myCar = new Car("Tesla", 100); // new -> Heap에 저장

        // 메서드 호출
        myCar.drive();
    }
}
```
