# 📝 Java 메서드 활용 예제 (`MethodTest` 클래스)

## 📌 내용

- **메서드 정의 및 호출** 학습
- 매개변수 및 반환값이 있는/없는 메서드 구현
- `Scanner` 객체를 이용한 사용자 입력 처리

---

## 💻 코드 정리

```java
package Ch08;

import java.util.Scanner;

class MethodTest {

    // Scanner 객체 생성
    Scanner sc = new Scanner(System.in);

    // 1️⃣ 매개변수 2개, 반환값 있음
    public int sum1(int n1, int n2) {
        return n1 + n2;
    }

    // 2️⃣ 매개변수 없음, 반환값 있음 (사용자 입력 활용)
    public int sum2() {
        return sc.nextInt() + sc.nextInt();
    }

    // 3️⃣ 매개변수 2개, 반환값 없음 (즉시 출력)
    public void sum3(int n1, int n2) {
        System.out.println(n1 + n2);
    }

    // 4️⃣ 매개변수 없음, 반환값 없음 (사용자 입력 후 즉시 출력)
    public void sum4() {
        System.out.println(sc.nextInt() + sc.nextInt());
    }
}

public class C05MethodMain {
    public static void main(String[] args) {
        MethodTest t1 = new MethodTest();
        
        System.out.println(t1.sum1(10, 20));  // 30 출력
        System.out.println(t1.sum2());       // 사용자 입력 두 개 받아 합 출력
        t1.sum3(10, 20);                     // 30 출력 (반환값 없음)
        t1.sum4();                           // 사용자 입력 두 개 받아 합 출력 (반환값 없음)
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **`sum1(int, int)` - 매개변수 있음, 반환값 있음**

```java
public int sum1(int n1, int n2) {
    return n1 + n2;
}
```

- 두 개의 정수를 받아 합을 반환하는 메서드
- 호출 예: `t1.sum1(10, 20)` → `30` 반환

### 2️⃣ **`sum2()` - 매개변수 없음, 반환값 있음**

```java
public int sum2() {
    return sc.nextInt() + sc.nextInt();
}
```

- `Scanner`를 이용해 사용자 입력을 두 개 받아 합산 후 반환
- 호출 예: `t1.sum2();` (입력값이 5, 10이면 `15` 반환)

### 3️⃣ **`sum3(int, int)` - 매개변수 있음, 반환값 없음**

```java
public void sum3(int n1, int n2) {
    System.out.println(n1 + n2);
}
```

- 두 개의 정수를 받아 즉시 출력
- 반환값 없음 (`void`)
- 호출 예: `t1.sum3(10, 20);` → `30` 출력

### 4️⃣ **`sum4()` - 매개변수 없음, 반환값 없음**

```java
public void sum4() {
    System.out.println(sc.nextInt() + sc.nextInt());
}
```

- 사용자 입력을 두 개 받아 합산 후 즉시 출력
- 반환값 없음 (`void`)
- 호출 예: `t1.sum4();` (입력값이 7, 8이면 `15` 출력)

## 🔎 추가 정보

### ✅ **메서드의 반환 유형 차이**

|메서드|매개변수|반환값|동작 방식|
|---|---|---|---|
|`sum1(int, int)`|O|O|두 수의 합을 반환|
|`sum2()`|X|O|사용자 입력 두 개를 합산 후 반환|
|`sum3(int, int)`|O|X|두 수의 합을 즉시 출력|
|`sum4()`|X|X|사용자 입력 두 개를 합산 후 즉시 출력|

- **반환값이 있는 경우 (`return`)** → 연산 결과를 다른 곳에서 활용 가능
- **반환값이 없는 경우 (`void`)** → 직접 `System.out.println()`으로 출력
