# 📝 클래스와 객체 - `C03Person` 예제

## 📌 내용

- **클래스 선언과 객체 생성**
- **객체의 속성(멤버 변수) 및 기능(메서드) 활용**
- **`toString()` 메서드 오버라이딩 활용**

---

## 💻 코드 정리

```java
package Ch08;

class C03Person {
    // 속성 (멤버 변수)
    String name;
    int age;
    float height;
    double weight;

    // 기능 (메서드)
    void talk() {
        System.out.printf("%s 님이 말합니다\n", this.name);
    }

    void walk() {
        System.out.printf("%s 님이 걷습니다\n", this.name);
    }

    // 속성 정보 출력
    void showInfo() {
        System.out.printf("%s %d %.2f %.2f\n", this.name, this.age, this.height, this.weight);
    }

    // 객체 정보 출력 (toString() 오버라이딩)
    @Override
    public String toString() {
        return "C03Person [name=" + name + ", age=" + age + ", height=" + height + ", weight=" + weight + "]";
    }
}

public class C03PersonMain {
    public static void main(String[] args) {
        // 객체 생성
        C03Person hong = new C03Person();

        // 속성 값 설정
        hong.name = "홍길동";
        hong.age = 15;
        hong.height = 177.5F;
        hong.weight = 70.5;

        // 메서드 호출
        hong.talk();
        hong.walk();
        hong.showInfo();

        // 객체 정보 출력 (toString 활용)
        System.out.println(hong.toString());
        System.out.println(hong); // toString()이 재정의되었기 때문에 자동 호출
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **클래스 `C03Person` 속성 정의**

```java
String name;
int age;
float height;
double weight;
```

- `name` → 문자열 (이름)
- `age` → 정수형 (나이)
- `height` → 실수형 (키)
- `weight` → 실수형 (몸무게)

✅ **객체의 속성(멤버 변수)은 `C03Person` 인스턴스가 생성될 때 메모리에 할당됨**

---

### 2️⃣ **메서드 정의**

#### 🔹 `talk()`, `walk()`

```java
void talk() {
    System.out.printf("%s 님이 말합니다\n", this.name);
}
void walk() {
    System.out.printf("%s 님이 걷습니다\n", this.name);
}
```

- `this.name`을 활용하여 현재 객체의 `name` 속성값을 사용

✅ **객체의 기능(메서드)은 객체가 수행할 동작을 정의**

#### 🔹 `showInfo()`

```java
void showInfo() {
    System.out.printf("%s %d %.2f %.2f\n", this.name, this.age, this.height, this.weight);
}
```

- 객체의 모든 속성을 출력하는 메서드
- `%.2f`를 사용해 `height`, `weight`를 **소수점 2자리까지 출력**

---

### 3️⃣ **객체 정보 확인 (`toString()` 오버라이딩)**

```java
@Override
public String toString() {
    return "C03Person [name=" + name + ", age=" + age + ", height=" + height + ", weight=" + weight + "]";
}
```

- `toString()`을 재정의하여 객체 정보를 문자열로 반환
- `System.out.println(hong);` 호출 시 자동으로 `toString()` 실행

✅ **객체의 정보를 쉽게 출력할 수 있도록 `toString()` 오버라이딩을 활용**

---

### 4️⃣ **객체 생성 및 사용 (`C03PersonMain`)**

```java
C03Person hong = new C03Person();
hong.name = "홍길동";
hong.age = 15;
hong.height = 177.5F;
hong.weight = 70.5;
```

- `new C03Person();` → **객체 생성 (Heap 메모리에 저장)**
- 속성 값 설정

---

### 5️⃣ **객체 메서드 호출**

```java
hong.talk();
hong.walk();
hong.showInfo();
```

- 객체의 기능을 실행하여 **출력 결과 생성**

```java
System.out.println(hong.toString());
System.out.println(hong);
```

- `toString()`을 재정의했기 때문에 `System.out.println(hong);` 만으로 객체 정보 출력
