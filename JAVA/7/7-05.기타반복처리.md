# 📝 기타 반복 처리

## 📌 내용

- `List` 컬렉션을 사용하여 데이터를 저장
- 다양한 반복문 (`for`, `for-each`, `Stream forEach`)을 이용한 데이터 출력

---

## 💻 코드 정리

```java
package Ch07;

import java.util.List;
import java.util.ArrayList;

public class C05기타반복처리 {
    public static void main(String[] args) {
        
        // List 컬렉션 생성 및 데이터 추가
        List<String> lists = new ArrayList<String>();
        lists.add("JAVA");
        lists.add("JSP/SERVLET");
        lists.add("SPRING STS");
        lists.add("SPRINGBOOT");
        lists.add("REACT");
        lists.add("ORACLE");
        
        // 1️⃣ 일반 for문
        for (int i = 0; i < lists.size(); i++) {
            System.out.println(lists.get(i));
        }

        System.out.println("---------------------");

        // 2️⃣ 향상된 for문 (for-each)
        for (String subject : lists) {
            System.out.println(subject);
        }

        System.out.println("---------------------");

        // 3️⃣ Stream API의 forEach 메서드
        lists.stream().forEach((item) -> {
            System.out.println(item);
        });
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **일반 for문**

```java
for (int i = 0; i < lists.size(); i++) {
    System.out.println(lists.get(i));
}
```

- 인덱스를 활용해 `List`의 요소를 하나씩 출력
- `lists.get(i)`를 사용하여 직접 요소 접근

✅ **장점:**

- 인덱스를 활용할 수 있어 `i` 값을 조작하거나 특정 범위만 순회할 때 유용

⚠️ **단점:**

- `size()`를 계속 호출해야 하므로 비효율적일 수 있음
- 인덱스를 관리해야 하는 번거로움

---

### 2️⃣ **향상된 for문 (for-each)**

```java
for (String subject : lists) {
    System.out.println(subject);
}
```

- 컬렉션을 직접 순회하며 요소를 하나씩 꺼내 사용
- 인덱스 없이 `List`의 요소를 접근 가능

✅ **장점:**

- 코드가 간결하고 가독성이 높음
- `size()`를 따로 호출할 필요 없음

⚠️ **단점:**

- 인덱스를 직접 조작할 수 없음
- `break`나 `continue`를 활용할 경우 일반 `for`문보다 유연성이 떨어짐

---

### 3️⃣ **Stream API의 `forEach()`**

```java
lists.stream().forEach((item) -> {
    System.out.println(item);
});
```

- `Stream`을 활용해 `forEach()`를 실행
- 람다식 `((item) -> { System.out.println(item); })`을 사용하여 리스트의 각 요소를 출력

✅ **장점:**

- **병렬 처리 가능** (`parallelStream()` 사용 시 성능 향상)
- **메서드 참조** (`System.out::println`) 사용 가능 → `lists.forEach(System.out::println);`

⚠️ **단점:**

- 단순 출력에는 적합하지만, 인덱스를 직접 활용할 수 없음
- 실행 순서를 보장하지 않음 (`parallelStream()` 사용 시)
