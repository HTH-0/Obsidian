# 📝 Java 멀티스레드 동기화 문제

## 📌 내용

- 멀티스레드 환경에서 **공유 변수 사용 문제**
- `counter++` 연산이 스레드 간 충돌(레이스 컨디션) 발생 가능
- `synchronized` 또는 `AtomicInteger`를 사용하여 해결 가능

---

## 💻 문제 코드

```java
class IncrementThread implements Runnable {
    private static int counter = 0;  // 공유 변수

    public int getCounter() {
        return counter;
    }

    @Override
    public void run() {
        for (int i = 0; i < 100000; i++) {
            counter++;  // 공유 변수 증가 (레이스 컨디션 발생 가능)
            System.out.println(Thread.currentThread().getName() + " counter : " + counter);
        }
    }
}

public class C04ThreadMain_Ex {
    public static void main(String[] args) throws InterruptedException {
        IncrementThread incrementThread1 = new IncrementThread();
        IncrementThread incrementThread2 = new IncrementThread();
        IncrementThread incrementThread3 = new IncrementThread();
        IncrementThread incrementThread4 = new IncrementThread();

        Thread thread1 = new Thread(incrementThread1);
        Thread thread2 = new Thread(incrementThread2);
        Thread thread3 = new Thread(incrementThread3);
        Thread thread4 = new Thread(incrementThread4);

        thread1.setName("TH1");
        thread2.setName("TH2");
        thread3.setName("TH3");
        thread4.setName("TH4");

        thread1.start();
        thread2.start();
        thread3.start();
        thread4.start();

        thread1.join();
        thread2.join();
        thread3.join();
        thread4.join();

        System.out.println("Final value: " + incrementThread1.getCounter());
    }
}
```

---

## 🔎 문제 분석

### 1️⃣ **레이스 컨디션 발생**

- `counter++` 연산은 **비원자적 연산** (읽기 → 증가 → 저장 과정 포함)
- 여러 스레드가 동시에 실행되면 **값이 덮어씌워지는 문제 발생 가능**
- `Final value`가 예상보다 작거나, 실행마다 값이 다르게 나올 수 있음

### 2️⃣ **잘못된 객체 생성**

- `IncrementThread`의 여러 객체를 생성했지만, `counter`는 `static` 변수
- 모든 `Thread`가 **각기 다른 `IncrementThread` 객체를 사용**하지만,  
    **하나의 `counter` 값을 공유** → 동기화 문제 발생

---

## 🔧 해결 방법

### ✅ **방법 1: `synchronized` 사용 (동기화 블록)**

```java
class IncrementThread implements Runnable {
    private static int counter = 0;

    public synchronized void increment() {  // 동기화 적용
        counter++;
    }

    public int getCounter() {
        return counter;
    }

    @Override
    public void run() {
        for (int i = 0; i < 100000; i++) {
            increment();  // 동기화된 메서드 호출
        }
    }
}
```

- `increment()` 메서드를 `synchronized`로 설정하여 **한 번에 하나의 스레드만 접근 가능**
- **성능 저하 가능성 있음** (다중 스레드 환경에서 병목 발생)

---

### ✅ **방법 2: `AtomicInteger` 사용 (CAS 기반 동기화)**

```java
import java.util.concurrent.atomic.AtomicInteger;

class IncrementThread implements Runnable {
    private static AtomicInteger counter = new AtomicInteger(0);

    public int getCounter() {
        return counter.get();
    }

    @Override
    public void run() {
        for (int i = 0; i < 100000; i++) {
            counter.incrementAndGet();  // 원자적 증가 연산
        }
    }
}
```

- `AtomicInteger`를 사용하면 내부적으로 **CAS(Compare-And-Swap) 연산**을 사용하여 동기화 문제 해결
- **성능이 더 좋음** (스레드 대기 없이 비동기적으로 연산 가능)

## 🔥 핵심 정리

- **멀티스레드 환경에서 공유 변수 사용 시 동기화 필요**
- `synchronized`를 사용하면 간단하지만 **성능 저하 가능성**
- `AtomicInteger`를 사용하면 **보다 효율적인 동기화 가능**
- `counter++` 같은 비원자적 연산을 멀티스레드 환경에서 직접 사용하면 **레이스 컨디션 발생** 가능
