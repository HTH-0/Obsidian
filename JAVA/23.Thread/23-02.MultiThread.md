# 📝 Java GUI + 멀티스레드 프로그래밍

## 📌 내용

- `Swing`을 활용한 GUI 프로그램 개발
- `JButton`, `JTextArea`, `JTextField`를 활용한 이벤트 처리
- `Runnable` 인터페이스를 이용한 멀티스레드 적용
- `interrupt()`를 활용한 스레드 종료

## 💻 공부 코드

### 1️⃣ **GUI 메인 클래스 (`C03SwingMain`)**

```java
package Ch23;

import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;
import java.awt.event.KeyEvent;
import java.awt.event.KeyListener;
import javax.swing.*;

class C03GUI extends JFrame implements ActionListener, KeyListener {
    JButton btn1, btn2, btn3, btn4;
    JTextField txt1;
    JTextArea area1, area2;
    Thread th1, th2;

    C03GUI() {
        super();
        setTitle("THREAD 확인하기");

        JPanel pan1 = new JPanel();
        btn1 = new JButton("시작");
        btn2 = new JButton("중지");
        btn3 = new JButton("시작");
        btn4 = new JButton("중지");
        txt1 = new JTextField();
        area1 = new JTextArea();
        area2 = new JTextArea();
        JScrollPane scroll1 = new JScrollPane(area1);
        JScrollPane scroll2 = new JScrollPane(area2);

        scroll1.setBounds(50, 50, 190, 280);
        scroll2.setBounds(300, 50, 190, 280);
        txt1.setBounds(50, 350, 190, 30);
        btn1.setBounds(50, 400, 80, 30);
        btn2.setBounds(160, 400, 80, 30);
        btn3.setBounds(300, 400, 80, 30);
        btn4.setBounds(410, 400, 80, 30);

        btn1.addActionListener(this);
        btn2.addActionListener(this);
        btn3.addActionListener(this);
        btn4.addActionListener(this);
        txt1.addKeyListener(this);

        area1.setEditable(false);
        pan1.add(btn1); pan1.add(btn2);
        pan1.add(btn3); pan1.add(btn4);
        pan1.add(txt1); pan1.add(scroll1);
        pan1.add(scroll2);
        pan1.setLayout(null);

        add(pan1);
        setBounds(100, 100, 600, 500);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setResizable(false);
        setVisible(true);
    }

    @Override
    public void actionPerformed(ActionEvent e) {
        if (e.getSource() == btn1) {
            System.out.println("btn1..clicked");
            C03Worker1 w1 = new C03Worker1(this);
            th1 = new Thread(w1);
            th1.start();
        }
        if (e.getSource() == btn2 && th1 != null) {
            System.out.println("btn2..clicked");
            th1.interrupt();
            th1 = null;
        }
        if (e.getSource() == btn3) {
            System.out.println("btn3..clicked");
            C03Worker2 w2 = new C03Worker2(this);
            th2 = new Thread(w2);
            th2.start();
        }
        if (e.getSource() == btn4 && th2 != null) {
            System.out.println("btn4..clicked");
            th2.interrupt();
            th2 = null;
        }
    }

    @Override
    public void keyPressed(KeyEvent e) {
        if (e.getKeyCode() == KeyEvent.VK_ENTER) {
            String tmp = txt1.getText();
            area1.append(tmp + "\n");
            txt1.setText("");
        }
    }

    @Override public void keyTyped(KeyEvent e) {}
    @Override public void keyReleased(KeyEvent e) {}
}

public class C03SwingMain {
    public static void main(String[] args) {
        new C03GUI();
    }
}
```

### 2️⃣ **스레드 클래스 (`C03Worker1`, `C03Worker2`)**

```java
package Ch23;

public class C03Worker1 implements Runnable {
    C03GUI gui;

    C03Worker1(C03GUI gui) {
        this.gui = gui;
    }

    @Override
    public void run() {
        while (true) {
            try {
                gui.area1.append("WORKER01... \n");
                Thread.sleep(500);
            } catch (InterruptedException e) {
                System.out.println("WORKER01 INTERRUPTED...");
                break;
            }
        }
    }
}
```

## 🔎 주요 개념

### 1️⃣ **Swing 기반 GUI 구현**

- `JFrame`을 상속하여 GUI 창 생성
- `JButton`, `JTextArea`, `JTextField` 등을 배치
- `ActionListener`, `KeyListener`를 구현하여 이벤트 처리

### 2️⃣ **멀티스레드 적용**

- `Runnable` 인터페이스를 구현한 `C03Worker1`, `C03Worker2` 클래스에서 `Thread.sleep(500)`을 통해 반복 실행
- `interrupt()`를 사용하여 스레드 안전하게 종료

### 3️⃣ **GUI와 스레드 연동**

- `C03Worker1`, `C03Worker2`는 `C03GUI`의 참조를 받아 `JTextArea`에 데이터 추가
- `btn1`, `btn3` 클릭 시 스레드 시작, `btn2`, `btn4` 클릭 시 `interrupt()` 호출하여 중지

## 🔎 실행 결과 예상

### **버튼 클릭 시 동작**

1. `btn1 (시작)` 클릭 → `WORKER01...`이 `area1`에 반복 출력
2. `btn2 (중지)` 클릭 → `WORKER01 INTERRUPTED...` 출력 후 스레드 종료
3. `btn3 (시작)` 클릭 → `WORKER02...`이 `area2`에 반복 출력
4. `btn4 (중지)` 클릭 → `WORKER02 INTERRUPTED...` 출력 후 스레드 종료
5. `Enter` 키 입력 시 `txt1`의 입력값이 `area1`에 추가
