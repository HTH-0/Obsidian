# 📝 Java 스트림(Stream)을 이용한 데이터 처리 예제

## 📌 내용

- **Stream의 중개 연산** (`filter`, `map`, `sorted`)과 **최종 연산**(`collect`, `forEach`) 사용
- 람다 표현식 및 메서드 참조(`::`) 활용으로 코드 간결화
- 컬렉션(List)에 포함된 객체 데이터 처리 및 변환

---

## 💡 주요 개념

- **메서드 참조(Method Reference)**
    
    - 메서드를 간결하게 표현할 수 있는 문법
    
    ```java
    클래스명::메서드명
    객체명::메서드명
    ```
    
- **스트림 중개 연산**
    
    - `filter`: 조건에 따른 요소 필터링
    - `map`: 요소 변환
    - `sorted`: 정렬 처리
- **스트림 최종 연산**
    
    - `collect`: 처리된 스트림을 컬렉션으로 반환
    - `forEach`: 스트림 요소를 개별적으로 처리

## 💻 공부 코드 정리

```java
import java.util.*;
import java.util.stream.*;

class Person {
	private String name;
	private int age;

	Person(String name, int age) {
		this.name = name;
		this.age = age;
	}

	public int getAge() { return age; }
	public String getName() { return name; }

	@Override
	public String toString() {
		return "이름 : " + name + ", 나이 : " + age;
	}
}

class Employee extends Person {
	String company, department, role;

	public Employee(Person person) {
		super(person.getName(), person.getAge());
	}

	public void setCompany(String company){ this.company = company; }
	public void setDepartment(String department){ this.department = department; }
	public void setRole(String role){ this.role = role; }

	@Override
	public String toString() {
		return "Employee [이름=" + getName() + ", 나이=" + getAge() +
			   ", 회사=" + company + ", 부서=" + department + ", 직책=" + role + "]";
	}
}

public class C01StreamMain {
	public static void main(String[] args) {
		List<Integer> nums = Arrays.asList(1, 2, 3, 4, 5);

		// filter로 짝수 선택
		List<Integer> evens = nums.stream()
			.filter(item -> item % 2 == 0)
			.collect(Collectors.toList());

		System.out.println("짝수 필터링: " + evens);

		// filter와 map을 이용하여 짝수의 제곱 처리
		List<Integer> squares = nums.stream()
			.filter(item -> item % 2 == 0)
			.map(item -> item * item)
			.collect(Collectors.toList());

		System.out.println("짝수 제곱: " + squares);

		// Person 객체 리스트 생성
		List<Person> persons = Arrays.asList(
			new Person("홍길동", 55),
			new Person("남길동동", 45),
			new Person("서길길동동", 35),
			new Person("동덩길길동동", 25)
		);

		// 나이 역순으로 정렬
		List<Integer> agesDesc = persons.stream()
			.map(Person::getAge)
			.sorted((a, b) -> b - a)
			.collect(Collectors.toList());

		System.out.println("나이 내림차순: " + agesDesc);

		// 이름 길이를 오름차순 정렬
		List<Integer> nameLengths = persons.stream()
			.map(Person::getName)
			.map(String::length)
			.sorted()
			.collect(Collectors.toList());

		System.out.println("이름 길이 오름차순: " + nameLengths);

		// Person → Employee 객체 변환
		List<Employee> employees = persons.stream()
			.map(Employee::new)
			.collect(Collectors.toList());

		employees.forEach(System.out::println);
	}
}
```

---

## 🔎 코드 분석 (단계별)

### 1️⃣ **filter**로 짝수만 선택

```java
.filter(item -> item % 2 == 0)
```

- 결과: `[2, 4]`

### 2️⃣ **map**으로 제곱 변환

```java
.map(item -> item * item)
```

- `[2,4] → [4,16]`

### 3️⃣ **Person 객체의 나이를 역순 정렬**

```java
.sorted((a, b) -> b - a)
```

- `[55, 45, 35, 25]`

### 4️⃣ **이름의 길이를 오름차순 정렬**

```java
.map(Person::getName).map(String::length).sorted()
```

- 이름 길이만 뽑아 오름차순으로 정렬
- 결과 예: `[3,4,5,6]`

### 5️⃣ **Person 객체 → Employee 객체 변환**

```java
.map(Employee::new)
```

- Person 객체를 Employee 객체로 변환하여 새로운 컬렉션 생성
