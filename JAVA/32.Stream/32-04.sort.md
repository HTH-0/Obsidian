# 📝 Java 스트림 정렬 - `sorted()` 사용법

## 📌 내용

- Java 스트림에서 **정렬**을 수행하는 `sorted()` 메서드 학습
- 숫자 리스트를 오름차순 정렬하여 새로운 리스트로 반환

---

## 💻 코드 정리

```java
import java.util.Arrays;
import java.util.List;
import java.util.stream.Collectors;

public class C04Sorted {
    public static void main(String[] args) {
        List<Integer> numbers2 = Arrays.asList(5, 2, 8, 1, 4);
        List<Integer> sortedNumbers = numbers2.stream()  // [[stream() (Java)]]
                                              .sorted()   // [[sorted() (Java)]]
                                              .collect(Collectors.toList()); // [[collect() (Java)]]
        System.out.println(sortedNumbers);
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ 리스트 생성

```java
List<Integer> numbers2 = Arrays.asList(5, 2, 8, 1, 4);
```

- 정렬 대상이 되는 숫자 리스트

### 2️⃣ 스트림 변환 및 정렬

```java
numbers2.stream().sorted()
```

- `stream()` → 리스트를 스트림으로 변환
- `sorted()` → 기본 정렬 기준(오름차순)으로 정렬

### 3️⃣ 리스트로 수집

```java
.collect(Collectors.toList())
```

- 정렬된 결과를 새로운 리스트로 수집하여 반환
