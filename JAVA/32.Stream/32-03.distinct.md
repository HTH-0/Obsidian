# 📝 Java 스트림(Stream) - distinct 사용법

## 📌 내용

- **`distinct()`**: 중복 요소 제거하는 스트림의 **중개 연산**
- 리스트 내 **중복 데이터 제거** 후 새로운 리스트 반환

---

## 💡 주요 개념

- **distinct() 특징**
    - 중복 제거 시 객체의 **equals()**와 **hashCode()**로 중복 여부 판단
    - 순서를 유지하면서 중복 요소만 제거

**distinct 사용 문법**

```java
.distinct()
```

---

## 💻 공부 코드 정리

```java
import java.util.*;
import java.util.stream.*;

public class C03Distinct {
	public static void main(String[] args) {

		List<Integer> list = Arrays.asList(1,2,2,3,3,3,4,5,5);
		System.out.println("원본 리스트: " + list);

		List<Integer> distinctedList = list.stream()
			.distinct()
			.collect(Collectors.toList());

		System.out.println("중복 제거 후: " + distinctedList);
	}
}
```

---

## 🔎 코드 분석 (단계별)

### 1️⃣ **리스트 생성 (중복 포함)**

```java
List<Integer> list = Arrays.asList(1,2,2,3,3,3,4,5,5);
```

- 중복 요소 존재하는 리스트 생성

### 2️⃣ **distinct()로 중복 요소 제거**

```java
.distinct()
```

- 스트림 내 중복된 요소 제거
- 최종적으로 중복되지 않는 요소만 반환

### 3️⃣ **최종 연산 - 리스트로 반환**

```java
.collect(Collectors.toList())
```

- 최종적으로 처리된 결과를 리스트 형태로 반환
