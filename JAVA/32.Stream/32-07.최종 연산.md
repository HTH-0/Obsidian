# 📝 Java 스트림 - 최종 연산 정리

## 📌 내용

- 스트림 연산 중 **최종 연산**(Terminal Operation) 학습
- `forEach`, `collect`, `reduce`, `min`, `max`, `count`, `anyMatch` 등
- 최종 연산은 **스트림을 소비하고 결과를 반환**함

---

## 💻 코드 정리

### ✅ `forEach`

```java
List<String> names = Arrays.asList("John", "Jane", "Mike");
names.stream()
     .forEach(System.out::println);  // 출력: John Jane Mike
```

- 요소를 하나씩 꺼내어 처리 (반환값 없음)
- [[forEach() (Java)]]

---

### ✅ `collect`

```java
Set<String> nameSet = names.stream()
                           .collect(Collectors.toSet());
System.out.println(nameSet);  // 출력: [John, Jane, Mike]
```

- 스트림을 Set, List 등으로 변환
- [[collect() (Java)]], [[Collectors.toSet() (Java)]]

---

### ✅ `reduce`

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
Optional<Integer> sum = numbers.stream()
                               .reduce((a, b) -> a + b);
System.out.println(sum.orElse(0));  // 출력: 15
```

- 모든 요소를 누적 연산으로 처리
- [[reduce() (Java)]]

---

### ✅ `min`, `max`

```java
Optional<Integer> minNumber = numbers.stream()
                                     .min(Comparator.naturalOrder());
System.out.println(minNumber.orElse(0));  // 출력: 1

Optional<Integer> maxNumber = numbers.stream()
                                     .max(Comparator.naturalOrder());
System.out.println(maxNumber.orElse(0));  // 출력: 8
```

- 최소/최대값 찾기
- [[min() (Java)]], [[max() (Java)]], [[Comparator.naturalOrder() (Java)]]

---

### ✅ `count`

```java
long count = numbers.stream()
                    .count();
System.out.println(count);  // 출력: 5
```

- 요소 개수 반환
- [[count() (Java)]]

---

### ✅ `anyMatch`

```java
boolean hasEvenNumber = numbers.stream()
                               .anyMatch(n -> n % 2 == 0);
System.out.println(hasEvenNumber);  // 출력: true
```

- 하나라도 조건을 만족하면 true
- [[anyMatch() (Java)]]

---
