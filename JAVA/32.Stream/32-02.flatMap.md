# 📝 Java 스트림(Stream) - flatMap 사용법

## 📌 내용

- **`flatMap()`**: 여러 개의 스트림을 하나의 스트림으로 **평면화(flatten)**하는 중개 연산
- 중첩된 리스트(`List<List<Integer>>`)의 데이터를 하나의 리스트(`List<Integer>`)로 병합

---

## 💡 주요 개념

- **flatMap()의 특징**
    - 중첩된 구조를 풀어내어 하나의 연속된 스트림으로 만들어 줌
    - `map()`과 달리 반환된 스트림을 연결하여 평면화 처리

**flatMap 사용 문법**

```java
.flatMap(Collection::stream)  
.flatMap(list -> list.stream())  
```

---

## 💻 공부 코드 정리

```java
import java.util.*;
import java.util.stream.*;

public class C02FlatMap {
	public static void main(String[] args) {

		List<List<Integer>> numbers = Arrays.asList(
			Arrays.asList(1, 2, 3),
			Arrays.asList(4, 5, 6),
			Arrays.asList(7, 8, 9)
		);

		List<Integer> flatList = numbers.stream()
			.flatMap(List::stream)
			.collect(Collectors.toList());

		System.out.println("원본 리스트(중첩): " + numbers);
		System.out.println("평면화(flatMap): " + flatList);
	}
}
```

---

## 🔎 코드 분석 (단계별)

### 1️⃣ **중첩된 리스트 구조 생성**

```java
List<List<Integer>> numbers = Arrays.asList(
	Arrays.asList(1, 2, 3),
	Arrays.asList(4, 5, 6),
	Arrays.asList(7, 8, 9)
);
```

- 리스트 안에 리스트가 있는 구조 (중첩 구조)

### 2️⃣ **flatMap으로 평면화 처리**

```java
.flatMap(List::stream)
```

- 내부 리스트를 각각의 요소로 펼쳐(flatten)서 **하나의 스트림**으로 연결
- `List::stream` 메서드 참조 활용

### 3️⃣ **최종 연산으로 리스트 반환**

```java
.collect(Collectors.toList())
```

- 처리된 결과를 최종적으로 하나의 리스트로 반환
