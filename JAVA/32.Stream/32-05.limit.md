# 📝 Java 스트림 제한 - `limit()` 사용법

## 📌 내용

- Java 스트림에서 **앞에서부터 원하는 개수만 추출**하는 `limit()` 메서드 학습
- 스트림 요소 중 앞에서 3개만 추출하여 리스트로 반환

---

## 💻 코드 정리

```java
import java.util.Arrays;
import java.util.List;
import java.util.stream.Collectors;

public class C05Limited {

    public static void main(String[] args) {
        List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
        List<Integer> limitedNumbers = numbers.stream()     // [[stream() (Java)]]
                                              .limit(3)     // [[limit() (Java)]]
                                              .collect(Collectors.toList()); // [[collect() (Java)]]
        System.out.println(limitedNumbers); // 출력: [1, 2, 3]
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ 리스트 생성

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
```

- 원본 리스트에는 5개의 정수가 들어 있음

### 2️⃣ 스트림 변환 + 제한

```java
numbers.stream().limit(3)
```

- `stream()` → 리스트를 스트림으로 변환
- `limit(3)` → 앞에서부터 3개의 요소만 추출

### 3️⃣ 리스트로 수집

```java
.collect(Collectors.toList())
```

- 제한된 결과를 새 리스트로 반환
