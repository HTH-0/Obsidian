# 📝 Java 스트림(Stream) 개념 정리

## 📌 내용

- **Java 스트림(Stream)**: 자바 8에서 도입된 데이터 처리 기능
- 컬렉션의 데이터를 쉽고 효율적으로 처리 및 변환
- **중개 연산(intermediate)**과 **최종 연산(terminal)**으로 구성

---

## 🧩 스트림 주요 연산 정리

### 🚧 중개 연산(Intermediate operations)

- 여러 개 체이닝 가능, 실제 처리 지연(lazy)

|연산|역할|
|---|---|
|`filter()` 🔥|조건으로 요소 선택 (필터링)|
|`map()` 🔥|요소를 다른 형태로 변환|
|`flatMap()`|요소를 스트림으로 평면화|
|`distinct()`|중복 요소 제거|
|`sorted()`|요소 정렬|
|`limit()`|요소 개수 제한|
|`skip()`|앞의 일부 요소 건너뜀|

### 🚩 최종 연산(Terminal operations)

- 스트림 처리의 최종 단계 (스트림 종료)

|연산|역할|
|---|---|
|`forEach()` 🔥|각 요소 반복 처리|
|`collect()` 🔥|처리 결과를 컬렉션으로 반환|
|`reduce()` 🔥|요소를 하나의 결과로 축소|
|`min()` / `max()`|최소/최대 요소 찾기|
|`count()`|요소 개수 반환|
|`anyMatch()` / `allMatch()` / `noneMatch()`|조건 일치 여부 확인|
|`findFirst()` / `findAny()`|첫 번째 또는 임의 요소 반환|

## 💻 코드 예시(핵심 코드 정리)

**중개 및 최종 연산 사용 예시**

```java
import java.util.*;
import java.util.stream.*;

public class StreamExample {
	public static void main(String[] args) {
		List<Integer> nums = Arrays.asList(10, 20, 30, 40, 50);

		// 중개연산(filter, map), 최종연산(collect, forEach)
		List<Integer> result = nums.stream()
			.filter(n -> n > 20)         // 20 초과 값 필터링
			.map(n -> n * 2)             // 각 요소를 2배로 변환
			.collect(Collectors.toList()); // 결과를 리스트로 반환(최종연산)

		result.forEach(System.out::println);  // 결과 출력(최종연산)
	}
}
```

---

## 🔎 코드 분석(단계별)

### 1️⃣ **스트림 생성**

```java
nums.stream()
```

- 컬렉션(List)을 스트림으로 변환하여 처리 시작

### 2️⃣ **중개 연산 - 필터링(`filter`)**

```java
.filter(n -> n > 20)
```

- 조건(n > 20)을 만족하는 요소만 남김  
    (결과: `[30, 40, 50]`)

### 3️⃣ **중개 연산 - 변환(`map`)**

```java
.map(n -> n * 2)
```

- 남은 요소들을 각각 2배로 변환  
    (결과: `[60, 80, 100]`)

### 4️⃣ **최종 연산 - 결과 수집(`collect`)**

```java
.collect(Collectors.toList())
```

- 스트림을 최종 리스트 형태로 변환하여 반환

### 5️⃣ **최종 연산 - 출력(`forEach`)**

```java
result.forEach(System.out::println);
```

- 리스트의 요소를 차례대로 출력
