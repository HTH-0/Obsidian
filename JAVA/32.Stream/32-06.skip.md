# 📝 Java 스트림 건너뛰기 - `skip()` 사용법

## 📌 내용

- Java 스트림에서 **앞의 N개 요소를 건너뛰는** `skip()` 메서드 학습
- 스트림에서 처음 2개 요소를 제외하고 나머지를 리스트로 반환

---

## 💻 코드 정리

```java
import java.util.Arrays;
import java.util.List;
import java.util.stream.Collectors;

public class C06Skip {
    public static void main(String[] args) {
        List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
        List<Integer> skippedNumbers = numbers.stream()      // [[stream() (Java)]]
                                              .skip(2)       // [[skip() (Java)]]
                                              .collect(Collectors.toList()); // [[collect() (Java)]]
        System.out.println(skippedNumbers); // 출력: [3, 4, 5]
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ 리스트 생성

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
```

- 총 5개의 숫자를 가진 리스트 생성

### 2️⃣ 스트림 변환 + 건너뛰기

```java
numbers.stream().skip(2)
```

- `stream()` → 스트림으로 변환
- `skip(2)` → 앞의 2개 요소(1, 2)를 제외하고 처리

### 3️⃣ 리스트로 수집

```java
.collect(Collectors.toList())
```

- 나머지 요소들을 새 리스트로 수집 후 반환
