# 📌 제네릭과 `Object`를 활용한 동물 출력 메서드 구현

## 🔹 핵심 개념

- **제네릭 메서드 (`<T extends Animal>`)**: `Animal`을 상속받은 타입만 허용
- **다형성 활용 (`Object[]`)**: 다양한 객체를 배열로 받아 출력 가능
- **오버라이딩 (`toString()`)**: 각 클래스에서 출력 형식을 맞춤 설정

---

## 💻 코드 정리

```java
package Ch16;

// Animal 클래스 (부모 클래스)
class Animal {
    String name;
}

// Panda 클래스 (Animal 상속)
class Panda extends Animal {
    public Panda(String name) {
        this.name = name;
    }

    @Override
    public String toString() {
        return "팬더 이름 : " + name;
    }
}

// Tiger 클래스 (Animal 상속)
class Tiger extends Animal {
    public Tiger(String name) {
        this.name = name;
    }

    @Override
    public String toString() {
        return "호랑이 이름 : " + name;
    }
}

public class C04GenericMain {

    // ✅ 제네릭 메서드: Animal을 상속받은 객체 배열을 받아 출력
    public static <T extends Animal> void PrintByGeneric(T[] arr) {
        for (T el : arr) {
            System.out.println(el);
        }
    }

    // ✅ Object 배열을 이용한 출력 메서드 (다형성 활용)
    public static void PrintByObject(Object[] animals) {
        for (Object el : animals) {
            System.out.println(el);
        }
    }

    public static void main(String[] args) {

        // 🐅 Tiger 객체 배열
        Tiger[] arr1 = { new Tiger("시베리안 호랑이"), new Tiger("뱅갈 호랑이"), new Tiger("그냥 호랑이") };
        PrintByGeneric(arr1);

        // 🐼 Panda 객체 배열
        Panda[] arr2 = { new Panda("중국 팬더"), new Panda("래서 팬더"), new Panda("그냥 팬더") };
        PrintByGeneric(arr2);

        // 🐅🐼 다양한 동물을 포함한 Object 배열
        Object[] arr3 = { new Tiger("시베리안 호랑이"), new Panda("래서 팬더"), new Panda("그냥 팬더") };
        PrintByObject(arr3);
    }
}
```

## 🔎 코드 분석

### 1️⃣ **`Animal` 클래스 (부모 클래스)**

```java
class Animal {
    String name;
}
```

- **모든 동물 클래스의 공통 속성 (`name`)을 정의**
- `Animal`을 직접 객체로 생성하지 않고, **하위 클래스에서만 사용**

### 2️⃣ **`Panda` & `Tiger` 클래스 (`Animal` 상속)**

```java
class Panda extends Animal {
    public Panda(String name) {
        this.name = name;
    }

    @Override
    public String toString() {
        return "팬더 이름 : " + name;
    }
}
```

```java
class Tiger extends Animal {
    public Tiger(String name) {
        this.name = name;
    }

    @Override
    public String toString() {
        return "호랑이 이름 : " + name;
    }
}
```

- `Animal`을 상속받아 **각 동물의 특성을 유지**
- `toString()`을 오버라이딩하여 출력 형식 지정

### 3️⃣ **제네릭 메서드 (`PrintByGeneric`)**

```java
public static <T extends Animal> void PrintByGeneric(T[] arr) {
    for (T el : arr) {
        System.out.println(el);
    }
}
```

- `<T extends Animal>`: **Animal을 상속받은 클래스만 사용 가능**
- `T[] arr`: **동물 객체 배열을 받아 출력**

### 4️⃣ **Object 배열을 이용한 출력 메서드 (`PrintByObject`)**

```java
public static void PrintByObject(Object[] animals) {
    for (Object el : animals) {
        System.out.println(el);
    }
}
```

- `Object[]` 배열을 통해 **다양한 타입의 객체를 한꺼번에 처리**
- `Object` 타입을 사용하면, `Animal`뿐만 아니라 모든 객체 활용 가능

### 5️⃣ **객체 생성 및 실행 (`main` 메서드)**

```java
public static void main(String[] args) {
    Tiger[] arr1 = { new Tiger("시베리안 호랑이"), new Tiger("뱅갈 호랑이"), new Tiger("그냥 호랑이") };
    PrintByGeneric(arr1);

    Panda[] arr2 = { new Panda("중국 팬더"), new Panda("래서 팬더"), new Panda("그냥 팬더") };
    PrintByGeneric(arr2);

    Object[] arr3 = { new Tiger("시베리안 호랑이"), new Panda("래서 팬더"), new Panda("그냥 팬더") };
    PrintByObject(arr3);
}
```

- `PrintByGeneric(arr1)`, `PrintByGeneric(arr2)`: **제네릭을 이용해 `Tiger[]`과 `Panda[]` 처리**
- `PrintByObject(arr3)`: **`Object[]`을 이용해 `Tiger`, `Panda` 객체 섞어 출력**

## 🔎 추가 정보

- **제네릭 (`<T extends Animal>`) 사용 시 장점**:
    
    - `Animal`을 상속받은 객체만 받을 수 있어 **안전성 증가**
    - 형변환 없이 `T` 타입으로 활용 가능
- **`Object[]`를 사용할 때 단점**:
    
    - 모든 타입을 허용하므로 **원치 않는 타입도 전달 가능** (`Integer`, `String` 등)
    - `Animal`로 자동 형변환되지 않음 → **캐스팅 필요**
