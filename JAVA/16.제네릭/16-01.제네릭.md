# 📌 제네릭(Generic)과 타입 제한 (`extends`)

## 🔎 내용 요약

- **제네릭(Generic)**: 여러 타입을 일반화하여 하나의 클래스로 처리
- **타입 제한 (`extends`)**: 특정 클래스나 인터페이스를 상속받은 타입만 허용
- **`toString()` 오버라이딩**: 객체의 문자열 표현을 커스터마이징

---

## 💻 코드 정리

```java
package Ch16;

class 호빵재료 { }

class 팥 extends 호빵재료 {
    @Override
    public String toString() {
        return "단팥";
    }
}

class 슈크림 extends 호빵재료 {
    @Override
    public String toString() {
        return "슈크림";
    }
}

class 야채 extends 호빵재료 {
    @Override
    public String toString() {
        return "야채";
    }
}

class 민트초코 {
    @Override
    public String toString() {
        return "민트초코";
    }
}

class 호빵<T extends 호빵재료> {  // 타입 제한: 호빵재료를 상속한 클래스만 사용 가능
    private T material;

    호빵(T material) {
        this.material = material;
    }

    @Override
    public String toString() {
        return material + "(으)로 만든 호빵";
    }
}

public class C01GenericMain {
    public static void main(String[] args) {
        호빵<팥> ob1 = new 호빵<>(new 팥());
        System.out.println(ob1);

        호빵<슈크림> ob2 = new 호빵<>(new 슈크림());
        System.out.println(ob2);

        호빵<야채> ob3 = new 호빵<>(new 야채());
        System.out.println(ob3);

        // 오류 발생: 민트초코는 호빵재료를 상속하지 않음
        // 호빵<민트초코> ob4 = new 호빵<>(new 민트초코());
        // System.out.println(ob4);
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **제네릭 클래스 선언**

```java
class 호빵<T extends 호빵재료> { }
```

- `T extends 호빵재료` → `호빵재료`를 상속받은 클래스만 사용 가능
- `민트초코`는 `호빵재료`를 상속하지 않으므로 사용 불가

### 2️⃣ **객체 생성 및 출력**

```java
호빵<팥> ob1 = new 호빵<>(new 팥());
System.out.println(ob1);
```

- `호빵<팥>` 객체를 생성
- `toString()` 오버라이딩된 내용 출력 → `"단팥(으)로 만든 호빵"`

### 3️⃣ **호빵재료를 상속하지 않은 클래스 사용 시 오류**

```java
호빵<민트초코> ob4 = new 호빵<>(new 민트초코());  // 오류 발생
```

- `민트초코`는 `호빵재료`를 상속하지 않았기 때문에 제네릭 타입 제한에 의해 사용 불가

## 🔎 추가 정보

### ✅ **제네릭 타입 제한 (`extends`)**

- `T extends 클래스명` → 해당 클래스를 상속받은 하위 클래스만 사용 가능
- `T extends 인터페이스명` → 해당 인터페이스를 구현한 클래스만 사용 가능

### ✅ **제네릭의 장점**

- **코드 재사용성 증가**: 다양한 타입을 하나의 클래스에서 처리 가능
- **타입 안정성 보장**: 컴파일 타임에서 타입 검증 가능
