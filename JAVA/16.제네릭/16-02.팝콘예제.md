# 📌 제네릭 클래스와 상속을 활용한 팝콘 클래스 구현

## 🔹 핵심 개념

- **제네릭 클래스 (`PopCorn<T>`)**: 다양한 팝콘 재료를 처리할 수 있도록 설계
- **제네릭 제한 (`T extends 팝콘재료`)**: `팝콘재료` 클래스를 상속받는 타입만 사용 가능
- **객체 다형성**: `toString()` 오버라이딩을 활용하여 재료별 출력 처리

---

## 💻 코드 정리

```java
package Ch16;

// 팝콘 재료 추상 클래스
abstract class 팝콘재료 {}

// 캬라멜 팝콘 재료
class 캬라멜 extends 팝콘재료 {
    @Override
    public String toString() {
        return "캬라멜";
    }
}

// 버터옥수수 팝콘 재료
class 버터옥수수 extends 팝콘재료 {
    @Override
    public String toString() {
        return "버터옥수수";
    }
}

// 제네릭 팝콘 클래스 (팝콘재료를 상속받은 클래스만 허용)
class PopCorn<T extends 팝콘재료> {
    private T meterial; // 팝콘 재료

    public PopCorn(T meterial) {
        this.meterial = meterial;
    }

    @Override
    public String toString() {
        return "PopCorn [meterial=" + meterial + " 맛 팝콘]";
    }
}

// 실행 클래스
public class C02Ex {
    public static void main(String[] args) {
        // 캬라멜 팝콘 생성
        PopCorn<캬라멜> ob1 = new PopCorn<>(new 캬라멜());
        System.out.println(ob1);

        // 버터옥수수 팝콘 생성
        PopCorn<버터옥수수> ob2 = new PopCorn<>(new 버터옥수수());
        System.out.println(ob2);
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **`팝콘재료` 클래스 (추상 클래스)**

```java
abstract class 팝콘재료 {}
```

- `팝콘재료`는 **추상 클래스**로 선언하여 직접 객체 생성 불가
- 다양한 팝콘 재료를 만들기 위한 **부모 클래스 역할**

### 2️⃣ **팝콘 재료 클래스 (캬라멜, 버터옥수수)**

```java
class 캬라멜 extends 팝콘재료 {
    @Override
    public String toString() {
        return "캬라멜";
    }
}
```

```java
class 버터옥수수 extends 팝콘재료 {
    @Override
    public String toString() {
        return "버터옥수수";
    }
}
```

- `toString()` 메서드를 오버라이딩하여 **재료 이름을 문자열로 반환**

### 3️⃣ **제네릭 팝콘 클래스 (`PopCorn<T>`)**

```java
class PopCorn<T extends 팝콘재료> {
    private T meterial; 

    public PopCorn(T meterial) {
        this.meterial = meterial;
    }

    @Override
    public String toString() {
        return "PopCorn [meterial=" + meterial + " 맛 팝콘]";
    }
}
```

- `T` 타입 매개변수 사용 → **팝콘 재료에 따라 객체를 유연하게 생성**
- `T extends 팝콘재료` → **팝콘재료 클래스를 상속받은 클래스만 사용 가능**
- `toString()`에서 **재료명을 출력하도록 설정**

### 4️⃣ **객체 생성 및 실행 (`main` 메서드)**

```java
public class C02Ex {
    public static void main(String[] args) {
        PopCorn<캬라멜> ob1 = new PopCorn<>(new 캬라멜());
        System.out.println(ob1);

        PopCorn<버터옥수수> ob2 = new PopCorn<>(new 버터옥수수());
        System.out.println(ob2);
    }
}
```

- `PopCorn<캬라멜>` → **캬라멜 팝콘 객체 생성**
- `PopCorn<버터옥수수>` → **버터옥수수 팝콘 객체 생성**
- `toString()`을 통해 `PopCorn [meterial=캬라멜 맛 팝콘]`과 같이 출력됨

## 🔎 추가 정보

- **제네릭 제한 (`extends`)**: `T` 타입을 `팝콘재료`의 하위 클래스만 허용 → `PopCorn<Integer>` 같은 잘못된 사용 방지
- **객체 다형성 활용**: `toString()`을 오버라이딩하여 재료별 출력 맞춤 처리
