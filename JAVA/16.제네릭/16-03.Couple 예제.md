# 📌 제네릭을 활용한 `Couple` 클래스 구현

## 🔹 핵심 개념

- **제네릭 클래스 (`Couple<X, Y>`)**: 두 개의 `Person` 객체를 다룰 수 있도록 설계
- **제네릭 제한 (`X extends Person, Y extends Person`)**: `Person` 클래스를 상속받은 타입만 사용 가능
- **객체 다형성**: `toString()`을 오버라이딩하여 객체 정보 출력

---

## 💻 코드 정리

```java
package Ch16;

// Person 클래스 (부모 클래스)
class Person {
    String name;
    int age;
    String addr;

    public Person(String name, int age, String addr) {
        this.name = name;
        this.age = age;
        this.addr = addr;
    }
}

// Man 클래스 (Person 상속)
class Man extends Person {
    public Man(String name, int age, String addr) {
        super(name, age, addr);
    }

    @Override
    public String toString() {
        return "Man [name=" + name + ", age=" + age + ", addr=" + addr + "]";
    }
}

// Woman 클래스 (Person 상속)
class Woman extends Person {
    public Woman(String name, int age, String addr) {
        super(name, age, addr);
    }

    @Override
    public String toString() {
        return "Woman [name=" + name + ", age=" + age + ", addr=" + addr + "]";
    }
}

// 제네릭 커플 클래스 (Person을 상속받은 타입만 허용)
class Couple<X extends Person, Y extends Person> {
    private X member1;
    private Y member2;

    // 생성자
    public Couple(X member1, Y member2) {
        this.member1 = member1;
        this.member2 = member2;
    }

    // toString() 오버라이딩
    @Override
    public String toString() {
        return "멤버 1 : " + member1 + ", 멤버 2 : " + member2;
    }
}

// 실행 클래스
public class C03GenericMain {
    public static void main(String[] args) {
        // Man과 Woman 객체를 포함하는 Couple 생성
        Couple<Man, Woman> couple1 = new Couple<>(new Man("홍길동", 50, "대구"), new Woman("영희", 40, "울산"));
        System.out.println("couple1 : " + couple1);

        // 잘못된 사용 (제네릭 제한에 의해 오류 발생)
        // Couple<Integer, Integer> couple2 = new Couple<>(100, 200);
        // System.out.println("couple2 : " + couple2);
    }
}
```

## 🔎 코드 분석

### 1️⃣ **`Person` 클래스 (부모 클래스)**

```java
class Person {
    String name;
    int age;
    String addr;

    public Person(String name, int age, String addr) {
        this.name = name;
        this.age = age;
        this.addr = addr;
    }
}
```

- `name`, `age`, `addr` 필드를 가진 **부모 클래스**
- 생성자를 통해 값을 초기화

### 2️⃣ **`Man` & `Woman` 클래스 (`Person` 상속)**

```java
class Man extends Person {
    public Man(String name, int age, String addr) {
        super(name, age, addr);
    }

    @Override
    public String toString() {
        return "Man [name=" + name + ", age=" + age + ", addr=" + addr + "]";
    }
}
```

```java
class Woman extends Person {
    public Woman(String name, int age, String addr) {
        super(name, age, addr);
    }

    @Override
    public String toString() {
        return "Woman [name=" + name + ", age=" + age + ", addr=" + addr + "]";
    }
}
```

- `Person` 클래스를 상속받아 **Man, Woman 객체 생성 가능**
- `toString()`을 오버라이딩하여 객체 정보 출력

### 3️⃣ **제네릭 `Couple<X, Y>` 클래스**

```java
class Couple<X extends Person, Y extends Person> {
    private X member1;
    private Y member2;

    public Couple(X member1, Y member2) {
        this.member1 = member1;
        this.member2 = member2;
    }

    @Override
    public String toString() {
        return "멤버 1 : " + member1 + ", 멤버 2 : " + member2;
    }
}
```

- **두 개의 제네릭 타입 (`X, Y`)을 가지는 클래스**
- `X extends Person, Y extends Person` → `Person`을 상속받은 클래스만 사용 가능
- `toString()` 오버라이딩을 통해 객체 정보 출력

### 4️⃣ **객체 생성 및 실행 (`main` 메서드)**

```java
public class C03GenericMain {
    public static void main(String[] args) {
        Couple<Man, Woman> couple1 = new Couple<>(new Man("홍길동", 50, "대구"), new Woman("영희", 40, "울산"));
        System.out.println("couple1 : " + couple1);
    }
}
```

- `Couple<Man, Woman>` → `Man`과 `Woman` 객체를 매개변수로 전달하여 `Couple` 객체 생성
- `toString()`을 호출하여 객체 정보 출력

## 🔎 추가 정보

- **제네릭 제한 (`extends`)**: `X`와 `Y`는 반드시 `Person`을 상속받은 클래스여야 함 → `Couple<Integer, Integer>` 같은 잘못된 사용 방지
- **객체 다형성 활용**: `toString()`을 오버라이딩하여 객체 정보를 맞춤 출력
