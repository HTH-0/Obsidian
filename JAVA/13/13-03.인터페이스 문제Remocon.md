# 📝 Java 인터페이스 활용 - Remocon 예제

## 📌 내용

- **인터페이스 `Remocon`**을 이용하여 `Tv`, `Radio` 클래스 구현
- `powerOn()`, `powerOff()`, `SetVolumn(int vol)` 추상 메서드 활용
- **최대/최소 볼륨 조절 로직** 추가
- **정적 메서드**를 사용하여 `Remocon` 타입 객체를 제어

---

## 💻 코드 정리

```java
package Ch13;

interface Remocon {
    int MAX_VOL = 100;  // [[MAX_VOL (Java)]]
    int MIN_VOL = 0;    // [[MIN_VOL (Java)]]

    void powerOn();     // [[powerOn() (Java)]]
    void powerOff();    // [[powerOff() (Java)]]
    void SetVolumn(int vol);  // [[SetVolumn() (Java)]]
}

class Tv implements Remocon {
    @Override
    public void powerOn() {
        System.out.println("TV를 켭니다.");
    }

    @Override
    public void powerOff() {
        System.out.println("TV를 끕니다.");
    }

    @Override
    public void SetVolumn(int vol) {
        int Tvol = vol;
        if (Tvol > MAX_VOL) {
            System.out.println("최대 볼륨을 넘어갈 수 없습니다.");
            Tvol = MAX_VOL;
        } else if (Tvol < MIN_VOL) {
            System.out.println("최소 볼륨을 넘어갈 수 없습니다.");
            Tvol = MIN_VOL;
        }
        System.out.println("TV 볼륨: " + Tvol);
    }
}

class Radio implements Remocon {
    @Override
    public void powerOn() {
        System.out.println("Radio를 켭니다.");
    }

    @Override
    public void powerOff() {
        System.out.println("Radio를 끕니다.");
    }

    @Override
    public void SetVolumn(int vol) {
        int Rvol = vol;
        if (Rvol > MAX_VOL) {
            System.out.println("최대 볼륨을 넘어갈 수 없습니다.");
            Rvol = MAX_VOL;
        } else if (Rvol < MIN_VOL) {
            System.out.println("최소 볼륨을 넘어갈 수 없습니다.");
            Rvol = MIN_VOL;
        }
        System.out.println("Radio 볼륨: " + Rvol);
    }
}

public class C03InterfaceMain {
    public static void TurnOn(Remocon controller) {
        controller.powerOn();
    }

    public static void TurnOff(Remocon controller) {
        controller.powerOff();
    }

    public static void SetVolumn(Remocon controller, int vol) {
        controller.SetVolumn(vol);
    }

    public static void main(String[] args) {
        Tv tv = new Tv();
        Radio radio = new Radio();

        tv.SetVolumn(30);
        SetVolumn(tv, 20);

        TurnOn(tv);
        TurnOff(tv);

        TurnOn(radio);
        TurnOff(radio);
    }
}
```

## 🔎 코드 분석

### 1️⃣ **인터페이스 정의**

```java
interface Remocon {
    int MAX_VOL = 100;
    int MIN_VOL = 0;

    void powerOn();
    void powerOff();
    void SetVolumn(int vol);
}
```

- `MAX_VOL`, `MIN_VOL`은 **상수 (`public static final` 생략 가능)**
- `powerOn()`, `powerOff()`, `SetVolumn()`은 **추상 메서드 (`public abstract` 생략 가능)**

### 2️⃣ **TV 클래스 구현**

```java
class Tv implements Remocon {
    @Override
    public void powerOn() {
        System.out.println("TV를 켭니다.");
    }

    @Override
    public void powerOff() {
        System.out.println("TV를 끕니다.");
    }

    @Override
    public void SetVolumn(int vol) {
        int Tvol = vol;
        if (Tvol > MAX_VOL) {
            System.out.println("최대 볼륨을 넘어갈 수 없습니다.");
            Tvol = MAX_VOL;
        } else if (Tvol < MIN_VOL) {
            System.out.println("최소 볼륨을 넘어갈 수 없습니다.");
            Tvol = MIN_VOL;
        }
        System.out.println("TV 볼륨: " + Tvol);
    }
}
```

- **`Remocon` 인터페이스 구현**
- `powerOn()`, `powerOff()` 메서드 오버라이딩
- `SetVolumn(int vol)`에서 볼륨이 범위를 초과하면 **최대/최소 볼륨 제한**

### 3️⃣ **Radio 클래스 구현**

```java
class Radio implements Remocon {
    @Override
    public void powerOn() {
        System.out.println("Radio를 켭니다.");
    }

    @Override
    public void powerOff() {
        System.out.println("Radio를 끕니다.");
    }

    @Override
    public void SetVolumn(int vol) {
        int Rvol = vol;
        if (Rvol > MAX_VOL) {
            System.out.println("최대 볼륨을 넘어갈 수 없습니다.");
            Rvol = MAX_VOL;
        } else if (Rvol < MIN_VOL) {
            System.out.println("최소 볼륨을 넘어갈 수 없습니다.");
            Rvol = MIN_VOL;
        }
        System.out.println("Radio 볼륨: " + Rvol);
    }
}
```

- `Tv`와 동일한 구조이지만, `Radio` 클래스에 맞게 볼륨 설정 적용

### 4️⃣ **정적 메서드를 활용한 인터페이스 제어**

```java
public static void TurnOn(Remocon controller) {
    controller.powerOn();
}

public static void TurnOff(Remocon controller) {
    controller.powerOff();
}

public static void SetVolumn(Remocon controller, int vol) {
    controller.SetVolumn(vol);
}
```

- `Remocon` 타입을 매개변수로 받아 **다형성 적용**
- `TurnOn()`, `TurnOff()`, `SetVolumn()`을 사용하여 TV와 라디오를 동일한 방식으로 제어 가능

### 5️⃣ **메인 메서드에서 실행**

```java
Tv tv = new Tv();
Radio radio = new Radio();

tv.SetVolumn(30);
SetVolumn(tv, 20);

TurnOn(tv);
TurnOff(tv);

TurnOn(radio);
TurnOff(radio);
```

- `Tv`와 `Radio` 객체 생성
- `SetVolumn()`을 직접 호출하거나 정적 메서드를 활용해 설정
- `TurnOn()`, `TurnOff()`를 사용하여 TV와 라디오의 전원을 조작
