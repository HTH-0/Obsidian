### 🔎 **NullPointerException 예제 분석**

---

## 📌 **내용 정리**

- `NullPointerException` 발생 원인과 예외 처리 학습
- `try-catch`를 사용하여 프로그램이 비정상 종료되지 않도록 방어
- `printStackTrace()` 활용하여 예외 발생 지점 추적

---

## 💻 **코드 정리**

```java
package Ch15;

public class C01NullpointerExceptionMain {
    public static void main(String[] args) {
        try {
            String str = null;  // null 값을 가진 문자열 변수
            System.out.println(str.toString());  // NullPointerException 발생
        } catch (NullPointerException e) {
            e.printStackTrace();  // 예외 발생 원인 및 스택 트레이스 출력
        }

        // 예외 발생 후에도 프로그램이 정상적으로 실행됨
        System.out.println("HELLOWORLD");
        System.out.println("HELLOWORLD");
    }
}
```

---

## 🔎 **코드 분석**

### 1️⃣ **`NullPointerException` 발생**

```java
String str = null;
System.out.println(str.toString());
```

- `str`이 `null` 상태에서 `toString()` 호출 시 `NullPointerException` 발생

### 2️⃣ **예외 처리 (`try-catch`)**

```java
try {
    String str = null;
    System.out.println(str.toString());
} catch (NullPointerException e) {
    e.printStackTrace();
}
```

- `try` 블록에서 예외 발생 가능 코드 실행
- `catch` 블록에서 `NullPointerException`을 처리하여 프로그램 종료 방지

### 3️⃣ **예외 정보 출력 (`printStackTrace()`)**

```java
e.printStackTrace();
```

- 예외 발생 위치 및 원인 출력
- 개발 중 디버깅에 유용

### 4️⃣ **예외 발생 후에도 프로그램 실행**

```java
System.out.println("HELLOWORLD");
System.out.println("HELLOWORLD");
```

- 예외 발생 후에도 정상적으로 실행됨 → 프로그램이 비정상 종료되지 않음

---

## 🔎 **추가 정보**

- `e.getMessage()` → 예외 메시지 출력
- `e.toString()` → 예외 타입과 메시지 출력
- `e.getStackTrace()` → 예외 발생 위치 배열 반환
