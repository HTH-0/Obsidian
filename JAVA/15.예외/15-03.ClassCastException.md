### 📌 `ClassCastException` 발생 코드 분석

---

### 💡 주요 개념

- **업캐스팅(Upcasting)**: `Animal` 타입 변수에 `Dog` 또는 `Cat` 객체 저장 가능
- **다운캐스팅(Downcasting)**: `Animal` 타입을 다시 `Dog` 또는 `Cat`으로 변환
- **`ClassCastException` 발생 조건**
    - `Animal` 타입이 실제로 `Dog`가 아닌 객체(`Cat`)일 때 `Dog`로 캐스팅 시 예외 발생

---

### 💻 코드 정리

```java
package Ch15;

class Animal {}  // 부모 클래스

class Dog extends Animal {}  // 자식 클래스 (Dog)

class Cat extends Animal {}  // 자식 클래스 (Cat)

public class C03ClassCastExceptionMain {
    
    public static void changeDog(Animal animal) {
        Dog down = (Dog) animal;  // 다운캐스팅
    }

    public static void main(String[] args) {
        try {
            Animal poppy = new Dog();  // 업캐스팅 (정상)
            Animal tori = new Cat();   // 업캐스팅 (정상)

            changeDog(tori);  // ❌ ClassCastException 발생
            changeDog(poppy); // 실행되지 않음 (이미 예외 발생)
        
        } catch (ClassCastException e) {
            System.out.println("예외 발생: " + e.getMessage());  
            System.out.println("예외 원인: " + e.getCause());
        }

        System.out.println("HELLO WORLD");  // 예외 처리로 정상 실행됨
    }
}
```

---

### 🔎 코드 분석

#### 1️⃣ **업캐스팅**

```java
Animal poppy = new Dog();  // 정상
Animal tori = new Cat();   // 정상
```

- 부모 타입(`Animal`) 변수에 자식 객체(`Dog`, `Cat`) 저장 가능 (업캐스팅)

#### 2️⃣ **다운캐스팅 (문제 발생 부분)**

```java
changeDog(tori);  // Cat 객체를 Dog로 캐스팅 → ClassCastException 발생
```

- `tori`는 `Cat` 객체지만 `Dog`로 강제 형변환 시도 → `ClassCastException`

#### 3️⃣ **예외 처리**

```java
catch (ClassCastException e) {
    System.out.println("예외 발생: " + e.getMessage());
}
```

- `ClassCastException` 발생 시 예외 메시지 출력 후 프로그램 계속 실행

#### 4️⃣ **예외 발생 후에도 실행되는 코드**

```java
System.out.println("HELLO WORLD");
```

- 예외 발생했지만 `try-catch`로 처리되어 정상적으로 실행됨

### 🛠 해결 방법

1️⃣ **`instanceof` 연산자로 타입 체크 후 캐스팅**

```java
public static void changeDog(Animal animal) {
    if (animal instanceof Dog) {
        Dog down = (Dog) animal;
        System.out.println("변환 성공");
    } else {
        System.out.println("변환 실패: Dog 타입이 아님");
    }
}
```

2️⃣ **다형성을 활용한 안전한 형변환**

```java
class Animal {
    public void makeSound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Bark");
    }
}

class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Meow");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal animal = new Cat();
        animal.makeSound();  // Meow (다운캐스팅 불필요)
    }
}
```

- **다운캐스팅 없이도** `makeSound()` 호출 가능 → `instanceof` 필요 없음
