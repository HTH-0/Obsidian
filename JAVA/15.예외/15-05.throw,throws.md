### 📌 `throw`와 `throws` 예외 처리 코드 분석

---

### 💡 주요 개념

- **`throw`**: 예외를 강제로 발생시킬 때 사용
- **`throws`**: 메서드에서 예외가 발생할 가능성이 있음을 선언
- `try-catch`를 사용하여 예외가 발생해도 프로그램이 정상 실행되도록 처리 가능

---

### 💻 코드 정리

```java
package Ch15;

class A {
    public void Ex1() throws NullPointerException {
        System.out.println("Ex1 process 1");
        throw new NullPointerException("Ex1 NULL Exception");  // 예외 발생
    }
}

class B {
    public void Ex2() throws NullPointerException {
        System.out.println("Ex2 process 1");
        throw new NullPointerException("Ex2 NULL Exception");  // 예외 발생
    }
}

public class C05ThrowAndThrowsMain {
    public static void main(String[] args) {
        System.out.println("실행코드 1");
        System.out.println("실행코드 2");

        A a = new A();
        B b = new B();

        try {
            a.Ex1();  // ❌ 예외 발생 (Ex1 process 1 출력 후)
            b.Ex2();  // 실행되지 않음 (이미 예외 발생)
        } catch (Exception e) {
            System.out.println("예외 발생: " + e.getMessage());
        }

        System.out.println("실행코드 3");  // 예외 발생해도 정상 실행됨
    }
}
```

---

### 🔎 코드 분석

#### 1️⃣ **예외 발생 (`throw`)**

```java
public void Ex1() throws NullPointerException {
    System.out.println("Ex1 process 1");
    throw new NullPointerException("Ex1 NULL Exception");
}
```

- `throw new NullPointerException(...)` → 강제로 `NullPointerException` 발생
- `throws`를 사용하여 메서드에서 예외 발생 가능성을 선언

#### 2️⃣ **예외 처리 (`try-catch`)**

```java
try {
    a.Ex1();  // ❌ 여기서 예외 발생
    b.Ex2();  // 실행되지 않음
} catch (Exception e) {
    System.out.println("예외 발생: " + e.getMessage());
}
```

- `a.Ex1()` 실행 중 예외 발생 → `catch` 블록으로 이동
- `b.Ex2()`는 실행되지 않음 (`a.Ex1()`에서 예외 발생하여 흐름 종료)

#### 3️⃣ **예외 발생 후에도 실행되는 코드**

```java
System.out.println("실행코드 3");
```

- 예외가 발생해도 `catch` 블록에서 처리되므로 프로그램이 중단되지 않고 실행됨

---

### 🛠 해결 방법

1️⃣ **예외가 발생해도 `Ex1()`과 `Ex2()`를 모두 실행하려면?**

```java
try {
    a.Ex1();
} catch (Exception e) {
    System.out.println("예외 발생: " + e.getMessage());
}

try {
    b.Ex2();
} catch (Exception e) {
    System.out.println("예외 발생: " + e.getMessage());
}
```

- `a.Ex1()`과 `b.Ex2()` 각각 `try-catch`로 감싸 예외 발생 여부와 상관없이 실행

2️⃣ **여러 개의 예외를 다르게 처리하려면?**

```java
try {
    a.Ex1();
} catch (NullPointerException e) {
    System.out.println("NullPointerException 발생: " + e.getMessage());
} catch (Exception e) {
    System.out.println("기타 예외 발생: " + e.getMessage());
}
```

- `NullPointerException`과 기타 예외를 다르게 처리
