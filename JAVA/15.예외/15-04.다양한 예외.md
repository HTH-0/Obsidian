### 📌 다양한 예외(Exception) 처리 코드 분석

---

### 💡 주요 개념

- **`NullPointerException`**: `null` 값을 참조하려 할 때 발생
- **`ArrayIndexOutOfBoundsException`**: 배열의 유효 범위를 초과하여 접근할 때 발생
- **`NumberFormatException`**: 숫자로 변환할 수 없는 문자열을 `Integer.parseInt()`로 변환 시 발생
- **`ClassCastException`**: 잘못된 타입으로 형변환할 때 발생

---

### 💻 코드 정리

```java
package Ch15;

class Animal {}  
class Dog extends Animal {}  
class Cat extends Animal {}  

public class C04ExceptionMain {
    public static void main(String[] args) {

        // 1️⃣ NullPointerException 발생
        try {			
            String str = null;
            str.toString();  // ❌ 예외 발생
        } catch (NullPointerException e) {
            System.out.println("NullPointerException: " + e.getMessage());
        }

        // 2️⃣ ArrayIndexOutOfBoundsException 발생
        try {			
            int arr[] = {10, 20, 30};
            arr[5] = 100;  // ❌ 배열 인덱스 초과
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("ArrayIndexOutOfBoundsException: " + e.getMessage());
        }

        // 3️⃣ NumberFormatException 발생
        try {			
            Integer.parseInt("a1234");  // ❌ 숫자로 변환 불가능한 문자열
        } catch (NumberFormatException e) {
            System.out.println("NumberFormatException: " + e.getMessage());
        }

        // 4️⃣ ClassCastException 발생
        try {			
            Animal animal = new Dog();
            Cat yummi = (Cat) animal;  // ❌ Dog을 Cat으로 변환 불가능
        } catch (ClassCastException e) {
            System.out.println("ClassCastException: " + e.getMessage());
        }

        System.out.println("HELLO WORLD");  // 예외가 발생해도 정상 실행됨
    }
}
```

---

### 🔎 코드 분석

#### 1️⃣ **`NullPointerException`**

```java
String str = null;
str.toString();  // ❌ null 객체를 참조하려고 하면 예외 발생
```

- `null` 값을 가진 변수를 `toString()` 등으로 접근하면 `NullPointerException`

#### 2️⃣ **`ArrayIndexOutOfBoundsException`**

```java
int arr[] = {10, 20, 30};
arr[5] = 100;  // ❌ 배열 인덱스 초과
```

- 배열의 크기(3)보다 큰 `arr[5]`를 접근하려고 하면 `ArrayIndexOutOfBoundsException`

#### 3️⃣ **`NumberFormatException`**

```java
Integer.parseInt("a1234");  // ❌ "a1234"는 숫자로 변환 불가능
```

- 숫자가 아닌 문자열(`"a1234"`)을 `Integer.parseInt()`로 변환 시 `NumberFormatException`

#### 4️⃣ **`ClassCastException`**

```java
Animal animal = new Dog();
Cat yummi = (Cat) animal;  // ❌ Dog을 Cat으로 변환 불가능
```

- `Dog` 객체를 `Cat`으로 형변환하려고 하면 `ClassCastException` 발생

#### 5️⃣ **예외 발생 후에도 실행되는 코드**

```java
System.out.println("HELLO WORLD");
```

- 모든 예외를 `try-catch`로 처리했기 때문에 프로그램이 중단되지 않고 정상 실행됨

---

### 🛠 해결 방법

1️⃣ **`NullPointerException` 방지**

```java
if (str != null) {
    str.toString();
}
```

- `null` 여부를 체크하고 메서드 호출

2️⃣ **`ArrayIndexOutOfBoundsException` 방지**

```java
if (5 < arr.length) {
    arr[5] = 100;
}
```

- 배열 크기 확인 후 접근

3️⃣ **`NumberFormatException` 방지**

```java
try {
    Integer.parseInt("a1234");
} catch (NumberFormatException e) {
    System.out.println("올바른 숫자를 입력하세요.");
}
```

- 입력 값이 숫자인지 확인 후 변환

4️⃣ **`ClassCastException` 방지 (`instanceof` 사용)**

```java
if (animal instanceof Cat) {
    Cat yummi = (Cat) animal;
} else {
    System.out.println("변환 불가능한 타입");
}
```

- 형변환 전에 객체 타입을 확인
