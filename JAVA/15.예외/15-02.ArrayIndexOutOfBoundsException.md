### 📌 `ArrayIndexOutOfBoundsException` 발생 코드 분석

---

### 💡 주요 개념

- 배열의 크기를 초과하는 인덱스에 접근하면 `ArrayIndexOutOfBoundsException` 발생
- `for` 문에서 `i < 4`로 설정되어 있어 `arr[3]`을 접근할 때 예외 발생
- 예외 발생 시 이후 코드(`System.out.println("HELLO WORLD");`)는 실행되지 않음

---

### 💻 코드 정리

```java
package Ch15;

public class C02ArrayIndexBoundExceptionMain {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30};  // 배열 선언 및 초기화

        for (int i = 0; i < 4; i++)  // 배열 범위를 초과하는 루프
            System.out.println(arr[i]);  

        System.out.println("HELLO WORLD");  // 예외 발생으로 실행되지 않음
    }
}
```

---

### 🔎 코드 분석

#### 1️⃣ **배열 선언 및 초기화**

```java
int[] arr = {10, 20, 30};
```

- 크기가 3인 정수형 배열 선언
- `arr[0] = 10`, `arr[1] = 20`, `arr[2] = 30`

#### 2️⃣ **배열 요소 출력 (예외 발생 부분)**

```java
for (int i = 0; i < 4; i++)
    System.out.println(arr[i]);
```

- `i = 0 → arr[0] = 10`
- `i = 1 → arr[1] = 20`
- `i = 2 → arr[2] = 30`
- `i = 3 → arr[3]` (배열 크기 초과) → `ArrayIndexOutOfBoundsException` 발생

#### 3️⃣ **예외 발생 후 코드 실행 불가**

```java
System.out.println("HELLO WORLD");
```

- `Exception`이 발생하면 프로그램이 비정상 종료되므로 실행되지 않음

---

### 🛠 해결 방법

1️⃣ **배열의 크기를 초과하지 않도록 `length` 활용**

```java
for (int i = 0; i < arr.length; i++)
    System.out.println(arr[i]);
```

2️⃣ **예외 처리 (`try-catch` 사용)**

```java
try {
    for (int i = 0; i < 4; i++)
        System.out.println(arr[i]);
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("배열 범위를 벗어났습니다.");
}
System.out.println("HELLO WORLD");  // 예외 발생해도 실행됨
```
