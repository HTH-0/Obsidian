# 📌 싱글톤 패턴을 활용한 `ShopService` 구현

## 📝 내용 요약

- **싱글톤 패턴**을 적용하여 `ShopService` 클래스 구현
- `private` 생성자를 사용하여 **외부에서 객체 생성을 방지**
- `static` 메서드 (`getInstance()`)를 통해 **유일한 인스턴스를 반환**

---

## 💻 코드 정리

```java
package Ch11;

class ShopService {
    private static ShopService instance;  // 유일한 인스턴스 저장

    private ShopService() {}  // private 생성자로 외부 객체 생성 방지

    public static ShopService getInstance() {  
        if (instance == null)  // 최초 한 번만 객체 생성
            instance = new ShopService();
        return instance;  // 동일한 인스턴스 반환
    }
}

public class C05Ex {
    public static void main(String[] args) {
        ShopService obj1 = ShopService.getInstance();
        ShopService obj2 = ShopService.getInstance();

        if (obj1 == obj2) {
            System.out.println("같은 ShopService 객체입니다.");
        } else {
            System.out.println("다른 ShopService 객체 입니다.");
        }
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **싱글톤 패턴 적용**

```java
private static ShopService instance;
```

- `static` 변수 → **클래스가 로딩될 때 단 한 번만 할당됨**
- `ShopService`의 **유일한 인스턴스를 저장**

```java
private ShopService() {}
```

- `private` 생성자 → **외부에서 `new ShopService()` 호출 방지**

```java
public static ShopService getInstance() {
    if (instance == null)  // 객체가 없으면 생성
        instance = new ShopService();
    return instance;  // 동일한 인스턴스 반환
}
```

- `static` 메서드 → **클래스명으로 직접 호출 가능**
- 최초 호출 시 객체를 생성하고 이후에는 **동일한 객체를 반환**

### 2️⃣ **싱글톤 객체 비교 테스트**

```java
ShopService obj1 = ShopService.getInstance();
ShopService obj2 = ShopService.getInstance();

if (obj1 == obj2) {
    System.out.println("같은 ShopService 객체입니다.");
} else {
    System.out.println("다른 ShopService 객체 입니다.");
}
```

- `obj1`과 `obj2`가 **동일한 객체인지 확인**
- 싱글톤 패턴이 적용되었으므로 **항상 같은 객체를 반환해야 함**

## 🔎 추가 정보

### ✅ 싱글톤 패턴의 장점

1. **객체 생성 제한** → 불필요한 객체 생성을 방지하여 **메모리 절약**
2. **일관된 상태 유지** → 동일한 객체를 여러 곳에서 공유
3. **전역 접근 가능** → `getInstance()`를 통해 어디서든 접근 가능

### ✅ 싱글톤 패턴 개선 (스레드 안전 보장)

- `멀티스레드 환경`에서 동기화 처리가 필요할 수 있음
- `synchronized` 키워드를 사용하여 **스레드 안전한 싱글톤 구현**

```java
public static synchronized ShopService getInstance() {
    if (instance == null)
        instance = new ShopService();
    return instance;
}
```

- `synchronized`를 사용하면 **여러 스레드에서 동시에 접근해도 하나의 객체만 생성됨**
- 하지만 **성능 저하 가능성**이 있음
