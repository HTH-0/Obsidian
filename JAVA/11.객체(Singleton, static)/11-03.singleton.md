# 📌 싱글톤 패턴 (Singleton Pattern) 구현

## 📝 내용 요약

- **싱글톤 패턴**: 하나의 클래스에서 단 하나의 인스턴스만 생성되도록 하는 디자인 패턴
- `private` 생성자를 이용하여 **외부에서 객체 생성 차단**
- `static` 메서드 (`getInstance()`)를 통해 **유일한 인스턴스 반환**

---

## 💻 코드 정리

```java
package Ch11;

class Company {
    int n1;
    int n2;

    // toString 오버라이드 (객체 정보 출력)
    @Override
    public String toString() {
        return "Company [n1=" + n1 + ", n2=" + n2 + "]";
    }

    // 싱글톤 패턴 구현
    private static Company instance;  // static 변수: 유일한 인스턴스를 저장

    private Company() {}  // private 생성자: 외부에서 객체 생성 불가

    public static Company getInstance() {  
        if (instance == null) {  // 최초 호출 시 객체 생성
            instance = new Company();
        }
        return instance;  // 항상 동일한 인스턴스 반환
    }
}

public class C03SingletonPattern {
    public static void main(String[] args) {
        Company com1 = Company.getInstance();  // 싱글톤 객체 반환
        Company com2 = Company.getInstance();  // 같은 객체 반환

        com1.n1 = 100;
        com2.n2 = 200;

        System.out.println("com1 : " + com1);
        System.out.println("com2 : " + com2);
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **싱글톤 패턴 적용**

```java
private static Company instance;
```

- `static` 변수 → **클래스가 로딩될 때 메모리에 단 한 번 할당**
- **유일한 인스턴스**를 저장하는 역할

```java
private Company() {}
```

- `private` 생성자 → **외부에서 객체 생성 불가능**
- `new Company()`를 통한 직접적인 객체 생성을 방지

```java
public static Company getInstance() {
    if (instance == null) {
        instance = new Company();  // 최초 한 번만 객체 생성
    }
    return instance;
}
```

- `static` 메서드 → **클래스명으로 접근 가능**
- 인스턴스가 없을 경우 **한 번만 생성**, 이후 호출 시 **기존 인스턴스를 반환**

### 2️⃣ **객체 생성 및 값 변경**

```java
Company com1 = Company.getInstance();
Company com2 = Company.getInstance();
```

- `getInstance()` 호출 시 **항상 동일한 객체 반환**
- `com1`과 `com2`는 같은 객체를 참조

```java
com1.n1 = 100;
com2.n2 = 200;
```

- `com1.n1 = 100` → `com2.n1`도 100 (동일 객체이므로)
- `com2.n2 = 200` → `com1.n2`도 200 (동일 객체이므로)

### 3️⃣ **객체 출력**

```java
System.out.println("com1 : " + com1);
System.out.println("com2 : " + com2);
```

- `toString()`을 통해 **같은 객체임을 확인 가능**

## 🔎 실행 결과

```plaintext

com2 : Company [n1=100, n2=200]
```

- `com1`과 `com2`가 같은 객체를 참조하므로, **동일한 값이 출력됨**

## 🔎 추가 정보

### ✅ 싱글톤 패턴의 특징

1. **하나의 인스턴스만 생성** → 메모리 절약
2. **여러 클래스에서 동일한 인스턴스 사용** → 일관된 데이터 유지
3. **객체 생성을 `private` 생성자로 제한** → `new` 사용 불가

### ✅ 싱글톤 패턴 사용 예시

- **설정 관리 객체 (Configuration Manager)**
- **로그 관리 (Logger)**
- **데이터베이스 연결 (Database Connection)**
- **스레드 풀 (Thread Pool)**
