# 📝 `String` 클래스의 메모리 구조 및 비교 연산

## 📌 내용 요약

- `String` 객체의 **리터럴 방식 vs `new` 연산자 방식** 차이 학습
- `System.identityHashCode()`를 사용하여 **메모리 주소 비교**
- == 연산자와 `.equals()`의 차이점 이해

---

## 💻 코드 정리

```java
package Ch09;

public class C04StringClass {
    public static void main(String[] args) {
        String str1 = "java";
        String str2 = "java";
        String str3 = new String("java");
        String str4 = new String("java");

        // 메모리 주소 출력
        System.out.printf("%X\n", System.identityHashCode(str1));  // [[identityHashCode (Java)]]
        System.out.printf("%X\n", System.identityHashCode(str2));
        System.out.printf("%X\n", System.identityHashCode(str3));
        System.out.printf("%X\n", System.identityHashCode(str4));

        System.out.println("-----------------------------");

        // == 연산자로 객체 비교
        System.out.println("str1 == str2 ? : " + (str1 == str2));  // true
        System.out.println("str3 == str4 ? : " + (str3 == str4));  // false
        System.out.println("str1 == str3 ? : " + (str1 == str3));  // false
        System.out.println("str2 == str4 ? : " + (str2 == str4));  // false
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **문자열 저장 방식의 차이**

```java
String str1 = "java";
String str2 = "java";
```

- **리터럴 방식**으로 문자열을 생성하면 **String Pool**에서 관리됨
- 같은 문자열 리터럴이 있을 경우 **이미 존재하는 객체를 재사용**

```java
String str3 = new String("java");
String str4 = new String("java");
```

- `new` 키워드를 사용하면 **Heap 영역**에 **새로운 객체가 생성됨**
- `str3`과 `str4`는 서로 다른 메모리 주소를 가지는 **독립적인 객체**

### 2️⃣ **메모리 주소 비교 (`System.identityHashCode()`)**

```java
System.out.printf("%X\n", System.identityHashCode(str1));
System.out.printf("%X\n", System.identityHashCode(str2));
System.out.printf("%X\n", System.identityHashCode(str3));
System.out.printf("%X\n", System.identityHashCode(str4));
```

- `str1`과 `str2`는 **같은 메모리 주소**를 가짐 (String Pool에서 재사용됨)
- `str3`과 `str4`는 **서로 다른 메모리 주소**를 가짐 (Heap에 개별적으로 생성)

### 3️⃣ **객체 비교 (== 연산자)**

```java
System.out.println("str1 == str2 ? : " + (str1 == str2));  // true
System.out.println("str3 == str4 ? : " + (str3 == str4));  // false
System.out.println("str1 == str3 ? : " + (str1 == str3));  // false
System.out.println("str2 == str4 ? : " + (str2 == str4));  // false
```

- `str1 == str2` → **true** (같은 String Pool 객체)
- `str3 == str4` → **false** (`new`로 생성된 서로 다른 객체)
- `str1 == str3`, `str2 == str4` → **false** (리터럴 풀과 Heap의 객체는 다름)

## 🔎 추가 정보

### 🔹 == vs `.equals()`

- == → **객체의 메모리 주소 비교**
- `.equals()` → **객체의 내용(값) 비교**

#### `.equals()`를 사용한 문자열 비교

```java
System.out.println("str3.equals(str4) ? : " + str3.equals(str4));  // true
```

- `str3.equals(str4)` → **true** (값이 같음)
- `.equals()`를 사용해야 문자열 값 자체를 비교 가능

#### 🔹 `intern()`을 사용한 String Pool 저장

```java
String str5 = str3.intern();
System.out.println("str1 == str5 ? : " + (str1 == str5));  // true
```

- `.intern()`을 호출하면 **String Pool의 동일한 문자열을 가리키게 됨**
- `str1`과 `str5`는 동일한 메모리 주소를 가지게 됨
