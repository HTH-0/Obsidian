# 📝 `this` 키워드 학습 정리

## 📌 내용

- `this` 키워드의 역할 및 활용법
- `this()`를 이용한 생성자 호출
- `this`를 사용해 멤버 변수와 지역 변수 구별
- 객체의 메모리 주소(해시코드) 확인

---

## 💻 코드 정리

```java
package Ch09;

class C03Simple {
    int x;
    int y;

    // 기본 생성자
    C03Simple() {
        this(0, 0);  // 다른 생성자 호출
        System.out.println("C03Simple() 생성자");
    }

    // 매개변수 1개 생성자
    C03Simple(int x) {
        this(x, 0);  // 다른 생성자 호출
        System.out.println("C03Simple(int x) 생성자");
    }

    // 매개변수 2개 생성자
    C03Simple(int x, int y) {
        System.out.println("C03Simple(int x, int y) 생성자");
        this.x = x;
        this.y = y;
    }

    // 현재 객체의 참조 반환
    C03Simple getThis() {
        return this;
    }
}

public class C03This {
    public static void main(String[] args) {
        C03Simple ob = new C03Simple();  // 기본 생성자 호출
        System.out.println(ob);          // 객체의 메모리 주소 출력
        System.out.println(ob.getThis()); // `this`로 반환된 객체 주소 출력
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **기본 생성자 (`C03Simple()`)**

```java
C03Simple() {
    this(0, 0);
    System.out.println("C03Simple() 생성자");
}
```

- `this(0, 0)`을 사용하여 **두 개의 매개변수를 받는 생성자** 호출
- 이후 `"C03Simple() 생성자"` 출력

### 2️⃣ **생성자 오버로딩 (`C03Simple(int x)`)**

```java
C03Simple(int x) {
    this(x, 0);
    System.out.println("C03Simple(int x) 생성자");
}
```

- `this(x, 0)`을 사용해 **매개변수 2개 생성자 호출**
- `"C03Simple(int x) 생성자"` 출력

### 3️⃣ **멤버 변수 초기화 (`C03Simple(int x, int y)`)**

```java
C03Simple(int x, int y) {
    System.out.println("C03Simple(int x, int y) 생성자");
    this.x = x;
    this.y = y;
}
```

- 최종적으로 호출되는 생성자로, 멤버 변수 `x`, `y`를 초기화
- `this.x = x`, `this.y = y`를 통해 **지역 변수와 멤버 변수 구별**

### 4️⃣ **현재 객체의 참조 반환 (`getThis()`)**

```java
C03Simple getThis() {
    return this;
}
```

- 현재 객체의 참조를 반환
- `this`는 **현재 객체 자신을 가리킴**

### 5️⃣ **객체 생성 및 `this` 비교**

```java
C03Simple ob = new C03Simple();
System.out.println(ob);
System.out.println(ob.getThis());
```

- `System.out.println(ob);` → 객체의 메모리 주소 출력
- `System.out.println(ob.getThis());` → `this`를 반환하여 동일한 주소 출력

---

## 🔎 추가 정보

- **`this()`는 반드시 생성자의 첫 줄에서 호출**해야 함
- **같은 클래스 내에서 다른 생성자를 호출할 때 사용**
- **객체의 해시코드를 확인할 때 `this` 사용 가능**
- **현재 객체를 반환하여 메서드 체이닝 가능**
