# 📝 Java 접근 한정자와 정보 은닉

## 📌 내용

- **접근 한정자**(Access Modifiers) 사용법 학습
- **정보 은닉(Encapsulation)** 원칙 적용
- **getter & setter**를 활용한 데이터 접근 및 수정

---

## 💻 코드 정리

```java
package Ch09;

// 접근 한정자 예제
class C01Person {
    private String name;  // [[private (Java)]]
    private int age;
    String addr;  // [[default (Java)]]

    // 생성자
    public C01Person(String name, int age, String addr) {  
        this.name = name;
        this.age = age;
        this.addr = addr;
    }

    // getter (private 변수 접근)
    public String getName() {  
        return this.name;
    }

    // setter (private 변수 수정)
    public void setAge(int age) {  
        this.age = age;
    }

    public String getAddr() {
        return addr;
    }

    public void setAddr(String addr) {
        this.addr = addr;
    }
}

public class C01정보은닉 {
    public static void main(String[] args) {
        C01Person person1 = new C01Person("홍길동", 55, "대구");

        System.out.println(person1.getName());  // [[getName() (Java)]]
        person1.setAge(56);  // [[setAge() (Java)]]
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **접근 한정자**

```java
private String name;
private int age;
String addr;
```

- `private` : 해당 클래스 내부에서만 접근 가능 (정보 은닉)
- `default` : 동일 패키지 내에서 접근 가능

### 2️⃣ **생성자(Constructor)**

```java
public C01Person(String name, int age, String addr) {
    this.name = name;
    this.age = age;
    this.addr = addr;
}
```

- 객체 생성 시 초기화 역할
- `this` 키워드 사용하여 멤버 변수 초기화

### 3️⃣ **getter & setter 메서드**

```java
public String getName() {
    return this.name;
}

public void setAge(int age) {
    this.age = age;
}
```

- `getter`: private 변수 값을 외부에서 가져오기
- `setter`: private 변수 값을 변경 (유효성 검사 가능)

### 4️⃣ **객체 생성 및 데이터 수정**

```java
C01Person person1 = new C01Person("홍길동", 55, "대구");

System.out.println(person1.getName());
person1.setAge(56);
```

- `new C01Person(...)` → 객체 생성
- `getName()`으로 `name` 값 가져오기
- `setAge(56)`으로 `age` 값 변경

## 🔎 추가 정보

- **정보 은닉 (Encapsulation)**
    
    - `private` 키워드를 사용하여 직접 접근을 차단하고, `getter`/`setter`를 통해 접근
    - 데이터를 보호하고, 필요하면 유효성 검사를 추가 가능
- **접근 제어자 요약**
    
    |접근 제어자|클래스 내부|같은 패키지|상속 관계|모든 클래스|
    |---|---|---|---|---|
    |`private`|O|X|X|X|
    |`default`|O|O|X|X|
    |`protected`|O|O|O|X|
    |`public`|O|O|O|O|
