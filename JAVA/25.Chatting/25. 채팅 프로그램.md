# 📌 Java GUI 기반 소켓 채팅 프로그램 분석

## 💡 주요 개념

- **Swing GUI 사용**: `JFrame`, `JTextArea`, `JTextField`를 활용하여 UI 구성
- **소켓 통신**: `Socket` 및 `ServerSocket`을 이용하여 클라이언트-서버 연결
- **멀티스레딩**: `Runnable` 인터페이스를 구현하여 송수신을 별도 스레드로 처리
- **데이터 입출력**: `DataInputStream`, `DataOutputStream`을 사용해 문자열 교환

---

## 📌 1. 클라이언트 (ClientUI.java, ClientRecvThread.java)

### **💻 주요 코드: `ClientUI.java`**

```java
client = new Socket("192.168.16.203",7002);
System.out.println("[SERVER] 연결 시작합니다");

// INOUT STREAM
System.out.println("CLIENT IP : " + client.getInetAddress());
dout = new DataOutputStream(client.getOutputStream());
din = new DataInputStream(client.getInputStream());
area.append("[SERVER] 에 접속완료했습니다.");

// 수신 스레드 실행
ClientRecvThread recv = new ClientRecvThread(din, this);
Thread th = new Thread(recv);
th.start();
```

#### 🔎 **설명**

- `Socket`을 이용해 서버(`192.168.16.203:7002`)와 연결
- `DataInputStream`, `DataOutputStream`을 생성하여 데이터 송수신 준비
- `ClientRecvThread`를 실행하여 서버 메시지를 수신

---

### **💻 주요 코드: `ClientRecvThread.java`**

```java
while(true) {
    recv = din.readUTF();
    if(recv.equals("q"))
        break;
    gui.area.append("[SERVER] : " + recv + "\n");
}
```

#### 🔎 **설명**

- `din.readUTF()`를 통해 서버의 메시지를 읽어 GUI `JTextArea`에 추가
- `"q"` 수신 시 루프를 종료하여 스레드 종료

---

### **💻 주요 코드: `keyPressed()`**

```java
if(e.getKeyCode()==10) { // 엔터 키 입력 시
    try {
        area.append("[Client] : " + txt1.getText() + "\n");
        dout.writeUTF(txt1.getText());
        dout.flush();
        txt1.setText("");
        area.setCaretPosition(area.getDocument().getLength());
    } catch(Exception e2) {
        e2.printStackTrace();
    }
}
```

#### 🔎 **설명**

- 엔터 키 입력 시 `JTextField`의 내용을 `JTextArea`에 출력
- `writeUTF()`를 사용해 서버로 메시지 전송
- 입력 필드 초기화 후 스크롤을 최하단으로 이동

## 📌 2. 서버 (ServerUI.java, ServerRecvThread.java)

### **💻 주요 코드: `ServerUI.java`**

```java
server = new ServerSocket(7003);
System.out.println("[INFO] SERVER SOCKET LISTENING");

client = server.accept();
System.out.println("[SERVER] 연결 시작합니다");

// INOUT STREAM
dout = new DataOutputStream(client.getOutputStream());
din = new DataInputStream(client.getInputStream());
area.append("[CLIENT] " + client.getInetAddress() + " 접속하셨습니다\n");

// 수신 스레드 실행
ServerRecvThread recv = new ServerRecvThread(din, this);
Thread th = new Thread(recv);
th.start();
```

#### 🔎 **설명**

- `ServerSocket(7003)`을 생성해 연결 대기
- `accept()` 호출로 클라이언트 연결 수락
- `DataInputStream`, `DataOutputStream`을 사용해 송수신 준비
- `ServerRecvThread`를 실행하여 클라이언트 메시지를 수신

---

### **💻 주요 코드: `ServerRecvThread.java`**

```java
while(true) {
    recv = din.readUTF();
    if(recv.equals("q"))
        break;
    gui.area.append("[CLIENT] " + recv + "\n");

```

#### 🔎 **설명**

- 클라이언트에서 `readUTF()`를 통해 메시지를 받아 `JTextArea`에 추가
- `"q"` 입력 시 루프 종료

---

## 🎯 **핵심 정리**

1. **Swing 기반 GUI 채팅 프로그램**
    
    - `JTextArea`, `JTextField`, `JScrollPane`을 이용한 UI 구성
2. **소켓 통신**
    
    - `Socket`으로 클라이언트-서버 연결
    - `ServerSocket`으로 서버 실행 후 `accept()`로 연결 대기
3. **멀티스레딩**
    
    - `Runnable`을 구현한 `ClientRecvThread`와 `ServerRecvThread`를 사용해 수신을 별도 스레드로 처리
4. **데이터 송수신**
    
    - `DataInputStream.readUTF()`로 메시지 수신
    - `DataOutputStream.writeUTF()`로 메시지 전송
