### 🔍 **BufferedReader를 활용한 파일 한 줄씩 읽기 (`readLine()`)**

#### 📌 **핵심 내용**

- **`BufferedReader.readLine()`을 활용한 파일 한 줄씩 읽기**
- **`FileReader`를 사용하여 파일 문자 스트림 열기**
- **`BufferedWriter`와 `PrintWriter`를 활용한 파일 쓰기 (주석 처리됨)**

---

## 💻 **코드 정리**

```java
package Ch20;

import java.io.BufferedReader;
import java.io.FileReader;
import java.io.Reader;

public class C02ReadLineMain {
    public static void main(String[] args) throws Exception {
        // 파일 읽기
        Reader in = new FileReader("C:\\IOTEST\\test2.txt");
        BufferedReader bin = new BufferedReader(in);

        while (true) {
            String data = bin.readLine(); // 한 줄씩 읽기
            if (data == null) break; // 파일의 끝(EOF)이면 종료
            System.out.println(data);
        }

        bin.close(); // 자원 해제
    }
}
```

---

## 🔎 **코드 분석**

### 1️⃣ **파일에서 한 줄씩 읽기**

```java
Reader in = new FileReader("C:\\IOTEST\\test2.txt");
BufferedReader bin = new BufferedReader(in);
```

- `FileReader` → **파일에서 문자 스트림을 읽음**
- `BufferedReader` → **버퍼링을 추가하여 성능 향상**  
    → `readLine()`을 지원하여 한 줄씩 읽기 가능

### 2️⃣ **파일 내용을 한 줄씩 출력**

```java
while (true) {
    String data = bin.readLine(); // 한 줄씩 읽기
    if (data == null) break; // 파일 끝이면 종료
    System.out.println(data);
}
```

- `readLine()` → 한 줄씩 읽음 (`\n` 또는 `\r\n`을 기준으로 구분)
- `data == null` → 파일의 끝(EOF)이면 반복 종료

### 3️⃣ **자원 해제**

```java
bin.close();
```

- `close()`를 호출하여 파일을 안전하게 닫음

## 🚀 **추가: 파일에 문자열 쓰기 (`BufferedWriter`, `PrintWriter` 활용)**

주석 처리된 **파일 쓰기 코드**를 활성화하면, `test2.txt` 파일에 문자열을 저장할 수 있음.

```java
import java.io.*;

public class C02ReadLineMain {
    public static void main(String[] args) throws Exception {
        // 🔹 파일에 문자열 저장
        Writer out = new FileWriter("C:\\IOTEST\\test2.txt");
        BufferedWriter bout = new BufferedWriter(out);
        PrintWriter pout = new PrintWriter(bout);

        pout.println("HELLO");
        pout.println("HELLO");
        pout.println("HELLO");

        pout.flush();
        pout.close();

        System.out.println("파일 저장 완료!");
    }
}
```

### 📌 **파일 쓰기 흐름**

1. `FileWriter` → **파일에 문자 단위로 쓰기**
2. `BufferedWriter` → **버퍼링을 추가하여 성능 향상**
3. `PrintWriter` → **`println()`을 활용하여 줄 단위 쓰기**
4. `flush()` → **버퍼에 남은 데이터 출력**
5. `close()` → **파일 닫기**

---

## 🚀 **개선된 점**

1. **`BufferedReader.readLine()` 활용** → 효율적인 줄 단위 읽기
2. **버퍼링을 통한 성능 향상** (`BufferedReader`, `BufferedWriter` 사용)
3. **파일을 안전하게 닫는 구조 적용** (`close()` 활용)
