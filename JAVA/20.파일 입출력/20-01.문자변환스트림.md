### 🔍 **문자 변환 스트림(InputStreamReader) 활용한 파일 읽기**

#### 📌 **핵심 내용**

- `InputStreamReader`를 활용한 **문자 변환 스트림**
- **파일에서 문자 데이터를 읽어오기** (`FileInputStream` → `BufferedInputStream` → `InputStreamReader`)
- `OutputStreamWriter`를 활용하여 **파일 저장(주석 처리됨)**

---

## 💻 **코드 정리**

```java
package Ch20;

import java.io.BufferedInputStream;
import java.io.FileInputStream;
import java.io.InputStream;
import java.io.InputStreamReader;

public class C01CharConvertStreamMain {
    public static void main(String[] args) throws Exception {
        // 파일에서 문자 읽기
        InputStream in = new FileInputStream("C:\\IOTEST\\test.txt");
        BufferedInputStream bin = new BufferedInputStream(in);
        InputStreamReader rin = new InputStreamReader(bin);

        while (true) {
            int data = rin.read();
            if (data == -1) break; // EOF(End of File) 체크
            System.out.print((char) data);
        }

        rin.close(); // 자원 해제
    }
}
```

---

## 🔎 **코드 분석**

### 1️⃣ **파일에서 문자 읽기**

```java
InputStream in = new FileInputStream("C:\\IOTEST\\test.txt");
BufferedInputStream bin = new BufferedInputStream(in);
InputStreamReader rin = new InputStreamReader(bin);
```

- `FileInputStream` → **파일에서 바이트 스트림을 읽음**
- `BufferedInputStream` → **버퍼링을 추가하여 성능 향상**
- `InputStreamReader` → **바이트를 문자(유니코드)로 변환**

### 2️⃣ **문자 데이터 읽기**

```java
while (true) {
    int data = rin.read();
    if (data == -1) break; // EOF 체크
    System.out.print((char) data);
}
```

- **`rin.read()`** → 1글자(유니코드 문자)를 읽음
- **`data == -1`** → 파일의 끝을 의미(EOF)
- **`(char) data`** → 정수 데이터를 문자로 변환 후 출력

### 3️⃣ **자원 해제**

```java
rin.close();
```

- `close()`를 호출하여 파일을 안전하게 닫음

## 🚀 **추가: 파일에 문자열 쓰기 (`OutputStreamWriter` 활용)**

주석 처리된 **파일 쓰기 코드**를 활성화하면, `test.txt` 파일에 문자열을 저장할 수 있음.

```java
import java.io.*;

public class C01CharConvertStreamMain {
    public static void main(String[] args) throws Exception {
        String str = "문자 변환 스트림 사용";

        // 🔹 파일에 문자열 저장
        OutputStream out = new FileOutputStream("C:\\IOTEST\\test.txt");
        OutputStreamWriter wout = new OutputStreamWriter(out);
        BufferedWriter bout = new BufferedWriter(wout);

        bout.write(str);
        bout.flush();
        bout.close();

        System.out.println("파일 저장 완료!");
    }
}
```

### 📌 **파일 쓰기 흐름**

1. `FileOutputStream` → **파일에 바이트 단위로 쓰기**
2. `OutputStreamWriter` → **문자를 바이트로 변환**
3. `BufferedWriter` → **버퍼링을 통해 성능 향상**
4. `flush()` → **버퍼에 남은 데이터 출력**
5. `close()` → **파일 닫기**

---

## 🚀 **개선된 점**

1. **바이트 스트림 → 문자 스트림 변환** (`InputStreamReader`, `OutputStreamWriter`)
2. **파일 읽기 성능 향상** (`BufferedInputStream` 사용)
3. **파일을 안전하게 닫는 구조 적용** (`close()` 활용)
