### 🔍 **객체 직렬화 & 역직렬화 (`ObjectInputStream` & `ObjectOutputStream`)**

#### 📌 **핵심 내용**

- **`Serializable` 인터페이스를 구현한 객체를 파일로 저장 & 읽기**
- **`ObjectOutputStream`을 활용한 객체 직렬화(Serialization)**
- **`ObjectInputStream`을 활용한 객체 역직렬화(Deserialization)**
- **파일을 활용한 객체 데이터 유지 및 복원**

---

## 💻 **코드 정리**

```java
package Ch20;

import java.io.FileInputStream;
import java.io.ObjectInputStream;
import java.io.Serializable;
import java.util.Date;

// ✅ 직렬화 가능 클래스
class Board implements Serializable {
    private static final long serialVersionUID = 1L;

    private int bno;
    private String title;
    private String content;
    private String writer;
    private Date date;

    // 생성자
    public Board(int bno, String title, String content, String writer, Date date) {
        this.bno = bno;
        this.title = title;
        this.content = content;
        this.writer = writer;
        this.date = date;
    }

    // Getter & Setter
    public int getBno() { return bno; }
    public void setBno(int bno) { this.bno = bno; }
    public String getTitle() { return title; }
    public void setTitle(String title) { this.title = title; }
    public String getContent() { return content; }
    public void setContent(String content) { this.content = content; }
    public String getWriter() { return writer; }
    public void setWriter(String writer) { this.writer = writer; }
    public Date getDate() { return date; }
    public void setDate(Date date) { this.date = date; }

    @Override
    public String toString() {
        return "Board [bno=" + bno + ", title=" + title + ", content=" + content +
               ", writer=" + writer + ", date=" + date + "]";
    }
}

// ✅ 객체 역직렬화
public class C04ObjectStreamMain {
    public static void main(String[] args) throws Exception {
        // 🔹 파일에서 객체 읽기
        FileInputStream in = new FileInputStream("C:\\IOTEST\\board.db");
        ObjectInputStream oin = new ObjectInputStream(in);

        Object obj = oin.readObject(); // 첫 번째 객체 읽기
        Board down = (Board) obj;
        System.out.println(down);

        oin.close(); // 자원 해제
    }
}
```

## 🔎 **코드 분석**

### 1️⃣ **객체 직렬화 클래스 (`Board`)**

```java
class Board implements Serializable {
    private static final long serialVersionUID = 1L;
```

- **`Serializable` 인터페이스 구현** → 객체 직렬화 가능
- **`serialVersionUID` 설정** → 직렬화 버전 관리 (클래스 변경 시 호환성 유지)

### 2️⃣ **파일에서 객체 읽기 (`ObjectInputStream`)**

```java
FileInputStream in = new FileInputStream("C:\\IOTEST\\board.db");
ObjectInputStream oin = new ObjectInputStream(in);

Object obj = oin.readObject();
Board down = (Board) obj;
System.out.println(down);

oin.close();
```

- `FileInputStream` → **파일에서 바이트 스트림을 읽음**
- `ObjectInputStream` → **객체 단위로 데이터를 읽음**
- `readObject()` → **파일에서 객체를 읽고 `Board` 타입으로 변환**
- `close()` → **자원 해제**

## 🚀 **추가: 객체 저장 (`ObjectOutputStream` 활용)**

주석 처리된 **파일 쓰기 코드**를 활성화하면, `board.db` 파일에 객체를 저장할 수 있음.

```java
import java.io.FileOutputStream;
import java.io.ObjectOutputStream;
import java.util.Date;

public class C04ObjectStreamMain {
    public static void main(String[] args) throws Exception {
        // 🔹 파일에 객체 저장
        FileOutputStream out = new FileOutputStream("C:\\IOTEST\\board.db");
        ObjectOutputStream oout = new ObjectOutputStream(out);

        oout.writeObject(new Board(1, "제목1", "하2", "홍길동", new Date()));
        oout.writeObject(new Board(2, "제목2", "하3", "남길동", new Date()));

        oout.flush();
        oout.close();

        System.out.println("파일 저장 완료!");
    }
}
```

### 📌 **파일 쓰기 흐름**

1. `FileOutputStream` → **파일을 바이트 스트림으로 저장**
2. `ObjectOutputStream` → **객체를 직렬화하여 저장**
3. `writeObject()` → **객체 데이터를 `board.db` 파일에 저장**
4. `flush()` → **버퍼에 남은 데이터 출력**
5. `close()` → **파일 닫기**

---

## 🚀 **개선된 점**

1. **`Serializable`을 활용하여 객체 데이터를 손쉽게 저장 및 복원 가능**
2. **객체 단위로 저장하여 데이터의 구조적 활용이 용이**
3. **파일을 안전하게 닫는 구조 적용 (`close()`)**
