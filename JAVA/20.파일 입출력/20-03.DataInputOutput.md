### 🔍 **DataInputStream & DataOutputStream을 활용한 바이너리 데이터 입출력**

#### 📌 **핵심 내용**

- **`DataOutputStream`을 활용한 기본 데이터 타입 저장**
- **`DataInputStream`을 활용한 데이터 읽기**
- **파일에 `UTF-8 문자열`, `double`, `int` 형식의 데이터를 저장 및 읽기**

---

## 💻 **코드 정리**

```java
package Ch20;

import java.io.DataInputStream;
import java.io.FileInputStream;

public class C03DataInoutStreamMain {
    public static void main(String[] args) throws Exception {
        // 🔹 파일에서 바이너리 데이터 읽기
        FileInputStream in = new FileInputStream("C:\\IOTEST\\test3.txt");
        DataInputStream din = new DataInputStream(in);

        String name = din.readUTF(); // UTF 문자열 읽기
        System.out.println("이름: " + name);

        double weight = din.readDouble(); // double 값 읽기
        System.out.println("몸무게: " + weight);

        int data = din.readInt(); // int 값 읽기
        System.out.println("점수: " + data);

        din.close(); // 자원 해제
    }
}
```

---

## 🔎 **코드 분석**

### 1️⃣ **바이너리 데이터 읽기**

```java
FileInputStream in = new FileInputStream("C:\\IOTEST\\test3.txt");
DataInputStream din = new DataInputStream(in);
```

- `FileInputStream` → **파일을 바이트 스트림으로 읽음**
- `DataInputStream` → **바이트 스트림을 기본 데이터 타입(`int`, `double`, `UTF-8` 등)으로 변환**

### 2️⃣ **데이터 읽기**

```java
String name = din.readUTF();
System.out.println("이름: " + name);

double weight = din.readDouble();
System.out.println("몸무게: " + weight);

int data = din.readInt();
System.out.println("점수: " + data);
```

- **`readUTF()`** → UTF-8 형식의 문자열 읽기
- **`readDouble()`** → double 데이터 읽기
- **`readInt()`** → int 데이터 읽기

### 3️⃣ **자원 해제**

```java
din.close();
```

- **파일 스트림을 닫아 메모리 누수 방지**

## 🚀 **추가: 데이터 파일 저장 (`DataOutputStream` 활용)**

주석 처리된 **파일 쓰기 코드**를 활성화하면, `test3.txt` 파일에 데이터를 저장할 수 있음.

```java
import java.io.DataOutputStream;
import java.io.FileOutputStream;

public class C03DataInoutStreamMain {
    public static void main(String[] args) throws Exception {
        // 🔹 파일에 데이터 저장
        FileOutputStream out = new FileOutputStream("C:\\IOTEST\\test3.txt");
        DataOutputStream dout = new DataOutputStream(out);

        dout.writeUTF("홍길동"); // UTF-8 문자열 저장
        dout.writeDouble(95.5); // double 값 저장
        dout.writeInt(100); // int 값 저장

        dout.flush();
        dout.close();

        System.out.println("파일 저장 완료!");
    }
}
```

### 📌 **파일 쓰기 흐름**

1. `FileOutputStream` → **파일을 바이트 스트림으로 저장**
2. `DataOutputStream` → **기본 데이터 타입(`UTF-8`, `double`, `int`) 변환 후 저장**
3. `flush()` → **버퍼에 남은 데이터 출력**
4. `close()` → **파일 닫기**

---

## 🚀 **개선된 점**

1. **`DataOutputStream` & `DataInputStream` 활용** → 바이너리 데이터 저장 및 읽기 가능
2. **바이트 스트림을 직접 다루지 않고 기본 데이터 타입을 변환하여 사용**
3. **파일을 안전하게 닫는 구조 적용** (`close()` 활용)
