# 📝 `break` & `continue` 활용하기

## 📌 학습 내용

- **`break`**: 반복문을 즉시 종료
- **`continue`**: 특정 조건에서 남은 반복문 코드 실행을 건너뛰고 다음 반복으로 이동
- **`break`를 활용한 여러 반복문 탈출** (`flag`, `Exit` 레이블 사용)
- **`continue`를 활용한 특정 조건 제외**

---

## 💻 코드 정리

```java
package Ch07;

import java.util.Scanner;

public class C03ContinueBreak {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // 1️⃣ break 사용 - 특정 입력(-1) 시 종료 후 합 출력
        int n;
        int sum = 0;
        while (true) {
            n = sc.nextInt();
            if (n == -1) {
                break;  // -1 입력 시 반복 종료
            }
            sum += n;
        }
        System.out.println("SUM : " + sum);

        // 2️⃣ flag 활용 - 특정 조건(7×7)에서 모든 반복문 탈출
        boolean flag = false;
        int dan = 2;
        while (dan < 10) {
            int i = 1;
            while (i < 10) {
                if (flag) break;
                if (dan == 7 && i == 7) flag = true;
                System.out.printf("%d x %d = %d\n", dan, i, dan * i);
                i++;
            }
            System.out.println();
            dan++;
        }

        // 3️⃣ 레이블을 활용한 전체 반복문 탈출
        dan = 2;
        Exit:
        while (dan < 10) {
            int i = 1;
            while (i < 10) {
                System.out.printf("%d x %d = %d\n", dan, i, dan * i);
                if (dan == 7 && i == 7) break Exit;  // 모든 반복문 탈출
                i++;
            }
            System.out.println();
            dan++;
        }

        // 4️⃣ continue 사용 - 3의 배수를 제외한 합 구하기
        sum = 0;
        for (int i = 1; i <= 10; i++) {
            if (i % 3 == 0) continue;  // 3의 배수일 경우 이후 코드 실행 건너뜀
            sum += i;
        }
        System.out.println("SUM : " + sum);

        sc.close();
    }
}
```

## 🔎 코드 분석

### 1️⃣ **`break` 사용 - 특정 입력 시 종료**

```java
while (true) {
    n = sc.nextInt();
    if (n == -1) {
        break;
    }
    sum += n;
}
```

- `while (true)`: 무한 루프
- `n == -1`이면 `break`로 루프 종료

### 2️⃣ **`flag`를 활용한 다중 반복문 탈출**

```java
boolean flag = false;
while (dan < 10) {
    int i = 1;
    while (i < 10) {
        if (flag) break;
        if (dan == 7 && i == 7) flag = true;
        System.out.printf("%d x %d = %d\n", dan, i, dan * i);
        i++;
    }
}
```

- `flag = true` 설정 후 `if (flag) break;`로 모든 반복문 탈출
- 특정 조건(7×7)에서만 `flag = true` 설정

### 3️⃣ **레이블(`Exit`)을 활용한 반복문 전체 탈출**

```java
Exit:
while (dan < 10) {
    while (i < 10) {
        if (dan == 7 && i == 7) {
            break Exit;  // 모든 반복문 탈출
        }
    }
}
```

- `break Exit;` 사용 시 해당 레이블(`Exit:`)이 지정된 반복문까지 한 번에 탈출

### 4️⃣ **`continue`를 활용한 특정 조건 제외**

```java
for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) continue;
    sum += i;
}
```

- `i % 3 == 0`이면 `continue` → 이후 코드 실행하지 않고 다음 반복 진행
- `3의 배수를 제외한 합`을 구하는 데 활용
