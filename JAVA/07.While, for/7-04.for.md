# 📝 `for` 반복문과 별 찍기 패턴

## 📌 학습 내용

- **`for` 문 기본 사용법**
- **두 정수 범위의 합 구하기**
- **정삼각형 및 역삼각형 별 찍기 패턴 구현**

---

## 💻 코드 정리

```java
package Ch07;

import java.util.Scanner;

public class C04For {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // 1️⃣ 1부터 10까지 합 구하기 (n~m 범위)
        System.out.print("두 정수를 입력하세요: ");
        int n = sc.nextInt();
        int m = sc.nextInt();
        
        if (n > m) { // n이 더 크다면 서로 교환
            int tmp = n;
            n = m;
            m = tmp;
        }
        
        int sum = 0;
        for (int i = n; i <= m; i++) {
            sum += i;
        }
        System.out.println("SUM: " + sum);

        // 2️⃣ 정삼각형 및 역삼각형 별찍기 패턴 출력
        System.out.print("삼각형 높이 입력: ");
        int height = sc.nextInt();  // 삼각형 높이 입력
        
        // 정삼각형 출력
        for (int h = 1; h <= height; h++) {
            int blank = height - h;   // 공백 개수
            int star = 2 * h - 1;     // 별 개수
            
            for (int i = 1; i <= blank; i++) {
                System.out.print(" ");
            }
            for (int j = 1; j <= star; j++) {
                System.out.print("*");
            }
            System.out.println();
        }
        
        // 역삼각형 출력
        for (int h = 1; h <= height; h++) {
            int blank = h;                          // 공백 개수
            int star = 2 * height - 2 * h - 1;      // 별 개수
            
            for (int i = 1; i <= blank; i++) {
                System.out.print(" ");
            }
            for (int j = 1; j <= star; j++) {
                System.out.print("*");
            }
            System.out.println();
        }

        sc.close();
    }
}
```

## 🔎 코드 분석

### 1️⃣ **1부터 10까지의 합 구하기 (`n ~ m` 범위)**

```java
int n = sc.nextInt();
int m = sc.nextInt();
if (n > m) { 
    int tmp = n;
    n = m;
    m = tmp;
}
int sum = 0;
for (int i = n; i <= m; i++) {
    sum += i;
}
System.out.println("SUM: " + sum);
```

- 두 수 `n`, `m`을 입력받아 작은 값에서 큰 값까지 합을 구함
- `if (n > m)` 조건을 활용하여 `n`이 `m`보다 크면 값을 서로 교환
- `for` 문을 사용하여 `sum` 누적

---

### 2️⃣ **정삼각형 별찍기**

```java
for (int h = 1; h <= height; h++) {
    int blank = height - h;   // 공백 개수
    int star = 2 * h - 1;     // 별 개수
    
    for (int i = 1; i <= blank; i++) {
        System.out.print(" ");
    }
    for (int j = 1; j <= star; j++) {
        System.out.print("*");
    }
    System.out.println();
}
```

- **공백 개수**: `height - h`
- **별 개수**: `2 * h - 1`
- `for` 문을 활용하여 공백을 먼저 출력한 후 별을 출력

#### 📌 실행 예시 (`height = 4`)

```
   *
  ***
 *****
*******
```

- **공백 개수**: `h`
- **별 개수**: `2 * height - 2 * h - 1`
- 정삼각형과 반대되는 구조
