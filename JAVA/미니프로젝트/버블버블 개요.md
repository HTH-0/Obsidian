### **Bubble Shooter 게임 코드 분석**

---

## **1️⃣ 프로젝트 개요**

- 이 프로젝트는 **버블 슈터 게임**으로, `JFrame`을 활용하여 게임 창을 만들고, `JLabel`을 사용하여 플레이어와 버블을 그래픽적으로 구현함.
- `Thread`를 이용하여 비동기적인 충돌 감지를 수행하며, `Runnable`을 구현한 서비스 클래스를 통해 충돌을 감지함.
- 배경을 이미지로 설정하고, 특정 색상의 픽셀을 감지하여 플레이어와 버블의 움직임을 제어함.

---

## **2️⃣ 주요 코드 분석**

### **📌 a. `BubbleFrame.java` (게임의 메인 프레임)**

#### **역할**

- `JFrame`을 상속하여 게임의 메인 창을 생성하고, `Player`를 초기화하며 키 이벤트를 처리함.
- `BackgroundMapService`를 실행하여 충돌 감지를 수행.

#### **주요 코드**

```java
public class BubbleFrame extends JFrame {
```

- `JFrame`을 확장하여 게임 창을 설정.

```java
private JLabel backgroundMap;
private Player player;
```

- 배경과 플레이어를 구성하는 객체.

```java
private void initObject() {
    backgroundMap = new JLabel(new ImageIcon("image/backgroundMap.png"));
    setContentPane(backgroundMap);
    
    player = new Player(context); 
    add(player);
}
```

- 배경 이미지 설정 및 `Player` 추가.

```java
private void initListener() {
    addKeyListener(new KeyAdapter() {
        @Override
        public void keyPressed(KeyEvent e) {
            if (e.getKeyCode() == KeyEvent.VK_LEFT && !player.isLeftWallCrash()) {
                player.left();
            }
        }
    });
}
```

- 키 입력을 감지하여 플레이어 이동을 제어.

```java
private void initService() {
    new Thread(new BackgroundMapService(player)).start();
}
```

- 충돌 감지를 위한 `BackgroundMapService` 실행.

### **📌 b. `Player.java` (플레이어 캐릭터)**

#### **역할**

- `JLabel`을 상속하여 화면에 플레이어를 표시하며, 이동 및 공격 기능을 구현함.

#### **주요 코드**

```java
private static final int SPEED = 4;
private static final int JUMPSPEED = 2;
```

- 이동 속도 및 점프 속도 정의.

```java
private int x, y;
private boolean isLeft, isRight, isUp, isDown;
```

- 위치 및 이동 상태를 저장.

```java
public void left() {
    isLeft = true;
    setRightWallCrash(false);
    direction = -1;
    setIcon(playerL);

    new Thread(() -> {
        while (isLeft) {
            x = x - SPEED;
            setLocation(x, y);
            try { Thread.sleep(10); } catch (Exception e) { e.printStackTrace(); }
        }
    }).start();
}
```

- 왼쪽 이동을 `Thread`를 사용하여 구현.

```java
public void attack() {
    Bubble bubble = new Bubble(context);
    context.add(bubble);
    new Thread(new BackgroundBubbleService(bubble)).start();
}
```

- `Bubble`을 생성하고, 충돌 감지를 위한 `BackgroundBubbleService` 실행.

### **📌 c. `Bubble.java` (버블 총알)**

#### **역할**

- `JLabel`을 상속하여 버블을 화면에 표시하고 이동 및 충돌 처리를 담당.

#### **주요 코드**

```java
private boolean isLeft, isRight, isUp, topWallCrash, leftWallCrash, rightWallCrash;
```

- 이동 방향 및 충돌 상태 저장.

```java
public void left() {
    isLeft = true;
    new Thread(() -> {
        for (int i = 0; i < 400; i++) {
            x = x - BUBBLESPEED;
            setLocation(x, y);
            Thread.sleep(1);

            if (leftWallCrash) {
                up();
                break;
            }
        }
    }).start();
}
```

- 왼쪽 이동 구현, 벽 충돌 시 `up()` 호출.

```java
public void pop() {
    new Thread(() -> {
        Thread.sleep(4000);
        if (topWallCrash) {
            setIcon(bomb);
            Thread.sleep(1000);
            context.remove(this);
            context.repaint();
        }
    }).start();
}
```

- 4초 후 버블이 터지는 효과 구현.

### **📌 d. `BackgroundMapService.java` (플레이어 충돌 감지)**

#### **역할**

- `Runnable`을 구현하여 백그라운드에서 플레이어의 충돌을 감지함.

#### **주요 코드**

```java
Color leftColor = new Color(image.getRGB(player.getX() - 10, player.getY() + 25));
Color rightColor = new Color(image.getRGB(player.getX() + 50 + 10, player.getY() + 25));
int bottomColor = image.getRGB(player.getX() + 10, player.getY() + 50 + 5);
```

- 플레이어의 좌우 및 바닥 충돌 감지.

```java
if (leftColor.getRed() == 255 && leftColor.getGreen() == 0 && leftColor.getBlue() == 0) {
    player.setLeftWallCrash(true);
    player.setLeft(false);
}
```

- 빨간색 벽과 충돌 시 왼쪽 이동 정지.

### **📌 e. `BackgroundBubbleService.java` (버블 충돌 감지)**

#### **역할**

- `Runnable`을 구현하여 버블이 천장이나 벽에 부딪히는 것을 감지.

#### **주요 코드**

```java
Color leftColor = new Color(image.getRGB(bubble.getX() - 10, bubble.getY() + 25));
Color rightColor = new Color(image.getRGB(bubble.getX() + 50 + 10, bubble.getY() + 25));
int topColor = image.getRGB(bubble.getX() + 25, bubble.getY() - 5);
```

- 버블의 좌우 및 천장 충돌 감지.

```java
if (topColor == -65536) { 
    bubble.setUp(false);
    bubble.setTopWallCrash(true);
    bubble.pop();
}
```

- 천장에 닿으면 `pop()` 실행.
