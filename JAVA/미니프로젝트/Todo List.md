## 1️⃣ 프로젝트 개요

- **프로젝트명:** `Simple To-Do List`
- **프로젝트 목적:** 사용자가 간단한 할 일 목록을 추가, 삭제, 조회할 수 있도록 하는 콘솔 기반의 To-Do 리스트 프로그램 개발
- **프로그램 설명:** 사용자가 입력한 할 일을 `ArrayList`에 저장하고, 리스트를 삭제하거나 조회할 수 있는 기능을 제공

## 3️⃣ 시스템 설계 및 코드 구조

- **프로젝트의 아키텍처:**
    
    - 단순한 절차적 프로그래밍 방식으로 구현
    - `ArrayList<String>`을 활용하여 할 일 목록 저장
    - `Scanner`를 이용한 사용자 입력 처리
    - `while` 루프와 `switch-case`문을 사용하여 메뉴 기반으로 동작
- **주요 클래스 및 역할**
    
    - `Todo`: 메인 클래스, 프로그램 실행 및 모든 기능 포함
- **주요 메서드 및 설명**
    
    - `main(String[] args)`: 프로그램 실행 및 메뉴 출력
    - `case 1`: 사용자가 할 일을 추가하는 기능
    - `case 2`: 사용자가 특정 번호를 입력하여 해당 할 일을 삭제하는 기능
    - `case 3`: 현재 저장된 할 일 목록을 조회하는 기능
    - `case 4`: 프로그램 종료

### ✨ 예제 코드

```java
System.out.println("\n📌 To-Do List");
System.out.println("1. 할 일 추가");
System.out.println("2. 리스트 삭제");
System.out.println("3. 조회");
System.out.println("4. 종료하기");
System.out.print("선택 : ");
```

## 5️⃣ 문제 해결 과정

- **문제점 1:**
    - 사용자가 여러 개의 할 일을 추가할 때, 종료 조건(`Y` 입력 시 종료)이 직관적이지 않음
    - 해결책: `while` 루프 내에서 "추가 완료(Y 입력)" 메시지를 더 명확하게 표시
- **문제점 2:**
    - 삭제할 때 번호를 잘못 입력하면 예외 발생 가능
    - 해결책: `if(num >= 0 && num < TodoList.size())` 조건문을 추가하여 예외 방지
- **기타 해결한 문제:**
    - `nextInt()` 사용 후 `nextLine()`을 호출하여 버퍼 문제 해결
