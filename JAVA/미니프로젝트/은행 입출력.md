## 📝 Java 은행 시스템 코드 정리

### 📌 주제: **객체 지향 프로그래밍을 활용한 은행 시스템 구현**

---

## 1️⃣ **공부 코드**

### **파일: `BankService.java`**

- `Bank`, `Owner` 클래스를 통해 은행과 고객 간의 금융 거래를 관리하는 시스템
- 주요 기능:
    - 계좌 등록
    - 입금 및 출금 기능
    - 은행 잔고 관리

---

## 2️⃣ **주요 개념**

### **1. 객체 지향 프로그래밍 (OOP) 적용**

- `Bank` 클래스: 은행을 관리하는 역할 (계좌 등록, 입출금 관리)
- `Owner` 클래스: 고객의 계좌 및 보유 금액을 관리하는 역할
- `HashMap` 사용: 계좌번호(`String`)와 잔고(`Double`)를 저장 및 관리

### **2. 캡슐화**

- 멤버 변수 `private` 설정: 외부 접근을 방지하고 메서드를 통해 조작하도록 설계
- `getter/setter` 메서드를 통해 제한적으로 변수 접근 허용

### **3. 은행과 고객 간의 상호작용**

- `Owner` 클래스가 `Bank` 객체를 이용하여 계좌를 등록하고, 입출금 작업을 수행함.

---

## 3️⃣ **주요 코드**

### **1. `Bank` 클래스 (은행 관리)**

```java
class Bank {
    private double bankMoney;  // 은행 총 보유 금액
    private String bankName;   // 은행 이름
    private Map<String, Double> account; // 계좌번호 및 잔고 저장

    public Bank(String bankname, double bankmoney) {
        this.bankName = bankname;
        this.bankMoney = bankmoney;
        this.account = new HashMap<>();
    }

    public void Register(String accountnumber) {
        if (!account.containsKey(accountnumber)) {
            account.put(accountnumber, 0.0);
            System.out.println("[" + this + "] 계좌번호 : " + accountnumber + " 가 등록되었습니다.");
        } else {
            System.out.println("존재하는 계좌번호 입니다.");
        }
    }

    public void Deposit(String accountnum, double money) {
        if (account.containsKey(accountnum)) {
            account.put(accountnum, money + account.get(accountnum));
            bankMoney += money;
            System.out.println("[" + this + "] 계좌 " + accountnum + " 에 " + money + "원이 입금되었습니다.");
        } else {
            System.out.println("존재하지 않는 계좌번호 입니다.");
        }
    }

    public void Withdraw(String accountnum, double money) {
        if (bankMoney >= money && account.get(accountnum) >= money) {
            account.put(accountnum, account.get(accountnum) - money);
            bankMoney -= money;
            System.out.println("[" + this + "] 계좌 " + accountnum + " 에서 " + money + "원이 출금되었습니다.");
        } else {
            System.out.println("잔액이 부족하여 출금할 수 없습니다.");
        }
    }
}
```

### **2. `Owner` 클래스 (고객 관리)**

```java
class Owner {
    private String name;   // 고객 이름
    private double balance;  // 고객 보유 현금
    private Map<String, Double> account;  // 고객 계좌 목록

    public Owner(String name, double balance) {
        this.name = name;
        this.balance = balance;
        this.account = new HashMap<>();
    }

    public void Register(String accountnumber, Bank bank) {
        if (!account.containsKey(accountnumber)) {
            bank.Register(accountnumber);
            account.put(accountnumber, 0.0);
            System.out.println("[" + this + "] 계좌번호 : " + accountnumber + " 가 등록되었습니다.");
        } else {
            System.out.println("이미 등록된 계좌입니다.");
        }
    }

    public void Deposit(String accountnum, double money, Bank bank) {
        if (!account.containsKey(accountnum) || balance < money) {
            System.out.println("계좌번호가 없거나 보유 금액이 부족합니다.");
            return;
        }
        bank.Deposit(accountnum, money);
        account.put(accountnum, money + account.get(accountnum));
        balance -= money;
        System.out.println("[" + this + "] 계좌 " + accountnum + " 에 " + money + "원이 입금되었습니다.");
    }

    public void Withdraw(String accountnum, double money, Bank bank) {
        if (!account.containsKey(accountnum) || account.get(accountnum) < money) {
            System.out.println("계좌번호가 없거나 출금 금액이 부족합니다.");
            return;
        }
        bank.Withdraw(accountnum, money);
        account.put(accountnum, account.get(accountnum) - money);
        balance += money;
        System.out.println("[" + this + "] 계좌 " + accountnum + " 에서 " + money + "원이 출금되었습니다.");
    }
}
```

### **3. `BankService` (테스트 실행)**

```java
public class BankService {
    public static void main(String[] args) {
        // 은행 객체 생성
        Bank b1 = new Bank("MyBank", 1000000.0);

        // 사용자 객체 생성
        Owner owner = new Owner("홍길동", 50000.0);

        // 계좌 등록
        owner.Register("123-456", b1);

        // 입금 테스트
        owner.Deposit("123-456", 20000, b1);

        // 출금 테스트
        owner.Withdraw("123-456", 10000, b1);
    }
}
```

## 5️⃣ **핵심 정리**

1. **은행과 고객을 클래스로 분리하여 객체 지향 프로그래밍 적용**
2. `HashMap`을 활용하여 계좌를 관리하고 입출금 기능을 구현
3. 고객이 계좌를 등록하고, 입출금 작업을 수행할 수 있도록 설계
4. `main` 메서드에서 실행하여 기능을 검증
