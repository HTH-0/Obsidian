### 📝 Java Reflection 개요

## 📌 주요 개념

- **Reflection(리플렉션)**: 실행 중인 프로그램에서 클래스, 메서드, 필드 등의 정보를 동적으로 조회 및 조작하는 기능
- **동적 객체 접근**: 컴파일 시점에 알 수 없는 클래스 정보를 런타임에 가져와 사용할 수 있음
- **주요 API**: `Class`, `Field`, `Method`, `Constructor`
- **활용 분야**: 프레임워크 개발(Spring, Hibernate 등), 테스트 프레임워크, 의존성 주입(DI), 동적 프록시
- **주의점**: 성능 오버헤드 발생 가능, 접근 제한 가능성(`private` 필드 등)

---

## 🔎 **Reflection 주요 클래스**

|클래스|설명|
|---|---|
|`Class`|클래스 정보를 담고 있는 객체|
|`Field`|클래스의 필드를 조회 및 수정|
|`Method`|클래스의 메서드를 조회 및 호출|
|`Constructor`|생성자를 조회하고 객체 생성|

---

## 💻 **예제 코드: Reflection 활용**

### 1️⃣ **클래스 정보 조회 (`Class`)**

```java
class Example {
    private String field;
    public void method() {}
}

public class ReflectionTest {
    public static void main(String[] args) throws ClassNotFoundException {
        Class<?> clazz = Class.forName("Example");

        System.out.println("클래스 이름: " + clazz.getName());
        System.out.println("슈퍼 클래스: " + clazz.getSuperclass().getName());
    }
}
```

---

### 2️⃣ **필드 정보 조회 및 수정 (`Field`)**

```java
import java.lang.reflect.Field;

class Example {
    private String message = "Hello";
}

public class ReflectionFieldTest {
    public static void main(String[] args) throws Exception {
        Example obj = new Example();
        Class<?> clazz = obj.getClass();

        Field field = clazz.getDeclaredField("message");
        field.setAccessible(true); // private 필드 접근 허용
        System.out.println("기존 값: " + field.get(obj));

        field.set(obj, "Reflection 적용됨");
        System.out.println("변경 후 값: " + field.get(obj));
    }
}
```

---

### 3️⃣ **메서드 조회 및 호출 (`Method`)**

```java
import java.lang.reflect.Method;

class Example {
    public void sayHello(String name) {
        System.out.println("Hello, " + name);
    }
}

public class ReflectionMethodTest {
    public static void main(String[] args) throws Exception {
        Example obj = new Example();
        Class<?> clazz = obj.getClass();

        Method method = clazz.getMethod("sayHello", String.class);
        method.invoke(obj, "Java");
    }
}
```

---

### 4️⃣ **생성자 조회 및 객체 생성 (`Constructor`)**

```java
import java.lang.reflect.Constructor;

class Example {
    private String message;
    public Example(String msg) {
        this.message = msg;
    }
    public void showMessage() {
        System.out.println("Message: " + message);
    }
}

public class ReflectionConstructorTest {
    public static void main(String[] args) throws Exception {
        Class<?> clazz = Example.class;

        Constructor<?> constructor = clazz.getConstructor(String.class);
        Example obj = (Example) constructor.newInstance("Reflection 사용");

        obj.showMessage();
    }
}
```

## 🔎 **핵심 정리**

1. **Reflection**을 사용하면 실행 중인 클래스의 정보를 조회 및 수정할 수 있음
2. **주요 API**: `Class`, `Field`, `Method`, `Constructor`
3. **활용 분야**: 프레임워크 개발(Spring, 테스트 도구, 동적 프록시 등)
4. **단점**: 성능 오버헤드 및 보안 이슈 가능 → 필요한 경우에만 사용

✅ **정적인 방식이 가능한 경우, Reflection 대신 일반적인 코드 사용 권장!**
