### 📝 Java Reflection을 활용한 객체 조작 (`C02BASIC.java`)

## 📌 주요 개념

- Reflection을 활용하여 **메서드 호출, 생성자 사용, 필드 값 변경**
- **`getDeclaredMethod()`** → 특정 메서드를 찾아 실행
- **`getConstructor()`** → 특정 생성자를 호출하여 객체 생성
- **`getDeclaredField()`** → 특정 필드에 값 설정

---

## 💻 **코드 분석**

```java
import java.lang.reflect.Constructor;
import java.lang.reflect.Field;
import java.lang.reflect.Method;

class Simple {
    String name;
    int age;
    String addr;

    public Simple() {}
    public Simple(String name) { this.name = name; }
    public Simple(String name, int age) { this.name = name; this.age = age; }
    public Simple(String name, int age, String addr) { this.name = name; this.age = age; this.addr = addr; }

    // Getter & Setter
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }
    public String getAddr() { return addr; }
    public void setAddr(String addr) { this.addr = addr; }

    @Override
    public String toString() {
        return "Simple [name=" + name + ", age=" + age + ", addr=" + addr + "]";
    }
}

public class C02BASIC {
    public static void main(String[] args) throws Exception {
        // 1️⃣ Reflection을 사용한 메서드 호출
        Simple ob = new Simple();
        ob.setAge(10);

        System.out.println(Simple.class);
        Class<?> clazz = Class.forName("Ch29_.Simple"); // 클래스 정보 가져오기

        Method method = clazz.getDeclaredMethod("getAge"); // getAge() 메서드 찾기
        Object result = method.invoke(ob); // 메서드 실행
        System.out.println(result); // 10 출력

        // 2️⃣ Reflection을 사용한 생성자 호출
        Constructor<?> constructor = clazz.getConstructor(String.class); // String 매개변수를 받는 생성자 찾기
        System.out.println(constructor);
        Object obj = constructor.newInstance("홍길동"); // 새로운 객체 생성
        System.out.println(obj); // Simple [name=홍길동, age=0, addr=null]

        // 3️⃣ Reflection을 사용한 필드 값 변경
        Field field = clazz.getDeclaredField("addr");
        field.setAccessible(true); // private 필드 접근 허용
        field.set(ob, "대구"); // addr 값을 "대구"로 변경
        System.out.println(ob); // Simple [name=null, age=10, addr=대구]
    }
}
```

---

## 🔎 **Reflection 주요 기능**

|기능|메서드|설명|
|---|---|---|
|메서드 호출|`getDeclaredMethod("메서드명")`|특정 메서드를 찾아 실행|
|생성자 호출|`getConstructor(매개변수 타입)`|특정 생성자를 호출하여 객체 생성|
|필드 값 변경|`getDeclaredField("필드명")`|특정 필드에 값 설정|

## 🔎 **핵심 정리**

1. **Reflection을 활용하여 동적으로 객체를 조작 가능**
2. `getDeclaredMethod()` → **메서드 실행**
3. `getConstructor()` → **객체 생성**
4. `getDeclaredField()` → **필드 값 변경**
