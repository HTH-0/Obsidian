### 📝 Java Reflection 활용 기본 예제 (`C01BASIC.java`)

## 📌 주요 개념

- **Reflection을 사용하여 클래스의 필드, 생성자, 메서드를 동적으로 조회**
- `Class.forName("java.lang.String")` → `String` 클래스 정보를 가져옴
- `getDeclaredFields()`, `getDeclaredConstructors()`, `getDeclaredMethods()` 메서드를 활용하여 정보 조회 가능

---

## 💻 **코드 분석**

```java
import java.lang.reflect.Constructor;
import java.lang.reflect.Field;
import java.lang.reflect.Method;

public class C01BASIC {
    public static void main(String[] args) throws Exception {
        
        // 1️⃣ Class 객체 생성 (String 클래스 정보 조회)
        Class<?> clazz = Class.forName("java.lang.String");

        // 2️⃣ 모든 필드 조회
//        Field[] fields = clazz.getDeclaredFields();
//        for (Field field : fields) {
//            System.out.println(field);
//        }

        // 3️⃣ 모든 생성자 조회
//        Constructor<?>[] constructors = clazz.getDeclaredConstructors();
//        for (Constructor<?> con : constructors) {
//            System.out.println(con);
//        }

        // 4️⃣ 모든 메서드 조회
        Method[] methods = clazz.getDeclaredMethods();
        for (Method m : methods) {
            System.out.println(m);
        }
    }
}
```

---

## 🔎 **Reflection 주요 메서드**

|메서드|설명|
|---|---|
|`getDeclaredFields()`|**모든 필드(변수) 정보 조회**|
|`getDeclaredConstructors()`|**모든 생성자 정보 조회**|
|`getDeclaredMethods()`|**모든 메서드 정보 조회**|

## 🔎 **핵심 정리**

1. **Reflection**을 사용하면 **클래스의 내부 구조(필드, 생성자, 메서드)를 동적으로 조회** 가능
2. `Class.forName("클래스명")` → **런타임에 클래스 정보를 가져올 수 있음**
3. `getDeclaredFields()` → **모든 필드 조회**
4. `getDeclaredConstructors()` → **모든 생성자 조회**
5. `getDeclaredMethods()` → **모든 메서드 조회**
6. **실무에서 남용 금지!**
    - **성능 저하** 발생 가능
    - **보안 문제** (private 접근 가능)

✅ **프레임워크(Spring, Hibernate)에서 동적 객체 조작 시 유용하게 사용!**
