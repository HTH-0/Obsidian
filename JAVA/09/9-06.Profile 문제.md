- **Getter & Setter 메서드 추가**
- **`toString()` 오버라이딩**: 필드 값을 `','`로 연결하여 반환

## 💻 코드 정리

```java
package Ch09;

class Profile {
    // 속성
    String name;
    String addr;
    String job;
    String major;

    // 1) 기본 생성자
    Profile() {}

    // 2) 모든 인자를 받는 생성자
    public Profile(String name, String addr, String job, String major) {
        this.name = name;
        this.addr = addr;
        this.job = job;
        this.major = major;
    }

    // 3) 문자열을 ',' 기준으로 나누어 속성에 저장하는 생성자
    public Profile(String all) {
        String[] words = all.split(",");
        this.name = words[0];
        this.addr = words[1];
        this.job = words[2];
        this.major = words[3];
    }

    // Getter & Setter
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public String getAddr() { return addr; }
    public void setAddr(String addr) { this.addr = addr; }

    public String getJob() { return job; }
    public void setJob(String job) { this.job = job; }

    public String getMajor() { return major; }
    public void setMajor(String major) { this.major = major; }

    // toString() 재정의
    @Override
    public String toString() {
        return "'" + name + "','" + addr + "','" + job + "','" + major + "'";
    }

    // 3) 특정 문자열 포함 여부 확인
    boolean isContain(String findstr) {
        return name.contains(findstr) || addr.contains(findstr) || job.contains(findstr) || major.contains(findstr);
    }

    // 4) 문자열을 ','로 나누어 속성과 비교
    boolean isEquals(String str) {
        String[] splitted = str.split(",");
        return splitted[0].equals(name) && splitted[1].equals(addr) && splitted[2].equals(job) && splitted[3].equals(major);
    }
}

public class C06Ex {
    public static void main(String[] args) {
        Profile hong = new Profile("홍길동,대구,프로그래머,컴퓨터공학");
        System.out.println(hong.toString());

        System.out.println("길동 포함여부 : " + hong.isContain("길동")); // true
        System.out.println("컴퓨터 포함여부 : " + hong.isContain("컴퓨터")); // true
        System.out.println("프로필 일치여부 : " + hong.isEquals("홍길동,대구,프로그래머,컴퓨터공학"));// true
        System.out.println("프로필 일치여부 : " + hong.isEquals("홍길동,울산,프로그래머,컴퓨터공학"));// false
    }
}
```

## 🔎 코드 분석

### 1️⃣ **문자열 기반 객체 생성**

```java
Profile hong = new Profile("홍길동,대구,프로그래머,컴퓨터공학");
```

- `"홍길동,대구,프로그래머,컴퓨터공학"` → `split(",")` 활용하여 필드 값에 저장

### 2️⃣ **객체 출력 (`toString()` 활용)**

```java
System.out.println(hong.toString());
```

- `'홍길동','대구','프로그래머','컴퓨터공학'` 형식으로 출력

### 3️⃣ **문자열 포함 여부 확인 (`isContain()`)**

```java
System.out.println("길동 포함여부 : " + hong.isContain("길동")); // true
System.out.println("컴퓨터 포함여부 : " + hong.isContain("컴퓨터")); // true
```

- `name`, `addr`, `job`, `major` 중 하나라도 `findstr`을 포함하면 `true` 반환

### 4️⃣ **문자열 비교 (`isEquals()`)**

```java
System.out.println("프로필 일치여부 : " + hong.isEquals("홍길동,대구,프로그래머,컴퓨터공학"));// true
System.out.println("프로필 일치여부 : " + hong.isEquals("홍길동,울산,프로그래머,컴퓨터공학"));// false
```

- `split(",")`으로 나눈 문자열과 속성을 비교하여 일치 여부 확인

## 🔎 추가 정보

- **`split(",")` 사용 시 주의점**
    
    - `"홍길동,대구,프로그래머"` → `ArrayIndexOutOfBoundsException` 발생 가능
    - 예외 처리를 추가하면 안정성이 증가함
    
    ```java
    public Profile(String all) {
        String[] words = all.split(",");
        if (words.length == 4) {
            this.name = words[0];
            this.addr = words[1];
            this.job = words[2];
            this.major = words[3];
        } else {
            throw new IllegalArgumentException("잘못된 입력 형식입니다.");
        }
    }
    ```
