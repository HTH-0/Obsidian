# 📝 캡슐화 (Encapsulation) 학습 정리

## 📌 내용

- **캡슐화**: 특정 목적을 가진 기능을 **하나의 단위**로 묶고, 내부 구현을 숨기는 기법
- **정보 은닉**: 외부에서 직접 접근할 수 없도록 특정 기능을 `private`으로 설정
- **메서드 내부 동작을 감추고** 외부에서는 제공된 인터페이스(`public`)만 사용

---

## 💻 코드 정리

```java
package Ch09;

// 엔진 클래스 (캡슐화 적용)
class Engine {
    // 내부 동작을 감춘 private 메서드
    private void 흡입() {
        System.out.println("외부로부터 공기를 빨아들인다.");
    }
    
    private void 압축() {
        System.out.println("가둔 공기를 압축시킨다.");
    }
    
    private void 폭발() {
        System.out.println("일정 수준 압축되면 폭발한다.");
    }
    
    private void 배기() {
        System.out.println("가스를 외부로 보낸다.");
    }

    // 공개된 인터페이스 (외부에서 접근 가능)
    public void EngineStart() {
        흡입();
        압축();
        폭발();
        배기();
    }
}

// 자동차 클래스 (엔진을 포함)
class Car {
    Engine engine; // 엔진 객체 포함 (HAS-A 관계)
    
    // 생성자에서 엔진 초기화
    Car() {
        engine = new Engine();
    }
    
    // 자동차의 동작을 정의
    void run() {
        engine.EngineStart();
    }
}

public class C02캡슐화 {
    public static void main(String[] args) {
        Car car = new Car();  // 자동차 객체 생성
        car.run();            // 자동차 작동 (엔진 시동)
    }
}
```

## 🔎 코드 분석

### 1️⃣ **`Engine` 클래스 (캡슐화 적용)**

```java
private void 흡입() { System.out.println("외부로부터 공기를 빨아들인다."); }
private void 압축() { System.out.println("가둔 공기를 압축시킨다."); }
private void 폭발() { System.out.println("일정 수준 압축되면 폭발한다."); }
private void 배기() { System.out.println("가스를 외부로 보낸다."); }
```

- 내부 동작(흡입, 압축, 폭발, 배기)은 `private`으로 설정 → **외부에서 직접 호출 불가**
- `public` 메서드 `EngineStart()`를 통해 **일련의 과정을 통합하여 제공**

### 2️⃣ **엔진을 실행하는 `EngineStart()`**

```java
public void EngineStart() {
    흡입();
    압축();
    폭발();
    배기();
}
```

- **외부에서 호출 가능한 메서드**
- `private` 메서드들을 내부적으로 실행 → **캡슐화된 동작을 제공**

### 3️⃣ **자동차 클래스 (`Car`)**

```java
class Car {
    Engine engine;

    Car() {
        engine = new Engine(); // 엔진 초기화
    }

    void run() {
        engine.EngineStart(); // 엔진 가동
    }
}
```

- **자동차(`Car`)는 엔진(`Engine`)을 포함** (`HAS-A` 관계)
- `run()`을 호출하면 내부적으로 `engine.EngineStart()` 실행
- **자동차는 엔진의 세부 동작을 몰라도 실행 가능**

### 4️⃣ **자동차 실행 (메인 메서드)**

```java
public static void main(String[] args) {
    Car car = new Car();
    car.run();
}
```

- `Car` 객체를 생성 → 내부적으로 `Engine` 객체가 생성됨
- `car.run();`을 실행하면 `EngineStart()`가 호출되어 **흡입 → 압축 → 폭발 → 배기** 과정이 수행됨

## 🔎 추가 정보

- **캡슐화를 통해 내부 구현을 숨기고 외부에서의 직접 접근을 차단**
- **필요한 기능만 `public`으로 제공하여 인터페이스를 명확하게 정의**
- **클래스 내부 동작을 보호하여 유지보수 및 확장성을 높임**
- **자동차가 엔진의 세부 동작을 몰라도 동작 가능 → 모듈화와 재사용성 증가**
