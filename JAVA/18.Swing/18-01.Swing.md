# 📝 Java Swing 학습 정리

## 📌 개요

- Java Swing을 사용한 GUI 애플리케이션 구현
- `JFrame`, `JPanel`, `JButton`, `JTextField`, `JTextArea` 등 UI 컴포넌트 활용
- 이벤트 처리(`ActionListener`, `KeyListener`, `MouseListener`) 적용

---

## 💻 코드 정리

### 1️⃣ **기본적인 JFrame 생성**

```java
import javax.swing.JFrame;

public class C01SwingMain {
    public static void main(String[] args) {
        JFrame frame = new JFrame("첫번째 프레임");
        frame.setBounds(100, 100, 500, 500);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setVisible(true);
    }
}
```

- `JFrame` 생성 후 크기 설정 및 화면에 표시
- `setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE)` → x버튼 클릭 시 프로세스 종료

---

### 2️⃣ **JFrame을 상속받아 GUI 클래스 구성**

```java
import javax.swing.JFrame;

class C02GUI extends JFrame {
    C02GUI(String title) {
        super(title);
        setBounds(100, 100, 500, 500);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setVisible(true);
    }
}

public class C02SwingMain {
    public static void main(String[] args) {
        new C02GUI("두번째 프레임");
    }
}
```

- `JFrame`을 상속받는 `C02GUI` 클래스 생성
- `super(title)` → 부모 클래스의 생성자를 호출하여 프레임 타이틀 설정

### 3️⃣ **JPanel 추가 및 배경 색상 설정**

```java
import java.awt.Color;
import javax.swing.JFrame;

class C03GUI extends JFrame {
    C03GUI(String title) {
        super(title);
        setBounds(100, 100, 500, 500);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setVisible(true);

        JPanel panel = new JPanel();
//      panel.setBackground(new Color(71, 144, 0)); // 배경색 설정
        add(panel);

}

public class C03SwingMain {
    public static void main(String[] args) {
        new C03GUI("패널 추가 프레임");

```

- `JPanel`을 추가하여 UI 컴포넌트 배치를 위한 컨테이너 역할 수행
- `setBackground(Color color)`를 이용해 배경 색상 변경 가능

### 4️⃣ **버튼, 텍스트 필드, 텍스트 영역 추가**

```java
import javax.swing.*;

class C04GUI extends JFrame {
    C04GUI(String title) {
        super(title);
        setBounds(100, 100, 250, 500);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

        JPanel panel = new JPanel();
        panel.setLayout(null);

        JButton btn1 = new JButton("BTN01");
        btn1.setBounds(10, 10, 100, 30);
        JButton btn2 = new JButton("BTN02");
        btn2.setBounds(120, 10, 100, 30);

        JTextField txt1 = new JTextField();
        txt1.setBounds(10, 50, 210, 35);

        JTextArea area1 = new JTextArea();
        JScrollPane scroll1 = new JScrollPane(area1);
        scroll1.setBounds(10, 90, 210, 360);

        panel.add(btn1);
        panel.add(btn2);
        panel.add(txt1);
        panel.add(scroll1);
        add(panel);
        
        setVisible(true);
    }
}

public class C04SwingMain {
    public static void main(String[] args) {
        new C04GUI("UI 컴포넌트 추가 프레임");
    }
}
```

- `JTextField` → 한 줄 입력 필드
- `JTextArea` → 여러 줄 입력 가능
- `JScrollPane` → 스크롤 가능 영역 추가

### 5️⃣ **이벤트 처리 (버튼 클릭 이벤트)**

```java
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;
import javax.swing.*;

class C06GUI extends JFrame implements ActionListener {
    JButton btn1, btn2, btn3, input;

    C06GUI(String title) {
        super(title);
        setBounds(100, 100, 410, 400);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

        JPanel panel = new JPanel();
        panel.setLayout(null);

        btn1 = new JButton("파일로 저장");
        btn1.setBounds(270, 10, 110, 30);
        btn2 = new JButton("1:1 요청");
        btn2.setBounds(270, 50, 110, 30);
        btn3 = new JButton("대화기록 보기");
        btn3.setBounds(270, 90, 110, 30);
        input = new JButton("입력");
        input.setBounds(270, 300, 110, 30);

        btn1.addActionListener(this);
        btn2.addActionListener(this);
        btn3.addActionListener(this);
        input.addActionListener(this);

        panel.add(btn1);
        panel.add(btn2);
        panel.add(btn3);
        panel.add(input);
        add(panel);

        setVisible(true);
    }

    @Override
    public void actionPerformed(ActionEvent e) {
        if (e.getSource() == btn1) {
            System.out.println("파일로 저장 클릭");
        } else if (e.getSource() == btn2) {
            System.out.println("1:1 요청 클릭");
        } else if (e.getSource() == btn3) {
            System.out.println("대화기록 보기 클릭");
        } else if (e.getSource() == input) {
            System.out.println("입력 버튼 클릭");
        }
    }
}

public class C06SwingEventMain {
    public static void main(String[] args) {
        new C06GUI("이벤트 처리 UI");
    }
}
```

- `ActionListener` 인터페이스를 구현하여 버튼 클릭 이벤트 처리
- `getSource()`를 활용해 클릭된 버튼 식별

### 6️⃣ **키보드 및 마우스 이벤트 처리**

```java
import java.awt.event.*;
import javax.swing.*;

class C07GUI extends JFrame implements ActionListener, KeyListener, MouseListener {
    JButton input;
    JTextField txt1;
    JTextArea area1;

    C07GUI(String title) {
        super(title);
        setBounds(100, 100, 410, 400);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

        JPanel panel = new JPanel();
        panel.setLayout(null);

        area1 = new JTextArea();
        JScrollPane scroll1 = new JScrollPane(area1);
        scroll1.setBounds(10, 10, 250, 280);

        input = new JButton("입력");
        input.setBounds(270, 300, 110, 30);
        txt1 = new JTextField();
        txt1.setBounds(10, 300, 250, 30);

        input.addActionListener(this);
        txt1.addKeyListener(this);
        area1.addMouseListener(this);

        panel.add(scroll1);
        panel.add(input);
        panel.add(txt1);
        add(panel);
        
        setVisible(true);
    }

    @Override
    public void keyPressed(KeyEvent e) {
        if (e.getSource() == txt1 && e.getKeyCode() == KeyEvent.VK_ENTER) {
            String message = txt1.getText();
            area1.append(message + "\n");
            txt1.setText("");
        }
    }

    @Override
    public void actionPerformed(ActionEvent e) {
        System.out.println("버튼 클릭");
    }

    // 생략된 다른 이벤트 핸들러...
}

public class C07SwingEventMain {
    public static void main(String[] args) {
        new C07GUI("이벤트 UI");
    }
}
```

- `KeyListener` 활용하여 `Enter` 입력 시 텍스트 추가
- `MouseListener`를 이용해 마우스 클릭 이벤트 처리
