# 📝 **Java 업캐스팅 & 다운캐스팅 예제**

## 📌 내용

- **업캐스팅(Upcasting)**: 서브 클래스 객체를 슈퍼 클래스 타입으로 참조
- **다운캐스팅(Downcasting)**: 업캐스팅된 객체를 다시 서브 클래스 타입으로 변환
- **메서드 오버라이딩** 활용 → 업캐스팅 상태에서도 오버라이딩된 메서드 호출 가능

---

## 💻 코드 정리

```java
package Ch12;

class C08Super {
    
    void func1() {
        System.out.println("C08Super.func1() call");
    }

    void func2() {
        // func2()는 오버라이딩을 위해 빈 상태 유지
    }
}

class C08Sub extends C08Super {

    @Override
    void func2() {
        System.out.println("C08Sub.func2() call");
    }
}

public class C08UpDownCastingMain {
    public static void main(String[] args) {

        // No casting (슈퍼 클래스 인스턴스)
        C08Super ob1 = new C08Super();
        ob1.func1();

        // No casting (서브 클래스 인스턴스)
        C08Sub ob2 = new C08Sub();
        ob2.func1(); // 상속된 메서드
        ob2.func2(); // 오버라이딩된 메서드 실행

        // Upcasting (서브 클래스 객체를 슈퍼 클래스 타입으로 참조)
        C08Super ob3 = new C08Sub();
        ob3.func1(); // 상속된 메서드
        ob3.func2(); // 오버라이딩된 메서드 실행 (C08Sub의 func2 호출)

        // 다운캐스팅을 수행하지 않으면 서브 클래스에서 추가한 멤버 접근 불가능
        // 다운캐스팅을 통해 C08Sub 타입으로 변환 가능
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **업캐스팅 (Upcasting)**

```java
C08Super ob3 = new C08Sub();
```

- `C08Sub` 객체를 `C08Super` 타입으로 참조
- `func1()`과 `func2()` 호출 가능 → `func2()`는 `C08Sub`의 오버라이딩된 메서드 실행

### 2️⃣ **업캐스팅의 특징**

```java
ob3.func1(); // C08Super.func1() 실행
ob3.func2(); // C08Sub.func2() 실행 (오버라이딩)
```

- 업캐스팅된 상태에서도 **오버라이딩된 메서드**(`func2()`)는 실행 가능
- 하지만, 서브 클래스에 추가된 **새로운 필드나 메서드**에는 접근 불가능

### 3️⃣ **다운캐스팅 (Downcasting)**

업캐스팅 상태에서는 서브 클래스의 추가된 멤버에 접근할 수 없음.  
이럴 때 다운캐스팅을 수행해야 함.

```java
C08Sub ob4 = (C08Sub) ob3; // 다운캐스팅
ob4.func2(); // C08Sub.func2() 실행
```

- `ob3`(업캐스팅된 객체)를 `C08Sub` 타입으로 변환
- 다운캐스팅 후 `C08Sub`의 고유 메서드 및 추가 멤버 접근 가능

---

## 🔎 추가 정보

- **업캐스팅**: 하위 클래스 객체를 상위 클래스 타입으로 변환 (자동 변환)
- **다운캐스팅**: 업캐스팅된 객체를 다시 하위 클래스 타입으로 변환 (명시적 변환 필요)
- **메서드 오버라이딩**: 업캐스팅 상태에서도 동적 바인딩을 통해 재정의된 메서드 실행 가능
