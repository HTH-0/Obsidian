# 📌 상속을 활용한 `Employee` 클래스 설계

## 📝 내용 요약

- **부모 클래스 `Employee`**: 모든 직원(Employee)의 공통 속성 (`name`, `age`, `addr`)을 정의
- **자식 클래스 `Parttimer`**: `Employee`를 상속받아 추가 속성 **시급(`hour_pay`)** 추가
- **자식 클래스 `Regular`**: `Employee`를 상속받아 추가 속성 **연봉(`salary`)** 추가
- **`toString()`을 오버라이딩하여 객체 정보를 출력**

---

## 💻 코드 정리

```java
package Ch12;

// 부모 클래스: 모든 직원(Employee)의 공통 속성을 정의
class Employee {
    public String name;
    private int age;
    private String addr;

    public Employee(String name, int age, String addr) {
        this.name = name;
        this.age = age;
        this.addr = addr;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        this.age = age;
    }

    public String getAddr() {
        return addr;
    }

    public void setAddr(String addr) {
        this.addr = addr;
    }
}

// 자식 클래스: 아르바이트 직원 (Parttimer)
class Parttimer extends Employee {
    private int hour_pay;  // 시급

    public Parttimer(String name, int age, String addr, int hour_pay) {
        super(name, age, addr);
        this.hour_pay = hour_pay;
    }

    public void setHourPay(int hour_pay) {
        this.hour_pay = hour_pay;
    }

    @Override
    public String toString() {
        return "Parttimer [hour_pay=" + hour_pay + ", name=" + name + ", age=" + getAge() + ", addr=" + getAddr() + "]";
    }
}

// 자식 클래스: 정규직 직원 (Regular)
class Regular extends Employee {
    private int salary;  // 연봉

    public Regular(String name, int age, String addr, int salary) {
        super(name, age, addr);
        this.salary = salary;
    }

    public void setSalary(int salary) {
        this.salary = salary;
    }

    @Override
    public String toString() {
        return "Regular [salary=" + salary + ", name=" + name + ", age=" + getAge() + ", addr=" + getAddr() + "]";
    }
}

public class C05Ex {
    public static void main(String[] args) {
        // 아르바이트 직원 객체 생성
        Parttimer emp1 = new Parttimer("홍길동", 25, "대구", 20000);
        emp1.setAge(100);  // age 변경

        // 정규직 직원 객체 생성
        Regular emp2 = new Regular("서길동", 45, "울산", 50000000);

        // 객체 정보 출력
        System.out.println(emp1);
        System.out.println(emp2);
    }
}
```

## 🔎 코드 분석

### 1️⃣ **부모 클래스 `Employee`**

```java
class Employee {
    public String name;
    private int age;
    private String addr;
}
```

- **공통 속성**
    - `name`: 직원 이름 (public, 직접 접근 가능)
    - `age`, `addr`: 직원 나이와 주소 (private, `getter/setter` 사용)
- **생성자와 `getter/setter` 추가**
    - `private` 속성(`age`, `addr`)은 직접 접근이 불가능하므로 `getter/setter` 사용

### 2️⃣ **자식 클래스 `Parttimer`**

```java
class Parttimer extends Employee {
    private int hour_pay;
}
```

- **부모 클래스의 속성(`name`, `age`, `addr`)을 상속받음**
- **추가 속성**
    - `hour_pay` (시급) 추가
- **생성자에서 `super(name, age, addr)`를 호출하여 부모 생성자 실행**
- **`toString()` 오버라이딩** → `Parttimer` 객체 정보 출력

### 3️⃣ **자식 클래스 `Regular`**

```java
class Regular extends Employee {
    private int salary;
}
```

- **부모 클래스의 속성(`name`, `age`, `addr`)을 상속받음**
- **추가 속성**
    - `salary` (연봉) 추가
- **생성자에서 `super(name, age, addr)`를 호출하여 부모 생성자 실행**
- **`toString()` 오버라이딩** → `Regular` 객체 정보 출력

### 4️⃣ **객체 생성 및 실행**

```java
Parttimer emp1 = new Parttimer("홍길동", 25, "대구", 20000);
emp1.setAge(100);  // setAge()를 이용해 변경 가능

Regular emp2 = new Regular("서길동", 45, "울산", 50000000);
```

- `Parttimer` 객체(`emp1`): `"홍길동", 25세, "대구", 시급 20000원`
- `Regular` 객체(`emp2`): `"서길동", 45세, "울산", 연봉 50000000원`
- `setAge(100)`을 사용하여 `emp1`의 나이를 변경

### 5️⃣ **객체 정보 출력**

```java
System.out.println(emp1);
System.out.println(emp2);
```

- `toString()` 오버라이딩으로 객체의 정보를 보기 쉽게 출력

## 🔎 추가 정보

### ✅ `toString()` 활용

- `toString()`을 오버라이딩하면 **객체의 정보를 문자열로 쉽게 출력 가능**
- 예제에서는 **직원 정보(이름, 나이, 주소)와 추가 속성(시급/연봉)을 한 번에 출력 가능하도록 구현**

### ✅ `super()`의 역할

- **부모 클래스의 생성자를 명시적으로 호출**
- `Parttimer`와 `Regular` 클래스는 **공통 속성(name, age, addr)을 부모 생성자를 통해 초기화**
