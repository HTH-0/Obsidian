# 📝 Java 메서드 접근 (Method Access)

## 📌 내용

- **업캐스팅(Upcasting)**과 **다운캐스팅(Downcasting)** 학습
- 업캐스팅된 객체에서 오버라이딩된 메서드는 호출 가능
- 업캐스팅 후, 부모 타입에 존재하지 않는 메서드는 호출 불가능
- 다운캐스팅을 통해 원래 타입으로 복원하면 하위 클래스의 메서드 사용 가능

---

## 💻 코드 정리

```java
package Ch12.ex;

// 메서드 접근 예제
class Vehicle {
    void start() {
        System.out.println("탈것의 시동을 겁니다");
    }
}

class Car extends Vehicle {
    void start() {
        System.out.println("자동차의 시동을 겁니다");
    }
    
    void turboBoost() {
        System.out.println("자동차가 터보로 가속합니다!");
    }
}

public class Ex02MethodAccess {
    public static void main(String[] args) {
        System.out.println("=== 연습문제 2: 메서드 접근 ===");

        Car c1 = new Car();     // 인스턴스 생성
        Vehicle v1 = c1;        // 업캐스팅

        v1.start();             // 오버라이딩된 메서드 호출 (동적 바인딩 적용)
//      v1.turboBoost();       // 컴파일 오류 (Vehicle 타입에는 turboBoost() 없음)

        Car c2 = (Car) v1;      // 다운캐스팅
        c2.turboBoost();        // turboBoost() 호출 가능
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **업캐스팅(Upcasting)**

```java
Vehicle v1 = c1;
```

- `Car` 인스턴스를 `Vehicle` 타입으로 업캐스팅
- `Vehicle` 타입이므로 부모 클래스에서 정의된 메서드만 접근 가능

### 2️⃣ **오버라이딩된 메서드 호출**

```java
v1.start();
```

- `Vehicle` 타입이지만, `Car`에서 오버라이딩된 `start()` 실행됨
- **동적 바인딩(Dynamic Binding)**으로 인해 실제 객체의 메서드가 실행

### 3️⃣ **부모 타입에서 하위 클래스 메서드 호출 불가**

```java
// v1.turboBoost();
```

- `Vehicle` 타입에는 `turboBoost()`가 없기 때문에 컴파일 오류 발생

### 4️⃣ **다운캐스팅(Downcasting)**

```java
Car c2 = (Car) v1;
```

- `v1`을 다시 `Car` 타입으로 변환하여 `turboBoost()` 호출 가능
- 다운캐스팅 시, 반드시 원래 `Car` 타입 객체인지 확인해야 함
- 잘못된 캐스팅은 `ClassCastException` 발생 가능

---

## 🔎 추가 정보

### ✅ **다운캐스팅 시 `instanceof` 사용**

```java
if (v1 instanceof Car) {
    Car c2 = (Car) v1;
    c2.turboBoost();
}
```

- `instanceof`를 사용하면 **안전한 다운캐스팅 가능**
- `true`일 때만 캐스팅을 수행하여 런타임 오류 방지
