# 📌 상속을 활용한 `ColorTV` 클래스 구현

## 📝 내용 요약

- **부모 클래스 `TV`**: `size`(인치) 정보를 저장하는 TV 클래스
- **자식 클래스 `ColorTV`**: `TV`를 상속받고, 추가적으로 `color`(컬러 수) 정보를 저장
- **생성자에서 `super(size)`를 활용하여 부모 클래스의 생성자 호출**
- **`printProperty()` 메서드에서 TV 크기와 컬러 수 출력**

---

## 💻 코드 정리

```java
package Ch12;

// 부모 클래스 (TV)
class TV {
    int size;

    TV(int size) {
        this.size = size;
    }
}

// 자식 클래스 (ColorTV) - TV 클래스를 상속
class ColorTV extends TV {
    int color;

    // 부모 클래스의 size를 상속받고, 추가로 color 속성 추가
    ColorTV(int size, int color) {
        super(size);  // 부모 클래스의 생성자 호출
        this.color = color;
    }

    // TV 크기와 컬러 수 출력
    void printProperty() {
        System.out.printf("%d인치 %d컬러\n", this.size, this.color);
    }
}

public class C04Ex {
    public static void main(String[] args) {
        ColorTV myTV = new ColorTV(32, 1024);
        myTV.printProperty();  // 32인치 1024컬러 출력
    }
}
```

## 🔎 코드 분석

### 1️⃣ **부모 클래스 `TV`**

```java
class TV {
    int size;

    TV(int size) {
        this.size = size;
    }
}
```

- `TV` 클래스는 `size` 속성을 가지고 있으며, **생성자로 값을 초기화**
- `size`는 TV의 화면 크기를 나타냄

### 2️⃣ **자식 클래스 `ColorTV` (상속)**

```java
class ColorTV extends TV {
    int color;

    ColorTV(int size, int color) {
        super(size);  // 부모 클래스(TV)의 생성자 호출
        this.color = color;
    }

    void printProperty() {
        System.out.printf("%d인치 %d컬러\n", this.size, this.color);
    }
}
```

- `ColorTV`는 `TV`를 **상속받아 `size` 속성을 물려받음**
- `color`(컬러 수) 속성을 추가하여, 컬러 TV의 색상 표현 능력 저장
- `super(size);` → **부모 클래스의 생성자 호출하여 `size` 값 초기화**
- `printProperty()` 메서드 → **TV 크기와 컬러 수를 출력**

### 3️⃣ **객체 생성 및 실행**

```java
ColorTV myTV = new ColorTV(32, 1024);
myTV.printProperty();
```

- `new ColorTV(32, 1024)` → `size=32`, `color=1024`
- `printProperty()` 실행 시 `"32인치 1024컬러"` 출력

## 🔎 추가 정보

### ✅ `super()`의 역할

- **부모 클래스의 생성자를 명시적으로 호출**
- 부모 클래스가 **매개변수를 받는 생성자만 존재할 경우**, 반드시 `super(값)`을 통해 호출해야 함

### ✅ `printProperty()`에서 부모 속성 출력 (`super.size` 사용 가능)

```java
void printProperty() {
    System.out.printf("%d인치 %d컬러\n", super.size, this.color);
}
```

- `super.size`는 부모 클래스(`TV`)의 `size` 속성을 가리킴
- 현재 코드에서는 `this.size`도 동일한 역할을 수행
