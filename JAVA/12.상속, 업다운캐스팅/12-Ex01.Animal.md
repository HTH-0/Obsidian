# 📝 Java 업캐스팅 (Upcasting)

## 📌 내용

- **업캐스팅(Upcasting)** 개념 학습
- `Animal` 클래스를 부모로, `Dog` 클래스를 자식으로 상속
- 업캐스팅 후 오버라이딩된 메서드 호출 가능 여부 확인
- 업캐스팅된 객체가 하위 클래스의 고유 메서드를 호출할 수 없는 이유

---

## 💻 코드 정리

```java
package Ch12.ex;

// 기본 업캐스팅 예제
class Animal {
    void makeSound() {
        System.out.println("동물이 소리를 냅니다");
    }
}

class Dog extends Animal {
    void makeSound() {
        System.out.println("멍멍!");
    }
    
    void fetch() {
        System.out.println("강아지가 공을 가져옵니다!");
    }
}

public class Ex01BasicUpCasting {
    public static void main(String[] args) {
        System.out.println("=== 연습문제 1: 기본 업캐스팅 ===");
        
        Dog d1 = new Dog();   // 인스턴스 생성
        Animal a1 = d1;       // 업캐스팅

        a1.makeSound();       // 메서드 실행 (오버라이딩된 메서드 호출)
//      a1.fetch();          // 컴파일 오류: Animal 타입에서는 fetch() 접근 불가
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **업캐스팅(Upcasting)**

```java
Animal a1 = d1;
```

- `Dog` 인스턴스를 `Animal` 타입의 참조 변수에 저장
- `Animal`이 부모 클래스이므로 자동 형 변환(업캐스팅) 가능

### 2️⃣ **오버라이딩된 메서드 호출**

```java
a1.makeSound();
```

- `Animal` 타입으로 참조해도, `Dog` 클래스에서 오버라이딩한 `makeSound()` 실행됨
- 이유: **동적 바인딩(Dynamic Binding)** 적용

### 3️⃣ **하위 클래스의 고유 메서드 호출 불가**

```java
// a1.fetch();
```

- `fetch()`는 `Dog` 클래스에만 존재
- `Animal` 타입에서는 해당 메서드가 정의되지 않아 **컴파일 오류 발생**

---

## 🔎 추가 정보

### ✅ **업캐스팅이 필요한 이유**

- 다형성(Polymorphism)을 활용하여 **부모 클래스 타입으로 여러 하위 클래스 관리 가능**
- 메서드 오버라이딩을 통해 **일관된 인터페이스 제공**

### ✅ **업캐스팅 후 하위 클래스 메서드를 호출하는 방법**

1. **다운캐스팅(Downcasting) 사용**
    
    ```java
    ((Dog) a1).fetch();  // 강제 형 변환 후 fetch() 호출 가능
    ```
    
2. **instanceof 검사를 통한 안전한 캐스팅**
    
    ```java
    if (a1 instanceof Dog) {
        ((Dog) a1).fetch();
    }
    ```
