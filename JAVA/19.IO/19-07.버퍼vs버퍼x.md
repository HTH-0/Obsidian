# 📌 Java 파일 복사 프로그램 (버퍼 사용)

## ✅ 핵심 개념

- **파일 복사**를 위한 `FileInputStream`과 `FileOutputStream` 사용
- **버퍼 미사용 vs 버퍼 사용** 속도 차이 비교
- **버퍼 크기 설정** (`byte[] buff = new byte[4096];`)

---

## 💻 코드 정리

```java
package Ch19;

import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.InputStream;
import java.io.OutputStream;

public class C07FileCopyMain {
    public static void main(String[] args) throws Exception {

        InputStream in = new FileInputStream("C:\\IOTEST\\dummy.exe");
        OutputStream out = new FileOutputStream("C:\\IOTEST\\COPY_dummy.exe");

        // 01. 버퍼 미사용 코드 (비활성화)
//        while (true) {
//            int data = in.read();
//            if (data == -1) break;
//            out.write((byte) data);
//            out.flush();
//        }

        // 02. 버퍼 사용
        byte[] buff = new byte[4096];  // 4KB 버퍼 생성
        while (true) {
            int data = in.read(buff);  // 버퍼 크기만큼 읽기
            if (data == -1) break;
            out.write(buff, 0, data);  // 읽은 크기만큼만 쓰기
            out.flush();
        }

        in.close();
        out.close();
    }
}
```

---

## 🔎 코드 분석

### **1️⃣ 파일 스트림 생성**

```java
InputStream in = new FileInputStream("C:\\IOTEST\\dummy.exe");
OutputStream out = new FileOutputStream("C:\\IOTEST\\COPY_dummy.exe");
```

- `FileInputStream` → 지정된 파일에서 **바이트 단위**로 데이터를 읽음
- `FileOutputStream` → 새로운 파일에 데이터를 **바이트 단위**로 씀

---

### **2️⃣ 버퍼 미사용 방식 (비효율적)**

```java
while (true) {
    int data = in.read();  // 1바이트씩 읽기
    if (data == -1) break;
    out.write((byte) data);  // 1바이트씩 쓰기
    out.flush();
}
```

- **문제점**: 한 번에 **1바이트**씩 읽고 쓰므로 **속도가 느림**
- **I/O 연산이 많아져** 성능 저하 발생

---

### **3️⃣ 버퍼 사용 방식 (효율적)**

```java
byte[] buff = new byte[4096];  // 4KB 버퍼
while (true) {
    int data = in.read(buff);  // 4KB씩 읽기
    if (data == -1) break;
    out.write(buff, 0, data);  // 읽은 크기만큼만 쓰기
    out.flush();
}
```

- **버퍼 사용 효과**: **4096바이트(4KB)씩 처리**하여 성능 향상
- **메모리 효율적 사용** → `data` 값만큼만 `write()`
- `out.flush()` → 버퍼의 데이터 즉시 파일에 기록

---

### **4️⃣ 파일 스트림 닫기**

```java
in.close();
out.close();
```

- **리소스 해제 필수**
- 파일 스트림을 닫아야 **메모리 누수 및 파일 충돌 방지**

---

## ⚡ 추가 정보

1. **버퍼 크기 조정**
    - 일반적으로 **4KB~8KB** 정도가 적절
    - 너무 크면 **메모리 낭비**, 너무 작으면 **속도 저하**
2. **성능 비교 (대략적인 속도 차이)**
    - **버퍼 미사용**: 약 **10~50배 느림**
    - **버퍼 사용**: **더 빠르게 파일 복사 가능**
