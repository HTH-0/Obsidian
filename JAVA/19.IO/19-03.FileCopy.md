### 📝 **파일 복사 프로그램 (C03FileCopyMain)**

## 📌 **내용 정리**

- Java의 `FileReader`와 `FileWriter`를 활용한 파일 복사 프로그램
- 명령행 인자(`args[]`)를 사용하여 원본 파일과 복사 대상 파일 지정
- `read()`와 `write()`를 활용한 1바이트 단위 복사

---

## 💻 **코드 정리**

```java
package Ch19;

import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;
import java.io.Reader;
import java.io.Writer;

public class C03FileCopyMain {

    private static String Filedir = "C:\\IOTEST\\"; // 기본 디렉터리 설정

    public static void main(String[] args) throws IOException { // args[0] = 원본 파일명, args[1] = 복사할 파일명
        for (String arg : args) {
            System.out.println(arg); // 입력된 인자 출력
        }

        // 파일 읽기 및 쓰기 스트림 생성
        Reader fin = new FileReader(Filedir + args[0]);
        Writer fout = new FileWriter(Filedir + args[1]);

        // 파일 복사 과정
        while (true) {
            int data = fin.read(); // 1바이트씩 읽기
            if (data == -1) break; // 파일 끝(EOF) 도달 시 종료
            fout.write((char) data); // 데이터 쓰기
            fout.flush(); // 즉시 파일에 반영
        }

        // 스트림 닫기
        fout.close();
        fin.close();
    }
}
```

---

## 🔎 **코드 분석**

### 1️⃣ **명령행 인자 출력**

```java
for (String arg : args) {
    System.out.println(arg);
}
```

- 프로그램 실행 시 전달된 명령행 인자를 출력
- `args[0]`: 원본 파일명, `args[1]`: 복사할 파일명

### 2️⃣ **파일 스트림 생성**

```java
Reader fin = new FileReader(Filedir + args[0]);
Writer fout = new FileWriter(Filedir + args[1]);
```

- `FileReader`: 지정된 파일에서 문자 데이터를 읽어옴
- `FileWriter`: 지정된 파일에 문자 데이터를 씀

### 3️⃣ **파일 복사 (1바이트 단위)**

```java
while (true) {
    int data = fin.read();
    if (data == -1) break; // 파일 끝(EOF) 도달 시 종료
    fout.write((char) data);
    fout.flush(); // 버퍼 비우기 (즉시 파일에 반영)
}
```

- `fin.read()`: 한 문자씩 읽기 (`int`형 반환, EOF 시 `-1`)
- `fout.write((char) data)`: 읽은 데이터를 문자로 변환하여 쓰기
- `flush()`: 버퍼 데이터를 강제 저장

### 4️⃣ **자원 해제**

```java
fout.close();
fin.close();
```

- 사용이 끝난 파일 스트림 닫기 (`close()`)
- `close()`를 호출하지 않으면 리소스 누수가 발생할 수 있음

## 🔎 **추가 정보**

### 🔹 **`FileReader`와 `FileWriter`의 특징**

- 문자 기반 스트림 (텍스트 파일에 적합)
- `read()`는 1바이트씩 읽기 때문에 대용량 파일 처리에는 비효율적

### 🔹 **효율 개선 방법**

1. **배열을 활용한 대량 읽기/쓰기**
    
    ```java
    char[] buffer = new char[1024];
    int length;
    while ((length = fin.read(buffer)) != -1) {
        fout.write(buffer, 0, length);
    }
    ```
    
    - 한 번에 1024바이트씩 읽어 속도를 개선
2. **`BufferedReader`와 `BufferedWriter` 사용**
    
    ```java
    BufferedReader fin = new BufferedReader(new FileReader(Filedir + args[0]));
    BufferedWriter fout = new BufferedWriter(new FileWriter(Filedir + args[1]));
    ```
    
    - 내부 버퍼 사용으로 I/O 속도 향상
