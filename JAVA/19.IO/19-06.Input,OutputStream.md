### 📌 **파일 복사 프로그램 (Java - InputStream & OutputStream)**

## 🔎 **개요**

- `FileInputStream`과 `FileOutputStream`을 사용하여 파일 복사
- **버퍼를 사용하지 않는 방식** vs **버퍼를 사용하는 방식** 비교

---

## 💻 **코드 정리**

```java
package Ch19;

import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.InputStream;
import java.io.OutputStream;

public class C07FileCopyMain {
    public static void main(String[] args) throws Exception {

        // 입력 스트림 (읽기) → 원본 파일 지정
        InputStream in = new FileInputStream("C:\\IOTEST\\dummy.exe");

        // 출력 스트림 (쓰기) → 복사할 파일 지정
        OutputStream out = new FileOutputStream("C:\\IOTEST\\COPY_dummy.exe");

        // 01. 버퍼 미사용 (주석 처리된 코드)
        /*
        while (true) {
            int data = in.read(); // 1바이트씩 읽음
            if (data == -1) { // EOF 체크
                break;
            }
            out.write((byte) data); // 1바이트씩 출력
            out.flush();
        }
        */

        // 02. 버퍼 사용 (4096 바이트 버퍼)
        byte[] buff = new byte[4096]; // 4KB 버퍼

        while (true) {
            int data = in.read(buff); // 버퍼 크기만큼 읽음
            if (data == -1) { // EOF 체크
                break;
            }
            out.write(buff, 0, data); // 읽은 크기만큼 출력
            out.flush(); // 강제 출력
        }

        // 스트림 닫기 (자원 해제)
        in.close();
        out.close();
    }
}
```

## 🔎 **코드 분석**

### **1️⃣ `FileInputStream` / `FileOutputStream` 객체 생성**

```java
InputStream in = new FileInputStream("C:\\IOTEST\\dummy.exe");
OutputStream out = new FileOutputStream("C:\\IOTEST\\COPY_dummy.exe");
```

- `FileInputStream` → 원본 파일을 읽어오는 입력 스트림
- `FileOutputStream` → 복사할 파일을 생성하는 출력 스트림

### **2️⃣ 버퍼 미사용 방식 (주석 처리된 코드)**

```java
while (true) {
    int data = in.read(); // 1바이트씩 읽음
    if (data == -1) { // EOF 체크
        break;
    }
    out.write((byte) data); // 1바이트씩 출력
    out.flush();
}
```

- `read()` 메서드는 **1바이트씩 읽음** → 성능이 낮음 (비효율적)
- `write()` 메서드로 **1바이트씩 출력**
- 파일 크기가 크면 **속도가 느림**

### **3️⃣ 버퍼 사용 방식**

```java
byte[] buff = new byte[4096]; // 4KB 크기의 버퍼 생성

while (true) {
    int data = in.read(buff); // 버퍼 크기만큼 읽음
    if (data == -1) { // EOF 체크
        break;
    }
    out.write(buff, 0, data); // 읽은 크기만큼 출력
    out.flush();
}
```

- **4KB 크기의 버퍼 사용 (`byte[] buff = new byte[4096];`)**
- `read(buff)` → 한 번에 4KB씩 읽음 → 성능 향상
- `write(buff, 0, data)` → 읽은 만큼만 출력

### **4️⃣ 스트림 닫기 (자원 해제)**

```java
in.close();
out.close();
```

- 사용한 스트림을 닫아 **메모리 누수 방지**
- 파일을 다 사용하면 반드시 `close()` 해야 함

---

## ✅ **버퍼 미사용 vs 버퍼 사용 성능 비교**

|방식|설명|속도|
|---|---|---|
|**버퍼 미사용**|1바이트씩 읽고 씀|느림|
|**버퍼 사용 (4KB)**|여러 바이트를 한 번에 읽고 씀|빠름|

- 파일 크기가 클수록 **버퍼 사용 방식이 훨씬 빠름**
- `BufferedInputStream` / `BufferedOutputStream`을 추가로 사용하면 더 효율적
