### 📝 Java 파일 출력 - `FileWriter` 사용

## 📌 내용

- `FileWriter`를 이용한 파일 쓰기 학습
- `write()` 메서드를 사용하여 문자열 작성
- `flush()`와 `close()`의 역할 확인

---

## 💻 코드 정리

```java
package Ch19;

import java.io.FileWriter;
import java.io.IOException;
import java.io.Writer;

public class C01WriteMain {
    public static void main(String[] args) throws IOException {
        // 파일 작성 객체 생성
        Writer fout = new FileWriter("C:\\IOTEST\\test1.txt");

        // 파일에 문자열 작성
        fout.write("test1\n");
        fout.write("test2\n");
        fout.write("test3\n");
        fout.write("test4\n");

        // 버퍼에 남아있는 데이터 출력 후 닫기
        fout.flush();
        fout.close();
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **파일 출력 객체 생성 (`FileWriter`)**

```java
Writer fout = new FileWriter("C:\\IOTEST\\test1.txt");
```

- `FileWriter`는 텍스트 파일에 데이터를 쓰는 클래스
- `"C:\\IOTEST\\test1.txt"` 경로에 파일을 생성하거나 기존 파일을 덮어씀
- `Writer` 인터페이스를 사용하여 확장 가능

### 2️⃣ **문자열 파일에 쓰기 (`write()`)**

```java
fout.write("test1\n");
fout.write("test2\n");
fout.write("test3\n");
fout.write("test4\n");
```

- `write(String s)` → 지정된 문자열을 파일에 기록
- `\n` 사용으로 줄바꿈 포함

### 3️⃣ **버퍼 비우기 (`flush()`)**

```java
fout.flush();
```

- 파일에 남아있는 데이터 즉시 출력
- `flush()`를 호출하지 않으면 일부 데이터가 기록되지 않을 수 있음

### 4️⃣ **파일 닫기 (`close()`)**

```java
fout.close();
```

- 파일을 닫아 자원 해제
- `close()` 호출 시 자동으로 `flush()` 실행됨

---

## 🔎 추가 정보

- `FileWriter`는 기본적으로 덮어쓰기 (Overwrite) 모드
- 기존 파일에 데이터를 추가하려면 `new FileWriter("경로", true)` 사용
- `try-with-resources` 문법 사용 시 `close()` 생략 가능

```java
try (Writer fout = new FileWriter("C:\\IOTEST\\test1.txt")) {
    fout.write("test1\n");
}
```
