## 🔎 **코드 분석: OpenWeatherMap API를 이용한 날씨 정보 조회**

### 📌 **내용**

- `HttpClient`를 이용해 OpenWeatherMap API에서 날씨 정보를 요청
- `Jackson ObjectMapper`를 이용해 JSON 응답을 `Java 객체`로 변환
- `대구(Daegu)`의 현재 날씨 정보를 조회하고 출력

---

## 💻 **코드 정리**

```java
package Ch19;

import java.io.IOException;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.util.ArrayList;

import com.fasterxml.jackson.databind.ObjectMapper;

public class C13Ex {

    public static void main(String[] args) throws IOException, InterruptedException {

        // OpenWeatherMap API 요청 URL
        String url = "https://api.openweathermap.org/data/2.5/weather";
        String q = "Daegu"; // 도시명
        String units = "metric"; // 섭씨 온도
        String lang = "kr"; // 언어 설정 (한국어)
        String appid = "e3ef06f5e824287e524c96c57275ee57"; // API 키

        url += "?q=" + q + "&units=" + units + "&lang=" + lang + "&appid=" + appid;
        System.out.println(url);

        // HTTP 요청 생성
        HttpRequest httpRequest = HttpRequest.newBuilder()
                .uri(URI.create(url))
                .GET()
                .build();

        // HTTP 요청 전송 및 응답 받기
        HttpClient httpClient = HttpClient.newHttpClient();
        HttpResponse<String> response =
                httpClient.send(httpRequest, HttpResponse.BodyHandlers.ofString());

        // JSON 응답을 Java 객체로 변환
        ObjectMapper objectMapper = new ObjectMapper();
        Root root = objectMapper.readValue(response.body(), Root.class);

        // 날씨 정보 출력
        System.out.printf("도시: %s\n", root.getName());
        System.out.printf("국가: %s\n", root.getSys().getCountry());
        System.out.printf("날씨 상태: %s (%s)\n", root.getWeather().get(0).getMain(), root.getWeather().get(0).getDescription());
        System.out.printf("현재 온도: %.2f°C (체감: %.2f°C)\n", root.getMain().getTemp(), root.getMain().getFeels_like());
        System.out.printf("온도 범위: 최저 %.2f°C / 최고 %.2f°C\n", root.getMain().getTemp_min(), root.getMain().getTemp_max());
        System.out.printf("기압: %d hPa, 습도: %d%%\n", root.getMain().getPressure(), root.getMain().getHumidity());

        if (root.getMain().getSea_level() != 0) {
            System.out.printf("해수면 기압: %d hPa\n", root.getMain().getSea_level());
        }
        if (root.getMain().getGrnd_level() != 0) {
            System.out.printf("지면 기압: %d hPa\n", root.getMain().getGrnd_level());
        }

        System.out.printf("가시 거리: %,d m\n", root.getVisibility());
        System.out.printf("구름량: %d%%\n", root.getClouds().getAll());
        System.out.printf("바람 속도: %.2f m/s (방향: %d°)\n", root.getWind().getSpeed(), root.getWind().getDeg());

        if (root.getWind().getGust() != 0) {
            System.out.printf("돌풍 속도: %.2f m/s\n", root.getWind().getGust());
        }

        // 좌표 정보 출력
        System.out.printf("위도: %.2f, 경도: %.2f\n", root.getCoord().getLat(), root.getCoord().getLon());

        System.out.printf("일출 시간: %d\n", root.getSys().getSunrise());
        System.out.printf("일몰 시간: %d\n", root.getSys().getSunset());
    }

    // 날씨 정보 관련 클래스들
    private static class Clouds {
        public int all;
        public int getAll() { return all; }
    }

    private static class Coord {
        public double lon;
        public double lat;
        public double getLon() { return lon; }
        public double getLat() { return lat; }
    }

    private static class Main {
        public double temp;
        public double feels_like;
        public double temp_min;
        public double temp_max;
        public int pressure;
        public int humidity;
        public int sea_level;
        public int grnd_level;

        public double getTemp() { return temp; }
        public double getFeels_like() { return feels_like; }
        public double getTemp_min() { return temp_min; }
        public double getTemp_max() { return temp_max; }
        public int getPressure() { return pressure; }
        public int getHumidity() { return humidity; }
        public int getSea_level() { return sea_level; }
        public int getGrnd_level() { return grnd_level; }
    }

    private static class Root {
        public Coord coord;
        public ArrayList<Weather> weather;
        public String name;
        public Main main;
        public int visibility;
        public Wind wind;
        public Clouds clouds;
        public Sys sys;

        public Coord getCoord() { return coord; }
        public ArrayList<Weather> getWeather() { return weather; }
        public String getName() { return name; }
        public Main getMain() { return main; }
        public int getVisibility() { return visibility; }
        public Wind getWind() { return wind; }
        public Clouds getClouds() { return clouds; }
        public Sys getSys() { return sys; }
    }

    private static class Sys {
        public String country;
        public int sunrise;
        public int sunset;
        public String getCountry() { return country; }
        public int getSunrise() { return sunrise; }
        public int getSunset() { return sunset; }
    }

    private static class Weather {
        public String main;
        public String description;
        public String getMain() { return main; }
        public String getDescription() { return description; }
    }

    private static class Wind {
        public double speed;
        public int deg;
        public double gust;
        public double getSpeed() { return speed; }
        public int getDeg() { return deg; }
        public double getGust() { return gust; }
    }
}
```

## 🔎 **코드 분석 (단계별 설명)**

### **1️⃣ API 요청 URL 생성**

```java
String url = "https://api.openweathermap.org/data/2.5/weather";
String q = "Daegu";
String units = "metric";
String lang = "kr";
String appid = "e3ef06f5e824287e524c96c57275ee57";

url += "?q=" + q + "&units=" + units + "&lang=" + lang + "&appid=" + appid;
```

- 대구의 날씨 정보를 요청하는 URL을 생성
- `units=metric`으로 설정하여 섭씨 온도로 받음
- `lang=kr`로 설정하여 한국어 응답을 받음

### **2️⃣ `HttpClient`를 이용한 요청 전송**

```java
HttpRequest httpRequest = HttpRequest.newBuilder()
        .uri(URI.create(url))
        .GET()
        .build();

HttpClient httpClient = HttpClient.newHttpClient();
HttpResponse<String> response =
        httpClient.send(httpRequest, HttpResponse.BodyHandlers.ofString());
```

- `HttpRequest`를 생성하여 GET 요청을 보냄
- `HttpClient.send()`를 이용해 요청을 보내고 응답을 받음

### **3️⃣ `Jackson`을 이용한 JSON 변환**

```java
ObjectMapper objectMapper = new ObjectMapper();
Root root = objectMapper.readValue(response.body(), Root.class);
```

- `ObjectMapper.readValue()`를 사용하여 JSON 데이터를 `Root` 객체로 변환

### **4️⃣ 날씨 정보 출력**

```java
System.out.printf("도시: %s\n", root.getName());
System.out.printf("현재 온도: %.2f°C (체감: %.2f°C)\n", root.getMain().getTemp(), root.getMain().getFeels_like());
System.out.printf("날씨 상태: %s (%s)\n", root.getWeather().get(0).getMain(), root.getWeather().get(0).getDescription());
```

- `Root` 객체에서 날씨 정보를 가져와 출력
