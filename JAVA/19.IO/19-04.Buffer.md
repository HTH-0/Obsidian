### 📝 **파일 읽기 속도 측정 (C04FileCopyMain)**

## 📌 **내용 정리**

- `FileReader`를 이용한 파일 읽기
- `char[]` 버퍼를 활용하여 대량으로 읽는 방식 사용
- 파일 읽기 속도를 측정 (`System.currentTimeMillis()` 활용)
- `StringBuffer`를 사용하여 문자열 데이터 저장

---

## 💻 **코드 정리**

```java
package Ch19;

import java.io.FileReader;
import java.io.IOException;
import java.io.Reader;

public class C04FileCopyMain {

    private static String Filedir = "C:\\IOTEST\\";

    public static void main(String[] args) throws IOException {

        Reader fin = new FileReader(Filedir + "test3.txt"); // 파일 읽기 스트림 생성
        int data = 0;
        
        StringBuffer buffer = new StringBuffer(); // 문자열 저장을 위한 StringBuffer
        char[] buf = new char[1024]; // 1024바이트 버퍼 생성
        
        long startTime = System.currentTimeMillis(); // 시작 시간 측정
        
        while ((data = fin.read(buf)) != -1) {
            buffer.append(buf); // 버퍼 내용을 StringBuffer에 추가
        }

        long endTime = System.currentTimeMillis(); // 종료 시간 측정
        System.out.println("소요 시간 : " + (endTime - startTime) + "ms");

        fin.close(); // 파일 스트림 닫기
    }
}
```

---

## 🔎 **코드 분석**

### 1️⃣ **파일 읽기 스트림 생성**

```java
Reader fin = new FileReader(Filedir + "test3.txt");
```

- `FileReader`를 사용하여 파일을 읽기 위한 스트림 생성

### 2️⃣ **버퍼 및 문자열 저장 객체 생성**

```java
StringBuffer buffer = new StringBuffer();
char[] buf = new char[1024]; // 1024 바이트 버퍼
```

- `StringBuffer`를 사용하여 문자열을 효율적으로 저장
- `char[]` 버퍼를 사용하여 1024바이트씩 읽기 (속도 향상)

### 3️⃣ **파일 읽기 및 속도 측정**

```java
long startTime = System.currentTimeMillis();
while ((data = fin.read(buf)) != -1) {
    buffer.append(buf); // 버퍼 데이터를 문자열 버퍼에 추가
}
long endTime = System.currentTimeMillis();
System.out.println("소요 시간 : " + (endTime - startTime) + "ms");
```

- `System.currentTimeMillis()`를 사용하여 읽기 속도를 측정
- `read(buf)`: 최대 1024바이트씩 읽어서 `buf`에 저장
- `buffer.append(buf)`: 읽은 데이터를 `StringBuffer`에 추가
    - **버그 주의**: `buf`는 덮어쓰기가 발생하므로 `new String(buf, 0, data)`로 변환하여 저장하는 것이 더 정확함

### 4️⃣ **스트림 닫기**

```java
fin.close();
```

- 자원 해제를 위해 `close()` 호출

## 🔎 **추가 정보**

### 🔹 **버그: `buffer.append(buf)`의 문제**

```java
buffer.append(buf);
```

- `buf`는 덮어쓰기가 발생하기 때문에 마지막 읽기 데이터보다 더 많은 데이터가 포함될 가능성이 있음
- **수정 방법:** 정확한 길이만큼만 저장
    
    ```java
    buffer.append(new String(buf, 0, data));
    ```
    

### 🔹 **파일 읽기 속도 개선 방법**

|방법|설명|성능|
|---|---|---|
|`read()`|1바이트씩 읽기|느림|
|`read(buf)`|버퍼 단위로 읽기|빠름|
|`BufferedReader`|내부 버퍼 사용|가장 빠름|

#### **BufferedReader 사용 예시**

```java
import java.io.*;

public class BufferedFileRead {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new FileReader("C:\\IOTEST\\test3.txt"));
        
        long startTime = System.currentTimeMillis();
        String line;
        while ((line = br.readLine()) != null) {
            // System.out.println(line); // 파일 내용 출력 (선택적)
        }
        long endTime = System.currentTimeMillis();

        System.out.println("소요 시간 : " + (endTime - startTime) + "ms");
        br.close();
    }
}
```

- `BufferedReader`는 내부 버퍼를 사용하여 빠르게 읽을 수 있음
