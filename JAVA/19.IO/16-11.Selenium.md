## 🔎 **코드 분석: Selenium을 이용한 네이버 쇼핑 데이터 크롤링 및 HTML 저장**

### 📌 **내용**

- `Selenium`을 이용하여 네이버 검색 → 쇼핑 페이지 이동 → 검색 결과 가져오기
- 검색 결과 HTML을 크롤링하여 파일로 저장
- 크롬 웹 드라이버(`chromedriver.exe`)를 이용하여 자동화 수행
- `JavascriptExecutor`를 사용하여 `target="_blank"` 속성을 제거해 새 창이 열리지 않도록 설정

---

## 💻 **코드 정리**

```java
package Ch19;

import java.io.*;
import java.util.List;
import java.util.UUID;

import org.openqa.selenium.*;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.chrome.ChromeOptions;

public class C11SelenumAPIMain {

    private static final String WEB_DRIVER_PATH = "src/Drivers/chromedriver.exe";

    public static void main(String[] args) throws IOException {

        // 브라우저 옵션 설정
        ChromeOptions options = new ChromeOptions();
//        options.addArguments("--headless"); // 백그라운드 실행
//        options.addArguments("--no-sandbox"); // 리눅스 환경에서 sandbox 사용 여부

        // WebDriver 객체 생성
        WebDriver driver = new ChromeDriver(options);
        driver.get("https://www.naver.com");

        // 네이버 검색창 요소 찾기
        WebElement searchEl = driver.findElement(By.id("query"));

        // 검색어 입력 및 엔터키 입력
        searchEl.sendKeys("모니터");
        searchEl.sendKeys(Keys.RETURN);

        // 쇼핑 탭 클릭
        WebElement shoppingBtnEl = driver.findElement(By.cssSelector(".api_pcpg_wrap .tab:nth-child(1)"));
        JavascriptExecutor js = (JavascriptExecutor) driver;
        js.executeScript("arguments[0].removeAttribute('target')", shoppingBtnEl);
        shoppingBtnEl.click();

        // '리뷰 많은순' 정렬 버튼 클릭
        List<WebElement> Els = driver.findElements(By.cssSelector(".subFilter_sort__lhuHl"));
        Els.forEach(el -> {
            if (el.getText().contains("리뷰 많은순")) {
                el.click();
            }
        });

        // 상품 목록 가져오기
        List<WebElement> El2s = driver.findElements(By.cssSelector(".basicList_list_basis__uNBZx"));

        // 결과를 HTML 파일로 저장
        Writer out = new FileWriter("C:\\IOTEST\\" + UUID.randomUUID() + ".html");

        // HTML 기본 구조 작성
        StringBuilder htmlContent = new StringBuilder();
        htmlContent.append("<!DOCTYPE html>\n<html lang=\"ko\">\n<head>\n<meta charset=\"UTF-8\">\n");
        htmlContent.append("<meta name=\"viewport\" content=\"width=device-width, initial-scale=1.0\">\n");
        htmlContent.append("<title>네이버 쇼핑 검색 결과</title>\n");

        // CSS 파일 링크 추가
        List<WebElement> cssLinks = driver.findElements(By.tagName("link"));
        for (WebElement link : cssLinks) {
            String rel = link.getAttribute("rel");
            if ("stylesheet".equals(rel)) {
                String href = link.getAttribute("href");
                System.out.println("CSS 링크 : " + href);
                htmlContent.append("<link rel=\"stylesheet\" href=\"").append(href).append("\">\n");
            }
        }

        htmlContent.append("</head>\n<body>\n");

        // 검색 결과 HTML 추가
        for (WebElement el : El2s) {
            String elHTML = el.getAttribute("outerHTML");
            htmlContent.append(elHTML).append("\n");
        }

        htmlContent.append("</body>\n</html>");

        // HTML 파일 저장
        out.write(htmlContent.toString());
        out.flush();
        out.close();
    }
}
```

## 🔎 **코드 분석 (단계별 설명)**

### **1️⃣ Selenium WebDriver 설정**

```java
ChromeOptions options = new ChromeOptions();
WebDriver driver = new ChromeDriver(options);
driver.get("https://www.naver.com");
```

- `ChromeOptions` 객체를 사용하여 브라우저 설정 (`headless` 모드 등 추가 가능)
- `ChromeDriver`를 실행하여 크롬 브라우저를 제어

### **2️⃣ 네이버 검색창에 키워드 입력**

```java
WebElement searchEl = driver.findElement(By.id("query"));
searchEl.sendKeys("모니터");
searchEl.sendKeys(Keys.RETURN);
```

- `findElement(By.id("query"))`로 검색창 찾기
- `.sendKeys("모니터")`로 키워드 입력 후 `.sendKeys(Keys.RETURN)`으로 엔터키 입력

### **3️⃣ 쇼핑 버튼 클릭 (새 창 열림 방지)**

```java
WebElement shoppingBtnEl = driver.findElement(By.cssSelector(".api_pcpg_wrap .tab:nth-child(1)"));
JavascriptExecutor js = (JavascriptExecutor) driver;
js.executeScript("arguments[0].removeAttribute('target')", shoppingBtnEl);
shoppingBtnEl.click();
```

- `JavascriptExecutor`를 사용하여 `target="_blank"` 속성을 제거해 새 창이 열리는 것을 방지
- `.click()`으로 클릭하여 쇼핑 페이지로 이동

### **4️⃣ 리뷰 많은순 정렬**

```java
List<WebElement> Els = driver.findElements(By.cssSelector(".subFilter_sort__lhuHl"));
Els.forEach(el -> {
    if (el.getText().contains("리뷰 많은순")) {
        el.click();
    }
});
```

- `.findElements(By.cssSelector(".subFilter_sort__lhuHl"))`로 정렬 버튼 목록 가져오기
- `if (el.getText().contains("리뷰 많은순"))` 조건을 만족하는 버튼 클릭

### **5️⃣ 상품 목록 가져오기**

```java
List<WebElement> El2s = driver.findElements(By.cssSelector(".basicList_list_basis__uNBZx"));
```

- `.findElements(By.cssSelector(".basicList_list_basis__uNBZx"))`로 상품 목록을 가져옴

### **6️⃣ HTML 파일 생성 및 저장**

```java
Writer out = new FileWriter("C:\\IOTEST\\" + UUID.randomUUID() + ".html");
StringBuilder htmlContent = new StringBuilder();
htmlContent.append("<!DOCTYPE html>\n<html lang=\"ko\">\n<head>\n<meta charset=\"UTF-8\">\n");
```

- `FileWriter`를 사용하여 검색 결과를 HTML 파일로 저장
- `UUID.randomUUID()`를 사용해 파일 이름을 무작위로 생성

### **7️⃣ CSS 스타일 적용**

```java
List<WebElement> cssLinks = driver.findElements(By.tagName("link"));
for (WebElement link : cssLinks) {
    String rel = link.getAttribute("rel");

```

- `<link>` 태그에서 `stylesheet` 속성을 가진 CSS 파일을 찾아 HTML에 포함

### **8️⃣ 상품 목록을 HTML에 추가**

```java
for (WebElement el : El2s) {
    String elHTML = el.getAttribute("outerHTML");
    htmlContent.append(elHTML).append("\n");
}
```

- `.getAttribute("outerHTML")`을 사용하여 HTML 내용을 그대로 가져와 추가

### **9️⃣ 파일 저장**

```java
out.write(htmlContent.toString());
out.flush();
out.close();
```

- HTML 내용을 파일로 저장하고 `flush()`, `close()` 호출

## 🔎 **추가 정보**

### **📌 `Selenium` 주요 메서드**

|메서드|설명|
|---|---|
|`findElement(By.id("id"))`|ID를 기준으로 요소 찾기|
|`findElement(By.cssSelector("css"))`|CSS 선택자를 이용하여 요소 찾기|
|`sendKeys("text")`|입력 필드에 텍스트 입력|
|`sendKeys(Keys.RETURN)`|엔터키 입력|
|`click()`|요소 클릭|

### **📌 `JavascriptExecutor` 활용**

- `executeScript("arguments[0].removeAttribute('target')", element);`  
    → 새 창이 열리는 `target="_blank"` 속성 제거

### **📌 `UUID.randomUUID()` 활용**

- 중복되지 않는 파일 이름을 생성하여 저장
