## 🔎 **코드 분석: REST API 요청 및 JSON 응답 처리**

### 📌 **내용**

- `HttpClient`를 사용하여 `REST API` 요청을 보내고 응답을 JSON 형식으로 받음
- `ObjectMapper`(`Jackson` 라이브러리)를 사용하여 JSON 데이터를 `Java 객체`로 변환
- `Daegu Food API`를 호출하여 대구 중구의 맛집 정보를 가져옴
- `ResponseObject` 클래스를 만들어 JSON 데이터를 파싱하여 활용

---

## 💻 **코드 정리**

```java
package Ch19;

import java.io.IOException;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.util.ArrayList;

import com.fasterxml.jackson.annotation.JsonProperty;
import com.fasterxml.jackson.databind.ObjectMapper;

public class C12RestRequestResponseMain {
    public static void main(String[] args) throws IOException, InterruptedException {

        // URL 및 요청 파라미터 설정
        String url = "https://www.daegufood.go.kr/kor/api/tasty.html";
        String mode = "json";
        String addr = "중구";
        url += "?mode=" + mode + "&addr=" + addr;

        // HttpRequest 생성
        HttpRequest httpRequest = HttpRequest.newBuilder()
                .uri(URI.create(url))
                .GET()
                .build();

        // HttpClient를 이용한 요청 전송
        HttpClient httpClient = HttpClient.newHttpClient();
        HttpResponse<String> response =
                httpClient.send(httpRequest, HttpResponse.BodyHandlers.ofString());

        // JSON 응답을 Java 객체로 변환
        ObjectMapper objectMapper = new ObjectMapper();
        ResponseObject responseObject = objectMapper.readValue(response.body(), ResponseObject.class);

        // 결과 출력
        System.out.println("Status : " + responseObject.getStatus());
        System.out.println("Total : " + responseObject.getTotal());
        System.out.println("첫 번째 데이터 : " + responseObject.getData().get(0));
    }

    // API 응답을 매핑할 Java 클래스
    private static class Data {
        @JsonProperty("BZ_NM")
        public String businessName; // 가게 이름

        @JsonProperty("TLNO")
        public String phoneNumber; // 전화번호

        @JsonProperty("FD_CS")
        public String foodCategory; // 음식 종류

        @JsonProperty("MNU")
        public String menu; // 대표 메뉴

        @JsonProperty("SMPL_DESC")
        public String description; // 설명

        Data() {}

        @Override
        public String toString() {
            return "업소명: " + businessName + ", 전화번호: " + phoneNumber + 
                   ", 음식 종류: " + foodCategory + ", 메뉴: " + menu + 
                   ", 설명: " + description;
        }
    }

    private static class ResponseObject {
        public String status;
        public String total;
        public ArrayList<Data> data;

        public String getStatus() {
            return status;
        }

        public String getTotal() {
            return total;
        }

        public ArrayList<Data> getData() {
            return data;
        }
    }
}
```

## 🔎 **코드 분석 (단계별 설명)**

### **1️⃣ API 요청 URL 구성**

```java
String url = "https://www.daegufood.go.kr/kor/api/tasty.html";
String mode = "json";
String addr = "중구";
url += "?mode=" + mode + "&addr=" + addr;
```

- API 요청 URL을 생성 (`mode=json`, `addr=중구` → JSON 형식으로 중구의 맛집 정보 요청)

### **2️⃣ `HttpRequest` 객체 생성**

```java
HttpRequest httpRequest = HttpRequest.newBuilder()
        .uri(URI.create(url))
        .GET()
        .build();
```

- `HttpRequest.newBuilder()`를 사용하여 HTTP 요청 생성
- `GET()` 요청 방식 설정

### **3️⃣ `HttpClient`로 요청 전송 및 응답 수신**

```java
HttpClient httpClient = HttpClient.newHttpClient();
HttpResponse<String> response =
        httpClient.send(httpRequest, HttpResponse.BodyHandlers.ofString());
```

- `HttpClient.newHttpClient()`를 사용하여 HTTP 요청을 보냄
- `send(httpRequest, HttpResponse.BodyHandlers.ofString())`로 문자열 형태의 응답 수신

### **4️⃣ `ObjectMapper`를 이용한 JSON 데이터 변환**

```java
ObjectMapper objectMapper = new ObjectMapper();
ResponseObject responseObject = objectMapper.readValue(response.body(), ResponseObject.class);
```

- `Jackson` 라이브러리의 `ObjectMapper`를 사용하여 JSON을 Java 객체로 변환
- `ResponseObject` 클래스를 사용하여 데이터를 매핑

### **5️⃣ 응답 데이터 출력**

```java
System.out.println("Status : " + responseObject.getStatus());
System.out.println("Total : " + responseObject.getTotal());
System.out.println("첫 번째 데이터 : " + responseObject.getData().get(0));
```

- `status`, `total` 값을 출력하고, 첫 번째 맛집 정보를 출력

## 🔎 **추가 정보**

### **📌 `HttpClient` 주요 메서드**

|메서드|설명|
|---|---|
|`HttpRequest.newBuilder()`|새로운 HTTP 요청 객체 생성|
|`.uri(URI.create(url))`|요청할 URL 지정|
|`.GET()`|GET 방식 요청 설정|
|`.build()`|요청 객체 생성|
|`HttpClient.newHttpClient()`|HTTP 클라이언트 객체 생성|
|`send(request, BodyHandlers.ofString())`|요청을 보내고 응답을 문자열로 받음|

### **📌 `Jackson`을 사용한 JSON 파싱**

|메서드|설명|
|---|---|
|`ObjectMapper.readValue(jsonString, Class<T>)`|JSON 문자열을 Java 객체로 변환|
|`@JsonProperty("json_key")`|JSON 필드명을 Java 필드명과 매핑|
