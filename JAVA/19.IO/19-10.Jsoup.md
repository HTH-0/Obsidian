## 🔎 **코드 분석: Jsoup을 이용한 이미지 크롤링 및 저장**

### 📌 **내용**

- `Jsoup`을 사용하여 `https://www.op.gg/champions` 웹 페이지에서 `<img>` 태그를 찾음
- 이미지 URL을 추출하여 파일로 저장
- `UUID`를 이용해 각 이미지를 고유한 파일명으로 저장
- `BufferedInputStream`을 사용하여 이미지 다운로드 성능 향상

---

## 💻 **코드 정리**

```java
package Ch19;

import java.io.*;
import java.net.URI;
import java.net.URISyntaxException;
import java.net.URL;
import java.util.UUID;

import org.jsoup.Connection;
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;
import org.jsoup.select.Elements;

public class C10JsoupMain {
    public static void main(String[] args) throws IOException, URISyntaxException {
        // URL 연결
        Connection conn = Jsoup.connect("https://www.op.gg/champions");
        Document doc = conn.get();

        // <img> 태그 가져오기
        Elements elements = doc.getElementsByTag("img");

        for (Element el : elements) {
            try {
                System.out.println(el);
                
                // 이미지 URL 추출
                String img_url = el.attr("src");
                System.out.println(img_url);

                // URL 객체 생성
                URL url = (new URI(img_url)).toURL();
                
                // 입력 스트림 생성 (이미지 다운로드)
                InputStream in = url.openStream();
                BufferedInputStream buffIn = new BufferedInputStream(in);
                
                // 출력 스트림 생성 (파일 저장)
                OutputStream out = null;
                if (img_url.contains(".png")) {
                    out = new FileOutputStream("C:\\IOTEST\\" + UUID.randomUUID() + ".png");
                } else if (img_url.contains(".svg")) {
                    out = new FileOutputStream("C:\\IOTEST\\" + UUID.randomUUID() + ".svg");
                } else if (img_url.contains(".webp")) {
                    out = new FileOutputStream("C:\\IOTEST\\" + UUID.randomUUID() + ".webp");
                } else {
                    out = new FileOutputStream("C:\\IOTEST\\" + UUID.randomUUID() + ".jpg");
                }

                // 이미지 데이터를 읽어 저장
                while (true) {
                    int data = buffIn.read();
                    if (data == -1) {
                        break;
                    }
                    out.write((byte) data);
                    out.flush();
                }

                // 스트림 닫기
                out.close();
                buffIn.close();
                in.close();
            } catch (IOException e) {
                e.printStackTrace();
            }
        }
    }
}
```

## 🔎 **코드 분석 (단계별 설명)**

### **1️⃣ Jsoup을 이용한 웹 페이지 크롤링**

```java
Connection conn = Jsoup.connect("https://www.op.gg/champions");
Document doc = conn.get();
```

- `Jsoup.connect(url)`을 사용하여 웹 페이지 요청
- `get()` 메서드를 호출하여 `Document` 객체를 가져옴 (HTML 전체 내용 저장)

### **2️⃣ `<img>` 태그 찾기**

```java
Elements elements = doc.getElementsByTag("img");
```

- `getElementsByTag("img")`를 이용해 모든 `<img>` 태그를 가져옴

### **3️⃣ 이미지 URL 추출**

```java
String img_url = el.attr("src");
```

- `attr("src")`를 이용해 `<img>` 태그의 `src` 속성 값(이미지 URL) 가져오기

### **4️⃣ URL 객체 변환**

```java
URL url = (new URI(img_url)).toURL();
```

- `img_url`을 `URI` 객체로 변환한 후 `toURL()`을 사용해 `URL` 객체 생성

### **5️⃣ 입력 스트림 생성 (이미지 다운로드)**

```java
InputStream in = url.openStream();
BufferedInputStream buffIn = new BufferedInputStream(in);
```

- `url.openStream()`으로 이미지 데이터를 `InputStream`으로 읽음
- `BufferedInputStream`을 사용해 성능 향상

### **6️⃣ 파일 저장을 위한 출력 스트림 생성**

```java
OutputStream out = null;

if (img_url.contains(".png")) {
    out = new FileOutputStream("C:\\IOTEST\\" + UUID.randomUUID() + ".png");
} else if (img_url.contains(".svg")) {
    out = new FileOutputStream("C:\\IOTEST\\" + UUID.randomUUID() + ".svg");
} else if (img_url.contains(".webp")) {
    out = new FileOutputStream("C:\\IOTEST\\" + UUID.randomUUID() + ".webp");
} else {
    out = new FileOutputStream("C:\\IOTEST\\" + UUID.randomUUID() + ".jpg");
}
```

- 이미지 파일 확장자(`.png`, `.svg`, `.webp`, `.jpg`)를 확인하여 적절한 확장자로 저장
- `UUID.randomUUID()`를 이용하여 고유한 파일 이름 생성

### **7️⃣ 이미지 데이터를 읽어 파일로 저장**

```java
while (true) {
    int data = buffIn.read();
    if (data == -1) {
        break;
    }
    out.write((byte) data);
    out.flush();
}
```

- `buffIn.read()`를 이용하여 한 바이트씩 데이터를 읽고 `out.write()`로 저장
- `flush()`를 호출하여 즉시 파일에 반영

### **8️⃣ 스트림 닫기**

```java
out.close();
buffIn.close();
in.close();
```

- 모든 스트림을 닫아 자원 누수 방지

## 🔎 **추가 정보**

### **📌 `Jsoup` 라이브러리의 주요 메서드**

|메서드|설명|
|---|---|
|`Jsoup.connect(url)`|웹 페이지에 연결|
|`Document.getElementsByTag(tag)`|특정 태그의 모든 요소 가져오기|
|`Element.attr(attribute)`|특정 속성 값 가져오기|

### **📌 `BufferedInputStream` 사용 이유**

- 일반 `InputStream`보다 속도가 빠름 (버퍼를 사용하여 읽기 성능 향상)

### **📌 `UUID.randomUUID()` 활용**

- 각 파일을 고유한 이름으로 저장하기 위해 `UUID` 사용
