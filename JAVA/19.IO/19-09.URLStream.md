## 🔎 **코드 분석: URLStream을 이용한 웹 페이지 내용 저장**

### 📌 **내용**

- `URL`을 사용하여 웹 페이지의 내용을 가져와서 로컬 파일(`index.html`)에 저장하는 프로그램
- `BufferedInputStream`과 `InputStreamReader`를 활용하여 입력 스트림을 효율적으로 처리
- `FileWriter`를 사용하여 데이터를 파일로 저장

---

## 💻 **코드 정리**

```java
package Ch19;

import java.io.*;
import java.net.URI;
import java.net.URL;

public class C09URLStreamMain {
    public static void main(String[] args) throws Exception {
        
        // URL 객체 생성 (URI를 URL로 변환)
        URL url = (new URI("https://contents.premium.naver.com/byteplus/byte/contents/250314043729973vt")).toURL();
        
        // URL의 내용을 읽어오는 InputStream 생성
        InputStream in = url.openStream();
        
        // 보조 스트림 추가 (BufferedInputStream + InputStreamReader)
        BufferedInputStream buffIn = new BufferedInputStream(in);
        Reader rin = new InputStreamReader(buffIn);
        
        // 출력 스트림 생성 (파일에 저장)
        Writer out = new FileWriter("C:\\IOTEST\\index.html");
        
        int data;
        // 한 글자씩 읽고 출력 및 파일 저장
        while ((data = rin.read()) != -1) {
            System.out.print((char) data);
            out.write((char) data);
            out.flush();
        }
        
        // 스트림 닫기
        rin.close();
        buffIn.close();
        in.close();
        out.close();
    }
}
```

## 🔎 **코드 분석 (단계별 설명)**

### **1️⃣ URL 객체 생성**

```java
URL url = (new URI("https://contents.premium.naver.com/byteplus/byte/contents/250314043729973vt")).toURL();
```

- `URI` 객체를 생성한 후 `toURL()`을 사용하여 `URL` 객체로 변환
- 웹 페이지의 내용을 가져오기 위해 사용

### **2️⃣ URL을 이용해 입력 스트림 생성**

```java
InputStream in = url.openStream();
```

- `openStream()` 메서드를 사용하여 웹 페이지의 내용을 `InputStream` 형태로 가져옴
- 기본적으로 바이트 단위로 읽음

### **3️⃣ 보조 스트림 추가**

```java
BufferedInputStream buffIn = new BufferedInputStream(in);
Reader rin = new InputStreamReader(buffIn);
```

- `BufferedInputStream`을 사용하여 입력 성능을 향상
- `InputStreamReader`를 이용하여 바이트 데이터를 문자 데이터로 변환

### **4️⃣ 파일 출력 스트림 생성**

```java
Writer out = new FileWriter("C:\\IOTEST\\index.html");
```

- `FileWriter`를 이용해 데이터를 `"C:\\IOTEST\\index.html"` 파일에 저장

### **5️⃣ 한 글자씩 읽어 출력 및 파일 저장**

```java
int data;
while ((data = rin.read()) != -1) {
    System.out.print((char) data); // 콘솔 출력
    out.write((char) data); // 파일 저장
    out.flush();
}
```

- `rin.read()`를 사용하여 한 글자씩 읽고
- `System.out.print()`로 콘솔에 출력
- `out.write()`를 사용하여 파일에 저장
- `flush()`를 호출하여 즉시 파일에 반영

### **6️⃣ 스트림 닫기**

```java
rin.close();
buffIn.close();
in.close();
out.close();
```

- 모든 스트림을 닫아 자원 누수 방지

## 🔎 **추가 정보**

### **📌 `BufferedInputStream`과 `InputStreamReader`의 역할**

|클래스|역할|
|---|---|
|`BufferedInputStream`|데이터를 버퍼에 저장하여 성능 향상|
|`InputStreamReader`|바이트 데이터를 문자 데이터로 변환|

### **📌 `flush()`의 역할**

- `flush()`는 버퍼에 저장된 데이터를 즉시 출력하도록 강제
- `FileWriter`는 내부적으로 버퍼링을 수행하므로 `flush()`를 사용하여 즉시 저장 가능
