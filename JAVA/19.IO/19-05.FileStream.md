### 📝 **파일 출력 (C06FileOutputStreamMain)**

## 📌 **내용 정리**

- `FileOutputStream`을 사용하여 **바이너리 데이터 쓰기**
- `write()`를 이용한 문자 및 바이트 데이터 저장
- `flush()`와 `close()`를 활용하여 데이터 저장 보장

---

## 💻 **코드 정리**

```java
package Ch19;

import java.io.FileOutputStream;
import java.io.IOException;
import java.io.OutputStream;
import java.nio.charset.StandardCharsets;

public class C06FileOutputStreamMain {
    public static void main(String[] args) throws IOException {

        // 파일 출력 스트림 생성 (test4.txt에 데이터 저장)
        OutputStream out = new FileOutputStream("C:\\IOTEST\\test4.txt");

        // 1️⃣ 문자열을 바이트 배열로 변환하여 저장 (UTF-8 인코딩)
        out.write("가".getBytes(StandardCharsets.UTF_8));

        // 2️⃣ 단일 문자 저장 (ASCII)
        out.write('b'); // 'b'의 ASCII 값(98) 저장
        out.write('c'); // 'c'의 ASCII 값(99) 저장
        out.write('d'); // 'd'의 ASCII 값(100) 저장

        // 3️⃣ 버퍼에 남아 있는 데이터를 파일에 즉시 저장
        out.flush();

        // 4️⃣ 스트림 닫기 (파일 저장 완료)
        out.close();
    }
}
```

---

## 🔎 **코드 분석**

### 1️⃣ **파일 출력 스트림 생성**

```java
OutputStream out = new FileOutputStream("C:\\IOTEST\\test4.txt");
```

- `FileOutputStream`을 이용하여 **바이너리 데이터**를 저장
- 기존 파일이 있으면 덮어쓰기, 없으면 새로 생성

### 2️⃣ **문자열을 바이트 배열로 변환 후 저장**

```java
out.write("가".getBytes(StandardCharsets.UTF_8));
```

- `"가"`는 한글(UTF-8 기준 3바이트)
- `getBytes(StandardCharsets.UTF_8)`: UTF-8 바이트 배열로 변환하여 저장

### 3️⃣ **단일 문자 저장**

```java
out.write('b'); // ASCII 98 저장
out.write('c'); // ASCII 99 저장
out.write('d'); // ASCII 100 저장
```

- `write(int b)`: ASCII 값(1바이트)으로 변환하여 저장
- 'b', 'c', 'd'는 각각 98, 99, 100의 바이트 값으로 저장됨

### 4️⃣ **버퍼 비우기 (`flush()`)**

```java
out.flush();
```

- 남아 있는 데이터를 강제 저장
- `flush()`를 사용하지 않으면 일부 데이터가 버퍼에 남아있을 수 있음

### 5️⃣ **스트림 닫기 (`close()`)**

```java
out.close();
```

- **파일 리소스를 해제**하여 메모리 누수 방지
- `close()`를 호출하지 않으면 파일이 제대로 저장되지 않을 수 있음

## 🔎 **추가 정보**

### 🔹 **`FileOutputStream`과 `BufferedOutputStream` 비교**

|스트림|특징|성능|
|---|---|---|
|`FileOutputStream`|바이트 단위 직접 파일 저장|기본 속도|
|`BufferedOutputStream`|내부 버퍼 활용 (8KB)|빠름|

#### **BufferedOutputStream 사용 예시**

```java
import java.io.*;

public class BufferedFileWrite {
    public static void main(String[] args) throws IOException {
        BufferedOutputStream out = new BufferedOutputStream(new FileOutputStream("C:\\IOTEST\\test4.txt"));

        out.write("안녕하세요".getBytes(StandardCharsets.UTF_8));
        out.flush(); // 버퍼 강제 비우기
        out.close(); // 스트림 닫기
    }
}
```

- `BufferedOutputStream`은 **내부 버퍼(8KB)**를 사용하여 **속도 향상**
