### 📝 Java 파일 입력 - `FileReader` 사용

## 📌 내용

- `FileReader`를 이용한 파일 읽기 학습
- `read()` 메서드를 사용하여 문자 단위로 읽기
- `StringBuffer`를 활용하여 문자열 저장 및 출력

---

## 💻 코드 정리

```java
package Ch19;

import java.io.FileReader;
import java.io.IOException;
import java.io.Reader;

public class C02ReaderMain {
    public static void main(String[] args) throws IOException {
        // 파일 읽기 객체 생성
        Reader fin = new FileReader("C:\\IOTEST\\test1.txt");

        int data = 0;
        StringBuffer buffer = new StringBuffer();

        // 파일 끝(-1)까지 한 글자씩 읽기
        while ((data = fin.read()) != -1) {
            buffer.append((char) data);
        }

        // 파일 내용 출력
        System.out.println(buffer);

        // 파일 닫기
        fin.close();
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **파일 입력 객체 생성 (`FileReader`)**

```java
Reader fin = new FileReader("C:\\IOTEST\\test1.txt");
```

- `FileReader`는 문자 기반 파일 읽기용 클래스
- `"C:\\IOTEST\\test1.txt"` 파일을 읽기 모드로 염

### 2️⃣ **파일 내용 읽기 (`read()`)**

```java
int data = 0;
StringBuffer buffer = new StringBuffer();

while ((data = fin.read()) != -1) {
    buffer.append((char) data);
}
```

- `read()`는 한 글자씩 읽고, 더 이상 읽을 내용이 없으면 `-1` 반환
- `StringBuffer`를 활용하여 문자열을 효율적으로 저장

### 3️⃣ **파일 출력 (`System.out.println()`)**

```java
System.out.println(buffer);
```

- `StringBuffer`에 저장된 내용을 한 번에 출력

### 4️⃣ **파일 닫기 (`close()`)**

```java
fin.close();
```

- 파일을 닫아 자원 해제

## 🔎 추가 정보

- `read()`는 한 문자씩 읽기 때문에 파일 크기가 크면 성능이 떨어질 수 있음
- **`BufferedReader`**를 사용하면 한 줄씩 읽는 것이 가능하며 성능이 향상됨
- 개선된 코드 (한 줄씩 읽기)

```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class C02BufferedReaderMain {
    public static void main(String[] args) {
        try (BufferedReader br = new BufferedReader(new FileReader("C:\\IOTEST\\test1.txt"))) {
            String line;
            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```
