# 📝 Java 지역 변수, 멤버 변수, static 변수

## 📌 내용

- **멤버 변수**: 클래스 내부에서 선언되며, 객체마다 독립적인 값 유지
- **static 변수**: 클래스가 공유하는 변수
- **지역 변수**: 메서드 내부 또는 특정 블록 `{}` 내에서 선언되고, 블록이 끝나면 소멸

---

## 💻 코드 정리

```java
package Ch08;

class C05Simple {
    int num = 10; // 멤버 변수

    void Func1() {
        System.out.println("멤버 변수 num : " + num);
        int num = 5; // 지역 변수 (멤버 변수와 동일한 이름)
        System.out.println("Func1 지역 변수 num : " + num);
        num++;      // 지역 변수 값 변경
        this.num++; // 멤버 변수 값 변경
    }

    void Func2() {
        System.out.println("멤버 변수 num : " + num);
        if (true) {
            int num = 100; // if 블록 내 지역 변수
            System.out.println("Func2 if 안 지역 변수 num : " + num);
        }
        System.out.println("멤버 변수 num : " + num); // if 블록 내 num과 무관

        while (num < 15) { // 멤버 변수 사용
            System.out.println("멤버 변수 num : " + num);
            num++; // 멤버 변수 값 변경
        }
    }

    void Func3(int num) { // 매개변수도 지역 변수
        this.num = num; // 멤버 변수에 매개변수 값 저장
        System.out.println(num);
    }
}

public class C05LocalVarMain {
    public static void main(String[] args) {
        C05Simple obj = new C05Simple();

        obj.Func1();
        obj.Func2();
        obj.Func3(5);
    }
}
```

## 🔎 코드 분석

### 1️⃣ **`Func1()` - 지역 변수 vs 멤버 변수**

```java
void Func1() {
    System.out.println("멤버 변수 num : " + num); // 10 출력
    int num = 5; // 지역 변수 선언 (멤버 변수와 이름 중복)
    System.out.println("Func1 지역 변수 num : " + num); // 5 출력
    num++;      // 지역 변수 값 변경 → 6
    this.num++; // 멤버 변수 값 변경 → 11
}
```

- **지역 변수 `num`이 멤버 변수 `num`을 가림**
- `this.num`을 사용하여 멤버 변수를 변경

### 2️⃣ **`Func2()` - if 블록 내 지역 변수**

```java
void Func2() {
    System.out.println("멤버 변수 num : " + num); // 11 출력
    if (true) {
        int num = 100; // if 블록 내 지역 변수
        System.out.println("Func2 if 안 지역 변수 num : " + num); // 100 출력
    }
    System.out.println("멤버 변수 num : " + num); // 11 출력 (if 블록 지역 변수 영향 없음)

    while (num < 15) { // 멤버 변수 사용
        System.out.println("멤버 변수 num : " + num);
        num++; // 멤버 변수 증가
    }
}
```

- **if 블록 내 `num`은 지역 변수이며, 블록을 벗어나면 소멸됨**
- **while 루프에서 사용되는 `num`은 멤버 변수**

### 3️⃣ **`Func3()` - 매개변수와 멤버 변수 구분**

```java
void Func3(int num) {
    this.num = num; // 매개변수 num 값을 멤버 변수 num에 저장
    System.out.println(num); // 입력받은 num 출력
}
```

- **매개변수도 지역 변수이며, `this.num`을 사용해 멤버 변수에 할당 가능**

## ⚠️ 주의할 점

1️⃣ **지역 변수와 멤버 변수의 이름이 같을 경우, 지역 변수가 우선됨**  
2️⃣ **`this`를 사용하면 멤버 변수에 접근 가능**  
3️⃣ **if, while 내부에서 선언된 변수는 해당 블록에서만 유효**  
4️⃣ **매개변수도 지역 변수의 일종**이며, 멤버 변수와 이름이 같으면 `this.num = num;`처럼 구분 필요
