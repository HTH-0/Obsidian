## 📝 생성자 (Constructor) 개념과 활용 in Java

### 📌 내용 요약

- **생성자(Constructor)**는 객체 생성 시 **한 번만 호출**되는 특수한 메서드
- **클래스 이름과 동일**하며, **반환 자료형이 없음**
- **디폴트 생성자**: 명시적으로 생성자를 정의하지 않으면 **컴파일러가 자동 삽입**
- **오버로딩 지원**: 다양한 매개변수를 가진 여러 생성자 정의 가능
- **`toString()` 메서드 오버라이딩** → 객체 정보를 문자열로 변환하여 출력

---

### 💻 코드 정리

```java
package Ch08;

// 생성자 메서드
class C08Simple {
    // 속성 (멤버 변수)
    int n1;
    double n2;
    boolean n3;
    String n4;

    // 디폴트 생성자
    C08Simple() {
        System.out.println("C08Simple() 생성자 호출 - 디폴트 생성자");
    }

    // 생성자 오버로딩
    C08Simple(int n1) {
        this.n1 = n1;
        System.out.println("C08Simple(int n1) 생성자 호출");
    }

    C08Simple(int n1, double n2) {
        this.n1 = n1;
        this.n2 = n2;
        System.out.println("C08Simple(int n1, double n2) 생성자 호출");
    }

    C08Simple(int n1, double n2, boolean n3) {
        this.n1 = n1;
        this.n2 = n2;
        this.n3 = n3;
        System.out.println("C08Simple(int n1, double n2, boolean n3) 생성자 호출");
    }

    // 모든 속성을 초기화하는 생성자
    public C08Simple(int n1, double n2, boolean n3, String n4) {
        this.n1 = n1;
        this.n2 = n2;
        this.n3 = n3;
        this.n4 = n4;
    }

    // toString() 오버라이딩 → 객체 정보 출력용
    @Override
    public String toString() {
        return "C08Simple [n1=" + n1 + ", n2=" + n2 + ", n3=" + n3 + ", n4=" + n4 + "]";
    }
}

public class C08ConstructorMain {
    public static void main(String[] args) {
        C08Simple ob1 = new C08Simple(10);
        C08Simple ob2 = new C08Simple(10, 10.5);
        C08Simple ob3 = new C08Simple(10, 10.5, true);
        C08Simple ob4 = new C08Simple(10, 10.5, true, "홍길동");

        System.out.println(ob1);  // toString() 호출됨
        System.out.println(ob2);
        System.out.println(ob3);
        System.out.println(ob4);
    }
}
```

### 🔎 코드 분석

#### 1️⃣ **생성자 정의**

```java
C08Simple(int n1) {
    this.n1 = n1;
    System.out.println("C08Simple(int n1) 생성자 호출");
}
```

- 생성자의 이름은 클래스 이름과 동일
- `this.n1 = n1;` → 멤버 변수 `n1`을 매개변수 값으로 초기화

#### 2️⃣ **생성자 오버로딩**

```java
C08Simple(int n1, double n2, boolean n3) {
    this.n1 = n1;
    this.n2 = n2;
    this.n3 = n3;
    System.out.println("C08Simple(int n1, double n2, boolean n3) 생성자 호출");
}
```

- 같은 이름의 생성자를 **매개변수 개수**에 따라 다르게 정의
- 객체 생성 시 **해당하는 생성자가 자동 호출됨**

#### 3️⃣ **모든 속성을 초기화하는 생성자**

```java
public C08Simple(int n1, double n2, boolean n3, String n4) {
    this.n1 = n1;
    this.n2 = n2;
    this.n3 = n3;
    this.n4 = n4;
}
```

- `this.n1`, `this.n2` 등으로 **멤버 변수 초기화**
- `super();`는 **명시적으로 부모 클래스 생성자 호출 (Object 클래스)**

#### 4️⃣ **toString() 오버라이딩**

```java
@Override
public String toString() {
    return "C08Simple [n1=" + n1 + ", n2=" + n2 + ", n3=" + n3 + ", n4=" + n4 + "]";
}
```

- 객체 정보를 쉽게 출력하기 위해 `toString()`을 재정의
- `System.out.println(ob1);` 호출 시 자동으로 `toString()`이 호출됨

#### 5️⃣ **객체 생성 및 생성자 호출**

```java
C08Simple ob1 = new C08Simple(10);
C08Simple ob2 = new C08Simple(10, 10.5);
C08Simple ob3 = new C08Simple(10, 10.5, true);
C08Simple ob4 = new C08Simple(10, 10.5, true, "홍길동");
```

- 각각 매개변수가 다른 생성자가 호출됨
- `System.out.println(ob1);`을 실행하면 `toString()` 결과가 출력됨

### 🔎 추가 정보

✅ **디폴트 생성자(Default Constructor)**

- 생성자를 정의하지 않으면 **컴파일러가 자동 삽입**
- `C08Simple ob = new C08Simple();` 가능

✅ **생성자 오버로딩(Constructor Overloading)**

- 매개변수 개수나 타입이 다르면 **여러 개의 생성자 정의 가능**
- 호출 시 **적절한 생성자가 자동 선택됨**

✅ **`this` 키워드**

- **멤버 변수와 매개변수 구분**: `this.n1 = n1;`
- **다른 생성자 호출 가능**: `this(10, 20.5);`

✅ **객체를 문자열로 변환 (`toString()`)**

- `toString()`을 오버라이딩하면 객체 정보를 쉽게 출력 가능
