### 📌 Java JDBC 트랜잭션 처리 (Rollback & Commit)

## 📌 주요 개념

- **JDBC 트랜잭션 관리**: `setAutoCommit(false)`를 사용하여 트랜잭션 제어
- **Commit & Rollback**:
    - **성공 시** `commit()`을 호출하여 변경사항 반영
    - **실패 시** `rollback()`을 호출하여 변경사항 취소
- **PreparedStatement 활용**: SQL 문 실행 최적화

---

## 💻 공부 코드

```java
package Ch21;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.SQLException;

public class C08Tx {
	
    static String id = "root";
    static String pw = "1234";
    static String url = "jdbc:mysql://localhost:3306/testdb";
    
    static Connection conn = null;
    static PreparedStatement pstmt = null;
    
    public static void main(String[] args) {
        try {
            // 1. MySQL JDBC 드라이버 로드
            Class.forName("com.mysql.cj.jdbc.Driver");
            System.out.println("Driver Loading Success..");

            // 2. DB 연결
            conn = DriverManager.getConnection(url, id, pw);
            System.out.println("DB CONNECTED..");

            // 3. 트랜잭션 시작 (자동 커밋 해제)
            conn.setAutoCommit(false);
            System.out.println("INSERT 시작..");

            // 4. 여러 개의 INSERT 실행
            pstmt = conn.prepareStatement("INSERT INTO tbl_std VALUES('a', 1, 'a')");
            pstmt.executeUpdate();

            pstmt = conn.prepareStatement("INSERT INTO tbl_std VALUES('b', 1, 'a')");
            pstmt.executeUpdate();

            pstmt = conn.prepareStatement("INSERT INTO tbl_std VALUES('c', 1, 'a')");
            pstmt.executeUpdate();

            pstmt = conn.prepareStatement("INSERT INTO tbl_std VALUES('d', 1, 'a')");
            pstmt.executeUpdate();

            // 5. 모든 SQL 실행 성공 시 commit
            conn.commit();
            System.out.println("INSERT 종료");

        } catch (Exception e) {
            try {
                System.out.println("오류 발생, ROLLBACK 실행");
                e.printStackTrace();
                conn.rollback();  // 오류 발생 시 모든 변경 사항 취소
            } catch (SQLException rollbackEx) {
                rollbackEx.printStackTrace();
            }
        } finally {
            try { if (pstmt != null) pstmt.close(); } catch (Exception e2) {}
            try { if (conn != null) conn.close(); } catch (Exception e2) {}
        }
    }
}
```

## 🔎 주요 코드 분석

### 1️⃣ **JDBC 드라이버 로드**

```java
Class.forName("com.mysql.cj.jdbc.Driver");
```

- **MySQL JDBC 드라이버를 로드**
- `com.mysql.cj.jdbc.Driver`는 MySQL 8 이상에서 사용되는 드라이버

---

### 2️⃣ **DB 연결**

```java
conn = DriverManager.getConnection(url, id, pw);
```

- **MySQL 데이터베이스 연결**
- `testdb` 데이터베이스에 접속

---

### 3️⃣ **트랜잭션 시작**

```java
conn.setAutoCommit(false);
```

- **자동 커밋 해제**
- 여러 개의 SQL 실행 후 `commit()`을 호출해야 실제 반영

---

### 4️⃣ **INSERT 실행**

```java
pstmt = conn.prepareStatement("INSERT INTO tbl_std VALUES('a', 1, 'a')");
pstmt.executeUpdate();
```

- **SQL 실행**
- `executeUpdate()`를 사용하여 `tbl_std` 테이블에 데이터 삽입

---

### 5️⃣ **Commit & Rollback**

```java
conn.commit();
```

- **트랜잭션이 정상적으로 실행되면 commit**
- 모든 SQL이 정상 실행되면 DB에 반영

```java
conn.rollback();
```

- **오류 발생 시 rollback**
- 실행된 모든 SQL 작업을 취소하여 DB 변경 사항 없음

## ✅ 실행 결과

### 🔹 정상 실행 시

```
Driver Loading Success..
DB CONNECTED..
INSERT 시작..
INSERT 종료
```

→ `tbl_std` 테이블에 데이터 4개가 추가됨

### 🔹 SQL 오류 발생 시 (예: 중복 키 삽입)

```
Driver Loading Success..
DB CONNECTED..
INSERT 시작..
오류 발생, ROLLBACK 실행
java.sql.SQLIntegrityConstraintViolationException: Duplicate entry 'a' for key 'PRIMARY'
```

→ **Rollback이 실행되므로 데이터 추가되지 않음**

## ✅ 핵심 정리

1️⃣ **트랜잭션 관리**

- `setAutoCommit(false)`: 수동으로 트랜잭션 관리
- `commit()`: 성공 시 변경사항 저장
- `rollback()`: 실패 시 변경사항 취소

2️⃣ **예외 처리**

- `try-catch-finally`로 예외 발생 시 안전한 종료

3️⃣ **JDBC 연결 해제**

- `pstmt.close()`, `conn.close()`를 `finally` 블록에서 실행
