### 🔍 **JDBC를 이용한 MySQL 데이터 업데이트 코드 분석**

#### 📌 **핵심 내용**

- JDBC를 이용한 **UPDATE 문 실행**
- `PreparedStatement`를 활용한 SQL 실행
- `executeUpdate()`를 통해 업데이트 적용 여부 확인
- **SQL 인젝션 방지**를 위한 바인딩 변수 사용

---

## 💻 **코드 정리**

```java
package Ch21;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.SQLException;

public class C03Update {
    public static void main(String[] args) {
        // DB 연결 정보
        String id = "root";
        String pw = "1234";
        String url = "jdbc:mysql://localhost:3306/testdb";

        // JDBC 참조 변수
        Connection conn = null;
        PreparedStatement pstmt = null;

        try {
            // MySQL JDBC 드라이버 로딩
            Class.forName("com.mysql.cj.jdbc.Driver");
            System.out.println("Driver Loading Success...");

            // 데이터베이스 연결
            conn = DriverManager.getConnection(url, id, pw);
            System.out.println("DB CONNECTED...");

            // SQL 쿼리 준비
            String name = args[0];
            int age = Integer.parseInt(args[1]);
            String addr = args[2];

            // ✅ 안전한 SQL 작성 방식 (PreparedStatement)
            pstmt = conn.prepareStatement("UPDATE tbl_std SET age=?, addr=? WHERE name=?");
            pstmt.setInt(1, age);
            pstmt.setString(2, addr);
            pstmt.setString(3, name);

            // SQL 실행
            int result = pstmt.executeUpdate();

            if (result > 0)
                System.out.println("UPDATE 성공");
            else
                System.out.println("UPDATE 실패");

        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            try {
                if (pstmt != null) pstmt.close();
                if (conn != null) conn.close();
            } catch (SQLException e) {
                e.printStackTrace();
            }
        }
    }
}
```

## 🔎 **코드 분석**

### 1️⃣ **DB 연결 정보 설정**

```java
String id = "root";
String pw = "1234";
String url = "jdbc:mysql://localhost:3306/testdb";
```

- **id, pw**: MySQL 사용자 계정 정보
- **url**: 데이터베이스 주소 (`testdb` 사용)

### 2️⃣ **JDBC 드라이버 로딩**

```java
Class.forName("com.mysql.cj.jdbc.Driver");
System.out.println("Driver Loading Success...");
```

- MySQL JDBC 드라이버를 **메모리에 로딩**
- 최신 JDBC 버전에서는 생략 가능하지만 **명시적으로 작성하는 것이 권장됨**

### 3️⃣ **데이터베이스 연결**

```java
conn = DriverManager.getConnection(url, id, pw);
System.out.println("DB CONNECTED...");
```

- `DriverManager.getConnection()`을 사용해 DB 연결

### 4️⃣ **사용자 입력값 받기**

```java
String name = args[0];
int age = Integer.parseInt(args[1]);
String addr = args[2];
```

- `args[]`를 통해 **프로그램 실행 시 전달된 인자값을 받음**
- **`Integer.parseInt()`**를 사용해 문자열을 정수로 변환

### 5️⃣ **SQL 실행 방식 비교**

✅ **(보안 강화) `?`를 사용한 PreparedStatement**

```java
pstmt = conn.prepareStatement("UPDATE tbl_std SET age=?, addr=? WHERE name=?");
pstmt.setInt(1, age);
pstmt.setString(2, addr);
pstmt.setString(3, name);
```

- `?`(바인딩 변수)를 사용하여 **SQL 인젝션 방지**
- `setInt()`, `setString()`을 사용하여 안전하게 값 전달

❌ **(보안 취약) 직접 문자열 삽입 방식**

```java
pstmt = conn.prepareStatement("UPDATE tbl_std SET age=" + age + ", addr='" + addr + "' WHERE name='" + name + "'");
```

- SQL 구문을 **문자열로 직접 조합하는 방식**
- **SQL 인젝션(SQL Injection)** 공격에 취약
    
    ```
    java C03Update "John'; DROP TABLE tbl_std; --" 30 "New York"
    ```
    
    위와 같이 실행하면 `tbl_std` 테이블이 삭제될 수도 있음.

### 6️⃣ **SQL 실행 및 결과 확인**

```java
int result = pstmt.executeUpdate();
if (result > 0)
    System.out.println("UPDATE 성공");
else
    System.out.println("UPDATE 실패");
```

- `executeUpdate()` → UPDATE 실행 후 **적용된 행 개수 반환**
- `result > 0`이면 **성공**, 그렇지 않으면 **실패**

### 7️⃣ **자원 해제**

```java
finally {
    try {
        if (pstmt != null) pstmt.close();
        if (conn != null) conn.close();
    } catch (SQLException e) {
        e.printStackTrace();
    }
}
```

- **`pstmt.close()`와 `conn.close()`를 반드시 호출**
- **메모리 누수 방지**

## 🚨 **SQL 인젝션 방지**

**보안에 취약한 코드 예시 (❌)**

```java
pstmt = conn.prepareStatement("UPDATE tbl_std SET age=" + age + ", addr='" + addr + "' WHERE name='" + name + "'");
```

- 사용자가 `'John'; DROP TABLE tbl_std; --` 같은 값을 입력하면 DB 테이블이 삭제될 수도 있음.

**보안이 강화된 코드 예시 (✅)**

```java
pstmt = conn.prepareStatement("UPDATE tbl_std SET age=?, addr=? WHERE name=?");
pstmt.setInt(1, age);
pstmt.setString(2, addr);
pstmt.setString(3, name);
```

- `?` 바인딩 변수를 사용해 SQL 인젝션을 원천 차단
