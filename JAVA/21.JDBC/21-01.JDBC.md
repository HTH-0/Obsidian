### 🔍 **JDBC를 이용한 MySQL 데이터베이스 연결 코드 분석**

#### 📌 **핵심 내용**

- JDBC를 이용한 MySQL 데이터베이스 연결 과정 학습
- `Connection`, `PreparedStatement`, `ResultSet` 객체 활용
- 예외 처리 및 `finally` 블록을 통한 자원 해제

---

## 💻 **코드 정리**

```java
package Ch21;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;

public class C01DBConn {
    public static void main(String[] args) {
        // DB 연결 정보
        String id = "root";
        String pw = "1234";
        String url = "jdbc:mysql://localhost:3306/testdb";

        // JDBC 참조 변수
        Connection conn = null;
        PreparedStatement pstmt = null;
        ResultSet rs = null;

        try {
            // MySQL JDBC 드라이버 로딩
            Class.forName("com.mysql.cj.jdbc.Driver");
            System.out.println("Driver Loading Success...");

            // 데이터베이스 연결
            conn = DriverManager.getConnection(url, id, pw);
            System.out.println("DB CONNECTED...");
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            // 연결 종료 (자원 해제)
            try {
                if (conn != null) conn.close();
            } catch (SQLException e) {
                e.printStackTrace();
            }
        }
    }
}
```

---

## 🔎 **코드 분석**

### 1️⃣ **DB 연결 정보 설정**

```java
String id = "root";
String pw = "1234";
String url = "jdbc:mysql://localhost:3306/testdb";
```

- **id, pw**: MySQL 사용자 계정 정보
- **url**: 데이터베이스 연결 URL
    - `jdbc:mysql://localhost:3306/testdb`
    - `localhost`: 로컬 MySQL 서버
    - `3306`: MySQL 기본 포트
    - `testdb`: 사용할 데이터베이스 이름

### 2️⃣ **JDBC 객체 선언**

```java
Connection conn = null;
PreparedStatement pstmt = null;
ResultSet rs = null;
```

- **`Connection`**: 데이터베이스 연결을 담당
- **`PreparedStatement`**: SQL 실행을 위한 객체
- **`ResultSet`**: 쿼리 실행 결과를 저장

### 3️⃣ **JDBC 드라이버 로딩**

```java
Class.forName("com.mysql.cj.jdbc.Driver");
System.out.println("Driver Loading Success...");
```

- **JDBC 드라이버를 로드**하여 `DriverManager`가 MySQL과 연결할 수 있도록 설정
- 최신 JDBC에서는 생략 가능하지만, **하위 호환성을 위해 명시적으로 로드**하는 것이 일반적

### 4️⃣ **데이터베이스 연결**

```java
conn = DriverManager.getConnection(url, id, pw);
System.out.println("DB CONNECTED...");
```

- `DriverManager.getConnection()`을 사용해 데이터베이스와 연결
- 연결이 성공하면 `"DB CONNECTED..."` 메시지 출력

### 5️⃣ **예외 처리 및 자원 해제**

```java
} catch (Exception e) {
    e.printStackTrace();
} finally {
    try {
        if (conn != null) conn.close();
    } catch (SQLException e) {
        e.printStackTrace();
    }
}
```

- **예외 처리**: `try-catch`를 사용해 **드라이버 로딩 실패, 연결 오류 등**을 처리
- **자원 해제**: `finally` 블록에서 `conn.close()`를 실행해 **메모리 누수 방지**

---

## 🔎 **추가 정보**

1. **JDBC 드라이버 등록 필요 여부**
    
    - 최신 JDBC 버전에서는 `Class.forName("com.mysql.cj.jdbc.Driver")` 생략 가능
    - 하지만 **명시적으로 작성하는 것이 권장됨** (하위 호환성 문제 방지)
2. **자원 해제**
    
    - `conn.close()`를 **finally 블록**에서 실행해야 **예외 발생 시에도** 연결이 닫힘
    - `PreparedStatement`와 `ResultSet`도 사용했다면, 추가로 `pstmt.close()`, `rs.close()` 실행 필요
