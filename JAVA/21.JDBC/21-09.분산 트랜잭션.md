### 📌 Java 분산 트랜잭션 (XA Transactions)

## 📌 주요 개념

- **XA 트랜잭션 (Distributed Transaction)**
    - 여러 개의 데이터베이스(Connection)에서 실행되는 SQL을 하나의 트랜잭션으로 묶어 처리
    - **2-Phase Commit(2PC)**: 트랜잭션이 원자성을 유지하도록 보장
- **XAConnection**: 분산 트랜잭션을 위한 데이터베이스 연결
- **XAResource**: XA 트랜잭션 관리
- **Xid**: 트랜잭션을 구별하는 식별자

---

## 💻 공부 코드

```java
package Ch21;

import java.sql.Connection;
import java.sql.PreparedStatement;
import javax.sql.XAConnection;
import javax.transaction.xa.XAResource;
import javax.transaction.xa.Xid;
import com.mysql.cj.jdbc.MysqlXADataSource;

public class C09분산Tx {

    public static void main(String[] args) throws Exception {
        // 1. 첫 번째 DB (bookdb) 연결 설정
        MysqlXADataSource xaDataSource1 = new MysqlXADataSource();
        xaDataSource1.setUrl("jdbc:mysql://localhost:3306/bookdb");
        xaDataSource1.setUser("root");
        xaDataSource1.setPassword("1234");

        // 2. 두 번째 DB (testdb) 연결 설정
        MysqlXADataSource xaDataSource2 = new MysqlXADataSource();
        xaDataSource2.setUrl("jdbc:mysql://localhost:3306/testdb");
        xaDataSource2.setUser("root");
        xaDataSource2.setPassword("1234");

        // 3. XAConnection 및 Connection 가져오기
        XAConnection xaConnection1 = xaDataSource1.getXAConnection();
        Connection conn1 = xaConnection1.getConnection();
        XAResource xaResource1 = xaConnection1.getXAResource();

        XAConnection xaConnection2 = xaDataSource2.getXAConnection();
        Connection conn2 = xaConnection2.getConnection();
        XAResource xaResource2 = xaConnection2.getXAResource();

        // 4. 트랜잭션 식별자 생성
        Xid xid1 = createXid(100, 1); // bookdb용 XID
        Xid xid2 = createXid(100, 2); // testdb용 XID

        try {
            // 5. 첫 번째 DB 트랜잭션 시작
            xaResource1.start(xid1, XAResource.TMNOFLAGS);
            PreparedStatement pstmt1 = conn1.prepareStatement("INSERT INTO tbl_user VALUES('a', '1', '1', false)");
            pstmt1.executeUpdate();
            PreparedStatement pstmt2 = conn1.prepareStatement("INSERT INTO tbl_user VALUES('b', '1', '1', false)");
            pstmt2.executeUpdate();
            xaResource1.end(xid1, XAResource.TMSUCCESS);

            // 6. 두 번째 DB 트랜잭션 시작
            xaResource2.start(xid2, XAResource.TMNOFLAGS);
            PreparedStatement pstmt3 = conn2.prepareStatement("INSERT INTO tbl_std VALUES('a', '1')");
            pstmt3.executeUpdate();
            PreparedStatement pstmt4 = conn2.prepareStatement("INSERT INTO tbl_std VALUES('b', '2')");
            pstmt4.executeUpdate();
            xaResource2.end(xid2, XAResource.TMSUCCESS);

            // 7. 2-Phase Commit 준비
            int prepare1 = xaResource1.prepare(xid1);
            int prepare2 = xaResource2.prepare(xid2);

            // 8. 커밋 수행
            if (prepare1 == XAResource.XA_OK && prepare2 == XAResource.XA_OK) {
                xaResource1.commit(xid1, false);
                xaResource2.commit(xid2, false);
                System.out.println("Transaction committed successfully.");
            } else {
                throw new Exception("Prepare failed for one or both databases.");
            }

        } catch (Exception e) {
            // 9. 롤백 수행 (오류 발생 시)
            xaResource1.rollback(xid1);
            xaResource2.rollback(xid2);
            System.out.println("Transaction rolled back due to an error.");
            e.printStackTrace();
        } finally {
            // 10. 자원 해제
            conn1.close();
            conn2.close();
            xaConnection1.close();
            xaConnection2.close();
        }
    }

    // XID 생성 메서드
    private static Xid createXid(int bid, int tid) {
        return new Xid() {
            private int formatId = 1;
            private byte[] branchQualifier = new byte[] { (byte) tid };
            private byte[] globalTransactionId = new byte[] { (byte) bid };

            @Override
            public int getFormatId() {
                return formatId;
            }

            @Override
            public byte[] getBranchQualifier() {
                return branchQualifier;
            }

            @Override
            public byte[] getGlobalTransactionId() {
                return globalTransactionId;
            }
        };
    }
}
```

## 🔎 주요 코드 분석

### 1️⃣ **XA 트랜잭션을 위한 DB 연결**

```java
MysqlXADataSource xaDataSource1 = new MysqlXADataSource();
xaDataSource1.setUrl("jdbc:mysql://localhost:3306/bookdb");
xaDataSource1.setUser("root");
xaDataSource1.setPassword("1234");
```

- `MysqlXADataSource`를 사용하여 **XA 트랜잭션을 지원하는 데이터베이스 연결** 생성
- 동일한 방식으로 **bookdb**와 **testdb** 두 개의 데이터베이스를 연결

---

### 2️⃣ **XAConnection 및 XAResource 생성**

```java
XAConnection xaConnection1 = xaDataSource1.getXAConnection();
Connection conn1 = xaConnection1.getConnection();
XAResource xaResource1 = xaConnection1.getXAResource();
```

- `XAConnection`: 분산 트랜잭션을 지원하는 연결
- `XAResource`: XA 트랜잭션을 관리하는 객체

---

### 3️⃣ **트랜잭션 시작**

```java
xaResource1.start(xid1, XAResource.TMNOFLAGS);
```

- **XA 트랜잭션을 시작**
- `xid1`을 통해 **bookdb**에서 트랜잭션 실행

---

### 4️⃣ **2PC (2-Phase Commit)**

```java
int prepare1 = xaResource1.prepare(xid1);
int prepare2 = xaResource2.prepare(xid2);
```

- **1단계: Prepare (사전 확인)**
- 모든 DB가 변경 사항을 적용할 준비가 되었는지 확인

```java
xaResource1.commit(xid1, false);
xaResource2.commit(xid2, false);
```

- **2단계: Commit (최종 적용)**
- 모든 DB에서 **commit**을 실행하여 변경 사항을 확정

---

### 5️⃣ **Rollback (오류 발생 시)**

```java
xaResource1.rollback(xid1);
xaResource2.rollback(xid2);
```

- **예외 발생 시 트랜잭션을 롤백**
- 두 개의 데이터베이스 모두 데이터 변경을 취소

---

## ✅ 실행 결과

### 🔹 정상 실행 시

```
Transaction committed successfully.
```

→ `bookdb.tbl_user`와 `testdb.tbl_std` 테이블에 데이터가 추가됨

### 🔹 SQL 오류 발생 시 (예: 중복 키)

```
Transaction rolled back due to an error.
java.sql.SQLIntegrityConstraintViolationException: Duplicate entry 'a' for key 'PRIMARY'
```

→ **Rollback 실행, 데이터베이스 변경 없음**

## ✅ 핵심 정리

1️⃣ **XA 트랜잭션 (분산 트랜잭션)**

- 여러 개의 DB(Connection)에서 **하나의 트랜잭션으로 묶어 실행**
- `XAResource`를 사용하여 **commit() / rollback() 수행**

2️⃣ **2-Phase Commit (2PC)**

- `prepare()` → 모든 DB가 트랜잭션을 준비
- `commit()` → 모든 DB에서 최종적으로 반영

3️⃣ **Rollback 처리**

- 오류 발생 시 `rollback()`을 실행하여 모든 변경사항 취소
