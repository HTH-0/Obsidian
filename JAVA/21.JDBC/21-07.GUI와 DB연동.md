### 1️⃣ **`Memo` 클래스 (데이터 모델)**

```java
class Memo {
    private int id;
    private String text;
    private LocalDateTime createdAt;

    public Memo(int id, String text, LocalDateTime createdAt) {
        this.id = id;
        this.text = text;
        this.createdAt = createdAt;
    }

    public int getId() { return id; }
    public void setId(int id) { this.id = id; }

    public String getText() { return text; }
    public void setText(String text) { this.text = text; }

    public LocalDateTime getCreatedAt() { return createdAt; }
    public void setCreatedAt(LocalDateTime createdAt) { this.createdAt = createdAt; }

    @Override
    public String toString() {
        return "Memo [id=" + id + ", text=" + text + ", createdAt=" + createdAt + "]";
    }
}
```

**✔️ 역할:**

- 데이터 저장을 위한 `Memo` 객체 생성
- `toString()` 오버라이드 → 콘솔 출력 시 `Memo` 정보 확인 가능

### 3️⃣ **`SelectFrame` 클래스 (데이터 조회 창)**

```java
class SelectFrame extends JFrame implements MouseListener, ActionListener {
    C07GUI mainUi;
    JTable table;
    JScrollPane scroll;
    JPanel panel;
    JButton btn1;
    String selectedText;

    SelectFrame(C07GUI mainUi) {
        super("SELECT 결과");
        this.mainUi = mainUi;
        setBounds(100, 100, 500, 500);
        setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
        
        panel = new JPanel();
        panel.setLayout(null);

        btn1 = new JButton("선택");
        btn1.setBounds(410, 10, 70, 30);
        btn1.addActionListener(this);

        panel.add(btn1);
        add(panel);
        setVisible(false);
    }

    void select(Connection conn, PreparedStatement pstmt, ResultSet rs) {
        if (scroll != null) {
            panel.remove(table);
            panel.remove(scroll);
        }

        String[] columns = {"ID", "TEXT", "CREATED_AT"};
        List<String[]> data = new ArrayList<>();

        try {
            pstmt = conn.prepareStatement("select * from tbl_memo");
            rs = pstmt.executeQuery();

            while (rs.next()) {
                data.add(new String[]{rs.getString("id"), rs.getString("text"), rs.getString("createdAt")});
            }

            String[][] arr = new String[data.size()][];
            for (int i = 0; i < data.size(); i++) {
                arr[i] = data.get(i);
            }

            table = new JTable(arr, columns);
            table.addMouseListener(this);

            scroll = new JScrollPane(table);
            scroll.setBounds(10, 10, 400, 400);
            panel.add(scroll);

        } catch (Exception e3) {
            e3.printStackTrace();
        } finally {
            try { rs.close(); } catch (Exception e2) {}
            try { pstmt.close(); } catch (Exception e2) {}
        }
    }
}
```

**✔️ 역할:**

- **DB에서 `tbl_memo` 데이터 조회**
- **JTable을 활용한 데이터 출력**
- **마우스 클릭 시 선택된 데이터 가져오기**
