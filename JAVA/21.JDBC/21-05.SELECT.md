### 🔍 **JDBC를 이용한 MySQL 데이터 조회 코드 분석**

#### 📌 **핵심 내용**

- JDBC를 활용한 **SELECT 문 실행**
- `PreparedStatement`를 사용하여 SQL 실행
- `ResultSet`을 활용하여 결과 데이터 출력
- **자원 해제(`close()`)를 적절히 처리하여 메모리 누수 방지**

---

## 💻 **코드 정리**

```java
package Ch21;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;

public class C05Select {
    public static void main(String[] args) {
        // DB 연결 정보
        String id = "root";
        String pw = "1234";
        String url = "jdbc:mysql://localhost:3306/testdb";

        // JDBC 참조 변수
        Connection conn = null;
        PreparedStatement pstmt = null;
        ResultSet rs = null;

        try {
            // MySQL JDBC 드라이버 로딩
            Class.forName("com.mysql.cj.jdbc.Driver");
            System.out.println("Driver Loading Success...");

            // 데이터베이스 연결
            conn = DriverManager.getConnection(url, id, pw);
            System.out.println("DB CONNECTED...");

            // SQL 실행 준비
            pstmt = conn.prepareStatement("SELECT * FROM tbl_std");

            // SQL 실행
            rs = pstmt.executeQuery();

            // 결과 출력
            while (rs.next()) {
                System.out.print(rs.getString("name") + " ");
                System.out.print(rs.getInt("age") + " ");
                System.out.print(rs.getString("addr") + "\n");
            }
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            // 자원 해제 (순서 중요: ResultSet → PreparedStatement → Connection)
            try { if (rs != null) rs.close(); } catch (SQLException e) { e.printStackTrace(); }
            try { if (pstmt != null) pstmt.close(); } catch (SQLException e) { e.printStackTrace(); }
            try { if (conn != null) conn.close(); } catch (SQLException e) { e.printStackTrace(); }
        }
    }
}
```

---

## 🔎 **코드 분석**

### 1️⃣ **DB 연결 정보 설정**

```java
String id = "root";
String pw = "1234";
String url = "jdbc:mysql://localhost:3306/testdb";
```

- **id, pw**: MySQL 사용자 계정 정보
- **url**: 데이터베이스 주소 (`testdb` 사용)

### 2️⃣ **JDBC 드라이버 로딩**

```java
Class.forName("com.mysql.cj.jdbc.Driver");
System.out.println("Driver Loading Success...");
```

- MySQL JDBC 드라이버를 **메모리에 로딩**
- 최신 JDBC 버전에서는 생략 가능하지만 **명시적으로 작성하는 것이 권장됨**

### 3️⃣ **데이터베이스 연결**

```java
conn = DriverManager.getConnection(url, id, pw);
System.out.println("DB CONNECTED...");
```

- `DriverManager.getConnection()`을 사용해 DB 연결

### 4️⃣ **SQL 실행 준비**

```java
pstmt = conn.prepareStatement("SELECT * FROM tbl_std");
```

- **`PreparedStatement`를 사용하여 SQL 실행**
- `tbl_std` 테이블의 모든 데이터를 가져오는 쿼리 실행

### 5️⃣ **SQL 실행 및 결과 출력**

```java
rs = pstmt.executeQuery();
while (rs.next()) {
    System.out.print(rs.getString("name") + " ");
    System.out.print(rs.getInt("age") + " ");
    System.out.print(rs.getString("addr") + "\n");
}
```

- **`executeQuery()`** → SELECT 실행 후 `ResultSet` 반환
- `rs.next()`를 통해 **각 행을 순차적으로 읽어 출력**

### 6️⃣ **자원 해제 (메모리 누수 방지)**

```java
finally {
    try { if (rs != null) rs.close(); } catch (SQLException e) { e.printStackTrace(); }
    try { if (pstmt != null) pstmt.close(); } catch (SQLException e) { e.printStackTrace(); }
    try { if (conn != null) conn.close(); } catch (SQLException e) { e.printStackTrace(); }
}
```

- `rs.close()` → `pstmt.close()` → `conn.close()` **순서대로 해제**해야 함
- **메모리 누수 방지**를 위해 `finally` 블록에서 실행

---

## 🚀 **개선된 점**

1. **PreparedStatement 사용** → SQL 실행 최적화 및 **SQL 인젝션 방지**
2. **ResultSet 활용** → SELECT 실행 결과 **행 단위 출력**
3. **자원 해제 최적화** → 메모리 누수 방지를 위한 **안전한 `close()` 처리**
