# 📝 Java 람다식 활용한 간단 계산기 예제

## 📌 내용

- **람다식(Lambda Expression)**을 활용하여 **사칙연산 계산기** 구현
- **함수형 인터페이스**를 이용한 추상 메서드 구현
- 간결한 코드로 알고리즘 표현 가능

---

## 🧩 주요 개념

- **함수형 인터페이스([[Functional Interface]])**
    
    - 한 개의 추상 메서드를 가진 인터페이스
    - 람다식을 통해 쉽게 구현 가능
- **람다식([[Lambda Expression]]) 문법**
    

```java
(매개변수) -> {실행문;}
(매개변수) -> 리턴값;  // return문 생략 가능
```

---

## 💻 공부 코드 정리

```java
interface Calculator {
	int calculate(int num1, int num2);  // 두 정수 연산 추상 메서드
}

public class C03LAMDA {
	public static void main(String[] args) {
		// 덧셈
		Calculator add = (a, b) -> a + b;

		// 뺄셈
		Calculator sub = (a, b) -> a - b;

		// 곱셈
		Calculator mul = (a, b) -> a * b;

		// 나눗셈
		Calculator div = (a, b) -> a / b;

		// 결과 출력
		System.out.println("덧셈: " + add.calculate(10, 20));
		System.out.println("뺄셈: " + sub.calculate(10, 20));
		System.out.println("곱셈: " + mul.calculate(10, 20));
		System.out.println("나눗셈: " + div.calculate(10, 20));
	}
}
```

---

## 🔎 코드 분석

### 1️⃣ **함수형 인터페이스 정의**

```java
interface Calculator {
	int calculate(int num1, int num2);
}
```

- 두 정수를 받아 연산 결과를 반환하는 단 하나의 추상 메서드 정의

### 2️⃣ **람다식을 이용한 연산 구현**

```java
Calculator add = (a, b) -> a + b; // 덧셈
Calculator sub = (a, b) -> a - b; // 뺄셈
Calculator mul = (a, b) -> a * b; // 곱셈
Calculator div = (a, b) -> a / b; // 나눗셈
```

- 각 연산을 람다식을 통해 간단하게 정의
- 중괄호, return문 생략해 더 간결하게 표현 가능

### 3️⃣ **연산 실행 및 결과 출력**

```java
System.out.println(add.calculate(10, 20));  // 덧셈 결과 출력
```

- 정의된 람다식(함수형 인터페이스)을 호출하여 결과 계산 및 출력
