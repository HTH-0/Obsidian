# 📝 Java 람다식(Lambda)과 함수형 인터페이스

## 📌 내용

- **함수형 인터페이스**를 정의하고 **람다식**으로 구현
- 매개변수 및 반환값이 다른 형태의 람다 표현 예시
- 람다식 내부에서 사용자 입력(`Scanner`)을 처리하는 예제

---

## 🧩 주요 개념

- **함수형 인터페이스([[Functional Interface]])**
    
    - 단 하나의 추상 메서드만 가진 인터페이스
    - 람다식으로 간결하게 구현 가능
- **람다식([[Lambda Expression]]) 문법**
    

```java
(매개변수) -> {실행문;}
(매개변수) -> 리턴값; // 실행문 1줄인 경우 중괄호와 return 생략 가능
```

---

## 💻 공부 코드 정리

```java
import java.util.Scanner;

interface Printer {
	String print();  // 반환값 존재, 매개변수 없는 추상 메서드
}

public class C02LAMDA {
	public static void main(String[] args) {

		Printer printer = () -> {
			Scanner sc = new Scanner(System.in);
			String message = sc.nextLine();
			sc.close();
			return message;
		};

		String returnValue = printer.print();
		System.out.println(returnValue);
	}
}
```

---

## 🔎 코드 분석

### 1️⃣ **함수형 인터페이스 정의**

```java
interface Printer {
	String print();  // 매개변수 없음, 문자열 반환
}
```

- 추상 메서드를 **한 개만** 정의하여 람다식으로 구현 가능하도록 설계

### 2️⃣ **람다식으로 인터페이스 구현**

```java
Printer printer = () -> {
	Scanner sc = new Scanner(System.in);
	String message = sc.nextLine();
	sc.close();
	return message;
};
```

- 람다식을 이용하여 익명 객체 생성 (구현 클래스 없이 바로 구현 가능)
- 사용자 입력을 받아 반환하는 기능을 람다식 내부에 정의

### 3️⃣ **람다식 호출 및 결과 출력**

```java
String returnValue = printer.print();
System.out.println(returnValue);
```

- 정의된 람다식(`print()` 메서드)을 호출하여 사용자 입력을 받아 출력
