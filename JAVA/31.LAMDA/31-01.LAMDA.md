# 📝 Java 람다식(Lambda)과 컬렉션 정렬

## 📌 내용

- **람다식**을 활용한 컬렉션(List) 정렬
- 메서드 참조(`System.out::println`)를 이용한 간결한 코드 작성
- 객체 정렬 시 비교 조건 정의

---

## 🧩 주요 개념

- **람다식(Lambda Expression)**
    
    - 간단한 익명 함수
    - 코드 간결화 및 함수형 프로그래밍 스타일 제공
    
    ```java
    (매개변수) -> { 실행문; }
    ```
    
- **메서드 참조(Method Reference)**
    
    - 기존 메서드를 짧게 표현 가능
    
    ```java
    클래스::메서드명
    ```

## 💻 공부 코드 정리

```java
import java.util.ArrayList;
import java.util.List;

class Person {
	private String name;
	private int age;

	Person(String name, int age){
		this.name = name;
		this.age = age;
	}

	public int getAge() { return age; }
	public void setAge(int age) { this.age = age; }

	public String getName() { return name; }
	public void setName(String name){ this.name = name; }

	@Override
	public String toString() {
		return "이름 : " + name + ", 나이 : " + age;
	}
}

public class C01LAMDA {
	public static void main(String[] args) {

		List<Person> list = new ArrayList<>();
		list.add(new Person("jung", 55));
		list.add(new Person("hong", 35));
		list.add(new Person("bob", 45));

		// 메서드 참조로 리스트 출력
		list.forEach(System.out::println);

		System.out.println("-----");

		// 나이를 기준으로 내림차순 정렬(람다 표현식)
		list.sort((a,b)-> b.getAge()-a.getAge());

		list.forEach(System.out::println);
	}
}
```

---

## 🔎 코드 분석

### 1️⃣ **List 생성 및 객체 추가**

```java
List<Person> list = new ArrayList<>();
list.add(new Person("jung", 55));
list.add(new Person("hong", 35));
list.add(new Person("bob", 45));
```

- `ArrayList`를 이용하여 `Person` 객체 관리

### 2️⃣ **메서드 참조(Method Reference) 출력**

```java
list.forEach(System.out::println);
```

- 메서드 참조로 리스트 내 모든 객체 출력
- `toString()` 자동 호출됨

### 3️⃣ **람다식 활용 정렬**

```java
list.sort((a,b)-> b.getAge()-a.getAge());
```

- 나이(`age`) 내림차순 정렬
- 람다 표현식을 통해 비교 로직 간결화
