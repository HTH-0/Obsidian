# 📝 디자인 패턴(Design Patterns) 개념 정리

## 📌 내용

- 디자인 패턴: 자주 발생하는 설계 문제를 해결하기 위한 **표준화된 방법**
- 총 8가지 패턴을 학습

---

## 🧩 패턴별 핵심 개념 정리

### 1️⃣ 싱글톤 패턴([[Singleton Pattern]])

- 클래스의 인스턴스를 오직 하나만 생성
- 전역 접근점 제공 (전역변수 없이 인스턴스 공유)

### 2️⃣ 팩토리 메서드 패턴([[Factory Method Pattern]])

- 객체 생성 과정을 서브클래스가 결정
- 슈퍼 클래스는 생성할 객체를 추상 메서드로 정의, 서브 클래스가 구현

### 3️⃣ 추상 팩토리 패턴([[Abstract Factory Pattern]])

- 관련 객체군을 생성하기 위한 인터페이스 제공
- 구체적인 팩토리를 변경하여 객체 생성 로직 분리

### 4️⃣ 빌더 패턴([[Builder Pattern]])

- 복잡한 객체를 단계적으로 생성
- 객체 생성 과정과 표현 방법을 분리하여 구현

### 5️⃣ 프로토타입 패턴([[Prototype Pattern]])

- 기존 객체를 복제(clone)하여 새 객체 생성
- 복잡한 초기화 과정을 생략하고 객체 복제 가능

### 6️⃣ 어댑터 패턴([[Adapter Pattern]])

- 호환되지 않는 인터페이스를 연결하는 중개자
- 기존 클래스를 수정하지 않고 호환성 유지

### 7️⃣ 옵저버 패턴([[Observer Pattern]])

- 객체 상태 변화 시 구독자(관찰자)에게 자동 알림
- 주체(subject)-관찰자(observer) 간 loose coupling 유지

### 8️⃣ 전략 패턴([[Strategy Pattern]])

- 실행 중 알고리즘 교체 가능
- 알고리즘을 독립적으로 캡슐화하여 상호 교체 용이

## 💻 코드 정리(예시)

**싱글톤(Singleton Pattern) 예시 코드**

```java
public class SingletonExample {
    private static SingletonExample instance = new SingletonExample();  // 유일한 인스턴스 생성

    private SingletonExample() {}  // private 생성자로 외부 인스턴스화 방지

    public static SingletonExample getInstance() {
        return instance;  // 유일한 인스턴스 반환
    }

    public void showMessage() {
        System.out.println("싱글톤 패턴 예시");
    }
}
```

---

## 🔎 코드 분석

### 1️⃣ **정적 인스턴스 생성**

```java
private static SingletonExample instance = new SingletonExample();
```

- 클래스 로드 시 최초 1회만 생성되는 단일 인스턴스
- 정적(static) 변수이므로 클래스 내부 공유됨

### 2️⃣ **private 생성자**

```java
private SingletonExample() {}
```

- 외부에서 인스턴스 직접 생성 차단
- 오직 클래스 내부에서만 인스턴스화 가능

### 3️⃣ **인스턴스 접근 메서드**

```java
public static SingletonExample getInstance() {
    return instance;
}
```

- 전역에서 싱글톤 인스턴스 접근
- 항상 같은 인스턴스 반환 보장
