## 🔍 조건을 이용한 데이터 조회

### 📌 수량(amount) 조건으로 조회하기

1. **🎯 쿼리 목적**:
    
    - `amount` 컬럼이 특정 수치 이상인 데이터 조회
2. **💻 SQL 구문**:
    

```sql
SELECT * FROM buytbl WHERE amount > 5;
```

3. **🧠 세부 설명**:
    - `SELECT *`: 모든 컬럼 데이터 조회
    - `WHERE amount > 5`: 수량(amount)이 5보다 큰 데이터만 필터링하여 조회

---

### 📌 가격(price) 범위로 조회하기

1. **🎯 쿼리 목적**:
    
    - 가격이 특정 범위(50~500) 내에 있는 데이터 조회
2. **💻 SQL 구문**:
    

```sql
SELECT userid, prodName FROM buytbl WHERE price BETWEEN 50 AND 500;
```

3. **🧠 세부 설명**:
    
    - `SELECT userid, prodName`: 사용자 아이디, 상품명 컬럼만 선택
    - `BETWEEN 50 AND 500`: 가격이 50 이상, 500 이하인 데이터만 조회
4. **💡 추가 팁**:
    
    - `BETWEEN`은 시작값과 끝값을 포함하는 조건을 만듦(양 끝값 포함)

---

### 📌 특정 가격(price) 이상 조회하기

1. **🎯 쿼리 목적**:
    
    - 가격이 일정 금액(100) 이상인 모든 데이터 조회
2. **💻 SQL 구문**:
    

```sql
SELECT * FROM buytbl WHERE price >= 100;
```

3. **🧠 세부 설명**:
    - `WHERE price >= 100`: 가격이 100 이상인 데이터만 가져옴

---

### 📌 특정 문자로 시작하는 데이터 조회(LIKE)

1. **🎯 쿼리 목적**:
    
    - `userid` 컬럼이 특정 문자('K')로 시작하는 데이터 조회
2. **💻 SQL 구문**:
    

```sql
SELECT * FROM buytbl WHERE userid LIKE 'K%';
```

3. **🧠 세부 설명**:
    - `LIKE 'K%'`: userid 컬럼 값이 문자 K로 시작하는 데이터를 찾음
        - `%`: 여러 개의 문자를 나타내는 와일드카드 문자

---

### 📌 특정 그룹명(groupname) 목록에 포함된 데이터 조회(IN)

1. **🎯 쿼리 목적**:
    
    - 그룹명이 '서적', '전자'인 데이터를 조회
2. **💻 SQL 구문**:
    

```sql
SELECT * FROM buytbl WHERE groupname IN ('서적', '전자');
```

3. **🧠 세부 설명**:
    - `IN ('서적', '전자')`: 그룹명이 '서적' 또는 '전자' 중 하나인 행만 조회

---

### 📌 특정 조건을 OR 연산으로 결합하여 조회하기

1. **🎯 쿼리 목적**:
    
    - 상품명이 '책'이거나, 사용자 아이디(userid)가 'W'로 끝나는 데이터 조회
2. **💻 SQL 구문**:
    

```sql
SELECT * FROM buytbl WHERE prodname = '책' OR userid LIKE '%W';
```

3. **🧠 세부 설명**:
    - `prodname = '책'`: 상품명이 정확히 '책'인 데이터
    - `OR userid LIKE '%W'`: userid가 'W'로 끝나는 데이터를 함께 조회

---

### 📌 공백 제거 및 대소문자 통일 후 특정 문자로 끝나는 데이터 조회

1. **🎯 쿼리 목적**:
    
    - userid 컬럼의 공백을 제거하고 대문자로 변환한 뒤, 'W'로 끝나는 데이터 조회
2. **💻 SQL 구문**:
    

```sql
SELECT * FROM buyTbl WHERE TRIM(UPPER(userid)) LIKE '%W';
```

3. **🧠 세부 설명**:
    
    - `UPPER(userid)`: userid 컬럼의 모든 문자를 대문자로 변환
    - `TRIM(...)`: 앞뒤 공백을 제거
    - `%W`: 'W'로 끝나는 데이터를 조회 (앞에는 임의의 문자열 가능)
4. **💡 추가 팁**:
    
    - `UPPER()`, `LOWER()`, `TRIM()` 함수는 데이터 조회 시 유용하게 활용 가능

### 📌 테이블 전체 데이터 조회

1. **🎯 쿼리 목적**:
    
    - 테이블의 모든 데이터 조회
2. **💻 SQL 구문**:
    

```sql
SELECT * FROM buytbl;
```

3. **🧠 세부 설명**:
    - 테이블의 전체 데이터를 확인하거나, 데이터 검증 목적으로 사용
    - 별도의 조건을 설정하지 않으므로 테이블 내 모든 데이터 반환
