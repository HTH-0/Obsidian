# 📘 Oracle 문자열 & 숫자 함수 정리

---

## 🔤 문자열 함수

---

### 📌 🔡 대소문자 변환

1. **🎯 쿼리 목적**:
    
    - 문자열을 대소문자 변환 및 첫 글자 대문자로 출력
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT userID,
           LOWER(userID) AS lower_id,
           UPPER(name) AS upper_name,
           INITCAP(LOWER(name)) AS init_cap
    FROM userTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - `LOWER(문자열)`: 소문자로 변환
        
    - `UPPER(문자열)`: 대문자로 변환
        
    - `INITCAP(문자열)`: 단어 첫 글자만 대문자로 변환
        

---

### 📌 📏 문자열 길이 확인

1. **🎯 쿼리 목적**:
    
    - 이름과 주소의 문자 수 확인
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT name, 
           LENGTH(name) AS name_length,
           LENGTH(addr) AS addr_length
    FROM userTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - `LENGTH(문자열)`: 문자열의 글자 수 반환
        

---

### 📌 ✂️ 문자열 추출 (SUBSTR)

1. **🎯 쿼리 목적**:
    
    - 문자열에서 일부 문자 추출
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT name,
           SUBSTR(name, 1, 1) AS first_char,
           SUBSTR(userID, 2) AS userid_part
    FROM userTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - `SUBSTR(문자열, 시작위치, 길이)`: 특정 위치에서 부분 문자열 추출
        
    - 길이 생략 시 끝까지 반환
        

---

### 📌 🔍 문자 위치 찾기 (INSTR)

1. **🎯 쿼리 목적**:
    
    - 특정 문자가 문자열 내 위치 확인
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT name, 
           INSTR(name, '김') AS position_kim
    FROM userTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - `INSTR(문자열, 찾을문자)`: 해당 문자의 위치 반환 (없으면 0)
        

---

### 📌 ⬛ 문자열 채우기 (LPAD/RPAD)

1. **🎯 쿼리 목적**:
    
    - 문자열의 길이를 맞추기 위해 특정 문자로 채움
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT userID,
           LPAD(userID, 10, '*') AS lpad_id,
           RPAD(name, 10, '-') AS rpad_name
    FROM userTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - `LPAD(문자열, 총길이, 채울문자)`: 왼쪽부터 채움
        
    - `RPAD(...)`: 오른쪽부터 채움
        

---

### 📌 ✂️ 공백 제거 (TRIM)

1. **🎯 쿼리 목적**:
    
    - 문자열 좌우측의 공백 제거
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT TRIM(' SQL ') AS trim_result,
           LTRIM(' SQL ') AS ltrim_result,
           RTRIM(' SQL ') AS rtrim_result
    FROM dual;
    ```
    
3. **🧠 세부 설명**:
    
    - `TRIM`: 양쪽 공백 제거
        
    - `LTRIM`: 왼쪽 공백만 제거
        
    - `RTRIM`: 오른쪽 공백만 제거
        

---

### 📌 🔁 문자열 치환 (REPLACE)

1. **🎯 쿼리 목적**:
    
    - 특정 문자열 또는 NULL 값 치환
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT name,
           REPLACE(mobile1, NULL, '없음') AS replace_null,
           REPLACE(addr, '서울', 'SEOUL') AS replace_addr
    FROM userTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - `REPLACE(문자열, 찾을문자, 바꿀문자)`
        
    - NULL 치환은 `NVL()`이 더 적절
        

---

### 📌 🔗 문자열 연결

1. **🎯 쿼리 목적**:
    
    - 여러 문자열을 연결해 출력
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT name,
           CONCAT(mobile1, '-') AS part1,
           CONCAT(CONCAT(mobile1, '-'), mobile2) AS mobile,
           mobile1 || '-' || mobile2 AS phone_number
    FROM userTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - `CONCAT(문자열1, 문자열2)` 또는 `||` 연산자 사용

## 🔢 숫자 함수

---

### 📌 🔄 반올림 & 절삭

1. **🎯 쿼리 목적**:
    
    - 가격을 천 단위로 나누고 반올림/절삭 적용
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT prodName, price,
           ROUND(price/1000, 2) AS round_thousands,
           TRUNC(price/1000, 1) AS trunc_thousands
    FROM buyTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - `ROUND(값, 자릿수)`: 반올림
        
    - `TRUNC(값, 자릿수)`: 절삭
        

---

### 📌 📈 올림 & 내림

1. **🎯 쿼리 목적**:
    
    - 가격의 백 단위 올림/내림
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT prodName, price,
           CEIL(price/100) AS ceil_hundreds,
           FLOOR(price/100) AS floor_hundreds
    FROM buyTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - `CEIL`: 올림
        
    - `FLOOR`: 내림
        

---

### 📌 ➗ 나머지 & 절대값

1. **🎯 쿼리 목적**:
    
    - 가격 계산의 나머지 및 특정 기준과의 차이 절대값 구하기
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT prodName, price, amount,
           MOD(price, 100) AS remainder_100,
           ABS(price - 500) AS abs_diff_500
    FROM buyTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - `MOD(a, b)`: a를 b로 나눈 나머지
        
    - `ABS(값)`: 절대값
        

---

### 📌 🧮 부호, 제곱, 제곱근

1. **🎯 쿼리 목적**:
    
    - 수치 데이터에 대한 다양한 수학적 계산
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT prodName, price,
           SIGN(price - 100) AS sign_price,
           POWER(amount, 2) AS amount_squared,
           SQRT(price) AS sqrt_price
    FROM buyTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - `SIGN(수식)`: 음수(-1), 0, 양수(1) 구분
        
    - `POWER(x, y)`: x의 y 제곱
        
    - `SQRT(x)`: 제곱근
