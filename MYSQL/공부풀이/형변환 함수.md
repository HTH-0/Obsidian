## 🔁 TO_CHAR 함수

---

### 📌 🗓️ 날짜 → 문자 변환

1. **🎯 쿼리 목적**:
    
    - 날짜 데이터를 다양한 형식의 문자열로 변환
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT name, mDate,
           TO_CHAR(mDate, 'YYYY-MM-DD') AS formatted_date,
           TO_CHAR(mDate, 'YYYY"년" MM"월" DD"일"') AS korean_date,
           TO_CHAR(mDate, 'YYYY/MM/DD HH24:MI:SS') AS date_with_time
    FROM userTbl;
    ```
    
    
3. **🧠 세부 설명**:
    
    - `'YYYY-MM-DD'`: ISO 기본 형식
        
    - `'YYYY"년" MM"월" DD"일"'`: 한국어 날짜 표현
        
    - `'HH24:MI:SS'`: 24시간제 시간 표현
        

---

### 📌 💰 숫자 → 문자 변환

1. **🎯 쿼리 목적**:
    
    - 숫자에 천단위 콤마, 소수점 등 서식을 적용해 문자열로 변환
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT prodName, price, amount,
           TO_CHAR(price, '999,999') AS formatted_price,
           TO_CHAR(price * amount, '999,999') AS total,
           TO_CHAR(price/1000, '0.00') AS price_thousands
    FROM buyTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - `'999,999'`: 천단위 콤마 포함 정수 표현
        
    - `'0.00'`: 소수점 두 자리까지 표현

## 🔁 TO_NUMBER 함수

---

### 📌 🔡 문자열 → 숫자 변환

1. **🎯 쿼리 목적**:
    
    - 숫자 형식의 문자열을 숫자 데이터로 변환
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT TO_NUMBER('1,000', '9,999') AS number_result,
           TO_NUMBER('￦2,000', 'L9,999') AS currency_to_number
    FROM dual;
    ```
    
3. **🧠 세부 설명**:
    
    - `'9,999'`: 쉼표 포함 숫자 형식 파싱
        
    - `'L9,999'`: 지역 통화 기호 처리

## 🔁 TO_DATE 함수

---

### 📌 🔤 문자열 → 날짜 변환

1. **🎯 쿼리 목적**:
    
    - 문자열을 날짜로 변환
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT TO_DATE('2023-12-25', 'YYYY-MM-DD') AS christmas,
           TO_DATE('20231225', 'YYYYMMDD') AS christmas_no_sep,
           TO_DATE('2023/12/25 14:30:00', 'YYYY/MM/DD HH24:MI:SS') AS christmas_time
    FROM dual;
    ```
    
3. **🧠 세부 설명**:
    
    - 날짜 구분자 여부에 따라 포맷 지정 필요
        
    - 시간 포함 시 `HH24:MI:SS` 사용

## 🔁 🔄 암시적 형변환

---

### 📌 🤖 자동 형변환 예시

1. **🎯 쿼리 목적**:
    
    - 문자열 타입 숫자 컬럼을 수치 연산에 사용
        
2. **💻 SQL 구문**:
    
    ```sql
    SELECT name, birthYear, 
           birthYear + 100 AS after_100years
    FROM userTbl;
    ```
    
3. **🧠 세부 설명**:
    
    - Oracle에서는 문자열이 숫자로 해석될 수 있으면 자동 변환됨
        
    - 실무에서는 명시적 형변환 권장 (`TO_NUMBER`)
