## ✅ 테이블 생성 시 주의사항 정리

### 🔹 1. 테이블명과 컬럼명 작성 규칙

- 의미를 갖는 **적절한 이름** 사용
    
- **가능한 단수형** 사용 권장 (예: `User` vs `Users`)
    
- **다른 테이블명과 중복되지 않도록** 주의
    

---

### 🔹 2. 컬럼 정의 방법

- 한 테이블 안에서는 **컬럼명이 중복될 수 없음**
    
- 테이블 이름과 컬럼 목록은 다음과 같이 작성:
    
    ```sql
    CREATE TABLE 테이블명 (컬럼1, 컬럼2, ...);
    ```
    
- 각 컬럼은 `,`로 구분하고, **마지막에는 세미콜론(;)**으로 종료
    

---

### 🔹 3. 컬럼명 작성 시 주의사항

- **다른 테이블과의 일관성** 고려 (→ 가독성, 유지보수 용이)
    
- **데이터 타입**은 반드시 명시해야 함
    
    ```sql
    컬럼명 자료형 [제약조건]
    ```
    

---

### 🔹 4. 컬럼명과 예약어 사용 제한

- 컬럼명은 **반드시 문자로 시작**해야 함 (숫자 시작 불가)
    
- **DBMS 예약어**(Reserved Word)는 컬럼명/테이블명으로 사용 불가
    
- 컬럼명/테이블명에 사용 가능한 문자:
    
    - **A~~Z, a~~z, 0~9, _ (언더스코어), $, #**
        

---

### 🔹 5. 기타 작성 팁

- 컬럼명은 **일관성 있게 작성**: 예) `reg_date`, `user_id`, `dept_code`
    
- **약어 남용 금지**, 필요 시 표준 약어 목록 사용
    

---

## ✅ 예시

```sql
CREATE TABLE Employee (
  emp_id     INT        PRIMARY KEY,
  emp_name   VARCHAR(50) NOT NULL,
  hire_date  DATE
);
```
