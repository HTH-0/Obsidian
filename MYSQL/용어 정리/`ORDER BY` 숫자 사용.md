
## 📌 `ORDER BY` 숫자 사용 시 의미 정리

### ✅ 숫자는 SELECT 절의 "쉼표 기준 순서"를 의미함

```sql
SELECT 컬럼1, 컬럼2, 컬럼3
FROM 테이블
ORDER BY 1, 3 DESC;
```

|숫자|의미|
|---|---|
|`1`|`SELECT` 절의 **첫 번째 컬럼**인 `컬럼1` 기준 오름차순 정렬|
|`3 DESC`|`SELECT` 절의 **세 번째 컬럼**인 `컬럼3` 기준 내림차순 정렬|

➡ **쉼표를 기준으로 SELECT 절에 적힌 순서**가 번호의 기준이 된다.

---

### ✅ 예시

```sql
SELECT DNAME, LOC, DEPTNO
FROM DEPT
ORDER BY 1, 3 DESC;
```

|순번|컬럼명|정렬방식|
|---|---|---|
|1|DNAME|오름차순|
|3|DEPTNO|내림차순|

---

### ⚠️ 주의 사항

- 숫자는 **컬럼명 기준이 아님**, 오직 `SELECT` 절에서의 **표현식 위치 순서**
    
- `SELECT *` 사용 시에는 컬럼 순서가 명확하지 않아 가독성이 떨어지므로 **비추천**
    
- 협업이나 유지보수 시에는 가급적 **컬럼명으로 직접 작성**하는 것이 좋음
    

---

필요하면 아래 항목도 Obsidian에 덧붙일 수 있음:

- `ORDER BY 1, 2, 3 DESC`는 순차 다중 정렬
    
- `ORDER BY 별칭` 사용도 가능 (`SELECT A AS B` → `ORDER BY B`)
    
- `ORDER BY`는 SQL에서 결과 행의 **정렬 순서를 지정**하는 구문
