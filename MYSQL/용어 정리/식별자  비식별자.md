---
aliases:
  - 식별자 / 비식별자
---

**"외래키이자 기본키"가 되는 경우 = 식별자 관계**의 대표적인 특징이야.

---

|구분|설명|
|---|---|
|**식별자 관계**|자식 테이블에서 부모 테이블의 PK가 **외래키(FK)**로 들어오고, 동시에 자식 테이블의 **기본키(PK)** 일부가 됨|
|**비식별자 관계**|부모의 PK는 자식 테이블에 **외래키(FK)**로만 들어오고, 자식 테이블의 PK에는 **포함되지 않음**|

---

### 🔸 예시 1: 식별자 관계

```sql
CREATE TABLE 회원 (
  회원ID INT PRIMARY KEY
);

CREATE TABLE 배송지 (
  회원ID INT,              -- 부모의 PK
  주소번호 INT,
  주소 TEXT,
  PRIMARY KEY (회원ID, 주소번호),         -- 부모 PK + 자식 자체 컬럼으로 복합 PK
  FOREIGN KEY (회원ID) REFERENCES 회원(회원ID)
);
```

> → 여기서 **회원ID는 외래키이자 기본키**  
> → 자식이 부모 없이는 식별 불가  
> ✅ **식별자 관계**

---

### 🔸 예시 2: 비식별자 관계

```sql
CREATE TABLE 배송지 (
  배송지ID INT PRIMARY KEY,   -- 자체 식별자
  회원ID INT NOT NULL,        -- 외래키 (하지만 PK는 아님)
  주소 TEXT,
  FOREIGN KEY (회원ID) REFERENCES 회원(회원ID)
);
```

> → 여기서 **회원ID는 외래키지만 기본키는 아님**  
> → 배송지는 자체적으로 식별 가능  
> ✅ **비식별자 관계**
