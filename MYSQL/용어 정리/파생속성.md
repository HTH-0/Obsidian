`파생 속성(Derived Attribute)`은 말 그대로 **다른 속성으로부터 계산(파생)되는 속성**을 말해.  
즉, **DB에 직접 저장되지 않고, 필요할 때 계산해서 사용하는 속성**이야.

---

### ✅ 예: 파생 속성의 대표 사례

|저장 속성|파생 속성|
|---|---|
|생년월일|나이|
|시급, 근무시간|월급|
|수량, 단가|총액|

→ `나이 = 현재날짜 - 생년월일`  
→ `총액 = 수량 × 단가`

> 즉, **이미 존재하는 데이터를 기반으로 계산** 가능하면 그건 파생 속성

---

### ✅ 파생 속성의 특징

|항목|설명|
|---|---|
|저장 여부|일반적으로 **DB에 저장하지 않음**|
|계산 시점|**요청 시점에 동적으로 계산**|
|무결성 관리|**저장하지 않기 때문에 무결성 문제 없음**|
|성능 고려|복잡한 계산이 자주 필요하면 **캐싱하거나 저장할 수도 있음**|

---

### ✅ ERD에서 표기법

- 파생 속성은 **점선 타원**(---)으로 표현함
    

```
    [회원]
     |
  ---------
  |       |
이름   ───나이 (파생 속성, 생년월일로부터 계산)
```

---

### ✅ 실제 SQL 예시

```sql
SELECT 이름, YEAR(CURDATE()) - YEAR(생년월일) AS 나이
FROM 회원;
```

→ `나이`는 계산된 컬럼 (파생), 실제 DB에는 저장되지 않음
