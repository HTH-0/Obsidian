## 단일행 NULL 관련 함수 정리

|함수 이름|설명|
|---|---|
|**NVL(표현식1, 표현식2)**  <br>**ISNULL(표현식1, 표현식2)**|- 표현식1이 `NULL`이면 `표현식2`를 반환  <br>- 두 표현식의 데이터 타입이 같아야 함  <br>- NULL 처리에서 가장 기본적으로 사용|
|**NULLIF(표현식1, 표현식2)**|- 표현식1과 표현식2가 같으면 `NULL` 반환  <br>- 같지 않으면 표현식1을 그대로 반환|
|**COALESCE(표현식1, 표현식2, ...)**|- 순서대로 표현식을 검사하여 `NULL`이 아닌 첫 번째 값을 반환  <br>- 모두 `NULL`이면 `NULL` 반환|
