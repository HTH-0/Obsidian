## ✅ 오라클 계층형 질의 (Hierarchical Query) 정리

---

### 📌 개요

> 계층형 질의는 **부모-자식 관계의 트리 구조**를 SQL로 탐색하는 기능이며, Oracle에서는 `CONNECT BY` 구문을 통해 지원함.

---

### ✅ 기본 문법

```sql
SELECT ...
FROM 테이블명
START WITH 시작조건
CONNECT BY [NOCYCLE] PRIOR 부모컬럼 = 자식컬럼
```

- `START WITH`: 루트(시작) 노드 지정
    
- `CONNECT BY`: 부모-자식 관계 지정
    
- `PRIOR`: "이전 행" = **부모**를 의미
    
- `LEVEL`: 계층 깊이를 나타내는 Oracle 전용 컬럼
    

---

### ✅ PRIOR 키워드

- `PRIOR`는 **항상 부모**를 의미함
    
- `CONNECT BY PRIOR A = B` → A가 부모, B가 자식
    
- `CONNECT BY A = PRIOR B` → B가 부모, A가 자식
    

#### 📌 기억 공식

> **"PRIOR가 붙은 쪽이 부모다."**

---

### ✅ 방향별 해석

|조건|탐색 방향|의미|
|---|---|---|
|`CONNECT BY PRIOR A = B`|순방향 (Top → Down)|A는 부모, B는 자식|
|`CONNECT BY A = PRIOR B`|역방향 (Bottom → Top)|B는 부모, A는 자식|

---

### ✅ 트리에서 PRIOR 위치

- 트리 구조를 생각하면 `PRIOR`가 **위(부모)**에 있어야 논리적으로 맞음
    
- 따라서 `CONNECT BY PRIOR 부모컬럼 = 자식컬럼`은 **자식이 부모를 참조한다**는 뜻
    

---

### ✅ LEVEL

- `START WITH`에서 지정된 루트는 항상 `LEVEL = 1`
    
- 자식 노드는 2, 3...으로 깊어짐
    
- **LEVEL이 가장 낮은 값이 루트(부모)** 노드임
    

---

### ✅ 순방향 + 역방향 함께 탐색하는 경우

- 자식(하위)도 보고, 상위(루트)도 보고 싶다면:
    

```sql
-- 상위로 올라가기 (역방향)
SELECT ...
FROM 부서
START WITH 부서코드 = 120
CONNECT BY 부서코드 = PRIOR 상위부서코드

UNION

-- 하위로 내려가기 (순방향)
SELECT ...
FROM 부서
START WITH 부서코드 = 120
CONNECT BY PRIOR 부서코드 = 상위부서코드;
```

---

### ✅ WHERE 절에서 PRIOR 사용 가능 여부

- `CONNECT BY` 절 외 `SELECT`, `WHERE`에서 `PRIOR` 사용은 **문법적으로 허용**되지만
    
- 실제 의미 있는 결과는 **`CONNECT BY`에서만** 발생함
    
- 실무와 시험에서는 **"PRIOR는 CONNECT BY에서만 사용한다"**고 이해하는 게 안전함
    

---

### ✅ 한 줄 요약

> 오라클의 계층형 질의는 `START WITH`와 `CONNECT BY`로 트리를 탐색하며, `PRIOR`는 부모를 가리키고 `LEVEL`은 계층 깊이를 나타낸다. 방향 판단은 PRIOR 위치를 기준으로 한다.
