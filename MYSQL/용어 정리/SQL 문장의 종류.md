## 📌 SQL 문장의 종류

### 1. DML (Data Manipulation Language) - 데이터 조작어

- **SELECT**:  
    데이터베이스에 저장된 데이터를 조회하거나 검색할 때 사용.  
    → `RETRIEVE`라고도 함.
    
- **INSERT / UPDATE / DELETE**:  
    테이블에 새로운 데이터를 입력(INSERT)하거나,  
    기존 데이터를 수정(UPDATE)하거나,  
    데이터를 삭제(DELETE)할 때 사용.
    

---

### 2. DDL (Data Definition Language) - 데이터 정의어

- **CREATE / ALTER / DROP / RENAME**:  
    테이블 등의 데이터 구조를 생성, 변경, 삭제, 이름 변경 등  
    데이터 구조를 정의하거나 수정할 때 사용.
    

---

### 3. DCL (Data Control Language) - 데이터 제어어

- **GRANT / REVOKE**:  
    데이터베이스 사용자에게 권한을 부여하거나 회수할 때 사용.
    

---

### 4. TCL (Transaction Control Language) - 트랜잭션 제어어

- **COMMIT / ROLLBACK**:  
    DML 명령 실행 결과를 **확정(COMMIT)** 하거나  
    문제가 생긴 경우 **되돌리기(ROLLBACK)** 를 수행.
