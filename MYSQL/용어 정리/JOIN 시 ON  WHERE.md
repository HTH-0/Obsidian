
| 조건 대상               | 위치      | 이유                                                 |
| ------------------- | ------- | -------------------------------------------------- |
| **기준 테이블(A)** 만의 조건 | `WHERE` | 기준 테이블은 항상 존재하므로, 필터링해도 문제가 없음                     |
| **조인 테이블(B)** 조건    | `ON`    | B는 없을 수도 있음(=NULL). WHERE에 조건 쓰면 OUTER JOIN 의미 사라짐 |
|  **A와 B의 공통 조인 조건** | `ON`    | 조인 자체를 성립시키는 조건 → 반드시 ON에 있어야 함                    |
