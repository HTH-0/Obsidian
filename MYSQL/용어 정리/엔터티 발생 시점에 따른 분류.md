## ✅ 먼저, 엔터티 발생 시점에 따른 주요 분류는 다음 3가지야:

### 1️⃣ **기본 엔터티 (Fundamental Entity)**

- 업무의 중심이 되는 실체
    
- 외부에서 생성되며 스스로 존재 가능
    
- 예: 고객, 사원, 제품 등
    

### 2️⃣ **중심 엔터티 (Main Entity / Transaction Entity)**

- 기본 엔터티와 관계를 맺으며 생성됨
    
- 업무 처리 과정에서 생성되는 행위 기반 데이터
    
- 예: 주문, 수강신청, 구매기록
    

### 3️⃣ **코드 엔터티 (Code Entity / Reference Entity)**

- 다른 엔터티에서 참조하는 코드성 정보 보관
    
- 자주 변경되지 않음
    
- 예: 직급코드, 국가코드, 결제수단코드
