### ✅ `ExceptionTestController.java`

```java
@Controller
@Slf4j
@RequestMapping("/except")
public class ExceptionTestController {

	@GetMapping("/ex")
	public void ex1_1() throws FileNotFoundException {
		log.info("GET -");
		throw new FileNotFoundException("파일을 찾을수가 없습니다.");
	}

	@GetMapping("/page01")
	public void ex1() throws FileNotFoundException {
		log.info("GET /except/page01");
		throw new FileNotFoundException("파일을 찾을수가 없습니다.");
	}

	@GetMapping("/page02/{num}/{div}")
	public String ex2(@PathVariable("num") int num,
	                  @PathVariable("div") int div,
	                  Model model) throws ArithmeticException {
		log.info("GET /except/page02..." + (num/div));
		model.addAttribute("result", (num/div));
		return "except/page02";
	}
}
```

### ✅ `GlobalExceptionHandler.java`

```java
@ControllerAdvice
@Slf4j
public class GlobalExceptionHandler {

	@ExceptionHandler(Exception.class)
	public String AllExceptionExceptionHandler(Exception e, Model model) {
		log.info("GlobalExceptionHandler's error : " + e);
		model.addAttribute("ex", e);
		return "global_error";
	}
}
```

## 🔍 코드 분석

### ✅ 클래스 및 어노테이션 설명

- `@ControllerAdvice`  
    → 프로젝트 전역에서 발생하는 예외를 공통적으로 처리할 수 있도록 지원하는 클래스에 사용  
    → 해당 클래스는 모든 컨트롤러의 예외를 가로채 처리함
    
- `@ExceptionHandler(Exception.class)`  
    → 지정된 예외 타입(Exception 등)이 발생했을 때 실행되는 메서드  
    → `@Controller`, `@RestController`, `@ControllerAdvice` 클래스 내부에 정의 가능
    
- `@Slf4j`  
    → Lombok에서 제공하는 로그 객체 생성용 어노테이션  
    → `log.info(...)`, `log.error(...)` 등을 사용할 수 있음
    

---

### ✅ 예외 발생 흐름

1. `MemoController`, `ExceptionTestController`에서 특정 상황에서 예외 발생 (`FileNotFoundException`, `ArithmeticException`)
    
2. 이 예외들은 `@ExceptionHandler` 메서드에서 처리
    
    - 하지만 각 컨트롤러에 주석처리된 상태 (`@ExceptionHandler(...)`) → 즉 **현재는 개별 컨트롤러에서 예외 처리하지 않음**
        
3. 대신, `GlobalExceptionHandler` 클래스가 전역 예외 처리 역할 수행 중
    
    - 모든 예외(`Exception.class`)를 한 곳에서 처리하고, `global_error.jsp`와 같은 에러 뷰 페이지로 연결
        

---

### ✅ 전역 예외 처리 방식 (GlobalExceptionHandler)

- `@ControllerAdvice` 덕분에, 모든 컨트롤러에서 발생하는 예외를 감지할 수 있음
    
- 메서드 이름은 자유롭게 설정 가능. 단, `@ExceptionHandler`에 지정된 타입이 일치해야 함
    
- 예외 정보를 `Model`에 담아 JSP로 전달 → 사용자에게 에러 메시지 노출
    

---

## 📌 요약

- `MemoController`, `ExceptionTestController`에서 각각 `FileNotFoundException`, `ArithmeticException` 예외가 발생함
    
- 현재는 각 컨트롤러에서 `@ExceptionHandler`가 주석 처리되어 있어, 전역 예외 처리만 작동함
    
- `GlobalExceptionHandler` 클래스가 모든 예외를 처리하며 `global_error.jsp` 페이지로 응답
    
- 이 구조는 예외를 일관되게 처리하고, 사용자에게 명확한 에러 페이지를 보여주는 데 유용함
