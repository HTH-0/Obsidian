# 🧪 DITest.java - 의존성 주입 테스트 클래스

## 📦 전체 코드

```java
package DITests;

import static org.junit.jupiter.api.Assertions.assertNotNull;

import org.junit.jupiter.api.Disabled;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.context.ApplicationContext;
import org.springframework.test.context.ContextConfiguration;
import org.springframework.test.context.junit.jupiter.SpringExtension;

import com.example.app.config.PersonComponent;
import com.example.app.domain.Dto.PersonDto;

@ExtendWith(SpringExtension.class)
@ContextConfiguration("file:src/main/webapp/WEB-INF/spring/root-context.xml")
class DITest {

	@Autowired
	private PersonDto personDto1;

	@Autowired
	private PersonDto personDto2;

	@Autowired
	private PersonDto person03;
	
	@Autowired
	private PersonDto personBean;

	@Autowired
	private PersonComponent personComponent;
	
	@Test
	@Disabled
	public void test() {
		System.out.println(personDto1);
		System.out.println(personDto2);
		System.out.println(person03);
		System.out.println(personBean);
		System.out.println(personComponent);
	}

	@Autowired
	private ApplicationContext applicationContext;
	
	@Test
	public void test2() {
		assertNotNull(applicationContext);
		System.out.println(applicationContext.getBean("personDto1"));
	}
}
```

---

## 🔍 코드 분석

### ✅ 클래스 및 어노테이션 설명

- `@ExtendWith(SpringExtension.class)`  
    JUnit5와 Spring을 연동하기 위한 설정. 테스트에서 Spring 기능 사용 가능.
    
- `@ContextConfiguration("file:src/main/webapp/WEB-INF/spring/root-context.xml")`  
    테스트에 사용할 Spring 설정 파일 지정. XML 기반 설정.
    

---

### ✅ 주요 필드 설명 (의존성 주입)

- `@Autowired private PersonDto personDto1` 등  
    root-context.xml 또는 Java Config에서 등록한 Bean들을 주입 받음.  
    같은 타입(`PersonDto`)이 여러 개 있어도 `id`나 `@Qualifier` 등을 통해 특정 Bean 주입 가능.
    
- `@Autowired private PersonComponent personComponent`  
    `@Component` 애노테이션으로 등록된 컴포넌트 클래스. 컴포넌트 스캔 대상.
    
- `@Autowired private ApplicationContext applicationContext`  
    Spring의 ApplicationContext를 주입 받아, Bean 직접 접근 가능.
    

---

### ✅ 주요 메서드 설명

- `@Test @Disabled public void test()`  
    현재 실행되지 않도록 비활성화(`@Disabled`) 되어 있음.  
    여러 Bean들의 주입 상태와 내용을 출력하는 디버그용 메서드.
    
- `@Test public void test2()`  
    `ApplicationContext`가 정상적으로 주입되었는지 검증 후,  
    `"personDto1"`이라는 이름의 Bean을 컨텍스트에서 가져와 출력.
    

---

## 📌 요약

- 이 테스트 클래스는 `root-context.xml` 설정 파일을 기반으로 다양한 방식으로 등록된 Bean들을 `@Autowired`를 통해 주입받는지 검증함.
    
- `PersonDto`는 XML 또는 Java 설정에서 수동 등록되었고, `PersonComponent`는 `@Component`로 자동 등록된 클래스.
    
- `ApplicationContext`를 활용한 수동 Bean 조회 예시도 포함되어 있어, DI와 컨테이너 활용을 모두 학습 가능.
