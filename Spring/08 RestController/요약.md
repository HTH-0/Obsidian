# 🧾 Spring RESTful Controller 요약

---

## 📌 1. 핵심 기술 개요

|구성 요소|설명|
|---|---|
|`@RestController`|JSON/XML 등 데이터 포맷을 반환하는 REST API 전용 컨트롤러|
|`@RequestMapping`|공통 URI 설정|
|`@GetMapping` 등|RESTful 방식의 HTTP 메서드 맵핑|
|`@RequestBody`, `@PathVariable`|요청 본문 또는 URL 경로 데이터 바인딩|
|`Axios`|비동기 HTTP 요청을 위한 JS 라이브러리 (프론트-백 통신에 활용)|
|`Jackson`|객체 ↔ JSON/XML 직렬화를 위한 필수 라이브러리|

---

## ✅ Step-by-Step 구성 요약

### ✅ Step 1. `@RestController` 개념 및 설정

- REST란 무엇인지, `@RestController`가 어떤 역할을 하는지 설명
    
- Jackson 의존성 추가로 JSON/XML 자동 변환 가능
    

### ✅ Step 2. `RestController_01`

- 다양한 포맷 응답 실습 (TEXT, JSON, XML, List 등)
    
- `produces` 속성으로 Content-Type을 제어
    

### ✅ Step 3. `RestController_02Memo`

- `MemoService` 연동하여 실제 CRUD API 구현
    
- 다양한 방식 (GET, POST, PUT, DELETE)을 실습
    
- `@RequestBody`, `@PathVariable` 실전 활용
    

### ✅ Step 4. `RestTestController` + `rest.jsp`

- JSP 페이지에서 테스트 UI 구성
    
- XHR, Axios 버튼으로 각각의 요청 시나리오 분리
    

### ✅ Step 5. Axios 비동기 요청 처리

- Axios를 활용한 GET/POST/PUT/DELETE 요청 처리
    
- 요청은 REST API 경로와 직접 연결됨
    
- 결과는 브라우저 콘솔에 출력
    

---

## 🔗 전체 흐름

```
rest.jsp (뷰)
   ↓ 버튼 클릭
JavaScript (Axios로 API 요청)
   ↓
@RestController (API 처리)
   ↓
Service → Mapper → DB
```

## ✅ 테스트 포인트 예시

|목적|요청 방식|URL 예시|
|---|---|---|
|메모 등록|GET|`/memo/add_rest_get?id=1&text=hello`|
|메모 등록|POST|`/memo/add_rest_post` (JSON 본문)|
