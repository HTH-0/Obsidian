# 📁 파일 업로드 & 다운로드 처리 (Spring 5.0.7.RELEASE 기준)

## 📦 전체 코드 요약

### ✅ 의존성 설정 (pom.xml)

```xml
<!-- commons-fileupload: multipart/form-data 처리용 -->
<dependency>
    <groupId>commons-fileupload</groupId>
    <artifactId>commons-fileupload</artifactId>
    <version>1.4</version>
</dependency>

<!-- commons-io: 파일 관련 I/O 처리 -->
<dependency>
    <groupId>commons-io</groupId>
    <artifactId>commons-io</artifactId>
    <version>2.8.0</version>
</dependency>
```

## 🧩 환경 설정

### ✅ web.xml 내 DispatcherServlet 설정

```xml
<servlet>
    <servlet-name>appServlet</servlet-name>
    <servlet-class>org.springframework.web.servlet.DispatcherServlet</servlet-class>
    <init-param>
        <param-name>contextConfigLocation</param-name>
        <param-value>/WEB-INF/spring/appServlet/servlet-context.xml</param-value>
    </init-param>
    
    <multipart-config>
        <location>/tmp</location> <!-- 임시 저장소 -->
        <max-file-size>10485760</max-file-size> <!-- 최대 파일 10MB -->
        <max-request-size>20971520</max-request-size> <!-- 요청 전체 크기 20MB -->
        <file-size-threshold>5242880</file-size-threshold> <!-- 5MB 초과 시 디스크로 저장 -->
    </multipart-config>
</servlet>
```

---

### ✅ servlet-context.xml에 MultipartResolver 등록

```xml
<beans:bean id="multipartResolver"
    class="org.springframework.web.multipart.commons.CommonsMultipartResolver">
    <beans:property name="maxUploadSize" value="20971520"/> <!-- 20MB 제한 -->
    <beans:property name="defaultEncoding" value="UTF-8"/>
</beans:bean>
```

## 🔧 파일 업로드 처리

### ✅ Controller

```java
@Controller
public class FileUploadController {

    @PostMapping("/upload")
    public String uploadFile(@RequestParam("file") MultipartFile file) throws IOException {
        if (!file.isEmpty()) {
            String uploadPath = "C:/upload/";
            String fileName = file.getOriginalFilename();
            file.transferTo(new File(uploadPath + fileName)); // 파일 저장
        }
        return "uploadSuccess"; // 업로드 성공 시 반환 페이지
    }
}
```

### ✅ JSP 업로드 폼

```jsp
<form action="/upload" method="post" enctype="multipart/form-data">
    <input type="file" name="file" />
    <button type="submit">업로드</button>
</form>
```

## 📥 파일 다운로드 처리

### ✅ Controller

```java
@Controller
public class FileDownloadController {

    @GetMapping("/download")
    public ResponseEntity<Resource> downloadFile(@RequestParam String filename) throws IOException {
        String uploadPath = "C:/upload/";
        Path path = Paths.get(uploadPath + filename);
        Resource resource = new InputStreamResource(Files.newInputStream(path));

        return ResponseEntity.ok()
                .header(HttpHeaders.CONTENT_DISPOSITION, "attachment; filename=\"" + filename + "\"")
                .contentType(MediaType.APPLICATION_OCTET_STREAM)
                .body(resource); // 파일 내용을 바디에 포함하여 응답
    }
}
```

### ✅ JSP 다운로드 링크

```jsp
<a href="/download?filename=example.txt">example.txt 다운로드</a>
```

## 📌 정리 요약

|항목|설명|
|---|---|
|업로드 방식|multipart/form-data, `MultipartResolver` 설정 필요|
|다운로드 방식|`ResponseEntity`를 통한 바이너리 스트림 전달|
|인코딩 처리|UTF-8 설정 필수 (한글 파일명 주의)|
|파일 크기 제한|`web.xml`과 `multipartResolver`에 설정|
|보안 주의사항|사용자 입력 파일명 검증 필요 (디렉토리 경로 공격 방지 등)|
|임시 저장소|`/tmp` 또는 지정된 경로에 파일 임시 저장|
