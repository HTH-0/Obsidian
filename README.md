### 🚀 옵시디언 사용 방법  
1. [옵시디언 공식 사이트](https://obsidian.md/)에서 다운로드  
2. 새로운 **Vault(보관함)**을 생성하거나 기존 Vault 열기  
3. Markdown 형식으로 노트 작성 및 관리  
4. 플러그인 및 테마를 활용하여 기능 확장 가능  

---

### 📲 Obsidian Vault 연동 방법

1. **레포지토리 클론**
   ```bash
   git clone https://github.com/HTH-0/Obsidian.git
   ```
2. **Obsidian에서 새로운 Vault 열기**
   - Obsidian 실행 → "Open folder as vault" 선택
   - 방금 클론 받은 `Obsidian` 폴더를 선택
