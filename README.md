
# 📂 옵시디언 백업용 레포지토리

이 레포지토리는 **옵시디언(Obsidian)**을 백업하고 관리하기 위한 저장소입니다.

---

## 🚀 옵시디언 사용 방법
1. [옵시디언 공식 사이트](https://obsidian.md/)에서 다운로드
2. 새로운 **Vault(보관함)**을 생성하거나 기존 Vault 열기
3. Markdown 형식으로 노트 작성 및 관리
4. 플러그인 및 테마를 활용하여 기능 확장 가능

---

## 📲 레포지토리 적용 방법
1. **레포지토리 클론**
   ```bash
   git clone https://github.com/HTH-0/Obsidian.git
   ```
2. 옵시디언에서 해당 폴더를 Vault로 설정
3. 변경 사항이 있으면 아래 명령어로 백업
   ```bash
   git add .
   git commit -m "백업 업데이트"
   git push origin master
   ```
