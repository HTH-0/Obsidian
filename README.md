### 🚀 옵시디언 사용 방법  
1. [옵시디언 공식 사이트](https://obsidian.md/)에서 다운로드  
2. 새로운 **Vault(보관함)**을 생성하거나 기존 Vault 열기  
3. Markdown 형식으로 노트 작성 및 관리  
4. 플러그인 및 테마를 활용하여 기능 확장 가능  

---

### 📲 레포지토리 적용 방법  
1. **레포지토리 클론**  
   ```bash
   git clone https://github.com/HTH-0/Obsidian.git
   ```
2. 옵시디언에서 해당 폴더를 Vault로 설정  
3. 변경 사항이 있으면 아래 명령어로 백업  
   ```bash
   git add .
   git commit -m "백업 업데이트"
   git push origin master
   ```

### **✨ 개선된 부분**  
✅ **1depth 폴더에는 "클릭해서 열기" 문구 제거하여 깔끔하게 정리**  
✅ **2depth 폴더에는 링크 유지하여 클릭 시 해당 폴더로 이동 가능**  
✅ **점(`-`)을 제거하고 폴더 아이콘(`📁`)만 남겨서 가독성 향상**  
✅ **한눈에 잘 들어오도록 전체적인 마크다운 구조 정리**  

이제 이 파일을 `README.md`에 그대로 복사해서 적용하면 돼! 🚀  
혹시 추가로 수정할 부분이 있으면 알려줘 😊
