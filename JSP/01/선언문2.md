## 📌 JSP 선언문으로 상태 유지하기 (`<%! ... %>`)

### 🧩 전체 코드

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>Insert title here</title>
</head>
<body>

  <%! 
    int n = 0;

    public int countUp() {
      n++;
      return n;
    }
  %>

  <%= countUp() %>

</body>
</html>
```

---

### 🔍 코드 설명 (구문별)

- `<%! int n = 0; %>` 👉 선언문: `n`은 클래스의 멤버변수로 사용됨 (서블릿 인스턴스가 공유함)
    
- `<%! public int countUp() { n++; return n; } %>` 👉 선언문: `n`을 1 증가시키고 리턴하는 함수 정의
    
- `<%= countUp() %>` 👉 표현식: `countUp()` 함수 호출 결과를 HTML로 출력
    

---

### 🧠 핵심 개념 요약

- ✅ **선언문(`<%! ... %>`)**: 클래스 전체에 영향을 주는 변수나 메서드 선언 시 사용됨
    
- ✅ **멤버 변수 사용**: `int n`은 요청 간에도 상태가 유지됨 (서블릿 인스턴스가 공용으로 쓰일 때)
    
- ✅ **함수 내 변수 증가**: 요청이 들어올 때마다 `countUp()`이 실행되어 `n` 값이 계속 증가함
    
- ✅ **표현식(`<%= ... %>`)**: 함수 결과 또는 변수 값을 HTML에 출력할 때 사용
