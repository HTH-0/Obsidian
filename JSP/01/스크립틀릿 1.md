## 📌 JSP Scriptlet 기본 예제 - 지역변수와 출력

### 🧩 전체 코드
```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>Insert title here</title>
</head>
<body>

<!--  
	Scriptlet : JSP-> Servlet파일로 변환될때 Servlet내의 Service 함수 안에서 처리되는 로직
	Service라는 함수내에서 동작하기 때문에 지역변수 선언, 반복문/분기문 처리가 가능
	하지만 함수를 벗어나면 지역변수는 소멸되기 때문에 요청시(ex 새로고침) 되면 상태값이 초기화 된다
-->
<%
	String str1 = "HELLO1";		//!!!!!!!!!!!!!!!!!!!!!!
	String str2 = "HELLO2";		//!!!!!!!!!!!!!!!!!!!!!!
	String str3 = str1 + str2;
	int a = 0;
	for(int i=0;i<10;i++){
		a++;
		System.out.println(i);
	}
%>

<%=str1 %><br>
<%=str2 %><br>
<%=str3 %><br>
<%=a %><br>

</body>
</html>
````

---

### 🔍 코드 설명 (구문별)

- `<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8"%>`  
    👉 JSP 페이지의 기본 설정 (언어, 콘텐츠 타입, 인코딩)
    
- `<% String str1 = "HELLO1"; %>`  
    👉 스크립틀릿 안에서 문자열 변수 `str1` 선언 및 초기화
    
- `<% String str2 = "HELLO2"; %>`  
    👉 `str2` 변수 선언 및 초기화
    
- `<% String str3 = str1 + str2; %>`  
    👉 `str1`과 `str2`를 합쳐 `str3`에 저장
    
- `<% int a = 0; %>`  
    👉 정수형 변수 `a`를 0으로 초기화
    
- `for(int i=0; i<10; i++){ a++; System.out.println(i); }`  
    👉 0부터 9까지 반복하면서 `a`를 1씩 증가 (총 10번), `i`는 서버 콘솔에 출력됨
    
- `<%=str1 %>`  
    👉 변수 `str1`의 값을 HTML로 출력
    
- `<%=str2 %>`  
    👉 변수 `str2`의 값을 HTML로 출력
    
- `<%=str3 %>`  
    👉 변수 `str3`의 값을 HTML로 출력 (`HELLO1HELLO2`)
    
- `<%=a %>`  
    👉 반복문 후 증가된 변수 `a` 값을 출력 (결과: 10)

### 🧠 핵심 개념 요약

- ✅ **Scriptlet(스크립틀릿)**: JSP에서 Java 코드를 삽입할 수 있는 영역. `<% %>` 안에 작성
    
- ✅ **표현식(Expression)**: 변수 값을 HTML에 출력할 때 사용. `<%= 변수명 %>` 형태
    
- ✅ **지역변수 특성**: Scriptlet 내에서 선언된 변수는 매 요청 시 새로 생성되어 이전 요청과 무관함
    
- ✅ **for 반복문 사용 가능**: JSP 내에서도 자바 문법으로 반복문/조건문 사용 가능
    
- ✅ **콘솔 출력은 브라우저에 보이지 않음**: `System.out.println()`은 서버 콘솔에만 출력됨
