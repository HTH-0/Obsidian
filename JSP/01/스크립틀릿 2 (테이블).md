````
## 📌 JSP에서 사용자 입력으로 동적 테이블 만들기 (⚠ 콘솔 입력 사용 예제)

### 🧩 전체 코드
```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>

<%
	java.util.Scanner sc = new java.util.Scanner(System.in);
	System.out.print("행 열 입력 : ");
	int row = sc.nextInt();
	int col = sc.nextInt();
	System.out.printf("행 : %d 열 : %d\n",row,col);
%>    
    
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>Insert title here</title>
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.0.2/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.0.2/dist/js/bootstrap.bundle.min.js"></script>
</head>
<body>

	<table class=table>
		<tbody>
			<%
			// tr 태그 반복
			for(int i=0;i<row;i++)
			{
			%>
				<tr>
					<%
					for(int j=0;j<col;j++)
					{
					%>
						<td><%=i+":"+j %></td>	
					<%
					}
					%>	
				</tr>
			<%
			}
			%>	
		</tbody>
	</table>

</body>
</html>
````

---

### 🔍 코드 설명 (구문별)

- `<%@ page ... %>` 👉 JSP 페이지의 인코딩과 설정 지정
    
- `java.util.Scanner sc = new java.util.Scanner(System.in);`  
    👉 콘솔에서 사용자 입력을 받기 위한 Scanner 객체 생성 (⚠ JSP에서는 권장되지 않음)
    
- `int row = sc.nextInt();` / `int col = sc.nextInt();`  
    👉 콘솔을 통해 입력받은 값으로 테이블의 행과 열 결정
    
- `System.out.print(...)`, `System.out.printf(...)`  
    👉 서버 콘솔에 출력 (브라우저에는 보이지 않음)
    
- `<table class=table>...</table>`  
    👉 Bootstrap 스타일이 적용된 HTML 테이블
    
- `for(int i=0; i<row; i++)`  
    👉 행(`tr`)을 입력된 `row`만큼 생성
    
- `for(int j=0; j<col; j++)`  
    👉 각 행에서 열(`td`)을 `col`만큼 생성
    
- `<td><%=i+":"+j %></td>`  
    👉 각 셀에 "행:열" 형식으로 인덱스 출력
