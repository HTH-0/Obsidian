## 📌 JSP 선언문과 표현식 사용 예제

### 🧩 전체 코드

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>Insert title here</title>
</head>
<body>

  <!-- 선언문: 서블릿으로 변환될 때 클래스 레벨에 포함됨 -->
  <%! 
    String name = "HONG GIL DONG";

    public String testFunc() {
      System.out.println("선언문 TEST");
      return "name : " + name;
    }
  %>

  <!-- 표현식: 서버 변수나 메서드의 값을 브라우저에 출력 -->
  NAME : <%= name %> <br/>
  testFunc() : <%= testFunc() %><br/>

  <!-- JSP가 서블릿으로 변환된 파일 위치 예시 -->
  <!-- 
    workspace\.metadata\.plugins\org.eclipse.wst.server.core\tmp0\
    work\Catalina\localhost\01_JSP\org\apache\jsp\C01
  -->

</body>
</html>
```

---

### 🔍 코드 설명 (구문별)

- `<%! String name = "HONG GIL DONG"; %>` 👉 선언문: `name`이라는 멤버 변수를 정의함
    
- `<%! public String testFunc() {...} %>` 👉 선언문: `testFunc()` 메서드를 정의함 (값 반환)
    
- `System.out.println(...)` 👉 서버 콘솔에 메시지를 출력 (사용자에겐 보이지 않음)
    
- `<%= name %>` 👉 `name` 변수 값을 클라이언트에게 출력
    
- `<%= testFunc() %>` 👉 `testFunc()` 실행 결과를 출력
    

---

### 🧠 핵심 개념 요약

- ✅ **선언문 (`<%! ... %>`)**: JSP가 서블릿으로 변환될 때 클래스 멤버로 들어감. 변수/메서드 선언에 사용
    
- ✅ **표현식 (`<%= ... %>`)**: 값을 HTML에 출력하고 싶을 때 사용
    
- ✅ **콘솔 출력 (`System.out.println`)**: 디버깅용 로그 출력, 브라우저에는 보이지 않음
    
- ✅ **JSP 처리 구조**: JSP는 서블릿으로 변환되어 실행됨. 선언문은 클래스 영역에, 표현식은 `service()` 메서드 안에 들어감
