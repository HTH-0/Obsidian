````
## 📌 JSP로 구구단 출력 테이블 만들기 (스크립틀릿 활용)

### 🧩 전체 코드
```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>구구단 출력</title>
</head>
<body>

	<h2>구구단 출력 (단수 입력)</h2>
	<form method="get">
		단 입력: <input type="text" name="dan">
		<input type="submit" value="출력">
	</form>

	<%
	String danParam = request.getParameter("dan");
	if (danParam != null && !danParam.equals("")) {
		try {
			int dan = Integer.parseInt(danParam);
	%>

	<table border="1" cellpadding="10">
		<thead>
			<tr>
				<th colspan="2"><%= dan %>단</th>
			</tr>
		</thead>
		<tbody>
			<%
				for (int i = 1; i <= 9; i++) {
			%>
			<tr>
				<td><%= dan + " x " + i %></td>
				<td><%= dan * i %></td>
			</tr>
			<%
				}
			%>
		</tbody>
	</table>

	<%
		} catch (NumberFormatException e) {
	%>
		<p style="color:red;">정수를 입력해주세요!</p>
	<%
		}
	}
	%>

</body>
</html>
````

---

### 🔍 코드 설명 (구문별)

- `<form method="get">...</form>`  
    👉 사용자로부터 단수를 입력받기 위한 HTML 폼 생성
    
- `request.getParameter("dan")`  
    👉 사용자가 입력한 단수를 문자열로 가져옴
    
- `Integer.parseInt(danParam)`  
    👉 문자열을 정수로 변환하여 변수 `dan`에 저장
    
- `for (int i = 1; i <= 9; i++)`  
    👉 1부터 9까지 반복하며 구구단 출력
    
- `<td><%= dan + " x " + i %></td>`  
    👉 곱셈 식을 테이블 셀에 출력 (예: 2 x 1)
    
- `<td><%= dan * i %></td>`  
    👉 곱셈 결과 출력
    
- `try~catch` 블록  
    👉 정수가 아닌 입력값이 들어왔을 경우 오류 메시지 출력
