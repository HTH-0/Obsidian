# JSP 강사조회 페이지 (`index.jsp`)

## 📚 공부 코드

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8"%>
<%@page import="java.text.DecimalFormat,Utils.*,java.util.*,java.time.*,java.time.format.*" %>
...
List<TeacherDto> list = OracleDBUtils.getInstance().selectAllTeacher();
for(TeacherDto dto : list) {
  ...
}
```

---

## 📌 주요 개념

- **JSP 기본 지시어**
    
    - `page`: 페이지 인코딩 설정
        
    - `import`: 자바 클래스 임포트 (`java.util`, `java.time`, `Utils.*` 등)
        
- **HTML 구조**
    
    - `wrapper` 클래스를 기준으로 전체 레이아웃 분리 (`header`, `nav`, `main`, `footer`)
        
    - 중앙에 **강사 조회 테이블** 위치
        
- **JSP include**
    
    - `Header.jsp`, `Nav.jsp`, `Footer.jsp` → 공통 레이아웃 분리 구성
        
- **Java 코드 삽입**
    
    - `<% %>`: 일반 자바 코드
        
    - `<%= %>`: 출력 표현식
        
    - `for` 루프를 통해 강사 목록을 테이블에 출력
        
- **날짜 및 금액 포맷팅**
    
    - `DecimalFormat`으로 수강료에 천 단위 쉼표 추가 (`#,###`)
        
    - `DateTimeFormatter`로 날짜 형식 변환 (예: `20240101` → `2024년01월01일`)
        

---

## 🔎 주요 코드

### 1. 강사 목록 조회

```jsp
List<TeacherDto> list = OracleDBUtils.getInstance().selectAllTeacher();
```

- `OracleDBUtils`는 DB 연결 유틸 클래스
    
- `selectAllTeacher()`로 `TBL_TEACHER_202201` 테이블 전체 조회
    

---

### 2. 반복문으로 테이블 출력

```jsp
for(TeacherDto dto : list) {
    ...
    <td><%=dto.getTeacher_code() %></td>
    <td><%=dto.getTeacher_name() %></td>
}
```

- 강사 DTO 리스트를 반복하며 `<tr>` 행을 생성
    

---

### 3. 수강료 포맷팅

```jsp
int price = dto.getClass_price();
DecimalFormat fmt = new DecimalFormat("#,###");
<td><%="\\"+fmt.format(price) %></td>
```

- `\300000` → `\300,000` 형식으로 변환
    

---

### 4. 날짜 포맷 변경

```jsp
String date = dto.getTeacher_regist_date();
DateTimeFormatter inFmt = DateTimeFormatter.ofPattern("yyyyMMdd");
LocalDate localDate = LocalDate.parse(date, inFmt);
DateTimeFormatter outFmt = DateTimeFormatter.ofPattern("yyyy년MM월dd일");
out.print("<td>"+localDate.format(outFmt)+"</td>");
```

- `20220125` → `2022년01월25일`로 출력
    
- `java.time.LocalDate`, `DateTimeFormatter` 사용

## ✅ 핵심 정리

- **DTO를 활용한 JSP 동적 테이블 출력**
    
- **수강료 포맷**: `DecimalFormat`
    
- **날짜 포맷**: `DateTimeFormatter`, `LocalDate`
    
- **include 디렉티브**로 공통 레이아웃 분리 (`Header`, `Nav`, `Footer`)
    
- JSP 안에서 Java 코드가 들어가는 전형적인 패턴 학습 예제
