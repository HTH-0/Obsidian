# 강사매출현황 페이지 (`강사 + 수업 매출 집계`)

## 📌 주요 개념

### 🧾 1. 데이터 조회

- `OracleDBUtils.getInstance().selectAllJoin2()` 호출
    
- 내부적으로 실행되는 SQL:
    

```sql
SELECT T.TEACHER_CODE, T.CLASS_NAME, T.TEACHER_NAME, SUM(C.TUITION)
FROM TBL_CLASS_202201 C
JOIN TBL_TEACHER_202201 T ON C.TEACHER_CODE = T.TEACHER_CODE
GROUP BY T.TEACHER_CODE, T.CLASS_NAME, T.TEACHER_NAME
ORDER BY SUM(C.TUITION) DESC
```

- 강사별 총 수강료 합계를 구하는 GROUP BY 쿼리
    

---

### 📦 2. DTO 구조 (`Join2Dto`)

|필드명|설명|
|---|---|
|teacher_code|강사코드|
|class_name|강의명|
|teacher_name|강사명|
|total_tuition|총매출 (수강료 합계)|

---

### 📋 3. 테이블 출력

- `for` 반복문으로 `Join2Dto` 리스트 출력
    
- 수강료 총합은 이미 SQL에서 계산된 값
    

---

### ✅ 핵심 정리

- **강사별 총 매출 집계**를 출력하는 통계용 JSP
    
- `SUM()` 집계 함수 결과를 DTO로 받아 출력
    
- 그룹화된 결과를 내림차순 정렬해 우수 강사 순위도 확인 가능
    
- 관리용 보고서 페이지 구성 예시로 활용 가능
