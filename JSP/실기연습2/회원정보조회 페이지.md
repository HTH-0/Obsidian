# 회원정보조회 페이지 (`회원 + 수강 + 강사 JOIN`)

## 📌 주요 개념

### 🧾 1. 데이터 조회

- `OracleDBUtils.getInstance().selectAllJoin1()` 호출
    
- 내부적으로 다음 SQL 실행됨:
    

```sql
SELECT C.REGIST_MONTH, M.C_NO, M.C_NAME, T.CLASS_NAME, C.CLASS_AREA, C.TUITION, M.GRADE
FROM TBL_MEMBER_202201 M
JOIN TBL_CLASS_202201 C ON C.C_NO = M.C_NO
JOIN TBL_TEACHER_202201 T ON C.TEACHER_CODE = T.TEACHER_CODE
```

- 이 결과를 `Join1Dto` 리스트로 저장
    

---

### 📦 2. DTO 구조 (`Join1Dto`)

|필드명|설명|
|---|---|
|regist_month|수강월|
|c_no|회원번호|
|c_name|회원명|
|class_name|강의명|
|class_area|강의장소|
|tuition|수강료|
|grade|등급|

---

### 📋 3. 테이블 출력

- `for` 반복문으로 리스트 출력
    
- `getXXX()` 메서드로 DTO 정보 추출 후 `<td>`에 출력
    

---

### ✅ 핵심 정리

- **회원, 수강, 강사 테이블을 조인한 결과를 보여주는 페이지**
    
- `Join1Dto`를 통해 조인된 결과를 담고 반복 출력
    
- 비즈니스 로직 없이 단순 조회 + 테이블 출력 구성
    
- JSP 반복문 (`for`)과 표현식 (`<%= %>`) 패턴 익히기 적합
