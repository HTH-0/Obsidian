## 📌 주요 개념

### 🧱 1. 전체 레이아웃 구조

- `Header.jsp`, `Nav.jsp`, `Footer.jsp` 공통 레이아웃 파일을 include
    
- 본문(`main`)에는 `수강신청` 폼이 HTML 테이블 형태로 존재
    

### 🔄 2. 서버에서 데이터 가져오기

```jsp
List<MemberDto> member_list = OracleDBUtils.getInstance().selectAllMember();
List<TeacherDto> teacher_list = OracleDBUtils.getInstance().selectAllTeacher();
```

- 회원과 강사 정보를 데이터베이스에서 조회하여 각각 리스트로 저장
    
- `select` 태그의 옵션으로 사용
    

### 🧾 3. 입력 필드 및 동작

|항목|설명|
|---|---|
|`수강월`|직접 입력|
|`회원명`|드롭다운 선택 → 회원번호 자동 세팅|
|`회원번호`|자동입력|
|`강의장소`|직접 입력|
|`강의명`|드롭다운 선택 → 강사코드 & 수강료 자동 세팅|
|`수강료`|회원번호에 따라 자동계산|
|`강사코드`|히든 필드로 처리|

## 🧠 주요 자바스크립트 동작

### ✅ 회원 선택 시

```js
form.c_name.addEventListener('change', function(e) {
	const selected = e.target.options[e.target.selectedIndex];
	const cno = selected.getAttribute("data-no");
	form.c_no.value = cno;

	if(price) {
		form.tuition.value = (cno < 20000) ? price : (price / 2);
	}
});
```

- 회원 선택 → `data-no`로 회원번호 설정
    
- `회원번호 < 20000`이면 수강료 100%, 아니면 50% 할인
    

---

### ✅ 강의명 선택 시

```js
form.class_name.addEventListener('change', function(e) {
	const selected = e.target.options[e.target.selectedIndex];
	price = selected.getAttribute("data-price");
	const teacherCode = selected.getAttribute("data-teacherCode");
	form.teacher_code.value = teacherCode;

	form.tuition.value = (cno < 20000) ? price : (price / 2);
});
```

- 강의명 선택 → 강사코드와 수강료 자동 입력
    
- 할인 로직도 동일하게 반영됨

### ✅ 유효성 검사 및 제출

```js
function isValid(){
	if(form.regist_month.value === ""){
		alert("수강월을 입력하세요");
		form.regist_month.focus();
		return;
	}
	if(form.c_name.value === ""){
		alert("회원명을 선택하세요");
		form.c_name.focus();
		return;
	}
	form.submit();
}
```

- `수강월`과 `회원명`이 비어 있으면 alert
    
- 통과 시 폼 제출

## ✅ 핵심 정리

- DB에서 **회원/강사 정보를 불러와서** 동적 폼 구성
    
- Java + HTML + JavaScript가 통합된 **JSP 폼 페이지**
    
- `select`의 `data-*` 속성을 활용한 **동적 값 전달**
    
- 회원번호에 따라 **수강료 할인 자동 계산**
    
- 자바스크립트로 **유효성 검사 및 동작 제어**
