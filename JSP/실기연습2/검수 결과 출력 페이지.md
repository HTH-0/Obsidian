---

## 📌 주요 개념

### 📦 1. useBean + setProperty

```jsp
<jsp:useBean id="voteDto2" class="Utils.VoteDto" scope="request" />
<jsp:setProperty name="voteDto2" property="*" />
```

- `VoteDto` 객체를 JSP에서 직접 생성 (`useBean`)
    
- `property="*"`: 요청 파라미터 이름과 DTO 필드명이 일치하면 자동 주입됨
    
- 예: `?v_name=홍길동` → `voteDto2.setV_name("홍길동")`
    

---

### 🔍 2. 주민등록번호 처리 로직

#### ✅ 생년월일 → 나이 계산

```jsp
String age = voteDto2.getV_jumin().substring(0,6); // 예: 860918
age = "19" + age; // 19860918로 변경 (고정)
LocalDate birth = LocalDate.parse(age, formatter);
int manAge = Period.between(birth, today).getYears();
```

- 주민번호 앞 6자리를 이용해 생년월일 파싱
    
- `LocalDate`로 날짜 객체 생성
    
- `Period.between()`으로 현재 날짜와 차이 계산 → 만 나이 구함
    

#### ✅ 성별 판별

```jsp
char gender = voteDto2.getV_jumin().charAt(6);
if(gender % 2 == 0) "여자" else "남자"
```

- 주민번호 7번째 자리를 이용해 성별 판별 (1/3/5 → 남자, 2/4/6 → 여자)

## 🧾 출력 테이블 구성

|컬럼명|내용|
|---|---|
|성명|`v_name`|
|생년월일|주민번호 앞 6자리 (`yyMMdd`)|
|나이|`만 XX세`로 출력|
|성별|주민번호 7번째 숫자 분석|
|후보번호|`m_no`|
|투표시간|`v_time`|
|유권자확인|`v_confirm` (`Y/N`)|

---

## 🧠 실행 흐름 요약

1. **이전 페이지**에서 전송된 폼 데이터가 `request` 영역에 담겨 전달됨
    
2. `jsp:useBean`으로 빈 객체 생성 → `setProperty`로 값 자동 주입
    
3. 주민번호 가공하여 **나이 계산** + **성별 판별**
    
4. 모든 정보 테이블에 출력
    

---

## ✅ 핵심 정리

- `jsp:useBean`, `setProperty`를 활용한 폼 데이터 매핑 예제
    
- `LocalDate`, `Period`로 나이 계산 로직 실습
    
- 주민등록번호를 바탕으로 **성별 및 생년월일 추출**
    
- 뷰에서 바로 자바코드로 계산 결과 출력하는 방식 학습 가능
