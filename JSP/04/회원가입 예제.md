# 📂 JSP 파일별 코드 분석 및 역할 정리

## 1. 📄 `join_form.jsp`

### ✅ 역할

- 사용자에게 **회원가입 양식**을 보여주는 페이지
    
- POST 방식으로 `join.jsp`에 데이터 전송
    

### 💻 주요 코드

```jsp
<form method="post" action="join.jsp">
    아이디: <input type="text" name="userid"><br>
    비밀번호: <input type="password" name="passwd"><br>
    이름: <input type="text" name="username"><br>
    <input type="submit" value="회원가입">
</form>
```

---

## 2. 📄 `join.jsp`

### ✅ 역할

- 회원가입 처리 (DB 저장)
    
- 성공 시 `login_form.jsp`로 Redirect
    
- 실패 시 alert 처리
    

### 💻 주요 코드

```jsp
<%@ include file="dbUtils.jsp" %>
<%
    String id = request.getParameter("userid");
    String pw = request.getParameter("passwd");
    String name = request.getParameter("username");

    try {
        Connection conn = getConnection();
        String sql = "INSERT INTO member(userid, passwd, username) VALUES (?, ?, ?)";
        PreparedStatement pstmt = conn.prepareStatement(sql);
        pstmt.setString(1, id);
        pstmt.setString(2, pw);
        pstmt.setString(3, name);
        pstmt.executeUpdate();

        response.sendRedirect("login_form.jsp");
    } catch (Exception e) {
        out.println("<script>alert('가입 실패');history.back();</script>");
    }
%>
```

## 3. 📄 `login_form.jsp`

### ✅ 역할

- 사용자에게 **로그인 폼**을 제공
    
- POST 방식으로 `validationCheck.jsp`에 데이터 전송
    

### 💻 주요 코드

```jsp
<form method="post" action="validationCheck.jsp">
    아이디: <input type="text" name="userid"><br>
    비밀번호: <input type="password" name="passwd"><br>
    <input type="submit" value="로그인">
</form>
```

---

## 4. 📄 `validationCheck.jsp`

### ✅ 역할

- 로그인 검증 (DB에서 아이디/비밀번호 확인)
    
- 성공 시 `myinfo.jsp`로 Redirect
    
- 실패 시 alert 처리
    

### 💻 주요 코드

```jsp
<%@ include file="dbUtils.jsp" %>
<%
    String id = request.getParameter("userid");
    String pw = request.getParameter("passwd");

    try {
        Connection conn = getConnection();
        String sql = "SELECT * FROM member WHERE userid = ? AND passwd = ?";
        PreparedStatement pstmt = conn.prepareStatement(sql);
        pstmt.setString(1, id);
        pstmt.setString(2, pw);
        ResultSet rs = pstmt.executeQuery();

        if(rs.next()) {
            response.sendRedirect("myinfo.jsp?userid=" + id);
        } else {
            out.println("<script>alert('로그인 실패');history.back();</script>");
        }
    } catch (Exception e) {
        response.sendRedirect("errors.jsp");
    }
%>
```

## 7. 📄 `errors.jsp`


## 8. 📄 `dbUtils.jsp`

### ✅ 역할

- DB 연결 및 자원 해제 유틸 JSP
    
- 여러 페이지에서 공통 include
    

### 💻 주요 코드

```jsp
<%@ page import="java.sql.*" %>
<%
    public Connection getConnection() throws Exception {
        Class.forName("com.mysql.jdbc.Driver");
        return DriverManager.getConnection("jdbc:mysql://localhost:3306/mydb", "root", "1234");
    }
%>
```

# 🧭 전체 흐름 요약 (Redirect 기반)

```plaintext
1. 회원가입 요청
   → join_form.jsp → join.jsp → login_form.jsp

2. 로그인 요청
   → login_form.jsp → validationCheck.jsp → myinfo.jsp

3. 마이페이지 정보 보기
   → myinfo.jsp → myinfo_form.jsp
```
