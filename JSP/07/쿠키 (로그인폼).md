# 📄 JSP - 쿠키 기반 자동 아이디/비밀번호 채움 로그인 폼

## 📌 개념 요약

쿠키에 저장된 `username`, `password`, 체크박스 여부(`idchk`, `pwchk`) 값을 로그인 폼에 자동 반영해주는 JSP 로그인 폼 구현 예제

---

## ✅ 주요 내용

- `session.getAttribute("isAuth") != null`  
    → 로그인 상태일 경우, 로그인 폼 접근을 막고 `main.jsp`로 리다이렉트
    
- `${cookie.username.value}`  
    → 쿠키에서 `username` 값을 꺼내 input의 `value`에 반영
    
- `${cookie.idchk != null ? 'checked' : ''}`  
    → 저장 여부 쿠키가 있을 경우, 체크박스를 체크 상태로 유지
    
- `<input type="checkbox" name="saveID">`  
    → 로그인 처리 시 쿠키 저장 여부 판단 기준
    

---

## 💻 코드 예시 (login_form.jsp)

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>

<%
	// 로그인 상태이면 main.jsp로 이동
	if(session.getAttribute("isAuth") != null){
		out.println("<script>alert('이미 로그인 상태입니다.')</script>");
		response.sendRedirect("./main.jsp");
	}
%>

<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>로그인 폼</title>
<style>
	label { font-size: .8rem; }
	span { font-size: .5rem; color: red; }
</style>
</head>
<body>

<h1>LOGIN FORM</h1>

<!-- 메시지 출력 (ex. 로그인 실패, 세션 만료 등) -->
<div style="min-height:25px; font-size:.8rem; color:orange">
	${param.message}
</div>

<form action="${pageContext.request.contextPath}/C07/03/login.jsp" method="post">
	<div>
		<label>아이디 :</label><span>${username_msg}</span><br/>
		<input type="text" name="username" 
			value="${cookie.username != null ? cookie.username.value : ''}" />
	</div>
	<div>
		<label>패스워드 :</label><span>${password_msg}</span><br/>
		<input type="password" name="password"
			value="${cookie.password != null ? cookie.password.value : ''}" />
	</div>
	<div>
		<input type="checkbox" id="saveID" name="saveID" 
			${cookie.idchk != null ? 'checked' : ''} />
		<label for="saveID">ID 저장</label>
	</div>
	<div>
		<input type="checkbox" id="savePW" name="savePW"
			${cookie.pwchk != null ? 'checked' : ''} />
		<label for="savePW">PW 저장</label>
	</div>
	<div>
		<button>로그인</button>
	</div>
</form>

</body>
</html>
```

---

## 📌 정리

|기능|설명|
|---|---|
|쿠키 자동 채움|`username`, `password` 쿠키값을 input value에 삽입|
|체크 상태 유지|`idchk`, `pwchk` 쿠키 존재 여부로 `checked` 처리|
|로그인 상태 검사|세션에 `isAuth`가 있으면 로그인된 상태로 간주|
|폼 제출 처리 경로|`C07/03/login.jsp` (로그인 처리 JSP로 전송)|

---

## 🔎 추가 개념

- 쿠키는 `request.getCookies()`로 접근하고, JSTL/EL에서는 `${cookie.이름.value}`로 출력 가능
    
- 로그인 처리 시 사용자가 체크한 항목에 따라 쿠키를 `response.addCookie()`로 저장해야 함
    
- 보안을 위해 비밀번호 자동저장은 실서비스에선 지양하거나 암호화 필요
