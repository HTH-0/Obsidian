# 📄 JSP - 로그인 처리 + ID/PW 쿠키 저장 기능 예제

## 📌 개념 요약

로그인 폼에서 "아이디 저장", "비밀번호 저장" 체크박스 선택 여부에 따라 쿠키를 생성하거나 삭제하고, 로그인 성공 시 세션 정보 저장과 함께 메인 페이지로 이동하는 JSP 로직

---

## ✅ 주요 내용

- `saveID`, `savePW` 파라미터를 통해 체크 여부 판단
    
- 쿠키 저장:
    
    - `new Cookie(name, value)` + `setMaxAge(초)` + `setPath()` + `addCookie()`
        
- 쿠키 삭제:
    
    - `setMaxAge(0)` 설정
        
- 로그인 성공 시:
    
    - `session.setAttribute("isAuth", true)` → 인증 상태 저장
        
    - `session.setMaxInactiveInterval(30)` → 세션 유지시간 30초 설정
        
- 모든 로그인 검증 실패 시 `forward`로 다시 로그인 폼 이동, 오류 메시지 전달
    

---

## 💻 코드 흐름 정리

```jsp
// 1. 파라미터 수집
String username = request.getParameter("username");
String password = request.getParameter("password");
String saveID = request.getParameter("saveID"); // 체크 여부
String savePW = request.getParameter("savePW");

// 2. 유효성 검사
if(username.isEmpty() || password.isEmpty()){
	request.setAttribute("username_msg", "..."); // 필요 시
	request.getRequestDispatcher("./login_form.jsp").forward(request, response);
	return;
}

// 3. ID & PW 검증 (하드코딩)
if(!username.equals("admin")){
	request.setAttribute("username_msg", "해당 ID는 존재하지 않습니다");
	request.getRequestDispatcher("./login_form.jsp").forward(request, response);
	return;
}
if(!password.equals("1234")){
	request.setAttribute("password_msg", "패스워드가 일치하지 않습니다");
	request.getRequestDispatcher("./login_form.jsp").forward(request, response);
	return;
}

// 4. 세션 저장
session.setAttribute("isAuth", true);
session.setAttribute("role", "ROLE_ADMIN");
session.setMaxInactiveInterval(30); // 30초 유지

// 5. 쿠키 저장 또는 삭제
if(saveID != null){
	// ID 저장 쿠키
	response.addCookie(new Cookie("username", username));
	response.addCookie(new Cookie("idchk", "on"));
} else {
	// ID 삭제 쿠키
	Cookie c = new Cookie("username", null); c.setMaxAge(0); response.addCookie(c);
	Cookie c2 = new Cookie("idchk", null); c2.setMaxAge(0); response.addCookie(c2);
}

if(savePW != null){
	// PW 저장 쿠키
	response.addCookie(new Cookie("password", password));
	response.addCookie(new Cookie("pwchk", "on"));
} else {
	// PW 삭제 쿠키
	Cookie c = new Cookie("password", null); c.setMaxAge(0); response.addCookie(c);
	Cookie c2 = new Cookie("pwchk", null); c2.setMaxAge(0); response.addCookie(c2);
}

// 6. 메인 페이지 이동
out.println("<script>alert('로그인 성공! MAIN page로 이동합니다.'); location.href='main.jsp';</script>");
```

---

## 📌 정리

|구분|설명|
|---|---|
|`saveID`|체크되면 `username`, `idchk` 쿠키 저장|
|`savePW`|체크되면 `password`, `pwchk` 쿠키 저장|
|`setMaxAge(0)`|쿠키 삭제 처리|
|`session.setAttribute()`|로그인 인증 및 권한 세션 저장|
|`response.addCookie()`|쿠키 생성/전송|
|`location.href`|로그인 성공 시 메인 페이지 이동|

## 🔎 추가 개념

- **보안 이슈 주의**: 비밀번호를 평문 쿠키에 저장하는 방식은 실서비스에서 절대 금지 (암호화 필수)
    
- `setPath("/01JSP/C07/03/login_form.jsp")` → 해당 경로에서만 쿠키 유효  
    → `setPath("/")`로 설정하면 프로젝트 전역에서 사용 가능
    
- 쿠키는 **클라이언트에 저장**되므로, 저장 위치/기한/보안 등에 주의 필요
