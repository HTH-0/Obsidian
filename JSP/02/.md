# 📄 사용자 입력값으로 동적 네비게이션 바 생성 (JSP + 스타일 적용)

## 📌 개념 요약

폼에서 전달된 열 이름과 스타일 문자열을 사용해 `<ul>` 요소로 구성된 동적 네비게이션을 출력하는 JSP 예제

---

## ✅ 주요 내용

- `request.getParameter()`로 전달된 `col1 ~ col4`, `style` 값을 JSP에서 수신
    
- `<ul style="...">` 형태로 사용자 입력 스타일을 직접 적용
    
- `<li>` 태그를 사용해 메뉴 항목 동적 출력
    
- 구조는 `header > nav > ul > li` 형태로 시맨틱하게 구성
    

---

## 💻 코드 예시 (C05Result.jsp)

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>

<%
	String col1 = request.getParameter("col1");
	String col2 = request.getParameter("col2");
	String col3 = request.getParameter("col3");
	String col4 = request.getParameter("col4");
	String navStyle = request.getParameter("style");
%>

<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>Insert title here</title>
<style>
	ul {
		list-style: none;
		padding: 0;
		margin: 0;
	}
	header {
		width: 100%;
	}
</style>
</head>
<body>

<div class="wrapper">
	<header>
		<div class="top-header"></div>
		<nav>
			<!-- 사용자 정의 스타일 적용 -->
			<ul style="<%=navStyle%>">
				<li><%=col1 %></li>
				<li><%=col2 %></li>
				<li><%=col3 %></li>
				<li><%=col4 %></li>
			</ul>
		</nav>
	</header>
	<main>
		<section></section>
	</main>
	<footer></footer>
</div>

</body>
</html>
```

---

## 📌 정리

- `navStyle` 값을 `<ul style="...">`에 직접 삽입해 실시간 스타일 적용
    
- 사용자 입력으로 메뉴 구성 + 스타일링까지 제어 가능
    
- 기본 레이아웃: header → nav → ul → li 구조
    
- `request.getParameter()`는 문자열만 처리하므로, 값 검증 필수
    

---

## 🔎 추가 개념

- 사용자 입력이 HTML/CSS로 바로 삽입되므로 **XSS 취약성 주의**
    
    - 실무에서는 `StringEscapeUtils.escapeHtml4()` 등으로 필터링 필요
        
- 스타일 예시 입력값
    
    ```
    display: flex; gap: 20px; background: lightblue; padding: 10px;
    ```
    
- 추후 반복 구조 도입 시 `JSTL <c:forEach>` 등을 활용하면 더 효율적
