## 🧾 JSP 페이지 구조 (`src/main/webapp/`)

### 🌐 루트 페이지

- `index.jsp`: 메인 진입 페이지
    
- `template.jsp`: 공통 템플릿 페이지 (Header, Nav, Footer 포함 예상)
    

### 📁 01 ~ 04 디렉토리: **CRUD 실습 단위별 모듈**

각 폴더에는 다음 JSP 페이지가 공통적으로 존재함:

- `index.jsp`: 목록 조회
    
- `create.jsp`: 데이터 입력 폼
    
- `read.jsp`: 단건 조회
    
- `update.jsp`: 수정
    
- `delete.jsp`: 삭제
    

> 각 디렉토리는 실습 파트로 나뉘어져 있어, 하나의 CRUD 기능을 반복적으로 익힐 수 있도록 구성되어 있음

### 📑 공통 레이아웃 (`layouts/`)

- `Header.jsp`, `Nav.jsp`, `Footer.jsp`: 사이트 공통 UI 구성 요소
    

---

## 🧩 의존 라이브러리

- `WEB-INF/lib/ojdbc6.jar`: 오라클 DB 드라이버 포함 → **Oracle DB 연동**

## 정리

- CRUD 실습용 구조 (각기 다른 4개의 도메인 예제)
    
- JSP + Java DTO + Oracle DB 구성
    
- 실습 순서대로 `01`, `02`, `03`, `04` 폴더 접근하여 작성된 코드를 확인하면 학습 흐름 파악 가능
