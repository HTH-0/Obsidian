# 🌐 JSP 내장 객체 (JSP Implicit Objects)

## 📌 개념 요약

JSP 페이지 내에서 별도 선언 없이 자동으로 사용할 수 있도록 JSP 컨테이너가 제공하는 **9개의 특수 객체**

---

## ✅ 주요 내용

- JSP 컨테이너가 자동 생성하여 JSP 내에서 사용할 수 있게 제공
    
- 역할별로 4가지 분류로 나눌 수 있음
    

|분류|객체|설명|
|---|---|---|
|**입출력 관련**|`request`, `response`, `out`|클라이언트 요청/응답 데이터 처리|
|**환경 및 범위 관련**|`session`, `application`, `pageContext`|사용자 상태, 전역 설정, JSP 정보 등|
|**JSP 페이지 제어 관련**|`page`, `config`|페이지 자체 및 초기화 정보|
|**예외 처리 관련**|`exception`|오류 처리용 (errorPage에서만 사용 가능)|

---

## 💻 내장 객체별 상세 설명

### 1️⃣ request

- **역할**: 클라이언트의 요청 정보를 담고 있음 (폼 데이터, URL 파라미터 등)
    
- **주요 메서드**:
    
    - `getParameter(name)` : 폼 파라미터 값 가져오기
        
    - `getRequestURI()` : 요청 URL 확인
        

```jsp
String id = request.getParameter("userid");
```

---

### 2️⃣ response

- **역할**: 서버에서 클라이언트로 보낼 응답 정보를 담는 객체
    
- **주요 메서드**:
    
    - `sendRedirect("url")` : 다른 페이지로 이동
        
    - `setContentType("text/html;charset=UTF-8")` : 응답 형식 지정
        

```jsp
response.sendRedirect("login.jsp");
```

---

### 3️⃣ out

- **역할**: JSP에서 출력 스트림을 제어 (HTML 출력 등)
    
- **주요 메서드**:
    
    - `out.print()`, `out.println()` : 클라이언트에 데이터 출력
        

```jsp
out.println("안녕하세요!");
```

---

### 4️⃣ session

- **역할**: 사용자별 상태 정보 저장 (세션 유지)
    
- **주요 메서드**:
    
    - `setAttribute(name, value)` : 세션에 데이터 저장
        
    - `getAttribute(name)` : 세션에서 데이터 가져오기
        

```jsp
session.setAttribute("userid", "admin");
```

---

### 5️⃣ application

- **역할**: 웹 애플리케이션 전체에서 공유되는 전역 정보 저장소
    
- **자료형**: `ServletContext`
    
- **주요 메서드**:
    
    - `setAttribute(name, value)` / `getAttribute(name)`
        

```jsp
application.setAttribute("siteName", "MySite");
```

---

### 6️⃣ pageContext

- **역할**: JSP 페이지의 컨텍스트 정보 제공 (다른 내장객체 접근 가능)
    
- **주요 기능**:
    
    - `getRequest()`, `getResponse()`, `getSession()` 등
        
    - EL에서 `${pageContext.request}`처럼 접근 가능
        

```jsp
String val = (String)pageContext.getAttribute("name");
```

---

### 7️⃣ page

- **역할**: 현재 JSP 페이지 자체 (자바의 `this`)
    
- **자료형**: `Object`, 실질적으로 `javax.servlet.jsp.HttpJspPage`
    

```jsp
out.println(page.getClass().getName());
```

---

### 8️⃣ config

- **역할**: JSP를 서블릿으로 변환했을 때의 초기 설정 정보 제공
    
- **자료형**: `ServletConfig`
    
- **주요 기능**: 초기화 파라미터 가져오기
    

```jsp
String encoding = config.getInitParameter("encoding");
```

---

### 9️⃣ exception

- **역할**: 예외 발생 시 예외 정보를 저장하는 객체
    
- **주의**: 반드시 `<%@ page isErrorPage="true" %>` 가 설정된 페이지에서만 사용 가능
    

```jsp
<%@ page isErrorPage="true" %>
에러 발생: <%= exception.getMessage() %>
```

---

## 📌 정리

|객체|설명|사용 조건|
|---|---|---|
|request|요청 데이터|항상 사용 가능|
|response|응답 설정|항상 사용 가능|
|out|출력 스트림|항상 사용 가능|
|session|사용자 세션|항상 사용 가능|
|application|전역 공유 정보|항상 사용 가능|
|pageContext|JSP 컨텍스트 제어|항상 사용 가능|
|page|JSP 자신(this)|항상 사용 가능|
|config|초기화 정보|항상 사용 가능|
|exception|예외 정보|errorPage에서만 가능|

---

## 🔎 추가 개념 요약

- **PageContext**는 여러 내장 객체에 접근할 수 있는 **중앙 컨트롤 객체**
    
- **ServletContext(application)**는 **웹 전체에 공유**, **Session**은 사용자 단위
    
- **Request/Response**는 요청-응답마다 새롭게 생성되며 서로 연결됨
    
- **out**은 최종적으로 클라이언트 브라우저에 **HTML 출력을 담당**함
