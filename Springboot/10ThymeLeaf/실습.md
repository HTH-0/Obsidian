---

## 🔧 Thymeleaf 설정

### ✅ `build.gradle`

```groovy
// Thymeleaf 의존성
implementation 'org.springframework.boot:spring-boot-starter-thymeleaf'
```

### ✅ `application.properties`

```properties
spring.thymeleaf.prefix=classpath:/templates/
spring.thymeleaf.suffix=.html
spring.thymeleaf.mode=HTML5
spring.thymeleaf.cache=false
spring.thymeleaf.view-names=th/*
```

---

## 📘 컨트롤러별 역할

### ✅ HomeController.java

```java
@Controller
public class HomeController {
    @GetMapping("/hello")
    public String hello(Model model) {
        model.addAttribute("name", "홍길동");
        return "hello";
    }
}
```

- **경로**: `/hello`
    
- **View**: `hello.html`
    
- **동작**: name 속성 전달 → 타임리프에서 `${name}` 출력
    

---

### ✅ FormController.java

```java
@Controller
public class FormController {

    @GetMapping("/form")
    public String showForm(Model model) {
        model.addAttribute("username", "");
        return "form";
    }

    @PostMapping("/form")
    public String submitForm(@RequestParam String username, Model model) {
        model.addAttribute("username", username);
        return "result";
    }
}
```

- **입력 폼 처리용**
    
- `form.html` → 폼 작성
    
- `result.html` → 결과 출력 (`username` 값 표시)
    

---

### ✅ UserController.java

```java
@Controller
public class UserController {

    @GetMapping("/user")
    public String showForm(Model model) {
        model.addAttribute("user", new User());
        return "userForm";
    }

    @PostMapping("/user")
    public String submit(@ModelAttribute User user, Model model) {
        return "userResult";
    }
}
```

- **객체 바인딩 실습**
    
- DTO 클래스 `User` 사용
    
- `th:object`, `th:field` 태그 실습

## 🖼️ 템플릿 파일 내용

### ✅ hello.html

```html
<h1>안녕하세요, <span th:text="${name}">이름</span>!</h1>
```

---

### ✅ form.html

```html
<form th:action="@{/form}" method="post">
    <input type="text" name="username" />
    <button type="submit">제출</button>
</form>
```

---

### ✅ result.html

```html
<p th:text="'입력한 이름은: ' + ${username}"></p>
```

---

### ✅ userForm.html

```html
<form th:action="@{/user}" th:object="${user}" method="post">
    이름: <input type="text" th:field="*{name}" /><br/>
    나이: <input type="number" th:field="*{age}" /><br/>
    <button type="submit">전송</button>
</form>
```

---

### ✅ userResult.html

```html
<p th:text="'이름: ' + ${user.name}"></p>
<p th:text="'나이: ' + ${user.age}"></p>
```
