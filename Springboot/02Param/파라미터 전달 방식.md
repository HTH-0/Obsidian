# 📤 Spring MVC 파라미터 전달 방식 정리

## ✅ 주요 파라미터 전달 방식 요약

|방식|어노테이션 / 타입|설명|
|---|---|---|
|쿼리 파라미터|`@RequestParam`|`?key=value` 형태로 전달된 요청 처리|
|폼 데이터 전체|`@ModelAttribute` (생략 가능)|DTO 전체 바인딩|
|경로 변수|`@PathVariable`|`/path/{value}` 형태의 URL 처리|
|요청 객체 수동 추출|`HttpServletRequest`|저수준 요청 데이터 직접 추출|
|결과 전달|`Model`|View(JSP)에 데이터 전달|

---

## 📦 예제 코드 모음

### 1. `@RequestParam` 사용 예

```java
@GetMapping("/search")
public String search(@RequestParam("keyword") String keyword, Model model) {
    log.info("검색 키워드: " + keyword);
    model.addAttribute("keyword", keyword);
    return "memo/search";
}
```

- `http://localhost:8080/search?keyword=spring`
    
- 요청 파라미터 `keyword` 값을 직접 변수로 받음
    

---

### 2. `@ModelAttribute` 생략 DTO 바인딩

```java
@PostMapping("/add")
public String add(@Valid MemoDto dto, BindingResult bindingResult) {
    log.info("등록 요청 데이터: " + dto);
    // DTO 내부의 필드명과 name 속성이 자동 매핑됨
}
```

- 폼 필드의 name이 DTO 필드와 일치할 경우 자동 바인딩됨
    
- `@ModelAttribute`는 생략 가능
    

---

### 3. `@PathVariable` 사용

```java
@GetMapping("/delete/{id}")
public String delete(@PathVariable("id") Long id) {
    log.info("삭제 요청 ID: " + id);
    return "redirect:/memo/list";
}
```

- URL: `/delete/123` → `id = 123` 전달됨
    

---

### 4. `HttpServletRequest` 직접 사용

```java
@PostMapping("/manual")
public String manual(HttpServletRequest request) {
    String id = request.getParameter("id");
    String content = request.getParameter("content");
    log.info("수동 추출: id=" + id + ", content=" + content);
    return "memo/result";
}
```

- 서블릿 API 직접 사용
    
- 주로 아주 유연하거나 복잡한 요청 처리에서 사용
    

---

### 5. `Model` 사용 예

```java
@GetMapping("/view")
public String view(Model model) {
    model.addAttribute("name", "홍길동");
    return "memo/view"; // view.jsp 에서 ${name} 으로 출력
}
```

---

## 📌 요약

|방식|주용도|특징|
|---|---|---|
|`@RequestParam`|단일 파라미터 추출|필수 여부 지정 가능 (`required=false`)|
|`@ModelAttribute`|폼 객체(DTO) 통째로 수집|생략 가능|
|`@PathVariable`|RESTful URL 처리|경로 기반 데이터 전달|
|`HttpServletRequest`|수동 처리 필요 시|낮은 수준, 자유도 높음|
|`Model`|View로 데이터 전달|JSP/Thymeleaf에서 사용|
