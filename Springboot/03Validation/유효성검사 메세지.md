# 🧾 Spring MVC 유효성 검사 메시지 출력 & @InitBinder 실제 적용 예

## ✅ 1. 유효성 실패 메시지 JSP 출력 예시

### 📌 컨트롤러에서 모델에 에러 담기

```java
for (FieldError error : bindingResult.getFieldErrors()) {
    model.addAttribute(error.getField(), error.getDefaultMessage());
}
```

- 예: `title` 필드에 오류 발생 시 → `model.addAttribute("title", "제목은 필수입니다.");`
    

---

### 📌 JSP 화면 출력 예 (memo/add.jsp 등)

```jsp
<form action="/memo/add" method="post">
    제목: <input type="text" name="title" />
    <span style="color:red">${title}</span>

    내용: <input type="text" name="content" />
    <span style="color:red">${content}</span>

    <button type="submit">등록</button>
</form>
```

- `model.addAttribute()`로 전달된 에러 메시지를 `${필드명}`으로 출력 가능
    
- 검증 대상 DTO의 필드명과 일치시켜야 함

## ✅ 2. `@InitBinder` 실전 적용 예시

### 📌 날짜 포맷 바인딩 예 (yyyy#MM#dd → LocalDate)

#### 💡 DTO: MemoDto.java

```java
private LocalDate dateTest;
```

#### 📌 컨트롤러: MemoController.java

```java
@InitBinder
public void initBinder(WebDataBinder binder) {
    binder.registerCustomEditor(LocalDate.class, "dateTest", new PropertyEditorSupport() {
        @Override
        public void setAsText(String text) throws IllegalArgumentException {
            if (text == null || text.isEmpty()) {
                setValue(LocalDate.now());
            } else {
                text = text.replaceAll("#", "-");
                setValue(LocalDate.parse(text, DateTimeFormatter.ofPattern("yyyy-MM-dd")));
            }
        }
    });
}
```

- 이 바인더는 `dateTest`라는 필드에만 적용됨
    
- `"2025#05#08"`과 같은 값이 들어와도 LocalDate로 변환됨

## 📌 전체 요약

|항목|설명|
|---|---|
|검증 메시지 전달|`model.addAttribute(필드명, 메시지)`|
|JSP 출력 방법|`${필드명}`으로 화면에 바로 출력 가능|
|@InitBinder 사용 이유|DTO 필드의 타입 변환 자동화 (ex: 문자열 → 날짜)|
|커스텀 에디터 작성|`PropertyEditorSupport` 사용해 변환 로직 구현|
