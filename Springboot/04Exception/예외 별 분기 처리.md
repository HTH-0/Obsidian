#  예외별 분기 처리 + MemoController 흐름 정리

## ✅ 1. 예외별 `@ExceptionHandler` 분기 처리 예시

```java
@ControllerAdvice
@Slf4j
public class GlobalExceptionHandler {

    @ExceptionHandler(FileNotFoundException.class)
    public String handleFileNotFound(FileNotFoundException e, Model model) {
        log.warn("파일 예외: {}", e.getMessage());
        model.addAttribute("ex", e);
        return "global_error";
    }

    @ExceptionHandler(ArithmeticException.class)
    public String handleArithmetic(ArithmeticException e, Model model) {
        log.warn("수학 예외: {}", e.getMessage());
        model.addAttribute("ex", e);
        return "global_error";
    }

    @ExceptionHandler(Exception.class)
    public String handleAll(Exception e, Model model) {
        log.warn("기타 예외: {}", e.getMessage());
        model.addAttribute("ex", e);
        return "global_error";
    }
}
```

|예외 타입|처리 메서드|
|---|---|
|`FileNotFoundException`|파일 관련 문제|
|`ArithmeticException`|수학 계산 오류 (0으로 나누기 등)|
|`Exception`|그 외 예외 전체|

## ✅ 2. MemoController 내 예외 발생 흐름

```java
@Controller
@Slf4j
@RequestMapping("/memo")
public class MemoController {

    @GetMapping("/ex")
    public void ex1_1() throws FileNotFoundException {
        log.info("GET /memo/ex");
        throw new FileNotFoundException("파일이 없습니다.");
    }
}
```

- `/memo/ex` 요청 시 강제로 `FileNotFoundException` 발생
    
- 컨트롤러 자체에 `@ExceptionHandler`가 없기 때문에,  
    `GlobalExceptionHandler`에서 전역 처리됨

## ✅ 3. JSP 연결 흐름

- 예외 발생 → 전역 핸들러 → `model.addAttribute("ex", 예외객체)`  
    → JSP(`global_error.jsp`)에서 `${ex}` 출력
    

---

## 🧾 참고: JSP에서 예외 메시지 외 상세 처리 예

```jsp
<c:if test="${not empty ex}">
    <p>에러 유형: ${ex.class.name}</p>
    <p>메시지: ${ex.message}</p>
</c:if>
```

## 📌 요약

|항목|설명|
|---|---|
|`@ExceptionHandler(특정예외)`|예외 타입별 분기 처리 가능|
|전역 처리 우선|컨트롤러 내에 핸들러가 없으면 전역 처리 적용|
|JSP 출력|`${ex}`, `${ex.message}`, `${ex.class.name}` 등|
