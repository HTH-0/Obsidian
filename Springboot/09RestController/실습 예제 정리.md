# 📡 RestController 실습 예제 정리

## 📦 전체 코드

```java
@RestController
@RequestMapping("/rest01")
public class RestController_01 {

    @GetMapping("/hello")
    public String hello() {
        return "Hello, REST!";
    }

    @GetMapping("/sendVO")
    public MemoDto sendVO() {
        MemoDto dto = new MemoDto();
        dto.setId(100);
        dto.setText("REST연습용 TEXT입니다.");
        return dto;
    }

    @PostMapping("/getVO")
    public String getVO(@RequestBody MemoDto dto) {
        System.out.println("REST에서 전달받은 VO 값 : " + dto.toString());
        return "전송성공!";
    }
}
```

---

## 🔍 코드 분석

### ✅ 클래스 및 어노테이션 설명

- `@RestController`  
    → 이 클래스의 모든 메서드는 **View가 아닌 데이터(JSON)**를 직접 반환함  
    → 내부적으로 `@Controller + @ResponseBody` 결합과 같음
    
- `@RequestMapping("/rest01")`  
    → 전체 경로 prefix 지정: `/rest01`으로 시작하는 요청 처리
    

---

### ✅ 주요 메서드 설명

#### 1. `hello()`

```java
@GetMapping("/hello")
public String hello() { return "Hello, REST!"; }
```

- `/rest01/hello` GET 요청 시
    
- 문자열 "Hello, REST!" 그대로 응답 바디에 반환됨
    

#### 2. `sendVO()`

```java
@GetMapping("/sendVO")
public MemoDto sendVO()
```

- `/rest01/sendVO` GET 요청 시
    
- `MemoDto` 객체를 반환 → **자동으로 JSON 형태로 직렬화됨**
    

**예상 응답**

```json
{
  "id": 100,
  "text": "REST연습용 TEXT입니다."
}
```

#### 3. `getVO()`

```java
@PostMapping("/getVO")
public String getVO(@RequestBody MemoDto dto)
```

- `/rest01/getVO` POST 요청 시, JSON 데이터를 수신
    
- `@RequestBody`가 붙은 `MemoDto`로 역직렬화됨
    
- DTO 내부 값 확인 후 문자열 응답
    

**요청 예시 (Postman 등에서 사용)**:

```json
{
  "id": 1,
  "text": "hello"
}
```

---

## ✅ 관련 DTO: MemoDto

> `MemoDto`는 다음과 같은 구조로 예상됩니다.

```java
public class MemoDto {
    private int id;
    private String text;

    // getter, setter, toString()
}
```

- Jackson이 내부적으로 getter/setter를 사용해 JSON <-> Java 객체 자동 변환
    

---

## ✅ 요청 흐름 요약

|동작|요청 경로|HTTP Method|설명|
|---|---|---|---|
|문자열 반환|`/rest01/hello`|GET|단순 문자열 응답|
|DTO 반환|`/rest01/sendVO`|GET|DTO를 JSON으로 응답|
|DTO 수신|`/rest01/getVO`|POST|JSON 요청 데이터를 MemoDto로 역직렬화|

---

## 📌 요약

- `@RestController`는 데이터(JSON)를 반환하는 API에 특화된 컨트롤러
    
- `@RequestBody`, `@ResponseBody`, `MemoDto`를 함께 사용하여 JSON 통신을 쉽게 구현 가능
    
- `sendVO()`는 서버 → 클라이언트 전송 예시, `getVO()`는 클라이언트 → 서버 전송 예시
    
- Postman이나 React Axios로 테스트하기 용이함
